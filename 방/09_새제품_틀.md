# [새 제품] 차곳간 — 시작 안내문 틀

파킹, 스튜디오, 무브(탁송), 트레이드처럼 새 제품을 시작할 때 쓰는 안내문입니다.
총괄 방이 아래 `○○` 를 채워 `방/1x_○○.md` 로 저장한 뒤, 새 작업방에 붙여 넣습니다.

---

## 너의 역할
너는 **차곳간 ○○** 화면과 기능 담당이야. ○○는 (누가 쓰는지, 무슨 일을 하는지 한 줄).
대표님은 개발 지식이 전혀 없어. 항상 쉬운 말(해요체)로, 바꾸기 전에 시안부터 보여 줘.

## 먼저 읽을 것
1. `CLAUDE.md`, `규칙/00_규칙장부.md`
2. `디자인/` 의 기준틀 — 특히 「새 제품 틀」
3. 참고: `워시/` (기준 제품)

## 고칠 수 있는 서랍
`○○/`

## 하지 말 것
- 새 화면을 처음부터 만들지 않음 → 기준틀의 「새 제품 틀」을 **복사해서** 시작
- 로그인·서버를 직접 만들지 않음 → 서버 방에 요청
- 모바일·앱 전용 화면을 따로 만들지 않음

## 시작 순서
1. 대표님께 ○○ 업체가 하루에 하는 일을 순서대로 여쭤봄 → 그 순서가 탭 순서
2. 기준틀 「새 제품 틀」 복사 → 메뉴·탭 이름만 바꾼 시안을 보여 드림
3. 필요한 자료 저장 창구 목록을 정리해 서버 방에 요청서 보냄
4. 보안이 걸리는 기능이 있으면 보안 방 검토부터

## 제품별 주의
- **무브(탁송)**: 기사 위치 정보 → 만들기 전에 보안 방 설계 검토
- **트레이드(거래)**: 돈이 오감 → 처음 설계부터 보안 방 참여, 결제 연결은 서버 방
- **파킹·스튜디오**: 기준틀에 예시 화면이 있음 (메뉴 이름은 실제 쓰는 말로 대표님 확인)

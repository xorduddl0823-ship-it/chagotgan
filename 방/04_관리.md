# [관리] 차곳간 — 시작 안내문

## 너의 역할
너는 본사 전용 **차곳간 관리(컨트롤센터)** 화면 담당이야. 결제, 계정 권한, 외부 연결(API) 관리 화면이 네 일이야.
대표님은 개발 지식이 전혀 없어. 항상 쉬운 말(해요체)로, 바꾸기 전에 시안부터 보여 줘.

## 먼저 읽을 것
1. `CLAUDE.md`, `규칙/00_규칙장부.md`
2. `관리/인수인계/`
3. `디자인/` 의 기준틀과 J안

## 고칠 수 있는 서랍
`관리/`

## 하지 말 것
- 관리 화면을 통합 입구(사용자 제품 묶음)에 넣지 않음. 관리는 **별채**: 주소(admin), 배포, 로그인 모두 따로
- 서버 창구(hq…)를 직접 만들거나 고치지 않음 → 서버 방에 요청
- 비밀 열쇠 값을 화면에 넣지 않음. 열쇠를 바꾸는 기능이 필요하면 서버 방에 요청 (화면은 이름과 상태만 보여 줌)

## 지금 알고 있는 사실
- 원본 `관제센터_index.html`, 워시 뼈대로 옮긴 `3_차곳간_관리_index.html`(메뉴 17개를 8묶음으로)
- 메뉴 8묶음 배치는 대표님 확인 대기
- 이름을 「관제센터」 → 「관리」로 바꾸는 중 (원본에 7곳 남음)
- 관리는 서버 `wash-api`의 hq 창구만 씀, 로그인은 아이디·비밀번호 + 문자 6자리
- 달력 메모 기능 일부는 서버에 시간·고치기 칸이 없어 빠져 있음

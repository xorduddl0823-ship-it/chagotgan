# [워시] 차곳간 — 시작 안내문

## 너의 역할
너는 **차곳간 워시**(광택·세차, 휠 복원, 판금·도색) 화면과 기능 담당이야. 워시는 모든 제품의 **기준(마스터)** 이라서 특히 조심해서 고쳐야 해.
대표님은 개발 지식이 전혀 없어. 항상 쉬운 말(해요체)로, 바꾸기 전에 시안부터 보여 줘.

## 먼저 읽을 것
1. `CLAUDE.md`, `규칙/00_규칙장부.md`
2. `워시/인수인계/`
3. `디자인/` 의 기준틀과 J안

## 고칠 수 있는 서랍
`워시/`

## 하지 말 것
- 서버 코드(wash-api)를 직접 고치지 않음 → 서버 방에 요청
- 공통 뼈대·스타일을 워시에서만 바꾸지 않음 → 바꿔야 하면 디자인 방에 요청 (워시가 바뀌면 모든 제품이 따라 바뀌어야 하기 때문)
- 탭 순서, 약관 글을 바꾸지 않음
- 모바일·앱 전용 화면을 따로 만들지 않음

## 지금 알고 있는 사실
- 주소 `app.cgg.co.kr`, 파일 `1_차곳간_워시_index.html`
- 휠·리페어는 가입 때 고르는 업종 (wash / wheel / repair)
- 「현장 화면」(홈·입고·출고·오늘·날짜 검색)은 머리말 맨 앞 버튼
- 아직 일부 기능이 구글 시트를 씀 → 서버 방이 수파베이스로 옮기는 중. 화면 쪽은 서버 호출 함수 속만 바꾸면 됨
- 매출 내역, 입·출금 내역, 세금계산서는 **체크 것을 그대로 옮겨** 씀 (입금 안내는 「입금 처리」 카드 안으로)
- 휴지통 위치는 대표님 확인 필요

## 첫 작업
인수인계서와 파일들을 비교해 최신 워시 파일 하나를 정하고, 끝나지 않은 정산 기능 목록을 대표님께 보여 드려. 서버 이사 때문에 기다려야 하는 일은 따로 표시해.

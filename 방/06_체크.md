# [체크] 차곳간 — 시작 안내문

## 너의 역할
너는 **차곳간 체크**(자동차 성능점검 업체용 정산) 화면과 기능 담당이야.
대표님은 개발 지식이 전혀 없어. 항상 쉬운 말(해요체)로, 바꾸기 전에 시안부터 보여 줘.

## 먼저 읽을 것
1. `CLAUDE.md`, `규칙/00_규칙장부.md`
2. `체크/인수인계/`
3. `디자인/` 의 기준틀과 J안

## 고칠 수 있는 서랍
`체크/`

## 하지 말 것
- 서버 코드(check-api)를 직접 고치지 않음 → 서버 방에 요청
- 공통 뼈대·스타일을 체크에서만 바꾸지 않음 → 디자인 방에 요청
- 탭 순서를 바꾸지 않음 (「정산 기록」은 이름도 자리(3번째)도 그대로)
- 모바일·앱 전용 화면을 따로 만들지 않음

## 지금 알고 있는 사실
- 주소 `check.cgg.co.kr`, 파일 `2_차곳간_체크_index.html`
- 서버는 수파베이스만 씀 (표 이름이 `check_` 로 시작)
- 워시와 같은 로그인 표를 씀
- 매출 내역, 입·출금 내역, 팝빌 세금계산서는 체크가 워시보다 앞서 있음 → 워시가 체크 것을 옮겨 감
- 설정에 「수집함 연결 — 구글 Apps Script」 카드가 남아 있음 (구글은 폐기 방침이므로 정리 여부를 대표님께 확인)

## 첫 작업
인수인계서를 읽고 최신 체크 파일을 정한 뒤, 「가온」 업체에만 맞춘 기능이나 문구가 있는지 확인해서 다른 업체도 쓸 수 있게 하려면 무엇을 바꿔야 하는지 대표님께 보고해.

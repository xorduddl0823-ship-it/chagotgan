# 알림톡을 먼저 쓰는 이유 — 솔라피 단가 비교 (2026-10-15, 총괄)

대표님 지시: 「문자 단가와 알림톡 단가가 너무 차이 나니, 알림톡을 모든 사용자 페이지에 적용」 → 규칙 5-6

## 솔라피 건당 단가 (VAT 별도, 월 1만 건 미만 기준)
| 종류 | 건당 | 알림톡과 비교 |
|---|---|---|
| 카카오 알림톡 | **13원** | 기준 |
| 문자 단문 SMS (한글 45자까지) | 18원 | 약 1.4배 |
| 문자 장문 LMS (45자 넘음) | **45원** | **약 3.5배** |
| 사진 문자 MMS | 110원 | 약 8.5배 |

- 알림톡은 월 1만 건이 넘으면 10원, 10만 건이 넘으면 8원으로 더 내려갑니다(최근 3개월 평균).
- 기본료·API 사용료는 없고, **발송에 성공한 건만** 돈이 나갑니다.
- 출처: 솔라피 가격 정책 https://solapi.com/pricing · 구간별 할인표 https://solapi.com/guides/tiered-pricing (단가는 바뀔 수 있음 → 바뀌면 이 표를 고칩니다)

## 우리에게 왜 중요한가
- 차곳간 안내(출고·청구서·입금 확인·기간 종료 등)는 업체명·차량번호·금액·날짜가 들어가 **대부분 45자를 넘는 장문(LMS, 45원)** 입니다.
- 같은 안내를 알림톡(13원)으로 보내면 **건당 32원, 약 70% 줄어듭니다.**
- 예: 한 달에 3,000건이면 문자 약 13만 5천 원 → 알림톡 약 3만 9천 원 (약 9만 6천 원 절약, VAT 별도)

## 규칙 (5-6 요약)
1. 모든 사용자 제품의 안내는 **알림톡 먼저**, 실패하면 솔라피가 **자동으로 문자 대체** (`disableSms: false`)
2. 문자만 보내는 기능을 새로 만들지 않음. 인증번호도 알림톡 템플릿이 있으면 알림톡
3. 템플릿 코드는 **관리 설정 칸**에. 비어 있으면 지금처럼 문자로 → 언제 올려도 안전
4. 알림톡은 **정보성만**: 결제·충전·연장을 권하는 문장·버튼 금지 (반려 사유)
5. 받는 사람이 거래 관계여야 함 (딜러·상사 = 차를 맡긴 사이, 업체 대표 = 차곳간과 계약한 사이)
6. 템플릿 본문과 보내는 글자가 **똑같아야** 함 → 문구를 바꾸려면 템플릿을 다시 심사받아야 함

# 구상: 자유 가입 + 체험판 + 결제 유도 (2026-10-14 대표님 말씀)

상태: **구상 단계 (확정 전)**. 다음 주 시험이 끝난 뒤 시안부터 만든다.

## 대표님 말씀 (그대로)
- 신규회원들이 회원가입은 좀 자유롭게 하되, 결제를 안 한 사람들이 로그인했을 때 베타(시연) 페이지를 주면서 간접 체험하게 만든 페이지를 보여주고 결제를 유도.
- 결제를 안 했을 땐 체험판 화면에서 알람 팝업이 뜨고, 일정 접속 시간이 지나면 강제 로그아웃, 그 아이피로 접속했을 땐 결제 유도.
- 가입 안내 문구는 일반적인 사이트의 표준 안내 문구로.

## 지금 워시에 이미 있는 것 (저장소 wash-api sb1, 워시 v111 기준)
- 가입은 관리 화면 「가입 코드」에 등록된 번호만 가능 (자유 가입 아님)
- 요금제 「무료 체험」(trial): 체험 기한(trial_until), 문자·세금계산서 무료 한도, 기한 끝나면 「보기만」 → 기한 지나면 로그인 막힘
- 화면 위 「요금제 띠」, 설정 → 내 요금제

| 2 | 결제 전 계정은 **체험판 화면**: 예시 자료가 채워진 시연 화면, 실제 저장·문자·세금계산서는 막음 | 워시, 디자인, 서버 |

## 총괄 방 의견 (결정 전 확인할 것)
- **IP로 알아보기는 비추천.** 같은 가게·같은 와이파이를 쓰는 다른 사람도 막히고, 휴대폰은 IP가 자주 바뀌어서 쉽게 피해 갈 수 있음. IP는 개인정보라 수집 안내도 필요.
  → 대신 **가입한 번호(계정) 기준**으로 "체험 시간 다 씀" 기록 + 같은 기기 기록을 함께 쓰는 방식 추천.
- 체험 시간 기준 정하기: 하루 몇 분? 가입 후 며칠? 
- 결제 수단(카드 정기결제 등)과 결제 화면은 아직 없음 → 서버 방이 결제 회사 연결 필요 (보안 검토 대상)
- 자유 가입을 열면 문자 인증 비용이 늘어남 → 하루 가입 시도 횟수 제한 필요

## 순서 (제안)
1. 다음 주 통합 UI 시험 끝내기
2. 대표님이 위 「확인할 것」 답하기
3. 디자인·워시 방: 체험판 화면 + 팝업 시안
4. 서버 방: 자유 가입, 체험 시간 제한, 결제 연결 설계 → 보안 방 검토
5. 대표님 확인 후 반영

## 추가 (2026-10-14 대표님 말씀)
- "신비스러우면서 차곳간을 궁금하게 만들고 계속 들어오게 유도하는 거야."
- 방향: 안내 문구(가입·로그인·오류)는 표준형으로 단정하게, **체험판 화면 연출**은 궁금증을 남기는 쪽으로.

### 총괄 방 아이디어 (시안 때 고를 후보)
| 아이디어 | 화면에서 이렇게 |
|---|---|
| 살짝만 보여 주기 | 매출·정산 숫자가 흐릿하게 가려진 채 보임. 「결제하면 우리 가게 숫자로 열려요」 |
| 하루에 하나씩 열리는 기능 | 체험 1일차 입고 기록, 2일차 정산, 3일차 세금계산서… 「내일 열리는 기능」 미리 보기 |
| 다음 문 미리 보기 | 잠긴 메뉴에 자물쇠와 한 줄 소개만. 누르면 짧은 시연 영상·그림 |
| 남은 시간 표시 | 화면 위에 「오늘 체험 시간 12분 남음」, 끝날 때 「내일 다시 열려요」 → 다시 오게 만들기 |
| 내 업종 맞춤 예시 | 가입 때 고른 업종(세차·휠·판금)에 맞춘 예시 자료로 채워 「내 가게 같다」는 느낌 |
- 주의: 과하게 막거나 속이는 느낌이 들지 않게 (결제 안 해도 무엇이 되는지 분명히)

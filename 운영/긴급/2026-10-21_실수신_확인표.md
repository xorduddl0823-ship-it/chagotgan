# 실수신 확인표 — 대표님 휴대폰으로 알림톡 1통씩 받아 보기 (알림톡 방 · 2026-10-21)

> 운영 반영(워시 서버 sb29 · 체크 서버 v54 · 워시 화면 v143 · 체크 화면 v56.9)이 끝난 **뒤에** 해요.
> 받는 번호는 **대표님 번호 하나**, 업체는 **시험 업체(워시테스트 / TEST 검사소)**만 써요. 실제 고객에게는 안 가요.
> 이 표는 준비만 했어요. 알림 방은 아무것도 보내지 않았고, 설정·템플릿 문구도 바꾸지 않았어요.

## 시작 전에 (1분)
- 관리 › 알림 › 알림톡 템플릿: 맨 위 **«카카오 채널 ID»가 «넣어 둠»**, **입고안내 · 청구서** 줄에 코드(`KA01TP…`)가 있어야 해요. **`check_arrive` 줄은 비워 둬요.**
- 워시테스트는 **이용 기간이 남아 있고 캐시(또는 남은 건수)가 있어야** 보내져요. 막히면 화면에 «이용 기간이 지났습니다» / «충전해야…»가 떠요.

## ① 워시 — «입고 등록» 한 번이면 입고 알림톡 1통
1. 워시테스트로 로그인 → **입고** 화면.
2. 차량번호(예: `12가3456`), **딜러 휴대폰 칸에 대표님 번호**, 딜러 이름 · 상사 · 작업을 **모두 채우고** **«입고 등록»**을 눌러요.
3. 저장되면 바로 입고 알림톡이 나가요(«입고 알림» 자동 · 기본 켜짐). 저장 뒤 뜨는 창에 **«입고 알림톡을 보냈어요»**가 보이면 서버가 넘긴 거예요.
   - 자동이 꺼진 업체면 같은 창의 **«딜러에게 입고 알림톡 보내기»** 단추를 눌러요.

휴대폰 **카카오톡**에 와야 할 글 (승인본 «차곳간_입고안내» · `#{…}` 자리에 값이 들어가요)
```
[차곳간] 차량 입고 안내
#{딜러명}님(#{상사명}), #{업체명}에 차량이 입고되었습니다.

차량번호: #{차량번호}
작업: #{작업내용}
입고시각: #{입고일시}

작업이 끝나면 다시 안내드리겠습니다.
문의: #{업체전화}

본 안내는 #{업체명}의 요청으로 차곳간이 보내드립니다.
```
- 상사 칸을 비우면 `(개인)`으로 나와요. 업체명·업체전화는 서버가 워시테스트 정보로 채워요.
- 버튼 없음.

## ② 체크 — «내 번호로 시험» 한 번이면 청구서 알림톡 1통
1. TEST 검사소 **대표** 계정으로 로그인(대표만 단추가 눌려요) → **월별 청구서 › 2. 청구서 보내기**.
2. 목록에서 청구서 하나를 고르고(차가 있는 달) **«내 번호로 시험»** → **«시험 보내기»**.
3. **지금 로그인한 대표님 휴대폰**으로만 가요. 청구처(딜러)에게는 안 가고 «보냄» 표시도 안 바뀌어요. 화면에 «내 번호로 시험 알림을 보냈어요»가 떠요.
   - 설정 › 우리 검사소의 **검사비 계좌**가 비어 있으면 먼저 넣어요.

휴대폰 **카카오톡**에 와야 할 글 (승인본 «차곳간_청구서»)
```
[차곳간] #{기간} 청구 내역 안내

#{받는곳} 님, #{업체명}에서 #{기간} 작업분 청구 내역을 보내드립니다.

· 작업 대수 : #{건수}대
· 청구 금액 : #{금액}원 (부가세 포함)
· 입금 기한 : #{입금기한}
· 입금 계좌 : #{계좌}

자세한 내역은 아래 버튼에서 확인하실 수 있습니다.
문의 #{업체전화}

본 안내는 #{업체명}의 요청으로 차곳간이 보내드립니다.
```
- 버튼 **«청구 내역 보기»** → `https://app.cgg.co.kr/v.html?c=k…` 를 눌러 청구 내역이 열리는지도 봐요.
- 기간은 «2026년 10월» 모양이에요. 입금 기한을 비우면 «확인 후 입금»으로 나와요.

## ② 알림톡이 아니라 **문자**로 왔다면 — 무엇이 빠졌다는 뜻일까요
문자 앱으로 왔다면 글이 짧은 «대체 문구»예요(예: `[차곳간] 12가3456 입고되었습니다.`). 아래 순서로 봐요.

| 순서 | 의심할 것 | 보는 곳 | 고치는 법 |
|---|---|---|---|
| 1 | **채널 ID가 비어 있음** | 관리 › 알림 › 알림톡 템플릿 맨 위 | 솔라피 › 카카오 › 채널 관리의 채널 ID(`KA01PF…`)를 넣고 «코드 저장» → **1분 뒤** 다시 |
| 2 | **그 줄(입고안내 / 청구서) 템플릿 코드가 비어 있음** | 같은 화면 그 줄 | 솔라피 › 카카오 › 템플릿 관리에서 같은 이름의 코드를 복사해 넣기 → 1분 뒤 |
| 3 | **코드가 다른 템플릿 것**이거나 승인 안 된 것 | 솔라피 템플릿 관리 | 이름이 «차곳간_입고안내» / «차곳간_청구서»이고 상태가 «승인»인 코드인지 확인 |
| 4 | **빈 칸이 있었음** (딜러 이름 · 작업 · 계좌 등) | 입력한 내용 | 빈 칸은 문자로 바뀌거나 알림톡에 «-»로 나올 수 있어요 → 시험 때는 칸을 모두 채워요 |
| 5 | **대표님 휴대폰 쪽** (카톡 미설치 · 차곳간 채널 차단 · 카톡 알림 꺼짐) | 휴대폰 | 위 1~4가 다 맞으면 이 경우예요. 솔라피가 저절로 문자로 대신 보낸 거라 **정상 동작**이에요 |

> 솔라피 메시지 내역에서 그 건의 **종류**가 «알림톡 실패 → 문자 대체»면 5번(또는 3번), 처음부터 «문자»면 1·2·4번이에요.

## ③ «확인 중»이 뜨면 — 솔라피에서 결과 보기
«확인 중» = 솔라피에 넘기는 중에 응답이 끊겨 **갔는지 안 갔는지 아직 모름**이에요. 실패가 아니에요. **다시 누르지 말고** 먼저 확인해요(두 번 갈 수 있어요).
1. 컴퓨터로 **https://console.solapi.com** 로그인.
2. 왼쪽 메뉴 **«메시지» › «발송 내역»**(화면에 따라 «메시지 로그»)을 열어요.
3. **받는 번호 = 대표님 번호**, 시간 = 방금 보낸 때로 찾아요.
4. 상태를 봐요:
   - **«성공» + 종류 «알림톡»** → 카톡으로 도착 = **실수신 확인됨** ✅
   - **«성공» + 종류 «문자(SMS/LMS)»** → 문자로 대신 도착 → 위 ② 표로
   - **«실패»** → 실패 까닭(코드)을 사진 찍어 총괄 방에 보내 주세요
   - **목록에 없음** → 솔라피에 안 넘어간 거예요 → 그때만 화면에서 한 번 다시 보내요

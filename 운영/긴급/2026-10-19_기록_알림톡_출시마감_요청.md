# [최우선] 내일부터 쓸 체크·워시의 «기록 저장»과 «알림톡» 마감 (대표님 지시 10/19)

함께 진행: 중복 사업자번호 출시 필수 4가지(`운영/긴급/` 기존 요청 · 범위 확정분). 이 두 일이 이번 작업의 전부예요.
**제외**: 디자인 개편 · 통합 로그인 개편 · 추가 기능(앱 안 가입 화면 개편 포함 — 보류).

## 1. 기록 (워시·체크)
- 등록·수정 뒤 새로고침·다시 로그인해도 그대로 남음
- 연속 클릭·재시도로 같은 기록이 두 번 생기지 않음(화면 막기 + 서버 멱등 키/유일 제약)
- 저장이 실패하면 «저장됨»으로 보이지 않음(실패 문구 + 다시 하기)
- 다른 업체 기록 조회·수정 차단(서버가 로그인 열쇠의 업체로만 판단)

## 2. 알림톡
- 실제로 쓸 알림 종류 목록과 승인된 템플릿 ID 표(이름 · 서버 키 · 템플릿 ID · 받는 사람 · 버튼 링크) — ID 값은 관리 설정 칸에 있는 것을 «있음/없음»과 앞 몇 자리만
- 받는 사람 · 차량 · 업체 · 금액 · 사진/기록 링크가 정확함(변수 이름 · 값 출처 표 + 시험)
- 기록 저장이 성공한 뒤에 보냄. 보내기가 실패해도 기록은 사라지지 않음
- 중복 발송 방지(같은 일 같은 받는 사람 한 번) · 실패 까닭 · 다시 보내기 · 결과 기록(cgg_sendlog 등) 확인
- 문자 대체 발송 조건(알림톡 실패 시 솔라피 자동 대체 등)과 비용(알림톡 13원 · 단문 18원 · 장문 45원, VAT 별도) 명시

## 3. 제출물 (한 번에 · `운영/긴급/챗지피티_검증_기록_알림톡/`)
- 최신 체크·워시 화면 코드와 서버 코드(바뀐 줄 diff + 커밋)
- 필요한 DB 변경 파일과 적용/미적용 상태
- 비밀키 없는 환경변수 예시(이름만, 값은 «여기에»)
- 격리된 시험 환경 실행 방법과 시험 결과(실행 수 · 통과 · 실패 · 건너뜀)
- 내일 쓸 기능별 «가능 / 차단 / 미확인» 표

## 금지
- 실제 고객에게 발송 금지. 운영 자료 변경·배포 금지.
- 실수신 발송 검사는 지정된 시험 번호로만, 대표님 별도 승인 뒤.
- 항목별로 따로 보고하지 않음. 고치고 시험한 뒤 한 번에 제출. 진행을 막는 결정만 모아서 질문.

| 방 | 맡는 것 |
|---|---|
| 서버 | wash-api · check-api 저장 멱등·유일 제약·업체 소속 확인 · 알림톡 보내기 순서(저장 뒤)·중복 방지·발송 기록·대체 문자 조건 · DB 변경 · 환경변수 예시 · 시험 환경 |

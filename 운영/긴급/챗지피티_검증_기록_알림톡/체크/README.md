2. **겹침 막기**: 같은 창구 · 같은 내용이 처리 중이면 새로 보내지 않고 처음 것의 답을 같이 받아요. 화면 단추는 저장이 끝날 때까지 잠그고, 확인 창 단추는 0.8초 안에 두 번 누르면 무시해요.
3. **실패 표시**: 실패하면 «저장했어요»가 아니라 빨간 글과 «다시 하기» 단추가 나와요(처음 누른 단추를 다시 눌러 줘요). 배달 상세 창처럼 창이 열려 있으면 그 창 안에도 빨간 글이 나와요(예전에는 창 뒤 맨 위에 떠서 안 보였어요).
4. **조용히 넘기던 저장**: 검사자 수수료(feeRules)가 저장에 실패해도 아무 말이 없던 것을 빨간 글로 알려요. 안내 글 «이 PC에 적어 뒀어요… 다음 서버 판부터»는 지금 맞는 말로 바꿨어요.

## 2. 서버 방에 바라는 것 (이름 맞추기 · 서버 방 확인 전)
- 몸통 칸 이름은 `rid`(24자 · 영문 소문자 + 숫자)이고, 쓰기 창구에만 와요. 지금 check-api는 모르는 칸을 무시해서, 화면을 먼저 올려도 해가 없어요.
- 서버가 해 줄 것(제안): (업체, fn, rid)를 24시간 동안 유일하게 저장해요. 같은 rid가 다시 오면 다시 하지 말고 처음 답을 그대로 줘요. 처음 것이 아직 처리 중이면 «처리 중이에요. 잠시 뒤 다시 확인해 주세요.»라고 답해요.
- 알림 보내기 창구(billSend · billBundleSend · remindSend · deliv_resend · deliv_arrive)는 같은 rid로 두 번 나가지 않게 해 주세요.
- **서버가 이 약속을 하기 전에는** «연결이 끊겼다가 다시 하기»에서 두 번 생길 수 있어요. 화면의 겹침 막기와 단추 잠금만으로 막을 수 있는 것은 «연속 클릭»까지예요(아래 표에서 «미확인»).

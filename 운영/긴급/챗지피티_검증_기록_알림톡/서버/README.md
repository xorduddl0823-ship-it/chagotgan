## 2. 알림톡 방 확인 4가지에 대한 답
1. **체크 청구서 `#{금액}` = `total_amount` — 부가세 포함이에요.** 줄 금액은 «단가 × 1.1»(검사소 부가세율)이거나 부가세 포함 «추가 금액»이에요. 합계는 그 줄들의 합이에요(v53 807~808줄).
2. **워시 `cash_done` `#{금액}` = 공급가 — 맞아요(의도).** 카드로 낸 돈 중 캐시로 들어가는 금액(공급가)이고, 부가세는 따로예요.
3. **체크 빈 값 → v53에서 고쳤어요.** `ataSend`와 도착 알림 모두 빈 값(«-»)이 있으면 알림톡 대신 대체 문구 문자로 보내요.
4. **밀린 달 버튼 — 가능해요.** 기준 청구서 보기 화면에 `unpaid`(달 · 청구 · 받음 · 남음 · 그 달 보기)가 함께 나와요(체크 v51 · 워시 sb26/sb27). 화면 표시는 체크·워시 방 몫이에요.

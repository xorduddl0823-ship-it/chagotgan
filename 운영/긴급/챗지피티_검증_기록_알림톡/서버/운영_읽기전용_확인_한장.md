# 운영 «읽기 전용» 확인 한 장 (대표님용 · 바뀌는 것 없음)

> 이 세 가지를 보면 «미확인»이 «확인됨»으로 바뀌어요. 아무것도 고치지 않아요. 결과 사진은 총괄 방에 보내 주세요.

## 1단계 — SQL 두 장(읽기만)
1. Supabase › SQL Editor 에 `서버/sql/27_운영상태_확인_읽기만.sql` 전체를 붙여 넣고 Run → 표를 사진으로.
   - 이 표로 보는 것: 같은 번호 막기 색인 · 잠금(트리거) · 행 보안(RLS) · 사진 보관함 공개 여부 · 새 표가 있는지.
2. 같은 곳에 `서버/sql/23_중복사업자번호_확인_읽기만.sql` 전체를 Run → 표를 사진으로(겹친 두 업체 관계 · 가려서 나와요).

## 2단계 — 화면 두 곳(사진만)
1. Supabase › Edge Functions › **Secrets(비밀값)** 목록에서 `ALLOW_LEGACY_KEY` 라는 **이름이 있는지만** 봐요(값은 열지도 적지도 않아요).
   - 없으면 «꺼짐»(정상)이에요. 있으면 «있음» 한 줄만 알려 주세요.
2. 지금 올라가 있는 서버 판: 워시 관리 화면 머리말(sb…)과 체크 화면 머리말(check-api v…)을 사진으로.

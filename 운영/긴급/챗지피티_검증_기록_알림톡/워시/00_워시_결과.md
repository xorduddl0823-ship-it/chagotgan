## 2. 서버 멱등 키 (서버 방과 맞출 이름)
| 무엇 | 키 | 서버가 할 일 |
|---|---|---|
| 기록 저장(apiSet · apiSetMany) | 업체 + 종류(col) + **기록 id** | 이미 `wash_write` 가 이 셋으로 덮어쓰기(upsert) — 같은 id 는 한 건. **유일 제약이 DB 에 실제로 걸려 있는지 확인 부탁** |
| 보내기(sendMsg) | **`sendKey`** (보낸 기록 id · `ob_…`) | 같은 업체 · 같은 sendKey 가 이미 «보냄»이면 다시 보내지 말고 그 결과를 돌려주기. 실패였으면 다시 보내기 허용. 알림톡 실패 뒤 화면이 문자로 다시 보낼 때도 **같은 sendKey** 가 가요(이것은 허용해야 해요). 서버가 아직 모르는 칸이면 무시돼서 지금 동작은 그대로 |

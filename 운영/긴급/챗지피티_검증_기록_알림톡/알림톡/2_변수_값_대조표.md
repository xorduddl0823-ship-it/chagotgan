# 2. 변수 → 값 대조표 (워시 sb27 · 체크 v52 · 알림톡 방 · 2026-10-19)

> 서버 코드에서 직접 찾은 값이에요. «화면»은 워시 화면이 `sendMsg` 로 넘기는 값, «서버»는 서버가 덮어쓰거나 만드는 값이에요.
> 워시: 화면이 넘긴 `#{업체명}`·`#{업체전화}`·`#{보기코드}`·`#{접속주소}`는 **버리고 서버 값으로**(`ataServerVars`). 빠진 변수가 하나라도 있으면 알림톡 대신 대체 문자(`noticeAta` · `sendMsg`).
> 체크: 빠진 값은 «-»로 채워 **알림톡 그대로** 보내요(워시와 다름 — 아래 ⚠ 3).

## 공통 (받는 사람 · 업체)

## ✅ 서버 방 답 (10/19 · 자세한 것: `운영/긴급/챗지피티_검증_기록_알림톡/서버/README.md` §2)
1. 체크 청구서 `total_amount` = **부가세 포함 맞음** (줄 금액 = 단가 × (1+부가세율) 또는 부가세 포함 추가 금액의 합).
2. 카드 충전 완료 금액 = 공급가 → **의도 맞음** (캐시로 들어가는 금액).
3. 체크 빈 값 → **check-api v53에서 고침**: 빈 값(«-»)이 하나라도 있으면 알림톡 대신 대체 문구 문자(워시와 같음). 운영은 v53을 올린 뒤부터.
4. 밀린 달 버튼 → 보기 화면 답에 함께 청구된 달(달·청구·받음·남음·그 달 보기)이 옴(체크 v51 · 워시 sb26/27). 화면 표시는 체크·워시 방 몫.

## (처음 보낸) 확인할 곳
1. **체크 청구서 금액 = `inv.total_amount`** — 승인 본문은 «청구 금액 : #{금액}원 (부가세 포함)». `total_amount`가 부가세 포함 금액인지 확인 필요.
2. **카드 충전 완료 금액 = 공급가**(부가세 뺀 값) — 본문 «충전금액»이 캐시로 들어간 금액이면 맞음. 카드로 낸 돈(부가세 포함)과 달라 보일 수 있어요(설계 의도 확인).
3. **체크는 빈 값을 «-»로 알림톡 발송**, 워시는 빈 값이 있으면 문자로. 받는 사람에게 «-님» 같은 글이 갈 수 있어요(예: 딜러명 없음). 워시처럼 맞추길 권해요.
4. **밀린 달 청구서**: 버튼(기준 청구서 1개)이 함께 청구된 달까지 보여 주는지 — 10/18 서버 방에 전함.
5. 시험: 실제 발송 없이 변수 값만 확인하려면 «시험 보내기»(체크 `test` → 로그인한 사람 번호)를 **지정 시험 번호로 · 대표님 승인 뒤**에만.

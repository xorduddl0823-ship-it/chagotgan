# 3. 문자 대체 조건 · 비용 표 (워시 sb27 · 체크 v52 · 알림톡 방 · 2026-10-19)

## 언제 문자로 가나요
| # | 상황 | 누가 문자로 바꾸나 | 어떤 글 |
|---|---|---|---|
| 1 | 관리에 **템플릿 코드나 채널 ID가 없음** | 서버 (처음부터 문자) | 대체 문구 (sb25부터 «안 나감» 없음 · 체크 배달 도착은 검사소 도착 문자) |
| 2 | **변수 값이 비어 있음** | 서버가 문자 (워시 · 체크 v53부터 같음 — v52까지 체크는 «-»로 채워 알림톡) | 대체 문구 |
| 3 | 솔라피가 요청을 **받지 않음**(`failedMessageList` · 템플릿·변수 불일치 등) 또는 요청 오류 | 서버가 바로 문자 | 대체 문구 |
| 4 | 솔라피는 받았지만 **카카오 전달 실패**(카톡 없음 · 채널 차단 · 휴대폰 꺼짐 등) | **솔라피가 자동**(`disableSms: false`) | 서버가 같이 넘긴 대체 문구(`text`) |
| 5 | 받는 번호가 없거나 10자리 미만 | 보내지 않음 (발송 기록에 «받는 번호가 없어 보내지 않음») | — |
| 6 | 체크: 보내는 번호(검사소 `sms_from` · `SMS_FROM`)가 둘 다 없음 | 보내지 않음 («보내는 번호 없음» 돌려줌) | — |

- 3번과 4번은 **겹치지 않아요**: 3번은 솔라피가 접수하지 않은 경우라 솔라피 대체가 없고, 서버가 한 번만 문자로 보내요. 4번은 서버가 다시 보내지 않아요 → **두 번 가지 않음**.
- 대체 문구는 `알림톡/12_전체_점검표.md` ⑦ 확정표와 같아요(sb25·v50부터 반영).

## 비용 (대표님 기준 단가 · VAT 별도)
| 종류 | 단가 | 언제 |
|---|---|---|
| 알림톡 | 13원 | 카톡으로 도착했을 때 |
| 단문 문자(SMS · 90바이트 = 한글 약 45자) | 18원 | 대체 문구가 90바이트 안 |
| 장문 문자(LMS) | 45원 | 90바이트 넘음 — 솔라피가 저절로 장문 |
| 사진 문자(MMS) | 대표님 솔라피 요금표 확인 필요 | 체크 배달 도착 문자에 사진 붙이기가 켜졌을 때 |

**실패하면 돈이 나가나요?** 솔라피는 **전달에 성공한 것만** 받아요(실패 건은 차감 뒤 돌려줌). 알림톡이 실패하고 문자가 대신 가면 **문자 값만** 나가요(알림톡 13원 + 문자가 아니라 문자 값 하나). → 대표님 솔라피 «요금/정산» 화면에서 한 번 확인 필요.

- 보내기 결과 줄: `unsure:true` 또는 `state:"확인 중"` 또는 `why`가 «확인 중»으로 시작
- 배달 다시 보내기: `{ok, bad, unsure}`의 `unsure` 수
- 기사 앱 도착 · 배달 기록: `발송결과:"확인 중"`
- 다시 보낸 같은 일의 앞 것이 확인 중: `__err`가 «확인 중»으로 시작(+ `__unsure:true`)
- 보낸 기록 줄 상태: `status:"확인 중"`

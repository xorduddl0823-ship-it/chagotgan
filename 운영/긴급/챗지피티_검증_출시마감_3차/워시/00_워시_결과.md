## 2. 서버 방에 알릴 것
- 화면이 알아듣는 «결과 불명» 모양: `__err` 에 «처리 중이에요» 또는 «확인 중» · 또는 결과 `{ok:false, unknown:true}` / `status:"unknown"`. 다른 모양이면 알려 주세요(한 줄 고침).
- 알림톡 → 문자 대체는 **화면도 같은 rid 로 한 번 더 부를 수 있어요**(서버가 «템플릿 ID 없음» 등 ok:false 로 답할 때). 서버가 ok:false 답을 rid 로 기억하면 문자가 안 나가고 «실패»로 보여요(두 번 가지는 않음). 서버가 대체를 직접 하면 화면은 ok 만 받아요.
- 보안 조건(보안 방): 서버는 «업체 + 사람 + fn + rid»로 찾음 — sb28 그대로.

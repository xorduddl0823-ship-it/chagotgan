| done 업데이트 오류를 보지 않음 | 끝낼 때 `state='run' and at=<내 표시>` 조건으로 바꾸고 바뀐 줄 수를 확인해요. 실패하면 보내기는 «확인 중»이에요. |

| 5분 뒤 지우기 · catch 지우기 → 자동 재발송 | 줄을 지우지 않아요. 보내기의 `run`/`unknown` 줄은 같은 rid로 다시 와도 보내지 않고 «확인 중이에요 — 보낸 기록에서 확인해 주세요. 자동으로 다시 보내지 않아요.»(`__checking:true`)로 답해요. |

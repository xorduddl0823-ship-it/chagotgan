## 알아 둘 것
- **«확인 중»**은 문자 업체가 받았는지 모르는 상태예요. 자동으로 다시 보내지 않아요.
  - «보낸 기록»에서 갔는지 보고, 안 갔으면 화면에서 «다시 보내기»(새 rid)를 눌러요.
- 접수(문자 업체가 받음)와 휴대폰 수신은 달라요. ⑥에서는 **휴대폰에 실제로 온 것**으로 판정해요.
- 체크 재검사 «매일 자동»은 check_remind 템플릿 코드가 등록되기 전까지 서버(v54)가 막아요(저장 거절 · 이미 켜진 것도 0건 · 손으로 보내기는 됨). 승인 상태는 알림톡 방 표를 봐요.
- 중복 정리(SQL 25)는 이 순서에 들어 있지 않아요. 대표님이 업체별로 승인한 뒤에 따로 해요.

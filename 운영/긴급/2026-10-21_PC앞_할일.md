# PC 앞에서 할 일 — 체크·워시 실사용 마감 (10/21)

파일은 모두 이 폴더에 번호 순서대로 있어요. 번호대로만 하면 돼요.
한 단계가 끝날 때마다 **사진을 총괄 방에 보내 주세요.** 이상하면 바로 멈추고 사진만 보내요.
걸리는 시간: 모두 합쳐 약 40분 (체크 화면은 검사장 쉬는 시간에).

금지: 고객에게 한꺼번에 보내기 · 기존 자료 지우기·합치기 · 체크 재검사 «매일 자동» 켜기.

---

## 가. 보기만 하는 확인 (5분 · 바뀌는 것 없음)

**1단계 — 지금 상태 보기**
1. https://supabase.com/dashboard 를 열고 차곳간 프로젝트를 눌러요.
2. 왼쪽 메뉴에서 SQL Editor 를 눌러요 → New query 를 눌러요.
3. `1_상태확인_SQL27.sql` 파일을 메모장으로 열어 전체를 복사해 붙여 넣어요.
4. Run 을 눌러요 → 아래 나온 표를 사진 찍어요(길면 2~3장).

**2단계 — 겹친 사업자번호 보기**
1. New query 를 눌러요.
2. `2_겹침확인_SQL23.sql` 전체를 붙여 넣고 Run → 사진.

**3단계 — 레거시 열쇠 이름 보기**
1. 왼쪽 메뉴 Edge Functions → Secrets 를 눌러요.
2. 목록에 **ALLOW_LEGACY_KEY** 라는 «이름»이 있는지만 봐요. 값은 누르지도 적지도 않아요.
3. «있음 / 없음»만 총괄 방에 알려 주세요.

**4단계 — 백업 날짜 보기**
- 왼쪽 메뉴 Database → Backups 를 눌러요 → 맨 위 날짜가 오늘인지 사진.

➡ **여기서 1~4 사진을 총괄 방에 보내고 «계속» 답을 기다려요.** (몇 분 안에 답해요)

**5단계 — 급한 고침(사업자번호 잠금)** `3_급한고침_사업자번호_잠금.sql`

## 마. 시험 업체로 확인 (10분 · 대표님 번호로만)

**자세한 단추 위치·와야 할 글 모양은 `10_알림1통_받아보기_확인표.md`를 보세요.** (워시 = 입고 화면 «입고 등록», 체크 = 월별 청구서 › 청구서 보내기 › «내 번호로 시험»)

워시(워시테스트)와 체크(TEST 검사소)에서 각각:
1. 기록 하나 저장 → 로그아웃 → 다시 로그인 → 그대로 있으면 ✅
2. 대표님 번호로 알림 1번 보내기 → 휴대폰에 온 문자 사진(받는 사람·차량·금액·링크 확인)
3. 같은 일을 바로 한 번 더 누르기 → 두 번째 문자가 안 오면 ✅
   («다시 보내기» 단추는 일부러 새로 보내는 것이라 이 시험이 아니에요.)

사진을 보내 주시면 총괄 방이 **워시 — 사용 가능/불가 · 체크 — 사용 가능/불가**로 바로 정리해요.

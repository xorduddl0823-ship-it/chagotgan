# PC 앞에서 할 일 — 체크·워시 실사용 마감 (10/21)

파일은 모두 이 폴더에 번호 순서대로 있어요. 번호대로만 하면 돼요.
한 단계가 끝날 때마다 **사진을 총괄 방에 보내 주세요.** 이상하면 바로 멈추고 사진만 보내요.
걸리는 시간: 모두 합쳐 약 40분 (체크 화면은 검사장 쉬는 시간에).

금지: 고객에게 한꺼번에 보내기 · 기존 자료 지우기·합치기 · 체크 재검사 «매일 자동» 켜기.

## 가. 보기만 하는 확인 (5분 · 바뀌는 것 없음)

**1단계 — 지금 상태 보기**
1. https://supabase.com/dashboard 를 열고 차곳간 프로젝트를 눌러요.
2. 왼쪽 메뉴에서 SQL Editor 를 눌러요 → New query 를 눌러요.
3. `1_상태확인_SQL27.sql` 파일을 메모장으로 열어 전체를 복사해 붙여 넣어요.
4. Run 을 눌러요 → 아래 나온 표를 사진 찍어요(길면 2~3장).

**2단계 — 겹친 사업자번호 보기**
1. New query 를 눌러요.
2. `2_겹침확인_SQL23.sql` 전체를 붙여 넣고 Run → 사진.

**3단계 — 레거시 열쇠 이름 보기**
1. 왼쪽 메뉴 Edge Functions → Secrets 를 눌러요.
2. 목록에 **ALLOW_LEGACY_KEY** 라는 «이름»이 있는지만 봐요. 값은 누르지도 적지도 않아요.
3. «있음 / 없음»만 총괄 방에 알려 주세요.

**4단계 — 백업 날짜 보기**
- 왼쪽 메뉴 Database → Backups 를 눌러요 → 맨 위 날짜가 오늘인지 사진.

➡ **여기서 1~4 사진을 총괄 방에 보내고 «계속» 답을 기다려요.** (몇 분 안에 답해요)

## 마. 실제 업체에서 확인 (대표님 10/21: 워시 = 브라더광택 정대봉 대표, 체크 = 가온진단평가)

대표님이 가~라를 끝내고 «올렸어요»를 알리면, 두 곳에 아래 글을 보내 확인을 부탁해요. 받는 번호는 **확인하는 분 본인 휴대폰 하나**뿐이에요(손님·딜러에게는 안 가게).

**워시 — 브라더광택 (정대봉 대표님)**
1. app.cgg.co.kr 새로고침(Ctrl+Shift+R 또는 앱 껐다 켜기) → 왼쪽 위 «v143.1».
2. 입고 화면 → 차량번호 `00테0000`(시험용), **딜러 휴대폰 칸에 정대봉 대표님 본인 번호**, 딜러 이름·상사·작업 **빈칸 없이** → «입고 등록»을 **빠르게 두 번** 눌러요.
3. 확인: 입고 목록에 **한 건만** 생김 · 카카오톡에 입고 안내 **1통만** 옴(이름·차량번호·작업·업체 전화 맞는지 사진).
4. 로그아웃 → 다시 로그인 → `00테0000`이 그대로 있음.
5. 끝나면 `00테0000`은 화면에서 지워도 돼요(시험으로 만든 것만). 알림톡 1건 값이 빠져요.

**체크 — 가온진단평가 (대표 계정)**
1. check.cgg.co.kr 새로고침 → 왼쪽 위 «체크 v56.9».
2. 월별 청구서 › 2. 청구서 보내기 → 청구서 하나 고르고 «내 번호로 시험» → «시험 보내기». (로그인한 대표 휴대폰으로만 가요. 딜러에게는 안 가요.)
3. 확인: 카카오톡에 청구서 알림 **1통** · 금액·링크 열림 사진.
4. 아무 기록(예: 메모 한 줄)을 저장 → 로그아웃 → 다시 로그인 → 그대로 있음.
5. 재검사 «매일 자동»은 켜지 마세요(잠겨 있으면 정상).

**«확인 중»이 뜨면 다시 누르지 말고** 총괄 방에 사진만 보내요(솔라피 기록으로 확인).

사진을 받으면 총괄 방이 **워시 — 사용 가능/불가 · 체크 — 사용 가능/불가**로 바로 정리해요.

# 차곳간 새 판 올리기 — 처음부터 천천히 (11/1)

## 이게 뭐예요?
지금 쓰는 체크·워시를 **새 판**으로 바꾸는 일이에요. 새 판은 이렇게 좋아져요.
- 단추를 두 번 눌러도 한 번만 저장되고, 문자도 두 번 가지 않아요.
- 저장이 안 됐는데 «저장됐어요»라고 잘못 보이는 일이 없어요.
- 같은 사업자번호로 두 번 가입하는 걸 막아요.
- 관리 화면에서 겹친 사업자번호를 승인·거절할 수 있고, 2쪽 [환불] 단추도 눌려요.

## 언제 하나요?
- **PC 앞에서**, 시간이 **1시간쯤** 있을 때 해요.
- 체크는 가온진단평가가 쓰는 중이라, **검사장이 일하지 않는 시간(저녁·쉬는 날)**에 하면 가장 안전해요.
- 오늘 청구서를 쓰실 거면 **청구서를 먼저 다 쓰고** 나중에 해요.

## 순서 (크게 다섯 덩어리)
| 덩어리 | 하는 일 | 시간 | 바뀌는 것 |
|---|---|---|---|
| 가 | 지금 상태 **보기만** | 5분 | 없음 |
| 나 | 데이터 규칙 넣기 (01~05 순서대로) | 10분 | DB 규칙 |
| 다 | 서버 2개 바꾸기 (06·07) | 5분 | 서버 |
| 라 | 화면 바꾸기 (08~11) | 15분 | 화면 |
| 마 | 실제로 알림 1통 받아 보기 | 10분 | 없음 |

**한 덩어리가 끝날 때마다 사진을 총괄 방에 보내 주세요.** 제가 «계속»이라고 하면 다음으로 가요. 이상하면 멈추고 사진만 보내요.

절대 하지 않는 것: 고객에게 한꺼번에 보내기 · 기존 자료 지우기 · 체크 재검사 «매일 자동» 켜기 · 관리 화면에서 사업자번호 «승인»「거절» 누르기(나중에 같이 해요).

## 가. 지금 상태 보기 (바뀌는 것 없음)

**1단계 — Supabase 열기**
1. 인터넷 창에서 https://supabase.com/dashboard 를 열어요.
2. 차곳간 프로젝트를 눌러요.

**2단계 — 01번 파일 붙여 넣기**
1. 왼쪽 메뉴에서 **SQL Editor** 를 눌러요.
2. 위쪽의 **New query** (또는 + 모양)를 눌러요. 빈 칸이 생겨요.
3. 이 폴더의 `01_상태보기.sql` 을 **메모장**으로 열어요. (파일에 마우스 오른쪽 → 연결 프로그램 → 메모장)
4. 메모장에서 Ctrl+A (전부 고르기) → Ctrl+C (복사).
5. Supabase 빈 칸을 한 번 누르고 Ctrl+V (붙여 넣기).
6. 오른쪽 아래 **Run** 을 눌러요.
7. 아래에 표가 나와요. **사진** 찍어요(길면 2~3장).

**3단계 — 02번 파일**
- 다시 **New query** → `02_겹친번호보기.sql` 을 같은 방법으로 붙여 넣고 **Run** → **사진**.

**4단계 — 열쇠 이름 보기**
1. 왼쪽 메뉴 **Edge Functions** → **Secrets** 를 눌러요.
2. 목록에 **ALLOW_LEGACY_KEY** 라는 **이름**이 있는지만 봐요. (값은 누르지도, 적지도 않아요)
3. «있음» 또는 «없음»만 알려 주세요.

**5단계 — 백업 날짜 보기**
- 왼쪽 메뉴 **Database** → **Backups** → 맨 위 날짜가 오늘(또는 어제)인지 **사진**.

➡ **여기까지 사진을 총괄 방에 보내고 «계속»을 기다려요.**

## 나. 데이터 규칙 넣기 (꼭 01→05 번호 순서)
방법은 2단계와 똑같아요: **New query → 파일 붙여 넣기 → Run → 맨 아래 표 사진**.

- **6단계**: `03_사업자번호_잠금.sql` → Run → 사진 («같은 번호 정리 필요» 줄이 나와도 괜찮아요)
- **7단계**: `04_같은번호_막기.sql` → Run → 사진 (겹친 두 업체는 지우지 않고 «승인 대기»로만 빠져요. 영업은 그대로예요)
- **8단계**: `05_한번만_처리.sql` → Run → 맨 아래 표가 «있음 · 있음 · 켜짐»인지 사진

➡ 사진 보내고 «계속» 기다려요.

## 라. 화면 바꾸기
zip 파일은 **압축을 풀지 말고** 그대로 끌어다 놓아요.

**11단계 — 워시 화면** `08_워시화면_v143.1.zip`
1. https://dash.cloudflare.com 열기 → 왼쪽 **Workers & Pages**.
2. **app.cgg.co.kr 이 연결된 칸**을 눌러요.
3. 파일 올리기(Upload) 화면에 zip을 끌어다 놓기 → **Deploy**.
4. https://app.cgg.co.kr 를 열고 Ctrl+Shift+R → 왼쪽 위 «v143.1» **사진**.

**12단계 — 시험 주소 먼저** `09_시험주소_묶음.zip`
1. Workers & Pages → **bold-water-9ce8** → Deployments → Upload → zip 놓기 → **Deploy**.
2. https://t.cgg.co.kr 열기 → «체크 v56.9»가 보이면 OK.

**13단계 — 체크 정식** `10_체크화면_v56.9.zip` (검사장이 일 안 할 때)
1. Workers & Pages → **check.cgg.co.kr 이 연결된 칸** → Upload → zip 놓기 → **Deploy**.
2. https://check.cgg.co.kr → Ctrl+Shift+R → «체크 v56.9» **사진**.
3. https://check.cgg.co.kr/driver/ → «v31» **사진**.

**14단계 — 관리 화면** `11_관리화면_v4.9.4.zip`
1. Workers & Pages → **chagotgan-admin** → Upload → zip 놓기 → **Deploy**.
2. 관리 화면 새로고침 → «v4.9.4» **사진**.
3. 업체 메뉴에 «사업자번호 승인 요청»이 보이고, 겹친 두 업체가 «대기»로 보이면 정상이에요. **승인·거절은 누르지 마세요.**
4. «문자·알림톡 보내는 업체» 칸에 «지원하지 않는 기능»이 떠도 정상이에요.

➡ 사진 보내 주세요.

## 마. 실제로 알림 1통 받아 보기
자세한 단추 위치와 와야 할 글 모양은 `12_알림_받아보기_확인표.md` 에 있어요.

**워시 — 브라더광택 (정대봉 대표님께 부탁)**
1. 입고 화면 → 차량번호 `00테0000`, 딜러 휴대폰 칸에 **정대봉 대표님 본인 번호**, 딜러 이름·상사·작업 **빈칸 없이** → «입고 등록»을 빠르게 두 번.
2. 목록에 **한 건만**, 카카오톡도 **1통만** 오면 OK → 사진.
3. 로그아웃 → 다시 로그인 → 그대로 있으면 OK. 끝나면 `00테0000`은 지워도 돼요.

**체크 — 가온진단평가 (대표 계정)**
1. 월별 청구서 › 청구서 보내기 → 하나 고르고 «내 번호로 시험» → «시험 보내기».
2. 로그인한 분 휴대폰에 카카오톡 **1통** → 금액·링크 사진.
3. 메모 한 줄 저장 → 로그아웃 → 다시 로그인 → 그대로 있으면 OK.

**«확인 중»이 뜨면 다시 누르지 말고** 사진만 보내요.

사진을 받으면 제가 **«워시 — 사용 가능/불가 · 체크 — 사용 가능/불가»** 로 알려 드려요.

- 데이터 규칙(나)은 되돌리기 전에 **꼭 총괄 방에 먼저** 알려 주세요(순서가 있어요).

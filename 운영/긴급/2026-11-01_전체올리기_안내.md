## 언제 · 얼마나
- PC 앞에서 **1시간 반쯤**. 체크(09)는 가온진단평가가 **일하지 않는 시간**에 올려요.
- 한 덩어리가 끝날 때마다 **사진을 총괄 방에 보내 주세요.** 제가 «계속»이라고 하면 다음으로 가요.

## 절대 하지 않는 것
고객에게 한꺼번에 보내기 · 기존 자료 지우기 · 체크 재검사 «매일 자동» 켜기 · 관리 화면 «사업자번호 승인·거절» 누르기(나중에 같이 해요).

## 공통 방법 두 가지 (여러 번 나와요)
- **[SQL 붙이기]** Supabase → 왼쪽 **SQL Editor** → 위 **+**(새 쿼리) → 파일을 **메모장**으로 열어 Ctrl+A, Ctrl+C → Supabase 빈 칸에 Ctrl+V → **Run** → 아래 표 **사진**.
- **[zip 올리기]** https://dash.cloudflare.com → 왼쪽 **Workers & Pages** → 칸 누르기 → 파일 올리기(Upload / Create deployment) → zip을 **압축 풀지 말고** 끌어다 놓기 → **Deploy** → 그 주소에서 **Ctrl+Shift+R** → 판 번호 **사진**.

## 마. 메인 홈페이지 (옛 판 백업 먼저 · 15분)
**14. 올라가 있는 칸 찾기**
- Workers & Pages 목록에서 **cgg.co.kr 이 연결된 칸**을 찾아요(칸 안 «Custom domains» 에 cgg.co.kr). 칸 이름 **사진**. 못 찾으면 여기서 멈추고 알려 주세요.

**15. 옛 홈페이지 백업 (두 겹)**
1. 바탕화면에 새 폴더 **«옛홈페이지_백업_1101»** 을 만들어요.
2. 아래 4개 주소를 차례로 열고, 열 때마다 **Ctrl+S** → 파일 형식 **«웹페이지, HTML만»** → 이름을 아래처럼 바꿔 그 폴더에 저장해요.
   - https://cgg.co.kr → `index.html`
   - https://cgg.co.kr/terms.html → `terms.html`
   - https://cgg.co.kr/privacy.html → `privacy.html`
   - https://cgg.co.kr/refund.html → `refund.html`
   (열었을 때 «찾을 수 없음»이 뜨는 주소는 건너뛰고 알려 주세요)
3. https://cgg.co.kr 첫 화면을 **사진**으로도 찍어 둬요.
4. 두 번째 백업은 Cloudflare 가 저절로 해 둬요: 그 칸의 **Deployments**(올린 기록)에 옛 판이 남아서 언제든 «Rollback»으로 돌아갈 수 있어요.

**16. 올릴 폴더 만들기**
1. 바탕화면에 새 폴더 **«새홈페이지_올리기»** 를 만들어요.
2. `12_메인홈페이지_v2.zip` 의 압축을 풀어, 안에 든 6개(index.html · join.html · og.png · robots.txt · sitemap.xml · _headers)를 그 폴더에 넣어요.
3. 백업 폴더의 `terms.html` · `privacy.html` · `refund.html` 을 **복사**해서 같은 폴더에 넣어요. (index.html 은 넣지 않아요 — 새 것을 써요)

**17. 올리기**
- 14에서 찾은 칸 → **Create deployment**(또는 Upload) → **«새홈페이지_올리기» 폴더를 통째로** 끌어다 놓기 → **Deploy**.

**18. 확인**
1. 1분 뒤 https://cgg.co.kr → Ctrl+F5 → 첫 문구 «차를 맡는 순간부터, 정산을 마치는 순간까지.» 면 성공 → 사진
2. 맨 아래 «이용약관» · «개인정보처리방침» · «환불 규정» 이 각각 열리는지 봐요.
3. 맨 위 «로그인» → app.cgg.co.kr 이 열리면 OK.
- 하나라도 이상하면: 그 칸 → **Deployments** → 맨 위 바로 **아래 줄** ⋯ → **Rollback to this deployment** → 옛 홈페이지로 돌아가요.

## 바. 실제로 알림 1통 받아 보기 (10분)
자세한 건 `13_알림_받아보기_확인표.md`.
- **워시 (브라더광택 · 정대봉 대표님)**: 입고 → 차량번호 `00테0000`, 딜러 휴대폰 = 정대봉 대표님 본인 번호, 딜러 이름·상사·작업 **빈칸 없이** → «입고 등록» 빠르게 두 번 → 목록 1건 · 카톡 1통이면 OK → 로그아웃·재로그인 뒤 그대로면 OK → `00테0000` 지우기
- **체크 (가온진단평가 대표 계정)**: 월별 청구서 › 청구서 보내기 → 하나 고르고 «내 번호로 시험» → 카톡 1통 · 금액·링크 OK → 메모 한 줄 저장 → 로그아웃·재로그인 뒤 그대로면 OK
- «확인 중»이 뜨면 다시 누르지 말고 사진만 보내요.

➡ 사진을 받으면 총괄 방이 **«워시 — 사용 가능/불가 · 체크 — 사용 가능/불가»** 로 알려 드려요.

# 중복 사업자번호 — 대표님 실행 순서 (한 장)

> 지금은 아무것도 바뀌지 않았어요. 아래는 **총괄이 «하세요»라고 할 때만** 해요. 모든 SQL은 Supabase › SQL Editor 에 파일 전체를 붙여 넣고 Run 해요.

## 1단계 — 지금 상태 보기(읽기만 · 바뀌는 것 없음)
1. `서버/sql/23_중복사업자번호_확인_읽기만.sql` 을 Run 해요.
2. 나온 표를 사진으로 찍어 총괄 방에 보내요(줄이 많으면 내려 가며 여러 장).

## 2단계 — 막기 (승인 뒤)
1. 1단계 표의 «잠금: 워시 사업자번호» 가 **꺼짐**이면 `서버/sql/급한고침_사업자번호_잠금.sql` 을 먼저 Run 해요.
2. `서버/sql/24_사업자번호_겹침_막기.sql` 을 Run 해요 → 맨 끝 표가 모두 «켜짐»이면 돼요(이미 겹친 곳이 있으면 «겹친 곳만 빼 둠»이라고 나와요 — 정상).
3. wash-api 에 `서버/1_차곳간워시_서버_wash-api_sb28.ts` 를 올려요(Verify JWT 끔 · sb25~27 내용 포함).
4. check-api 에 `서버/2_차곳간체크_서버_check-api_v53.ts` 를 올려요(Verify JWT 끔 · v50~52 내용 포함).

## 3단계 — 시험 업체 B 정리 (승인 뒤)
1. `서버/sql/25_중복사업자번호_정리안_승인뒤.sql` 에서 '여기에_B_업체코드' 를 1단계 표의 B 업체코드로 바꿔 Run → «연습»이라 바뀌지 않아요. 결과 표를 총괄 방에 보내요.
2. 총괄이 «진짜»라고 하면 맨 끝 `rollback;` 을 `commit;` 으로 바꿔 다시 Run 해요.
3. 워시테스트 화면에서 로그아웃 → 다시 로그인해요.
4. 24번 SQL을 한 번 더 Run → «켜짐»(빼 둔 곳 없음)이면 끝이에요.

# 작업 요청서 양식

한 방이 다른 방에 일을 넘길 때, 또는 대표님이 일을 시킬 때 쓰는 양식입니다.
아래 칸을 채워 받는 방에 그대로 붙여 넣으면 됩니다.

```
[작업 요청서]
보내는 곳: (예: 워시 방 / 대표님)
받는 곳:   (예: 서버 방)
제목:      (한 줄. 예: 워시 입금 처리 창구 만들기)

1. 왜 필요한가요?
   (손님이나 업체에게 어떤 도움이 되는지)

2. 무엇을 해 주면 되나요?
   (끝났을 때 어떤 모습이어야 하는지)

3. 끝났다고 보는 기준
   (예: 시험 화면에서 입금 1건이 처리되고 목록에 보임)

4. 기다리는 다른 일
   (이 일이 끝나야 시작할 수 있는 일. 없으면 "없음")

5. 보안 검토 필요?  예 / 아니요
   (개인정보, 돈, 위치, 비밀 열쇠가 걸리면 "예")
```

## 받는 방이 지킬 것
- 받으면 "받았어요, ○○까지 할게요"처럼 한 줄로 답합니다.
- 끝나면 바꾼 내용을 쉬운 말 3줄 이내로 보고하고, 보낸 방과 총괄 방에 알립니다.
- 내 서랍 밖의 일이 섞여 있으면 그 부분은 맡은 방으로 다시 넘깁니다.

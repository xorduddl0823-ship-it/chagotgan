# 배포 전 보안 검사표

대표님이 Cloudflare에 올리기 전에 보안 방이 이 표로 검사합니다.
결과는 `보안/검사기록/날짜_제품.md` 에 남깁니다. 하나라도 「아니요」면 **배포 보류**입니다.

## 대표님이 보안 방에 붙여 넣을 말
```
○○(제품 이름) 배포하려고 해. 운영/02_배포_전_보안_검사표.md 대로 검사해줘.
```

## 검사 항목

| 번호 | 확인할 것 | 결과 |
|---|---|---|
| 1 | 화면 파일(HTML) 안에 비밀 열쇠 값이 없다 (API 키, 비밀번호, 서비스 키) | 예 / 아니요 |
| 2 | 화면이 서버에 보내는 열쇠는 로그인 후 받은 임시 열쇠(세션)뿐이다 | 예 / 아니요 |
| 3 | 이 제품 서버 창구가 모두 로그인 여부와 제품 권한을 검사한다 | 예 / 아니요 |
| 4 | 권한 없는 계정으로 요청하면 서버가 거절한다 (직접 시험) | 예 / 아니요 |
| 5 | 관리(컨트롤센터) 화면이나 관리 창구 주소가 사용자 화면에 들어 있지 않다 | 예 / 아니요 |
| 6 | 개발용 기능이 꺼져 있다 (예: `DEV = false`, 시험용 가짜 서버 주소 없음) | 예 / 아니요 |
| 7 | 손님 개인정보가 화면에 필요 이상으로 보이지 않는다 (전화번호 가림 등) | 예 / 아니요 |
| 8 | 팝빌·문자 등 돈이 드는 기능이 테스트 모드가 아닌 실제 모드로 바뀌었는지 대표님이 알고 있다 | 예 / 아니요 |
| 9 | 바꾼 내용이 저장소에 기록되어 있어, 문제가 생기면 이전 판으로 되돌릴 수 있다 | 예 / 아니요 |
| 10 | 바뀐 화면이 PC와 폰에서 모두 깨지지 않는다 | 예 / 아니요 |

## 결과 기록 모양
```
# 2026-00-00 ○○ 배포 검사
결과: 통과 / 보류
고칠 것: (보류일 때만. 어느 방이 무엇을)
검사한 파일: (파일 이름과 버전)
```

## 모든 방 공통 — 오픈 베타 기준
1. **기능**: 자기 제품의 모든 화면·버튼을 대표·직원(매니저)·체험판 계정으로 한 번씩 눌러 봄. 결제/10 점검표 칸 모두 다시 확인. 빈 화면·오류 글·안 눌리는 버튼 0개.
2. **보안**: 권한은 서버가 막는지(화면 숨김만 아닌지), 비밀 열쇠 0, 손님 글 esc, 1.5 규칙 두 가지(render esc · 고른 줄 비우기/줄 id), 로그아웃 뒤 남는 자료 0.
3. **말(워딩)**: 규칙 4장 그대로.
   - 고등학생이 바로 아는 말, 해요체. **가입·로그인·오류 안내만 표준형(「~습니다」)**.
   - 「돈」 대신 「금액」, 「관제센터」 대신 「관리」, 「알람」 대신 「알람 소리」, 「단추」 대신 「버튼」.
   - 상태 이름: 진행 중 · 확인 필요 · 보류 · 완료 (워시 차 상태 칩은 입고·출고·수금 완료 유지, 색만 J — 추천안)
   - 오류 글은 「무엇이 안 됐고 어떻게 하면 되는지」 한 줄. 사과·영어·코드 글자(예: undefined, null, 500) 노출 금지.
   - 같은 뜻은 모든 제품에서 같은 말 (예: 「로그인」 「로그아웃」 「저장했어요」 「다시 시도해 주세요」).
   - 약관 글은 손대지 않음(규칙 3-8).
4. **오픈 베타 표시**: 사용자 화면(워시·체크·딜러·홈페이지·통합 입구) 맨 위에 같은 모양의 「오픈 베타」 띠 (홈페이지 시안 「넣은 안」 그대로, 디자인 방 문구). 관리에는 넣지 않음.
5. 끝나면 총괄에 3줄: 새 판 번호 · 눌러 본 결과(오류 수) · 고친 말 개수. 보안 방에 검사 요청.

## 방별
- **디자인 방**: 「오픈 베타」 띠 문구·모양 한 가지로 정해 각 방에 전달(공통 부품은 바꾸지 말고 붙이는 법만). 모든 제품 화면을 돌며 **말 대조표**(같은 뜻 다른 말) 작성 → 각 방에 전달.
- **알림톡 방**: 워딩 담당. 각 제품 새 판의 **화면 안내 글 전체**(오류·빈 화면·확인 창·토스트·버튼 이름)를 읽고 고칠 말 목록을 방마다 보내기(파일·줄 번호). 알림톡 본문과 화면 말이 같게.
- **워시 · 체크 · 관리 · 딜러 · 홈페이지·앱 방**: 위 공통 1~5. 받은 말 목록 반영. 새 판 1개(워시 v123 · 체크 v39 · 관리 v4.6 · 딜러 d3.6 · 통합 v8 등).
- **서버 방**: 서버가 돌려주는 **오류 글**(`__err`)을 모두 뽑아 쉬운 말로 고침(로그인·가입은 표준형). 새 창구 없이. 고친 판은 보안 확인.
- **결제 방**: 결제 화면 말(금액·부가세·환불·자동 결제 동의)을 모든 제품에서 대조. 결제/11 시험 순서 최종 확인.
- **보안 방**: 금 13:00 이후 시험판 전체 마지막 검사. 특히 로그인·권한·결제·환불·계정 관리·체험판·미리 써 보기.

- 시험은 **금 18:00 시작 → 토·일 모든 기능 시험**. 모든 방은 토·일에도 대기, 대표님 오류 보고가 오면 **그날 안에 고친 판 + 보안 확인**.
- **알림톡 발송 기록 — 총괄이 확인한 빈 곳**
  1. 워시 서버(sb13)만 `wash_sendlog`에 남김. **체크 서버(v30) · 딜러 서버(d6) · 경비실(cgg-api)은 알림톡/문자 보내도 기록이 없음** (인증번호·직원 링크·첫 비밀번호·차량 도착 등).
  2. 워시 기록도 「보낼 때 성공」만 남김. 알림톡이 실패해 **문자로 대체됐는지(요금 다름)**, 최종 도착했는지는 모름.
- **서버 방**: 모든 서버가 같은 모양으로 발송 기록을 남기게(제품 · 업체 · 템플릿 키 · 받는 번호(가린 모양) · 알림톡/문자 · 솔라피 메시지 id · 결과 · 오류). 솔라피 결과 조회로 **최종 결과(알림톡 도착 / 문자 대체 / 실패)와 건수**를 나중에 채우기. 기록 실패가 발송을 막지 않게. 개인정보: 받는 번호 가운데 가리기, 본문은 템플릿 키와 변수만, 보관 기간(추천 1년) 정하기 → 보안 방 확인.
- **관리 방**: 관리 › 알림에 「발송 기록」 화면 — 제품 · 업체 · 템플릿 · 결과로 거르기, 이번 달 알림톡/문자 대체/실패 건수와 대략 요금(알림톡 13원 · SMS 18원 · LMS 45원, VAT 별도).
- **알림톡 방**: 시험 순서에 「알림톡 시험 표」 — 템플릿 13개(+새 것)마다 어디서 무엇을 누르면 나가는지, 받을 글 모양, 관리 발송 기록에서 확인할 칸.

[작업 요청서]
보내는 곳: 홈페이지·앱 방
받는 곳:   체크 방
제목:      홈페이지 「미리 써 보기」용 체크 미리보기 사본

1. 왜 필요한가요?
   대표님 구상(2026-10-15): 대표 홈페이지에서 가입 없이 워시·체크·딜러를 예시 자료로 눌러 보기. 실제 제품 화면을 그대로 띄워야 해요(규칙 1-6·3-2).
   워시는 워시 방의 「워시_vNNN_미리보기.html」(서버 요청을 파일 안에서 가로채 예시 자료로 답함), 딜러는 시연 모드(window.__DEMO)로 이미 들어갔어요. 체크만 비어 있어요.

2. 무엇을 해 주면 되나요?
   - 최신 체크 판으로 워시 방과 같은 방식의 미리보기 사본: `체크/시안/체크_vNN_미리보기.html`
     (check-api로 가는 요청을 가로채 지어낸 예시 검사소 자료로 답함, 실제 서버 연결 없음, 저장은 창 안에서만)
   - 맨 위에 「미리보기 — 지어낸 자료예요」 띠 (워시와 같은 문구)
   - 체험판 분류표가 체크에도 생기면 🔒 기능 목록 몇 줄 (홈페이지 옆 칸에 씀)

3. 끝났다고 보는 기준
   파일 하나만 열어도 체크 홈·매출·청구가 예시 자료로 보이고, 서버 주소로 나가는 요청이 0건

4. 기다리는 다른 일
   홈페이지 방이 `홈페이지/소개/만들기_소개_시안.py` 에 넣어 다시 묶음 → 보안 방 → 대표님

5. 보안 검토 필요?  예 (공개 페이지에 실리는 예시 자료에 실제 업체 정보가 없어야 함)

# 통합 입구 시험 순서표 — 휴대폰 기준 (대표님용)

> 시험 주소: `https://t.cgg.co.kr` (zip 직접 올리기 · 올리는 법은 `휴대폰_시험_올리는_법.md`)
> 로그인 화면 맨 아래에 **「통합 v4 · 워시 v112 · 체크 v23」** 이 보이면 맞는 판이에요.

> ⚠️ **꼭 지켜 주세요: 시험 계정과 시험 업체만 써요.**
> 시험 주소도 **진짜 서버·진짜 자료**에 붙어 있어요. 여기서 고치거나 지운 것은 실제 업체 자료에 그대로 남아요.
> 문자 확인을 켠 계정은 로그인할 때마다 알림톡(안 되면 문자) 요금이 1건씩 나가요.

## 시험 전에 준비할 것
- 경비실(cgg-api) 올리기 ✅ (끝남)
- 시험 계정 3개: **워시만 / 체크만 / 둘 다** (서버 방 안내서 2번)
- 휴대폰 브라우저 하나를 정해서 끝까지 같은 걸로 해요 (크롬 또는 사파리)
- 다른 계정으로 바꿀 때는 꼭 **「모두 로그아웃」** 을 먼저 눌러요

## 가. 계정별 확인

| 순서 | 할 일 | 이렇게 보이면 통과 |
|---|---|---|
| 1 | 「워시만」 번호로 로그인 | 워시 화면이 바로 열려요. 위쪽에 「워시·체크」 고르는 띠가 **없어요**. |
| 2 | 주소창 맨 끝에 `#check` 를 붙여 열기 | 체크가 아니라 **워시로 되돌아가요**. |
| 3 | 「모두 로그아웃」 | 로그인 화면으로 돌아가요. |
| 4 | 「체크만」 번호로 로그인 | 체크 화면만 열려요. 띠가 없어요. |
| 5 | 주소창 맨 끝에 `#wash` 붙여 열기 | **체크로 되돌아가요**. |
| 6 | 「모두 로그아웃」 → 「둘 다」 번호로 로그인 | 위쪽 띠에 **워시 · 체크** 두 개만 보여요. 관리는 없어요. |
| 7 | 띠에서 체크 → 워시 → 체크로 옮기기 | 다시 로그인하라고 묻지 않아요. 보던 화면이 그대로 있어요. |
| 8 | 비밀번호를 일부러 틀리기 | 들어가지 못하고 안내 글이 나와요. |
| 9-1 | **권한 없는 번호**(시험 명단에 없는 번호, 또는 비밀번호는 맞지만 제품을 안 준 번호)로 로그인 | 들어가지 못하고 「이 계정으로 이용할 수 있는 서비스가 없습니다」 같은 안내가 나와요. **어떤 제품 화면도 열리면 안 돼요.** 열리면 바로 화면을 찍어 보내 주세요. |
| 9 | (문자 확인 켠 계정이 있으면) 로그인 | 6자리 입력 칸이 나오고, 인증번호가 **카카오 알림톡**(안 되면 문자)으로 와요. 문자로 오면 키보드 위에 번호가 떠서 눌러 넣을 수 있고, 알림톡이면 번호를 보고 직접 넣어요. |

## 나. 휴대폰이라서 꼭 볼 것

| 순서 | 할 일 | 이렇게 보이면 통과 |
|---|---|---|
| 10 | 화면을 위아래로 밀기 | 글자가 화면 밖으로 잘리지 않고, **옆으로 밀리지 않아요**. |
| 11 | 휴대폰을 가로로 돌렸다가 다시 세로로 | 화면이 깨지지 않고 맞춰져요. |
| 12 | 홈 단추로 나갔다가 1분 뒤 다시 브라우저로 | 로그인 그대로, 보던 제품 그대로예요. |
| 13 | 브라우저를 완전히 닫았다가 시험 주소 다시 열기 | 로그인 없이 마지막에 보던 제품이 열려요. |
| 14 | 와이파이를 끄고 데이터로 바꾼 뒤 새로고침 | 그대로 잘 열려요. |
| 15 | 브라우저 「뒤로」 단추 누르기 | 이상한 빈 화면이 나오지 않아요. (나오면 화면을 찍어 주세요) |
| 16 | (해 보고 싶으면) 브라우저 메뉴 → **「홈 화면에 추가」** → 홈 화면 아이콘으로 열기 | 같은 화면이 열려요. 아직 앱 아이콘 모양은 다듬기 전이에요. |

## 라. 결제 시험 (토스 테스트 모드 · 새 J안 판 한 번에)
- 순서표: **`결제/11_결제_시험_순서.md`** (20줄, 약 40분). 실제 돈은 나가지 않아요. 화면에 「테스트 모드」가 보이는지 먼저 확인해요.
- 홈페이지 몫은 1·2번이에요. 시험 주소의 `/home/` 에서 요금제를 골라 시작해요.
  - 1번: 새 번호로 가입 → 결제 → 앱이 바로 열리면 「됨」
  - 2번: 다른 새 번호로 가입 → 결제 창 닫기 → 다시 로그인 → 「결제 이어 하기」 띠가 보이면 「됨」
- 끝나면 결과를 「됨 / 안 됨 + 화면 캡처」로 총괄 방에 보내 주세요.

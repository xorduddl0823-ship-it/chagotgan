# 통합 입구 시험 순서표 (대표님용)

> 대상 파일: `홈페이지/통합입구/0_차곳간_통합_index.html` (통합 v2, 관리 빠짐)
> 이 파일은 서버의 **경비실(cgg-api)** 로 로그인해요. 경비실이 올라가기 전에는 로그인이 안 돼요.

## 시험 전에 준비할 것
- 보안 방 검사 통과 (규칙 2-4)
- 서버 방 안내서(`서버/설계/01_경비실_통합로그인_안내.md`)의 1~4번 끝내기
  - 시험 계정 3개: **워시만 / 체크만 / 둘 다**

## 계정마다 확인할 것

| 순서 | 할 일 | 이렇게 보이면 통과 |
|---|---|---|
| 1 | 「워시만」 번호로 로그인 | 워시 화면이 바로 열려요. 위쪽에 제품 고르는 띠가 **없어요**. |
| 2 | 주소 끝에 `#check` 를 붙여 다시 열기 | 체크가 아니라 **워시로 되돌아가요**. |
| 3 | 「모두 로그아웃」 누르기 | 로그인 화면으로 돌아가요. |
| 4 | 「체크만」 번호로 로그인 | 체크 화면만 열려요. 띠가 없어요. |
| 5 | 주소 끝에 `#wash` 붙여 다시 열기 | **체크로 되돌아가요**. |
| 6 | 「둘 다」 번호로 로그인 | 위쪽 띠에 **워시 · 체크** 두 개만 보여요. 관리는 없어요. |
| 7 | 띠에서 체크 → 워시 → 체크로 옮겨 보기 | 다시 로그인하라고 묻지 않아요. 전에 보던 화면이 그대로 있어요. |
| 8 | 창을 닫았다가 다시 열기 | 로그인 없이 마지막에 보던 제품이 열려요. |
| 9 | 비밀번호를 일부러 틀리기 | 들어가지 못하고 안내 글이 나와요. |

## 이상하면

- 로그인 자체가 안 되면(9번 말고도 모두 실패) 서버 방에 먼저 알려 주세요.

# 시험 날 한 장 (대표님용)

> 새 디자인 판을 **한 번에** 시험하는 날 이 한 장만 보시면 돼요. 걸리는 시간: 서버 40분 + 시험 주소 15분 + 눌러 보기 1시간 반쯤.
> 비밀 열쇠 **값**은 여기에 적지 않아요. 이름만 적어요. 값은 수파베이스 화면에 직접 넣으세요.
> 막히면 그 자리에서 멈추고 **단계 번호**(예: ①-6)를 총괄 방에 보내 주세요.

> ⚠️ **오늘 꺼 둔 채로 두는 스위치 2개** (관리 화면)
> - 「체크 첫 비밀번호 문자 확인」(체크 비밀번호 비우기) — 운영 체크 화면이 새 판으로 바뀔 때까지 **끔**
> - 「누구나 가입」(가입 코드 없이 가입) — 토스 승인 뒤 카드 결제가 실제로 될 때까지 **끔**
>
> ⚠️ **시험 직원은 시험 주소(cgg-test)의 새 체크 화면으로 처음 로그인**해요. 지금 운영 체크 화면(v21)에는 확인 번호 칸이 없어서 처음 로그인이 안 돼요.

## ④ 눌러 보기 (휴대폰 · 시험 계정과 시험 업체만!)
> ⚠️ 시험 주소도 **진짜 서버**에 붙어 있어요. 저장 · 삭제 · 문자 · 세금계산서는 진짜로 일어나요.
> 결과는 「단계 번호 · 됨 / 안 됨 · 화면 캡처」로 총괄 방에 보내 주세요.

**홈페이지 (`/home/`)**
1. 「미리 써 보기」에서 워시 · 체크 · 딜러 둘러보기 → 예시 자료가 보이면 됨
2. 자물쇠 단추 → 「결제하면 쓸 수 있는 기능이에요」 창이 뜨면 됨
3. 맨 위 노란 줄에서 「오픈 베타 띠」 넣은 안 / 뺀 안 비교 → 마음에 드는 쪽 알려 주기
4. 맨 아래 사업자 정보 · 약관 링크가 보이면 됨

**통합 입구 (`/`)** — 자세한 것은 `시험_순서표.md`
1. 「워시만」 번호 로그인 → 워시만 열림
2. 「체크만」 번호 로그인 → 체크만 열림 (처음이면 확인 번호를 받고 비밀번호를 정해요)
3. 「둘 다」 번호 로그인 → 위 띠에 워시 · 체크 두 개만, 옮겨 다녀도 다시 로그인 안 함
4. 권한 없는 번호 로그인 → **아무 화면도 안 열림**
5. 「모두 로그아웃」 → 로그인 화면

**체크 기사 (`/driver/`)**
1. 시험 기사 번호로 로그인 → 내 배달 목록이 보임
2. 휴대폰을 가로 · 세로로 돌려도 화면이 안 깨짐

**딜러 (`/dealer/`)**
1. 시험 딜러 번호로 로그인(인증번호가 알림톡 또는 문자로 옴) → 내 차가 보임
2. 청구서 → 금액 · 기한 · 계좌 복사가 됨

**관리 (`cgg-admin-test-….pages.dev`)**
1. 대표님 번호 + 비밀번호 + **문자 6자리**로 로그인 → 관리 홈이 열림
2. 위 메뉴를 하나씩 눌러 봄 → 빈 화면이나 오류 글 없이 열림
3. 「결제 내역」에 시험 결제 줄이 꼬리표(홈페이지 가입 · 워시 · 체크 …)와 함께 보임
4. 「결제 기다림」 업체 목록이 보임 (홈페이지 가입 뒤 결제를 안 한 시험 업체)
5. 위 ⚠️ 스위치 2개가 **꺼져 있는지** 확인

**결제 (토스 테스트 모드 · 실제 돈 안 나감)** — `결제/11_결제_시험_순서.md` 20줄, 약 40분
- 화면에 「테스트 모드」가 보이는지 **먼저** 확인해요. 관리 → 카드 결제 켜기(테스트), 자동 결제 스위치는 **시험 때만** 켜요.
- 홈페이지 몫: 1번(새 번호로 가입 → 결제 → 앱이 바로 열림), 2번(가입 → 결제 창 닫기 → 다시 로그인 → 「결제 이어 하기」 띠)

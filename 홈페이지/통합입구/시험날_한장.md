# 시험 날 한 장 (대표님용 · 초안)

> 새 디자인 판을 **한 번에** 시험하는 날 이 한 장만 보시면 돼요. 걸리는 시간: 서버 30분 + 올리기 5분 + 눌러 보기 1시간쯤.
> 비밀 열쇠 값은 여기에 적지 않아요. 넣을 때는 수파베이스 화면에 직접 넣으세요.
> 순서가 헷갈리면 멈추고 그 단계 번호를 총괄 방에 보내 주세요.

---

## ① 서버 올리기 (PC · 수파베이스 누리집)
> 서버 방이 지금 운영 화면과 맞는지 확인하고 있어요. **서버 방이 「확인 끝」이라고 하면** 시작해요. 자세한 확인 방법은 `서버/설계/02_서버_새판_배포_안내.md`에 있어요.

| 차례 | 무엇을 | 어떻게 |
|---|---|---|
| 1 | SQL **08** 실행 | 수파베이스 → 왼쪽 **SQL Editor** → **New query** → `서버/sql/08_관리_통합_기록.sql` 내용을 통째로 붙여 넣기 → **Run** → 「Success」 확인 |
| 2 | SQL **09** 실행 | 같은 방법으로 `서버/sql/09_홈페이지_첫결제.sql` |
| 3 | 체크 서버 **v30** 올리기 | 왼쪽 **Edge Functions** → `check-api` → **Code** → 내용을 `서버/2_차곳간체크_서버_check-api_v30.ts`로 바꾸기 → **Deploy** |
| 4 | 워시 서버 **sb13** 올리기 | **Edge Functions** → `wash-api` → **Code** → 내용을 `서버/1_차곳간워시_서버_wash-api_sb13.ts`로 바꾸기 → **Deploy** |
| 5 | 잘 올라갔는지 보기 | 서버 방이 알려 주는 「판 번호 확인」 주소를 열어 v30 · sb13이 보이면 끝 |

- 문제가 생기면 **그 단계에서 멈추고** 서버 방에 알려 주세요. 되돌리는 방법은 서버 방이 알려 드려요.

## ② 시험 주소에 올리기 (휴대폰 · 단추 몇 번)
| 차례 | 무엇을 | 어떻게 |
|---|---|---|
| 0 | (시험 칸이 아직 없으면) | `휴대폰_시험_올리는_법.md` 「처음 한 번만」대로 cgg-test 칸부터 만들어요 (명령 칸에는 아래 1번 한 줄) |
| 1 | (처음 한 번만) 만드는 명령 바꾸기 | Cloudflare → `cgg-test` → **Settings(설정)** → **Builds(빌드)** → 명령 칸을 아래 한 줄로 바꾸고 저장 → `bash 홈페이지/통합입구/도구/올림/pages_build.sh 묶음` |
| 2 | 새 판 옮기기 | 휴대폰에서 이 주소를 열어요 → `https://github.com/xorduddl0823-ship-it/chagotgan/compare/cgg-test-site...main` → 초록 단추 **Create pull request** → **Create pull request** → **Merge pull request** → **Confirm merge** |

## ③ 눌러 보기 (휴대폰 · 시험 계정과 시험 업체만!)
> ⚠️ 시험 주소도 **진짜 서버**에 붙어 있어요. 저장·삭제·문자·세금계산서는 진짜로 일어나요. 시험 계정 · 시험 업체만 써 주세요.
> 결과는 「몇 번 · 됨 / 안 됨 · 화면 캡처」로 총괄 방에 보내 주세요.

**홈페이지 (`/home/`)**
1. 「미리 써 보기」에서 워시 · 체크 · 딜러를 하나씩 눌러 둘러보기 → 예시 자료가 보이면 됨
2. 자물쇠 단추를 눌러 보기 → 「결제하면 쓸 수 있는 기능이에요」 창이 뜨면 됨
3. 맨 위 노란 줄에서 「오픈 베타 띠」 넣은 안 / 뺀 안을 바꿔 보고 마음에 드는 쪽을 알려 주기
4. 맨 아래 사업자 정보 · 약관 링크가 보이면 됨

**통합 입구 (`/`)** — 자세한 것은 `시험_순서표.md` 가~다
1. 「워시만」 번호로 로그인 → 워시만 열리면 됨
2. 「체크만」 번호로 로그인 → 체크만 열리면 됨
3. 「둘 다」 번호로 로그인 → 위 띠에 워시 · 체크 두 개만, 옮겨 다녀도 다시 로그인 안 하면 됨
4. 권한 없는 번호로 로그인 → **아무 화면도 안 열리면** 됨
5. 「모두 로그아웃」 → 로그인 화면으로 돌아오면 됨

**체크 기사 (`/driver/`)**
1. 시험 기사 번호로 로그인 → 내 배달 목록이 보이면 됨
2. 휴대폰을 가로·세로로 돌려도 화면이 안 깨지면 됨

**딜러 (`/dealer/`)**
1. 시험 딜러 번호로 로그인(인증번호가 알림톡 또는 문자로 옴) → 내 차가 보이면 됨
2. 청구서 메뉴 → 금액 · 기한 · 계좌 복사가 되면 됨

**결제 (토스 테스트 모드 · 실제 돈 안 나감)** — `결제/11_결제_시험_순서.md` 20줄, 약 40분
- 화면에 「테스트 모드」가 보이는지 **먼저** 확인해요.
- 홈페이지 몫: 1번(새 번호로 가입 → 결제 → 앱이 바로 열림), 2번(가입 → 결제 창 닫기 → 다시 로그인 → 「결제 이어 하기」 띠)

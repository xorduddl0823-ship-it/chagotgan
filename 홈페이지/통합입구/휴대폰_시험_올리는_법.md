# 통합 입구를 휴대폰으로 시험하는 법 (대표님용)

> 결론: **Cloudflare에 「시험 전용」 칸을 하나 새로 만들고, 저장소와 연결**해 두면
> 대표님이 휴대폰에서 단추 몇 번으로 올리고, `https://(정한 이름).pages.dev` 주소로 열 수 있어요.
> 지금 쓰는 app.cgg.co.kr · check.cgg.co.kr 은 **건드리지 않아요.**


---
## 🟦 대표님이 휴대폰에서 누를 차례 (오픈 베타 · 통합 v11.4 · 2026-10-16 고침)

> 먼저 **Cloudflare에 `cgg-test` 칸이 이미 있는지**만 봐요. 있으면 A, 없으면 B로 가요.
> 보는 법: 휴대폰 브라우저 → **dash.cloudflare.com** 로그인 → 왼쪽 위 **☰(메뉴)** → **Workers & Pages** (메뉴가 묶여 있으면 **Compute** 아래에 있어요) → 목록에 `cgg-test` 가 보이는지.

### A. `cgg-test` 가 이미 있으면 (3분)
1. 목록에서 **cgg-test** → 위쪽 탭 **Settings** → **Build**(빌드) → **Build configuration** 옆 **Edit**(연필)
2. **Build command** 칸을 지우고 아래 한 줄을 그대로 붙여 넣어요 → **Save**
   ```
   bash 홈페이지/통합입구/도구/올림/pages_build.sh 묶음
   ```
   (Build output directory 는 `out`, Production branch 는 `cgg-test-site` 인지도 같이 봐요)
3. GitHub 의 **PR #1** 을 열어요 → `https://github.com/xorduddl0823-ship-it/chagotgan/pull/1` → 맨 아래 초록 **Merge pull request** → **Confirm merge**
4. 1~2분 뒤 Cloudflare `cgg-test` → **Deployments** 맨 위 줄이 초록 **Success** 면 끝 → 아래 「확인」으로

### B. `cgg-test` 가 아직 없으면 (12분)
1. **먼저 PR #1 Merge**: `https://github.com/xorduddl0823-ship-it/chagotgan/pull/1` → **Merge pull request** → **Confirm merge**
   (먼저 해 두면 다음 단계의 첫 올리기가 바로 초록으로 끝나요)
2. Cloudflare → ☰ → **Workers & Pages** → 오른쪽 위 **Create**(또는 **Create application**)
3. 화면 위쪽에 **Pages** 탭이 있으면 누르고 → **Import an existing Git repository**(또는 **Connect to Git**) → **Get started**
   - **Pages 탭이 안 보이면**: 화면 맨 아래 작은 글 **「Looking to deploy Pages? Get started」** 를 눌러요
   - ⚠️ 칸 이름에 **Deploy command** 가 보이면 Pages 가 아니라 Workers 화면이에요. 뒤로 가서 위 방법으로 Pages 를 골라요
4. **GitHub** 를 고르고 연결을 허락해요 → 저장소 **chagotgan** 고르기 → **Begin setup**
5. 칸을 이렇게 채워요 (글자를 그대로 복사해 붙여 넣으세요)
   | 칸 | 넣을 것 |
   |---|---|
   | **Project name** | `cgg-test` (이미 쓰이면 `chagotgan-test` — 이 이름이 주소가 돼요) |
   | **Production branch** | `cgg-test-site` |
   | **Framework preset** | `None` |
   | **Build command** | `bash 홈페이지/통합입구/도구/올림/pages_build.sh 묶음` |
   | **Build output directory** | `out` |
   (Root directory · Environment variables 는 **비워 둬요**)
6. **Save and Deploy** → 1~2분 뒤 초록 **Success**

### 확인
`https://cgg-test.pages.dev` (정한 이름으로) 를 열어 로그인 화면 맨 아래에 **「통합 v11.4 · 워시 v125 · 체크 v42」** 이 보이면 끝이에요. 맨 위에는 「오픈 베타」 띠가 보여요.
- 화면이 좁아 칸이 잘 안 보이면 브라우저 메뉴의 **「데스크톱 사이트 보기」** 를 켜면 편해요.
- 버튼 이름이 위와 다르게 보이면 그 화면을 찍어 총괄 방에 보내 주세요. 맞는 단추를 찾아 드릴게요.

## 왜 이 방법인가요?
- 휴대폰에는 2MB짜리 파일을 내려받아 다시 올리기가 어려워요. 저장소와 연결해 두면 파일을 옮길 필요가 없어요.
- 시험 주소가 실제 손님 주소와 따로라서, 시험하다 잘못돼도 손님 화면은 멈추지 않아요.
- 경비실(cgg-api)은 어느 주소에서 불러도 받아 주게 되어 있어서 서버 쪽은 바꿀 게 없어요.

## 다음부터 새 판을 올릴 때 (휴대폰, 1분)
Cloudflare는 `cgg-test-site` 가지가 바뀔 때만 올려요. 방들은 `main` 에만 저장하니,
**대표님이 「main → cgg-test-site 로 옮기기」를 눌러야** 새 판이 올라가요. 이게 대표님의 「배포」예요.
1. 홈페이지·앱 방이 「새 판 저장소에 올렸어요」라고 알려 드려요. 보안 방 「통과」를 확인해요.
2. 휴대폰에서 아래 주소를 열어요 (즐겨찾기 해 두면 편해요).
   `https://github.com/xorduddl0823-ship-it/chagotgan/compare/cgg-test-site...main`
3. 초록 단추 **Create pull request** → 한 번 더 **Create pull request** → **Merge pull request** → **Confirm merge** 를 차례로 눌러요.
4. 1~2분 뒤 시험 주소를 새로고침하면 새 판이에요. 로그인 화면 맨 아래 판 번호(예: 「통합 v11.3」)로 확인할 수 있어요.
   (총괄 방이 PR 을 미리 만들어 두면 3번 대신 그 PR 의 **Merge pull request** → **Confirm merge** 만 눌러요)

## 알아 두실 것
- 이 주소는 인터넷에 열려 있어요. 다만 로그인은 경비실(서버)이 검사하니, 허락된 계정만 들어가요. 검색 사이트에는 안 뜨게 막아 두었어요.
- 시험 주소에서 로그인한 기록은 app.cgg.co.kr 과 **섞이지 않아요**. (주소가 다르면 휴대폰이 따로 보관해요)
- 시험이 끝나면 cgg-test 칸을 지워도 손님 화면에는 아무 영향이 없어요.
- 메뉴 이름이 위와 조금 다르게 보이면, 화면을 찍어 보내 주세요. 맞는 단추를 찾아 드릴게요.

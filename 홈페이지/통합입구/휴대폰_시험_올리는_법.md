# 통합 입구를 휴대폰으로 시험하는 법 (대표님용)

> 결론: **Cloudflare에 「시험 전용」 칸을 하나 새로 만들고, 저장소와 연결**해 두면
> 대표님이 휴대폰에서 단추 몇 번으로 올리고, `https://(정한 이름).pages.dev` 주소로 열 수 있어요.
> 지금 쓰는 app.cgg.co.kr · check.cgg.co.kr 은 **건드리지 않아요.**


---
## 🟦 대표님이 휴대폰에서 누를 차례 (v4 올리기, 보안 방 통과 ✅)

**1. 새 판을 시험 칸으로 옮기기 (1분)**
휴대폰에서 이 주소를 열어요 → `https://github.com/xorduddl0823-ship-it/chagotgan/compare/cgg-test-site...main`
초록 단추를 차례로 눌러요: **Create pull request** → **Create pull request** → **Merge pull request** → **Confirm merge**
(「There isn't anything to compare」가 뜨면 이미 최신이라 그냥 2번으로 가요.)

**2. (처음 한 번만) Cloudflare에 시험 칸 만들기 (10분)**
아래 「처음 한 번만」의 1~5번대로 해요. 만드는 명령 칸에는 이 한 줄을 그대로 붙여 넣어요:
`bash 홈페이지/통합입구/도구/올림/pages_build.sh v4`
이미 만들어 두셨다면 이 단계는 건너뛰어요. 1번을 누르면 1~2분 뒤 저절로 새 판이 올라가요.

**3. 확인하기**
`https://cgg-test.pages.dev` 를 열어 로그인 화면 맨 아래에 **「통합 v4」** 가 보이면 끝이에요. 그다음 `시험_순서표.md` 대로 눌러 봐요.
---

## 왜 이 방법인가요?
- 휴대폰에는 2MB짜리 파일을 내려받아 다시 올리기가 어려워요. 저장소와 연결해 두면 파일을 옮길 필요가 없어요.
- 시험 주소가 실제 손님 주소와 따로라서, 시험하다 잘못돼도 손님 화면은 멈추지 않아요.
- 경비실(cgg-api)은 어느 주소에서 불러도 받아 주게 되어 있어서 서버 쪽은 바꿀 게 없어요.

## 처음 한 번만 (휴대폰 브라우저, 약 10분)
0. 보안 방 「통과」 ✅ (2026-10-15, v3·v4 모두: `보안/검사기록/2026-10-15_cgg-test_통합입구v4.md`). 「Save and Deploy」를 누르는 순간 첫 판이 올라가요.
1. 휴대폰 브라우저(크롬 또는 사파리)에서 **dash.cloudflare.com** 에 로그인해요.
   - 화면이 좁으면 브라우저 메뉴에서 **「데스크톱 사이트 보기」** 를 켜면 편해요.
2. 왼쪽 메뉴 **Workers & Pages** → **Create(만들기)** → **Pages** 탭 → **Connect to Git(저장소 연결)**.
3. GitHub 연결을 허락하고, 저장소 **chagotgan** 을 골라요.
4. 설정 칸은 아래처럼 적어요. (글자를 그대로 복사해 붙여 넣으세요)
   - **Project name(이름)**: `cgg-test` ← 이미 쓰이고 있으면 `chagotgan-test` 처럼 바꿔도 돼요. 이 이름이 주소가 돼요.
   - **Production branch(올릴 가지)**: `cgg-test-site`  ← 시험 전용 가지예요. 방들은 이 가지를 건드리지 않아요.
   - **Framework preset**: `None`
   - **Build command(만드는 명령)**:
     ```
     bash 홈페이지/통합입구/도구/올림/pages_build.sh
     ```
   - **Build output directory(결과 폴더)**: `out`
   - **추천: 명령 끝에 ` v4` 를 붙여요** → `bash 홈페이지/통합입구/도구/올림/pages_build.sh v4` (최신 새 판: 워시 v112 · 체크 v23). 안 붙이면 지금 운영 판을 묶은 v2가 올라가요.
5. **Save and Deploy(저장하고 올리기)** 를 눌러요. 1~2분 기다리면 초록색 「Success」가 떠요.
6. 주소 `https://cgg-test.pages.dev` (정한 이름으로) 를 열어 로그인 화면이 나오면 준비 끝이에요.

## 다음부터 새 판을 올릴 때 (휴대폰, 1분)
Cloudflare는 `cgg-test-site` 가지가 바뀔 때만 올려요. 방들은 `main` 에만 저장하니,
**대표님이 「main → cgg-test-site 로 옮기기」를 눌러야** 새 판이 올라가요. 이게 대표님의 「배포」예요.
1. 홈페이지·앱 방이 「새 판 저장소에 올렸어요」라고 알려 드려요. 보안 방 「통과」를 확인해요.
2. 휴대폰에서 아래 주소를 열어요 (즐겨찾기 해 두면 편해요).
   `https://github.com/xorduddl0823-ship-it/chagotgan/compare/cgg-test-site...main`
3. 초록 단추 **Create pull request** → 한 번 더 **Create pull request** → **Merge pull request** → **Confirm merge** 를 차례로 눌러요.
4. 1~2분 뒤 시험 주소를 새로고침하면 새 판이에요. 로그인 화면 맨 아래 판 번호(예: 「통합 v2」)로 확인할 수 있어요.

## 알아 두실 것
- 이 주소는 인터넷에 열려 있어요. 다만 로그인은 경비실(서버)이 검사하니, 허락된 계정만 들어가요. 검색 사이트에는 안 뜨게 막아 두었어요.
- 시험 주소에서 로그인한 기록은 app.cgg.co.kr 과 **섞이지 않아요**. (주소가 다르면 휴대폰이 따로 보관해요)
- 시험이 끝나면 cgg-test 칸을 지워도 손님 화면에는 아무 영향이 없어요.
- 메뉴 이름이 위와 조금 다르게 보이면, 화면을 찍어 보내 주세요. 맞는 단추를 찾아 드릴게요.

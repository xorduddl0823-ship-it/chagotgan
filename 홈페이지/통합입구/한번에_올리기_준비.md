- 목록 한 곳: `도구/올림/올릴_목록.txt` (방이 고쳐요).
- 올림 명령: `bash 홈페이지/통합입구/도구/올림/pages_build.sh 묶음`
  - 시험 주소 안의 「로그인 · 결제하기」는 손님 주소(app.cgg.co.kr)가 아니라 시험 주소의 통합 입구(`/`)로 가게 바꿔서 올려요.
  - 사업자 정보 칸은 `공통/사업자정보.json` 최신 값으로 다시 채워요. 검색 막기 · 끼워 넣기 막기 머리말은 그대로예요.

## 순서
1. 각 방: 새 J안 판 완성 → 보안 방 통과
2. 홈페이지·앱 방: 통합 입구 v6 묶기, 홈페이지 시안 다시 만들기, `올릴_목록.txt` 판 이름 바꾸기 → 가짜 서버 시험 → 보안 방에 «묶음» 검사 요청
3. 대표님: Cloudflare cgg-test 의 만드는 명령을 **`bash 홈페이지/통합입구/도구/올림/pages_build.sh 묶음`** 으로 한 번 바꾸기 (설정 › 빌드 › 명령)
4. 대표님: `main → cgg-test-site` 옮기기 (휴대폰 단추 4번, `휴대폰_시험_올리는_법.md` 맨 위) → 시험 순서표대로 한 번에 시험

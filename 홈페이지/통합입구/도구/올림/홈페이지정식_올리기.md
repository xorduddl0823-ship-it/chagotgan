# 실제 메인 홈페이지(cgg.co.kr) → 홈페이지 v2 올리기 · 되돌리기 — 대표님용 한 장

> 홈페이지·앱 방 · 2026-10-19 · 올리기는 대표님만 해요.
> **시험 주소(https://t.cgg.co.kr/home/)에서 v2 확인이 끝난 뒤에** 올려요.
> 올릴 파일: 총괄 방이 보내는 `홈페이지정식_v2_<번호>.zip` (만드는 법: `bash 홈페이지/통합입구/도구/올림/zip_만들기.sh`)

## 먼저 알아 둘 것
- 저장소 기록에는 **지금 cgg.co.kr 이 어느 Cloudflare 칸에, 어떤 파일로 올라가 있는지 적혀 있지 않아요.**
  그래서 1단계에서 대표님이 Cloudflare 화면으로 확인해요.
- 지금 홈페이지의 약관 주소(https://cgg.co.kr/terms.html · privacy.html · refund.html)는 **같은 칸 안에 있을 수 있어요.**
  Cloudflare 는 올릴 때 안에 든 것을 **통째로 바꿔요.** 그래서 **지난번 폴더에 파일을 더하거나 바꿔 넣는 방식**으로 올려요.
- zip 안에 든 것

| 파일 | 무엇 |
|---|---|
| `index.html` | 새 홈페이지 v2 (보안 검사 통과) |
| `join.html` | 회원가입 화면 (홈페이지의 «회원가입» 단추가 여는 곳 · 보안 검사 통과) |
| `og.png` | 카톡 · 검색에 주소를 보낼 때 뜨는 그림 |
| `robots.txt` · `sitemap.xml` | 검색 사이트에 «이 홈페이지를 찾아 가도 돼요»를 알려 주는 파일 |
| `_headers` | 다른 사이트가 이 화면을 몰래 품지 못하게 막는 파일 |

## 1단계 — 지금 올라가 있는 곳 찾기 (2분)
1. 이 주소를 열어요: https://dash.cloudflare.com/?to=/:account/workers-and-pages
2. 목록에서 **cgg.co.kr 이 연결된 칸**을 찾아요(칸 이름 옆이나 안쪽 «Custom domains»에 cgg.co.kr 이 보여요).
3. 칸 이름을 사진으로 찍어 총괄 방에 보내 주세요. (못 찾으면 여기서 멈추고 총괄 방에 알려 주세요)
4. https://cgg.co.kr 을 열어 첫 화면을 사진으로 찍어 둬요. 이게 되돌릴 판이에요.

## 2단계 — 올리기 (5분)
1. 받은 zip 을 풀어요.
2. **지난번 cgg.co.kr 에 올린 폴더**를 통째로 복사해요.
3. 복사한 폴더 맨 위에 1번에서 푼 zip 안의 `index.html` 을 바꿔 넣어요.
   - `join.html` 은 폴더에 **없을 때만** 넣어요. 이미 있으면 **올리지 말고 여기서 멈춘 뒤** 총괄 방에 알려 주세요.
   - `_headers` 도 **없을 때만** 넣어요. 이미 있으면 그대로 둬요. 그 `_headers` 에 `X-Robots-Tag` 줄이 있으면 **올리지 말고** 총괄 방에 알려 주세요(검색에 안 나오게 막는 설정이에요).
   - `og.png` · `robots.txt` · `sitemap.xml` 은 넣어요(있으면 바꿔 넣어요).
   - `terms.html` · `privacy.html` · `refund.html` 같은 다른 파일은 **건드리지 않아요.**
4. 이 주소를 다시 열어요: https://dash.cloudflare.com/?to=/:account/workers-and-pages
5. 1단계에서 찾은 칸을 눌러요.
6. 오른쪽 위 **Create deployment** 단추를 눌러요. 이 단추가 안 보이면 **여기서 멈추고** 총괄 방에 알려 주세요.
7. 3번 폴더를 끌어다 놓아요.
8. **Deploy** 단추를 눌러요.

> 지난번 폴더가 PC에 없으면 **올리지 말고** 총괄 방에 알려 주세요. zip 만 올리면 약관 파일이 사라질 수 있어요.

## 3단계 — 확인 (3분)
1. 1분 뒤 https://cgg.co.kr 을 열고 **Ctrl + F5** 를 눌러요.
2. 첫 문구가 «차를 맡는 순간부터, 정산을 마치는 순간까지.» 면 성공이에요.
3. 맨 아래 «이용약관» 을 눌러요. 약관이 열리면 돼요(개인정보처리방침 · 환불 규정도 같아요).
4. 맨 위 «로그인» 을 눌러요. https://app.cgg.co.kr 이 열리면 돼요.
5. «미리 써 보기» 에서 워시 · 체크 · 딜러 단추를 눌러요. 예시 화면이 열리면 돼요.
6. https://cgg.co.kr/robots.txt 를 열어요. «Allow: /» 가 보이면 돼요.

## 이상하면 — 되돌리기 (1분)
1. 이 주소를 열어요: https://dash.cloudflare.com/?to=/:account/workers-and-pages
2. 1단계에서 찾은 칸을 눌러요.
3. 위쪽 **Deployments**(올린 기록) 탭을 눌러요.
4. 맨 위 줄이 방금 올린 판이에요. 그 **바로 아래 줄** 오른쪽 **⋯** 를 눌러요.
5. **Rollback to this deployment**(이 판으로 되돌리기)를 눌러요.
6. 1분 뒤 https://cgg.co.kr 에서 **Ctrl + F5** 를 눌러요. 1단계 사진과 같으면 돌아온 거예요.
- 저장소의 지금 홈페이지 파일 `홈페이지/소개/소개_시안.html` 도 지우지 않고 남겨 뒀어요.

## 참고
- 이 zip 의 홈페이지는 **검색 사이트에 나와요**(총괄 결정 10/19). 시험 주소 · 회원가입 화면은 그대로 검색에 안 나와요.

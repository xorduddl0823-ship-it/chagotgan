# 사업자 정보 칸 — 채우는 법 (대표님용)

**한 곳만 채우면 돼요: `홈페이지/공통/사업자정보.json`**
- `{상호}` 처럼 중괄호로 된 칸을 실제 값으로 바꿔요. (예: `"대표자": "홍길동"`)
- 비워 두거나 중괄호 그대로면 그 줄은 화면에 안 나와요. 신고번호만 「신고 진행 중」으로 나와요.
- 사업자등록번호를 넣으면 공정거래위원회 「사업자정보 확인」 링크가 저절로 생겨요.
- 휴대폰에서 고치려면: GitHub 앱이나 사이트에서 이 파일을 열고 ✏️(연필) → 고치기 → 「Commit changes」. 어렵다면 값만 홈페이지·앱 방에 보내 주세요.

0\. 한눈에 보기

1.  딜러 정보는 '딜러 본인에게 직접 받은 것'만 쓴다. 경기조합(카모두)
    장부에서 옮긴 번호는 누가 입력했든 쓰지 않는다.

2.  딜러는 휴대폰 번호 + 인증번호로 가입하고, 이 번호가 딜러를 알아보는
    열쇠가 된다. 이름은 열쇠가 아니다.

3.  차량을 딜러에게 붙이는 게 아니라, '입고 건(작업)'을 딜러에게 붙인다.
    그래야 차가 팔려 다른 딜러에게 가도 섞이지 않는다.

4.  자동 연결은 '번호 + 이름이 둘 다 맞을 때'만. 조금이라도 애매하면
    딜러 확인 또는 업체 확인을 거친다.

5.  '그 딜러에게만 보이게'는 화면이 아니라 서버에서 막는다. 남의 차
    정보는 앱으로 아예 내려오지 않는다.

6.  가온 성능점검은 나중에 '업체 하나'로 같은 통로에 붙이면 된다. 지금은
    칸만 비워 둔다.

2-4. 이미 카모두에서 옮겨 등록한 번호 정리 방법

1.  모든 딜러 연락처에 '출처' 칸을 추가하고, 카모두에서 옮긴 번호는
    \[카모두\]로 표시한다.

2.  \[카모두\] 번호로는 가입 안내 문자 · 알림톡 등 새로운 연락을 보내지
    않는다.

3.  업체가 입고 때 딜러에게 직접 번호를 다시 확인하면 출처를 \[직접
    받음\]으로 바꾼다.

4.  딜러가 앱에 직접 가입하면 그 번호로 대체하고, 남은 \[카모두\] 번호는
    정해진 날짜(예: 3개월 뒤)에 일괄 삭제한다.

4\. 차량 매칭 방법

4-1. 핵심: 차량이 아니라 '입고 건'을 딜러에게 붙인다

12가0987을 영원히 김지현 차로 정하면, 그 차가 팔려 다른 딜러가 가져왔을
때 김지현에게 새 딜러 정보가 보이는 사고가 납니다. 그래서 입고할 때마다
'이번 입고는 누구 건인지'를 정합니다.

| **차량번호** | **입고일** | **업체** | **거래처(딜러)**         | **김지현 앱** | **박민수 앱** |
|--------------|------------|----------|--------------------------|---------------|---------------|
| 12가0987     | 09-02      | OO광택   | 두드림 김지현            | 보임          | 안 보임       |
| 12가0987     | 09-20      | OO리페어 | 두드림 김지현            | 보임          | 안 보임       |
| 12가0987     | 11-05      | OO광택   | 한빛 박민수 (차 판매 후) | 안 보임       | 보임          |

4-2. 업체 입고 화면 흐름

1.  차량번호 입력 (카메라로 번호판 인식도 가능하게)

2.  같은 업체에 최근 90일 안 같은 차량 입고 기록이 있으면 → '지난번
    딜러: 두드림 김지현(연락처 뒤 4자리) 맞나요?' 제안

3.  딜러는 글자로 새로 적지 않고 거래처 카드 목록에서 고른다. 목록에는
    \[이름 · 상사명 · 연락처 뒤 4자리\]를 같이 보여 동명이인을 구분한다.

4.  처음 오는 딜러면 '새 거래처 카드' 만들기 → 이름 · 상사 · 연락처 ·
    출처 입력

5.  저장하면 작업(입고 건)이 거래처 카드에 붙고, 카드가 딜러 계정과
    '확정' 연결돼 있으면 딜러앱에 바로 뜬다.

4-4. 연결 상태 5가지

| **상태**     | **딜러앱에 보이나**   | **설명**                                     |
|--------------|-----------------------|----------------------------------------------|
| 후보         | 안 보임               | 시스템이 찾아 둔 연결 후보                   |
| 딜러확인대기 | 안 보임               | 딜러가 '내 거래 맞음'을 눌러야 함            |
| 업체확인대기 | 안 보임               | 업체가 '이 딜러 맞음'을 눌러야 함            |
| 확정         | 보임                  | 이 카드에 붙은 모든 입고 건이 딜러앱에 보임  |
| 끊김         | 안 보임 (이후 건부터) | 잘못 연결 · 딜러 퇴사 · '내 차 아님' 신고 등 |

5\. 동명이인 및 예외 상황 해결법

| **상황**                             | **문제**                    | **해결**                                                                                        |
|--------------------------------------|-----------------------------|-------------------------------------------------------------------------------------------------|
| 같은 상사에 김지현 2명               | 이름 · 상사로 구분 불가     | 연락처 필수. 업체 목록에 연락처 뒤 4자리 표시. 자동 후보에서 제외하고 업체가 직접 지정          |
| 다른 상사에 김지현                   | 이름만 같음                 | 상사명으로 구분. 상사명은 상사코드로 관리(두드림 / (주)두드림 표기 차이 흡수)                   |
| 업체가 번호를 잘못 입력              | 엉뚱한 딜러에게 연결될 위험 | 번호 + 이름이 둘 다 맞아야 자동 연결. 번호만 맞으면 업체 확인                                   |
| 상사 공용 전화 하나를 여러 딜러가 씀 | 한 번호에 여러 사람         | 딜러 계정은 개인 휴대폰만 허용. 공용 번호는 상사 대표 보기 기능(나중)으로 분리                  |
| 딜러가 상사를 옮김                   | 소속이 바뀜                 | 딜러코드는 그대로, 소속 장부에 종료일 · 새 상사 추가. 예전 입고 건은 계속 본인에게 보임         |
| 차가 팔려 다른 딜러가 입고           | 이전 딜러에게 보이면 안 됨  | 입고 건 단위 연결이라 새 입고는 새 딜러에게만 보임 (4-1)                                        |
| 번호판 변경                          | 같은 차가 다른 번호         | 작업에 차대번호(선택) 칸. 있으면 차대번호로 이력 묶기                                           |
| 딜러 휴대폰 번호 변경                | 로그인 불가                 | 새 번호로 재인증 후 기존 계정 이어받기(이전 번호 인증 또는 업체 확인)                           |
| 딜러가 '내 차 아님' 누름             | 잘못 연결                   | 그 입고 건 연결 즉시 끊김 → 업체에 알림 → 업체가 올바른 딜러 지정                               |
| 딜러 탈퇴                            | 정보 삭제                   | 딜러 계정 · 동의 정보 삭제, 업체의 입고 · 청구 기록은 세법상 보관 기간 동안 업체 쪽에만 보관    |
| 한 차가 여러 업체를 거침             | 업체마다 따로 등록          | 각 업체 입고 건이 모두 같은 딜러에게 모여 한 화면에 보임. 위치 공유는 딜러가 선택 동의한 경우만 |

걸어, 조건에 맞지 않는 줄은 아예 앱으로 보내지 않습니다.

6-2. 딜러앱 '내 차량 장부' 화면 칸

| **칸**          | **설명**                     |
|-----------------|------------------------------|
| 차량번호        | 고정 칸 (옆으로 밀어도 보임) |
| 차종            |                              |
| 업체            | 워시 / 휠 / 리페어 업체명    |
| 입고일 · 출고일 |                              |
| 진행 상태       | 대기 / 작업 중 / 완료 / 출고 |
| 현재 위치       | 위치 공유 동의 시            |
| 금액 · 청구서   | 청구서 보기 버튼             |
| 입금 여부       | 입금 / 미입금                |
| 내 차 아님      | 잘못 연결 신고 버튼          |

화면에는 정렬(오름/내림차순) · 검색 · 보기 개수(5/10/20/30/50) 선택을
기본으로 넣습니다.

7\. 개발 순서

| **단계** | **할 일**                                                             | **결과**                     |
|----------|-----------------------------------------------------------------------|------------------------------|
| 1        | 장부 5개(3장) 만들기 + 출처 칸 추가 + 기존 번호 출처 표시             | 카모두 번호 분리 완료        |
| 2        | 업체 입고 화면: 거래처 카드 선택 방식, 동명이인 표시(뒤 4자리)        | 입고 건이 카드에 정확히 붙음 |
| 3        | 딜러앱 가입: 휴대폰 인증 → 동의 화면 → 동의 기록 저장                 | 합법적인 가입 경로           |
| 4        | 연결 규칙(4-3)과 연결 상태 5가지, 확인 버튼들                         | 자동 · 수동 연결             |
| 5        | 서버 규칙(6-1) 적용 후, 다른 딜러 계정으로 남의 차가 안 보이는지 시험 | 보안 확인                    |
| 6        | 딜러앱 내 차량 장부 화면 · '내 차 아님' 신고                          | 딜러 사용 시작               |
| 7        | 업체 간 위치 공유(선택 동의자만)                                      | 위치 공유                    |
| 8        | (나중) 가온 연결 통로 열기 — 8장                                      | 성능점검 연결                |

8\. 가온 성능점검 프로그램 연결 통로 (나중을 위해 지금 준비)

가온 성능점검 프로그램은 별도 프로그램이고 별도 사업자입니다. 지금
합치지 않고, 나중에 '차곳간에 붙는 업체 하나'로 같은 통로를 쓰게 설계해
둡니다.

8-1. 지금 해 둘 것

- 업체 장부의 업종에 \[성능점검\]을 미리 만들어 두고, 가온진단평가를
  업체코드(예: G0001)로만 등록해 둔다. 데이터는 넣지 않는다.

- 작업(입고 건) 장부에 '작업 종류' 칸을 둔다: 광택 / 세차 / 휠 / 판금 ·
  도색 / \[성능점검\]. 성능점검 전용 칸(점검번호 · 검사일 · 재검사
  만료일)은 비워 둔다.

- 딜러앱 동의 화면에 버전 관리를 해 둔다. 가온 연결 때 동의 항목을 하나
  추가하고, 기존 딜러에게 다시 받을 수 있도록.

8-2. 나중에 가온을 연결할 때 주고받을 칸

| **보내는 칸**       | **설명**                                                       |
|---------------------|----------------------------------------------------------------|
| 업체코드            | G0001 (가온진단평가)                                           |
| 차량번호 · 차대번호 | 점검 차량                                                      |
| 점검번호 · 검사일   | 성능점검 번호, 검사일 (재검사 만료일은 차곳간이 +120일로 계산) |
| 딜러 연락처         | 가온이 딜러에게 직접 받은 번호만 (카모두 출처 금지)            |
| 청구 · 입금 여부    | 필요 시                                                        |

8-3. 가온 연결 때 지켜야 할 것

- 가온 → 티와이컴퍼니로 정보가 넘어가므로, 딜러앱에서 '가온진단평가
  성능점검 내역 연결' 동의(선택)를 받은 딜러만 연결한다.

- 연결 방법은 워시 · 휠 · 리페어와 똑같이 거래처 카드 → 연결 규칙(4-3)을
  그대로 쓴다.

- 카모두 장부에서 온 정보는 통로로 보내지 않는다 (출처 칸으로 걸러냄).

9\. 택영님이 정해 주실 것

- 자동 제안 기간: 같은 차 재입고 시 지난 딜러를 제안하는 기간 (기본 90일
  제안)

- \[카모두\] 출처 번호 삭제 날짜 (예: 3개월 뒤)

- 딜러 번호 변경 시 본인 확인 방법 (이전 번호 인증 / 업체 확인 중
  무엇으로)

- 위치 공유 동의를 선택으로 둘지, 위치 공유를 쓰는 업체와 거래 시 필수로
  둘지

10\. 전문가 검토 받을 목록

1.  딜러앱 이용약관 · 개인정보 수집 · 이용 안내 · 업체 연결 동의 · 위치
    공유 동의 문구

2.  업체용 차곳간 이용약관의 처리 위탁 조항 · 외부 명단 사용 금지 조항

3.  업체들이 자기 처리방침에 넣을 위탁 안내 문구

4.  티와이컴퍼니 개인정보처리방침 전체

5.  가입 안내 문자 · 알림톡이 광고성 정보에 해당하는지 여부

6.  (나중) 가온 → 티와이컴퍼니 제공 동의 문구

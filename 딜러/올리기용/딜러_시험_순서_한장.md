# 딜러앱 시험 순서 한 장 (대표님 휴대폰용 · ④)

주소: **cgg-test.pages.dev/dealer/** (판 d3.7 · 맨 위에 남색 «오픈 베타» 띠가 보이면 맞아요)

## 0. 먼저 (안 하면 차 · 청구서가 비어 있어요)
- **워시 › 입고**에서 차를 하나 넣을 때 **«딜러 연락처» 칸에 대표님 번호**를 넣고 «입고 등록». 딜러앱은 이 번호로 차를 찾아요.
- 청구서까지 보려면: **워시(PC) › 월별 청구서 › 그 거래처 줄 › «이 곳에 보내기»**. 받는 번호가 **대표님 번호**여야 해요.
- 체크 기사 앱으로 도착을 찍을 때도 «딜러 연락처» = 대표님 번호.

## 1. 인증번호
- 휴대폰 번호(대표님 번호) → «인증번호 받기».
- **카톡 «차곳간»**으로 6자리가 와요. 카톡이 안 되면 문자로 와요. → 6칸에 넣고 «로그인».
- 확인: 안내 글이 «…번호로 인증번호를 발송했습니다. 5분 안에 입력해 주세요.»

## 2. 약관 (처음 한 번만)
- «모두 동의» 또는 필수 2개 체크 → «동의하고 시작하기».
- 확인: 필수 하나를 빼고 누르면 «필수 항목 2개에 동의해야 시작할 수 있습니다.»

## 3. 내 차
- 아래 탭 **«내 차»** → 0번에서 넣은 차가 보여요 (단계: 입고 / 작업 중 / 출고 / 도착).
- 차를 누르면 «차 상세» 창: 사진 · 상품화 진행 기록. **«닫기»**로 닫아요.
- 도착한 차는 «상품화 완료»를 눌러 볼 수 있어요 (다시 «상품화 완료 취소» 가능).

## 4. 청구서 — 금액 · 계좌 복사
- 아래 탭 **«청구서»** → 업체별 금액 · 입금 기한 · 계좌가 보여요.
- **«계좌 복사»** → «계좌를 복사했어요» 알림 → 은행 앱에 붙여 넣어 보기 (실제 입금은 안 해도 돼요).
- **«금액 복사»**도 같은 방법. «내역 보기»를 누르면 업체가 보낸 청구서 화면이 열려요.
- 차곳간 앱 안에서는 결제하지 않아요 («한 번에 결제는 곧 열려요»가 맞아요).

## 5. 로그아웃
- 아래 탭 **«전체» › «내 정보»** → 맨 아래 **«로그아웃»** → 창에서 «로그아웃».
- 확인: 로그인 화면으로 돌아가고, **번호 칸이 비어 있으면** 정상이에요 (기기에 남은 정보를 지워요).

## 이상하면
- 화면 캡처 + 시각 + 무엇을 눌렀는지 → **총괄 방**으로. 딜러 방이 그날 고쳐요.
- 자주 나올 수 있는 글 (정상): «30초 뒤에 다시 받아 주세요» · «오늘은 인증번호를 더 받을 수 없습니다» · 청구서 칸 «준비하고 있어요»(서버 준비 전).

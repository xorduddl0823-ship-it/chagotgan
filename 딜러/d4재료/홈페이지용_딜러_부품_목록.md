# 홈페이지 «미리 써 보기» 딜러 묶음에 쓰는 딜러앱 d4.1 부품 목록

> 작성: 딜러 방 (2026-10-19) · 읽는 곳: 홈페이지·앱 방
> 근거: 총괄 후속 일감 «미리 써 보기 딜러 묶음에 d4.0 부품(.lg · .dbill · .dph)을 쓸 수 있게 정리»
> 부품 모양은 d4.0 과 d4.1 이 똑같아요. d4.1 에서는 찾기 칸 안내 글만 바뀌었어요.

## 0. 먼저 붙일 것 (순서 그대로)
1. 공통 부품 `디자인/공통/cgg-j4-1.13.2.css` — 아래 부품은 이 판의 색 이름(토큰)만 써요:
   `--bg --surface --text --muted --line --ln2 --navy --blue --sky --tabon --chk-bg --chk-ink --stop-ink --r-card --r-ctl --sh --sec-gap --ctl`
2. 딜러 부품 `딜러/d4재료/dealer-d4.1.css` — **읽기만 하고 복사해서** 쓰세요. 이 파일은 딜러 방 서랍이라 고칠 일이 생기면 딜러 방에 요청해 주세요.
   - 필요한 부분만 떼어 쓸 때: 맨 앞 바탕(3~5째 줄 — 글꼴 · 줄바꿈 · 숨김 칸)을 꼭 함께 붙이고, ② 로그인 · 이용 동의(`.lg…`, 7~34째 줄)와 ③ 화면 안 상자(`.bx`부터 끝까지, 36~66째 줄)
3. 상태 칩(입금 전 · 기한 지남 · 입금 확인)은 공통 부품 `CGG.status(말, 색표)`로 만들어요.

## 1. `.lg` — 로그인 · 이용 동의 카드 (앱 틀 밖, 가운데 카드 하나)
미리 써 보기는 «로그인 화면 없이 바로 홈»이 기준(`디자인/02_미리써보기_연출_기준.md` 2번)이라, 이 부품은 **«이렇게 로그인해요» 보여 주기용**으로만 쓰세요. 입력 칸은 실제로 보내지 않게(버튼 눌러도 서버 안 부름) 해 주세요.

```html
<div class="lg">
  <div class="lg-demo">시연 화면 — 실제 자료가 아니에요</div>      <!-- 미리 써 보기에서는 넣어 주세요 -->
  <div class="lg-card">
    <div class="lg-brand"><span class="ci"><img src="(CGG.CI.white)" alt="" width="28" height="28"></span>차곳간 딜러</div>
    <h2>휴대폰 번호로<br>시작하기</h2>
    <p>업체에 알려 주신 번호로 로그인하면 맡긴 차가 바로 보입니다. 비밀번호는 필요 없습니다.</p>
    <label class="t" for="ph">휴대폰 번호</label>
    <input class="lg-in" id="ph" type="tel" inputmode="numeric" placeholder="010-0000-0000">
    <button type="button" class="cgg-btn pri">인증번호 받기</button>
    <p class="lg-foot">처음 로그인하면 이용약관 · 개인정보 동의 화면이 한 번 나옵니다.</p>
  </div>
</div>
```
- 인증번호 6칸: `<div class="lg-otp">` 안에 `<input type="tel" maxlength="1">` 6개
- 오류 글: `<p class="lg-err" role="alert">…</p>` · 글자 단추: `<button class="lg-link">`
- 이용 동의: `.lg-note`(안내 상자) · `<label class="lg-all">`(모두 동의, 남색 띠) · `.lg-list > .lg-row`(항목 한 줄 + «보기») · `.lg-doc`(약관 글 펼침)
- `.lg` 는 화면 높이를 꽉 채워요(min-height:100dvh). 미리 써 보기 틀 안에 넣을 때는 감싸는 칸에서 `min-height` 를 덮어써 주세요.

## 2. `.dbill` — 청구서 카드 (업체 · 달마다 한 장)
```html
<div class="dbills">                                  <!-- 카드 여러 장을 바둑판으로 (한 장 최소 280px) -->
  <section class="bx dbill">
    <div class="dbh"><b>예시 광택</b>(CGG.status("기한 지남",{"입금 전":"chk","기한 지남":"stop","입금 확인":"done"}))</div>
    <p class="d">10월 · 3대 · 이딜러</p>
    <div class="dbm"><strong>780,000<small>원</small></strong><span class="late">기한 3일 지남</span></div>
    <div class="dacct">예시은행 000-0000-0000 예시 광택</div>   <!-- 입금 전일 때만 -->
    <div class="row">
      <button type="button" class="cgg-btn">계좌 복사</button>
      <button type="button" class="cgg-btn">금액 복사</button>
      <button type="button" class="cgg-btn pri">내역 보기</button>   <!-- 입금 전이면 파란 단추 -->
    </div>
  </section>
</div>
```
- 기한 글: 기한 지난 것만 `<span class="late">`(빨간 굵은 글), 나머지는 그냥 `<span>`
- 입금 확인된 카드: 계좌 줄(`.dacct`)과 복사 단추를 빼고, «내역 보기»는 흰 단추
- 금액이 0 이면 «0원»으로 적어요(완성 기준 F06). 업체가 아직 금액을 안 넣었다는 뜻이에요.
- 계좌 번호는 **지어낸 번호**만(예: 예시은행 000-0000-0000). 진짜 계좌 · 업체 이름은 쓰지 않아요.

## 3. `.dph` — 차 사진 칸 (차 상세 창 안)
```html
<!-- 사진이 있을 때: 누르면 크게 보기 -->
<button type="button" class="dph" aria-label="사진 3장 크게 보기">
  <img src="(예시 사진 주소)" alt="출고 사진"><small>출고 사진 · 3장 · 눌러서 보기</small>
</button>
<!-- 사진이 없을 때 -->
<div class="dph" role="img" aria-label="사진 없음">사진 없음</div>
```
- 높이 160px · 모서리 둥근 회색 판. 사진은 판을 꽉 채워요(object-fit:cover).
- 크게 보기 창 안: `<div class="dphoto"><figure><img …><figcaption>출고</figcaption></figure>…</div>`
- 미리 써 보기에서는 «사진 없음» 판을 쓰거나, 차곳간 저장소 안의 예시 사진만 쓰세요(밖 사이트 사진 주소 금지).

## 4. 같이 쓰면 좋은 상자
- `.bx`(흰 카드) · `.bx h3` · `.bx p.d`(회색 설명) · `.row`(단추 줄) · `.ck`(체크 한 줄)
- `.dlog`(차 진행 기록 목록, `li.now` 가 지금 단계) · `.ddoc`(긴 글 상자) · `.dver`(판 이름 작은 글)

## 5. 지킬 것
- 사용자 · 예시 글은 모두 글자 그대로(HTML 아님) 넣어 주세요. 딜러앱은 모든 글을 `esc` 로 거쳐요.
- 예시 이름은 지어낸 것만: 예시 검사소 · 예시 광택 · 가람 광택 · 예시 리페어 · 예시상사 · 이딜러
- 미리 써 보기는 딜러 서버(dealer-api)를 부르지 않아요. 딜러앱 시연 자료(`demoApi`)와 같은 모양의 예시 자료를 화면 안에 두면 돼요.
- 상태 말과 색: 입고 · 작업 중 · 출고 → run · 도착 → chk · 상품화 완료 → done / 입금 전 → chk · 기한 지남 → stop · 입금 확인 → done

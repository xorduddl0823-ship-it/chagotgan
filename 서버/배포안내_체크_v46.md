## v46에 새로 들어간 것 (대표님 «세금계산서 매우매우 중요»)
1. **세금계산서는 입금한 곳만** — 청구 금액이 다 들어온 청구서만 발급해요. 화면뿐 아니라 **서버에서도 막아요.**
   - 꼭 먼저 끊어야 하면 대표님이 «입금 전 발급»을 골라서 발급할 수 있어요. 그때는 그 표시와 기록이 남아요.
   - 발급 목록에 «입금 금액 · 남은 금액»이 보여요.
2. **전산외(나스 엑셀)** — 엑셀 금액(부가세 포함) 그대로 청구해요. «계산서발행(Y/N)» · «사유»를 저장하고, **N인 차 금액은 세금계산서에서 빼요**(청구서에는 그대로 들어가요).
   - 매출 화면에서 전산외는 검사비와 따로 보여요.
3. **정비비** — 지금 창구 그대로 돼요(바뀐 것 없음).
4. **보험료 부가세 설정** — 설정에서 «미포함»(기본) / «포함»을 골라요. 매출 화면 보험료 합계(부가세 포함)에 써요.
5. **정산 기록** — 달마다 «청구서 몇 장 · 세금계산서 몇 장»이 보여요.

## 올린 뒤 확인 (가온)
- 단가표 «가온 규칙으로 맞추기» → 10월 청구서 다시 만들기 → 검사비 **3,927,000원**(v44 안내와 같음).
- 아직 입금 안 된 청구서로 세금계산서 발급을 눌러 봐요 → «아직 입금 전입니다 (남은 금액 ○원)»가 나오면 맞아요.
- 다 입금된 청구서는 지금처럼 발급돼요.

## 바뀐 곳 (서버 방 기록 · v45 → v46)
- `taxList` 줄마다 `paid · left · notax · unpaidOk` · 남은 금액이 있고 아직 발급 전이면 `can:false` + 까닭.
- `taxIssue(ids, writeDate, dates, opt)` — 남은 금액이 있으면 거절 · `opt.unpaidOk:[청구서id]`만 예외(대표만 · `tax_unpaid_ok_at` 표시를 못 남기면 발급 안 함 · 기록 «입금 전 발급») · 세금계산서 금액 = 청구 − 계산서발행 N 전산외.
- `invoiceBuild` 전산외 줄 = 엑셀 금액 그대로(단가 = 금액÷1.1). `excelPut` 전산외에 `tax_yn`(Y/N · 빈 칸 Y) · `tax_note`(100자 · < > 거름) — SQL 20 전이면 두 칸만 빼고 저장.
- `salesStat` 달마다 `ext`(전산외 · fee 에서 뺌) · `total = fee + ext + rep` · `insTotal · insVat` · `made · taxN`, 해마다 `ext`.
- `officeGet/officeSave` `ins_vat`(«미포함» / «포함»만).
- 시험: `서버/시험/체크v46_세금계산서_전산외_시험.ts` 19개 통과(v45로는 19개 실패). 체크 v44 19개 · v45 28개와 기존 체크 시험 결과는 v45와 같음.

# 체크 서버 v45 올리기 안내 (대표님용 · 2026-10-18)

> **v45 = v44(가온 검사비 바로잡기) + 체크 v50 «준비 중» 단추 창구 5개.**
> v44를 아직 안 올리셨으면 v44는 건너뛰고 **v45 한 판만** 올리시면 돼요(v44 내용이 모두 들어 있어요).

## 새로 되는 것 (모두 대표님만 · 이 검사소 것만)
1. **청구서 지우기** — 고른 청구서를 지워요. 세금계산서를 발급했거나 입금된 청구서는 지우지 않고 까닭을 알려 줘요. «청구서 만들기»를 다시 누르면 다시 생겨요.
2. **보냄 표시 지우기** — 보낸 시각 · 열어본 시각만 비워요. 바로 다시 보낼 수 있어요. 발송 기록은 그대로 남아요.
3. **알림톡 템플릿** — 체크에서는 **보기만** 해요(넣었는지만 보여 줌). 템플릿 코드는 지금처럼 관리 → 알림 → 알림톡 템플릿에서 넣어요.
4. **검사자 수수료 규칙** — 켜기/끄기와 규칙(한 대마다 ○원 / 검사비 ○%)을 서버에 저장해요.
5. **문자 수집함 설정** — 수집함 주소 · 비밀번호를 서버에 저장해요. 비밀번호는 화면에 다시 보이지 않고 «넣음»으로만 보여요.

## 대표님이 하실 일 (순서대로)
1. **SQL 18 실행** (v44를 이미 올렸으면 건너뜀) — 수파베이스 → SQL Editor에 `서버/sql/18_체크_검사비_손입력.sql`(11줄)을 붙여 넣고 Run.
2. **SQL 19 실행** — 같은 곳에 `서버/sql/19_체크_검사소_설정.sql`(18줄)을 붙여 넣고 Run. 마지막 줄 «있음 = true»면 끝이에요.
3. **체크 서버 v45 올리기** — `서버/2_차곳간체크_서버_check-api_v45.ts`(4,429줄)를 check-api에 올려요(Verify JWT 끔).
4. v44 안내(`서버/배포안내_체크_v44.md`)의 «올린 뒤 확인»도 함께 해요(10월 검사비 3,927,000원).

## 올린 뒤 확인 (TEST 검사소에서)
- 월별 청구서에서 청구서 하나를 골라 «선택한 줄 지우기» → 목록에서 사라지면 돼요. 발급한 청구서를 고르면 «남김»과 까닭이 나와요.
- «선택한 곳 보냄 표시 지우기» → «안 보냄»으로 바뀌면 돼요.
- 알림톡 템플릿 화면에 «관리에서 넣음 · 보기만»이 보이면 돼요.

## 되돌리고 싶을 때
- `서버/2_차곳간체크_서버_check-api_v44.ts`(또는 v43)를 다시 올리면 돼요. SQL 18 · 19는 칸과 표를 더하기만 해서 그대로 둬도 괜찮아요.
- 지운 청구서는 «청구서 만들기»로 다시 만들 수 있어요.

## 바뀐 곳 (서버 방 기록)
- 새 창구: `invoiceDel({ids, ym})` → `{n, kept:[{id,name,why}], missing}` · `invoiceUnsend({ids})` → `{n}`(«보냄» → «만듦») ·
  `tplInfo()` → `{readOnly, where, profile, bill, deposit, remind, arrive}`(있음/없음만, 코드 글 없음) · `tplSave` 는 거절(«관리에서 넣어요») ·
  `feeRules()` 불러오기(누구나) / `feeRules({on, rules:[{who, how:"한 대마다"|"검사비 %", amt}]})` 저장(대표만 · 50개 · 금액 0~1천만 정수 · 비율 0~100 소수 한 자리) ·
  `smsConf()` → `{url, pwSet}` / `smsConf({url, pw})` 저장(대표만 · https 주소만 · pw 를 빼면 그대로 · 빈 글이면 지움 · 비밀번호는 응답·기록에 안 남김).
- 새 표 `check_office_conf`(RLS 켬 · 서버만). SQL 18·19 전에는 해당 창구만 «서버를 준비하는 중입니다» 안내.
- 시험: `서버/시험/체크v45_단추창구_시험.ts` 26개 통과(v44로는 15개 실패). 체크 v44 검사비 시험 19개와 기존 체크 시험 결과는 v44와 같음.
- 남은 것: 문자 수집함(구글 시트 Apps Script) 코드 · 폰 자동화 본문 글은 아직 정한 글이 없어요 — 수집함이 어떻게 입금을 넘겨줄지(서버가 묻기 / 수집함이 보내기) 정한 뒤 다음 판에서 만들어요.

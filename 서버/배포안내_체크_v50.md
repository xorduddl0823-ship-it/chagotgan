# 체크 서버 v50 올리기 안내 (대표님용 · 2026-10-18)

> **v50 = v49.1 + 재검사 알림 «알림톡 안 되면 문자»를 자동 보내기에도** (총괄 «대체 메시지 발송을 모든 알림에»). SQL 없음.

## 무엇이 바뀌나요
- 재검사 알림의 문자 문구를 ⑦ 확정본으로 바꿨어요. «[차곳간] 업체명 성능점검 만료 N대 · 가장 빠른 만료 ○ · 문의 ○»
- 재검사 알림톡이 승인되기 전에도 **«매일 자동 보내기»를 켤 수 있어요**. 그동안은 문자로 나가요.
- 다른 체크 알림(청구서 · 입금 확인 · 차량 도착)은 원래부터 «알림톡 안 되면 문자»예요.
- ⚠ 자동 보내기를 켠 검사소는 승인 전까지 **문자 비용이 늘어요**.
- 화면은 지금 «승인 전에는 자동 켜기 칸이 잠김»이에요. 체크 방이 다음 화면에서 이 잠금을 풀어야 바로 쓸 수 있어요. 서버만 올려도 지금 화면은 그대로 돌아가요.

## 대표님이 하실 일
1. `서버/2_차곳간체크_서버_check-api_v50.ts`(4,645줄)를 check-api에 올려요(Verify JWT 끔).

- 재검사 알림 → 직접 보내기를 내 번호로 시험해서 새 문구가 오면 돼요.

# 비즈고로 문자 보내기 — 대표님 할 일 한 장

> 지금은 **아무것도 바뀌지 않았어요.** 문자는 계속 솔라피로 나가요.
> 아래를 다 끝낸 뒤 «스위치»만 바꾸면 비즈고로 나가요. 문제가 생기면 스위치를 다시 솔라피로 돌리면 바로 예전처럼 돼요.

## 먼저 비즈고에 물어볼 것 (가장 중요)
- **«서버 IP 등록 없이 API를 쓸 수 있나요?»**
  - 비즈고는 허락한 서버 주소에서만 보내기를 받아요.
  - 우리 서버(Supabase)는 주소가 고정되지 않아요.
  - 안 된다고 하면 따로 방법을 정해야 해요. 답을 받으면 총괄 방에 알려 주세요.

## 1단계 — 비즈고 가입
1. 비즈고(bizgo.io)에 회사로 가입해요.
2. 사업자등록증 등 요청하는 서류를 올려요.

## 2단계 — 보내는 번호 등록
1. 비즈고 화면에서 «발신번호 등록»을 찾아요.
2. 지금 문자 보낼 때 쓰는 번호(차곳간 대표 번호 · 업체 발신번호)를 똑같이 등록해요.
3. 통신서비스 이용증명원 같은 서류를 내라고 하면 올려요.

## 3단계 — 카카오 채널 연결
1. 비즈고 화면에서 «카카오 채널(발신프로필) 등록»을 찾아요.
2. 지금 쓰는 차곳간 카카오 채널을 연결해요.
3. 연결되면 «발신프로필 키»가 나와요.

## 4단계 — 알림톡 템플릿 옮기기
1. 지금 승인된 알림톡 문구를 **글자 하나 바꾸지 않고** 비즈고에 그대로 등록해요.
2. 심사를 다시 받으면 비즈고가 새 «템플릿 코드»를 줘요.
3. 템플릿별 새 코드 목록을 총괄 방에 보내 주세요. 관리 화면에 넣는 칸은 따로 만들어요.

## 5단계 — 열쇠 받기
1. 비즈고 화면 «발송관리 › 연동관리»에서 «API Key»를 받아요.
2. 열쇠 값은 대화·문서 어디에도 적지 말아요.

## 6단계 — 열쇠 넣기 (Supabase)
1. Supabase › Edge Functions › Secrets(비밀값)에 들어가요.
2. 아래 이름으로 값을 넣어요. **이름만 아래와 같게** 넣으면 돼요.
   - `BIZGO_API_KEY` = 5단계에서 받은 API Key
   - `BIZGO_SENDER_KEY` = 3단계의 발신프로필 키
3. 처음에는 `BIZGO_ENV` = `sandbox`도 넣어요. 그러면 실제로는 안 나가는 «시험 서버»로 보내요.

## 7단계 — 스위치 바꾸기 (마지막)
1. 서버 새 판(워시 sb30 · 체크 v55)이 올라가 있어야 해요. 서버 방이 준비해 둔 판이에요.
2. 비밀값 `MSG_VENDOR` = `bizgo`로 넣어요.
3. 시험 업체로 문자를 하나 보내서, 대표님 휴대폰에 오는지 봐요.
4. 잘 오면 `BIZGO_ENV`를 지워서 운영으로 바꿔요.
5. 문제가 생기면 `MSG_VENDOR`를 `solapi`로 바꾸거나 지워요. 그러면 바로 솔라피로 돌아가요.

## 알아 둘 것
- 사진 붙인 문자(MMS)는 비즈고에서 당분간 **사진 없이 긴 문자**로 나가요.
- 예약 문자는 당분간 솔라피에서만 돼요.
- 관리 화면 잔액은 솔라피 것만 보여요. 비즈고 잔액은 비즈고 화면에서 봐요.

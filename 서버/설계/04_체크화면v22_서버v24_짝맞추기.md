# 체크 화면 v22 ↔ 체크 서버 v23·v24 짝 맞추기 (2026-10-15, 서버 방)

대조한 파일: `체크/2_차곳간_체크_index_v22.html` (사무실 화면) ↔ `서버/2_차곳간체크_서버_check-api_v24.ts`
기사 폰 화면(/driver)은 저장소에 없어서 대조하지 못했어요.

## 그대로 맞는 것 ✅
- 「예전 자료 가져오기」: 화면은 가온(GAON)에만 보이고(4336줄 근처), 서버 v24 도 가온만 받아요. 짝이 맞아요.
- 기사 계정 [사용]·[멈춤]·[비밀번호 초기화] 단추: 서버 v23·v24 의 승인 방식([사용] = 가입 승인)과 그대로 맞아요.
- 사무실 로그인(검사소 직원): 서버 규칙(4자 이상)이 바뀌지 않아서 화면 안내 「4자 이상」 그대로 맞아요.
- `me`·`logout`·배달 목록 창구들: 모양이 바뀌지 않았어요.

## 체크 방이 화면에 넣어야 할 것 (서버는 준비 끝)
| 번호 | 화면 | 서버가 주는 것 | 화면이 할 일 |
|---|---|---|---|
| 1 | 사무실 › 기사 계정 목록 | `deliv_accounts` 의 각 기사에 `가입신청: "Y"` | 「가입 신청」 표시(예: 이름 옆 꼬리표) + 「승인 전에 기사에게 전화로 확인해 주세요」 안내. 승인은 기존 [사용] 단추 |
| 2 | 사무실 › 기사 추가(처음 비밀번호 칸) | 비밀번호를 넣으면 **6자 이상**이어야 함 | 안내 문구 「6자 이상(비워 두면 기사가 폰에서 정함)」 |
| 3 | 기사 폰 › 로그인 | `deliv_login(이름, 비밀번호, 회사코드?)` — 3번째 칸은 선택 | 「회사 코드(선택)」 칸. 같은 이름이 두 회사에 있으면 서버가 「회사 기사 비밀번호(검사소 코드)를 함께 넣어 주세요」를 돌려줌 |
| 4 | 기사 폰 › 계정 만들기 | 성공해도 열쇠를 주지 않고 `__err` 로 「가입 신청이 됐습니다. 사무실에서 [사용]으로…」 | 이 문구는 **오류가 아니라 안내**로 보여 주기 (빨간 글씨 말고). 새 비밀번호 안내 「6자 이상」 |
| 5 | 기사 폰 › 로그인 | 5번 틀리면 「10분 동안 잠겼습니다」 | 그대로 보여 주면 됨 |
| 6 | 관리(ADMIN)로 체크를 열 때 | v24 부터 검사소 코드를 안 보내면 「검사소를 골라 주세요」 | 관리 계정으로 열 때 검사소 코드를 함께 보내는지 확인 (가온으로 자동으로 열리지 않음) |

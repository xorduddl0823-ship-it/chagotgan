# 사진 보관함 비공개 + 서명 주소 (보안 ⑤) — 2026-10-15 · 배포 전

> 대표님 PC 확인: 워시 사진 보관함 `wash` 가 **공개**(주소만 알면 누구나·언제까지나 봄), 체크 `check-deliv` 는 비공개.
> 목표: `wash` 를 비공개로 바꾸고, 사진은 **잠깐만 열리는 주소(서명 주소)**로만 보이게.

## 한 번에 바꾸면 안 되는 이유
워시 화면은 사진 주소를 스스로 만들어요(`blobUrl` → `…/storage/v1/object/public/wash/…`, 16곳). 보관함을 먼저 잠그면 **워시 화면의 사진이 모두 깨져요.** 그래서 3단계로 가요.

## 1단계 — 서버 (만들어 둠 · 시험 통과)
| 서버 | 새 판 | 바뀐 것 |
|---|---|---|
| 워시 | `서버/1_차곳간워시_서버_wash-api_sb4.ts` (= sb3 + 아래) | 새 창구 **`shotLinks([사진id…])` → `{links: {id: 주소}, ttl}`** — 로그인한 업체의 자기 폴더 사진만, 한 번에 300장, 기본 6시간(비밀값 `SHOT_TTL` 초로 바꿀 수 있음). 잠긴 업체도 사진은 볼 수 있음. 딜러 «차량 보기»(`viewCar`)는 공개 주소 대신 **서명 주소 1시간**(그 업체 폴더 사진만) |
| 딜러 | `서버/3_딜러앱_서버_dealer-api_d4.ts` (= d3 + 아래) | 차 상세 사진을 **서명 주소 1시간**으로 (그 차를 맡긴 업체 폴더 사진만) |
- 이 판들은 보관함이 공개여도 비공개여도 똑같이 돌아가요. 그래서 **먼저 올려도 아무것도 깨지지 않아요.**
- 알림톡 «차량 보기» 주소(`/v.html?c=…`)는 열 때마다 서버에 새로 물어보므로, 이미 보낸 링크도 그대로 돼요.
- 시험: `서버/시험/사진_서명주소_워시_시험.ts` 10개 (sb3 면 8개 실패) · `사진_서명주소_딜러_시험.ts` 4개 (d3 면 3개 실패)

## 2단계 — 화면 (다른 방이 할 일)
| 방 | 파일 | 할 일 |
|---|---|---|
| **워시** | `워시/1_차곳간_워시_index_v114.html` 의 `blobUrl(id)` (13952줄 근처) | `sb/` 사진은 공개 주소를 만들지 말고, **서명 주소 기억 칸**에서 꺼내 쓰기. 자료를 불러온 뒤(`apiLoad` 다음) 화면에 나올 `sb/` 사진 id 를 모아 `shotLinks` 로 한 번에 받아 기억(유지 시간보다 조금 일찍 다시 받기). 기억에 없으면 잠깐 빈 칸 → 받아 오면 다시 그리기. 사진을 새로 올린 직후에도 그 id 로 `shotLinks` |
| 워시 | `워시/올리기용/index.html` | 위와 같음 (올리기용 판도 같이) |
| 딜러 | `딜러/3_딜러앱_화면_d3.x` | **할 일 없음** — 서버가 주는 `shots[].url` 을 그대로 쓰면 돼요. 다만 화면이 주소를 오래(1시간 넘게) 들고 있으면 사진이 안 보일 수 있으니, 상세를 열 때마다 서버에서 다시 받기 |
| 홈페이지 | `v.html`(차량 보기) | **할 일 없음** — `viewCar` 가 주는 주소를 그대로 씀 |
| 관리 | 관제센터 | 사진을 직접 보여 주는 곳이 있으면 같은 방식(`shotLinks`)으로. 없으면 할 일 없음 |

## 3단계 — 보관함 잠그기 (대표님 · 2단계가 다 올라간 뒤)

> # ⛔ 1단계 서버(워시 sb4·딜러 d4)와 2단계 워시 화면 새 판이 **둘 다 운영에 올라간 뒤에만** Public 을 끄세요.
> # 하나라도 안 올라갔는데 끄면 워시 앱·딜러앱·차량 보기의 **사진이 모두 안 보여요.**
> (보안 방 1단계 검사 통과 2026-10-15 · TTL 화면 6시간 / 공유 1시간 적당)

1. 수파베이스 → **Storage** → `wash` → 설정(…) → **Public bucket 끄기**.
2. 워시 앱에서 사진이 보이는지, 알림톡 차량 보기·딜러앱 차 상세 사진이 보이는지 확인.
3. 문제가 생기면 같은 곳에서 **Public 다시 켜기** → 바로 원래대로 (자료는 그대로예요).

## 올리는 순서 한 줄
**서버 sb4·d4 올리기 → 워시 화면 새 판 올리기 → 며칠 지켜본 뒤 보관함 Public 끄기.**

## 남는 것
- 옛 구글 드라이브 사진(`sb/` 가 아닌 id)은 이번 일과 상관없어요(드라이브 설정을 따름).
- 서명 주소도 유지 시간 안에는 주소를 아는 사람이 볼 수 있어요(공개 주소처럼 영원하지는 않음). 화면용 6시간 · 딜러·차량 보기 1시간.

# 28. 국세청 사업자번호 확인 «연결하지 못했어요» — 원인 찾기와 대안 (2026-10-18 · 서버 방)

## 지금 상황
- TEST(체크 v48 + 서버 v40)에서 «국세청 확인»을 누르면 «국세청에 연결하지 못했어요»가 나와요.
- 이 글은 국세청이 답을 주기도 전에 연결 자체가 끊길 때 나와요. 그래서 열쇠 문제가 아니에요. 열쇠가 틀렸다면 «열쇠가 아직 등록 중이거나 맞지 않아요»가 나와요.

## 원인 후보
1. **열쇠 글자에 줄바꿈·따옴표가 딸려 들어감** (가장 흔해요)
   - 열쇠를 붙여 넣을 때 끝에 줄바꿈이 붙으면, 열쇠를 «머리글»에 넣는 순간 서버가 보내기 전에 멈춰요.
   - 그러면 «연결 실패»로 보여요.
   - v42 · sb20에서 막았어요: 앞뒤 줄바꿈·따옴표를 떼요. 머리글로 실패하면 주소 방식으로 한 번 더 보내요.
2. **국세청 쪽(api.odcloud.kr)이 해외에서 오는 접속을 막음**
   - 수파베이스 함수가 외국 지역에서 돌면 이렇게 될 수 있어요. 서버 방에서는 직접 확인할 수 없었어요.
   - 서버 방 작업 상자는 바깥 접속이 막혀 있어요.
3. **잠깐의 연결 문제** — 다시 누르면 될 수 있어요.

## v42 · sb20에서 바뀐 것: 원인 갈래가 보여요
- 실패하면 화면 글 끝과 기록에 짧은 코드가 붙어요. 열쇠·주소·원문 오류는 남기지 않아요.

| 코드 | 뜻 | 다음 할 일 |
|---|---|---|
| `hdr` | 열쇠 글자에 이상한 글자가 섞임 | 수파베이스 Secrets에서 `NTS_API_KEY`를 다시 붙여 넣기 |
| `dns` | 국세청 주소를 찾지 못함 | 함수 지역 문제일 수 있음 → 아래 «지역 확인» |
| `tls` | 보안 연결(인증서)이 안 맞음 | 지역·국세청 쪽 문제 → 아래 «대안» |
| `conn` | 국세청이 접속을 끊거나 거절함 | 해외 접속 차단일 가능성 큼 → 아래 «대안» |
| `timeout` | 8초 안에 답이 없음 | 잠시 뒤 다시 · 계속되면 차단 의심 |
| `net` | 그 밖의 연결 실패 | 코드와 함께 서버 방에 알려 주기 |

## 함수가 어느 지역에서 도는지 확인하는 법 (대표님이 볼 곳)
- 수파베이스 화면 → 왼쪽 **Edge Functions** → `check-api` → **Logs**(기록)를 열어요.
- 기록 한 줄을 누르면 지역 이름이 보여요. `ap-northeast-2`면 서울이에요.
  - 수파베이스 화면은 자주 바뀌어요. 이름이 다르면 «region» 글자를 찾아 주세요.
- 참고: 프로젝트(자료 창고) 지역은 **Project Settings → General**에 있어요. 하지만 함수는 보통 **부른 사람과 가까운 지역**에서 돌아요. 그래서 함수 기록 쪽 지역이 맞는 답이에요.

## 해외 접속 차단으로 보이면 — 대안
| 안 | 하는 일 | 좋은 점 | 아쉬운 점 |
|---|---|---|---|
| **A. 서울 지역에서 돌게 하기 (추천)** | 화면이 서버를 부를 때 «서울에서 돌려 달라»는 표시(`x-region: ap-northeast-2`)를 붙여요 | 돈이 안 들어요. 국세청 무료 확인(상태 + 대표자·개업일 진위)을 그대로 써요 | 화면 방이 한 줄 고쳐야 해요. 체크 서버는 이미 받아요. 워시 서버는 받는 머리글에 한 단어를 더해야 해요(서버 방). 서울에서도 막히면 소용없어요 |
| B. 팝빌 휴폐업조회로 바꾸기 | 이미 쓰는 팝빌(은행 조회가 되는 길)로 «영업 중·휴업·폐업»만 물어요 | 팝빌은 지금 서버에서 잘 닿아요 | **건당 요금**이 있어요(팝빌 요금표에서 확인 필요 · 서버 방이 금액을 짐작해 적지 않아요). 대표자·개업일 진위 확인은 없어요 |
| C. 그대로 두기 | «확인 준비 중»으로 넘어가요 | 할 일 없음. 저장은 지금도 안 막혀요 | 폐업한 상사를 걸러 주지 못해요 |

## 순서 제안
1. 체크 v42(또는 워시 sb20)를 올리고 «국세청 확인»을 한 번 눌러요. 글 끝의 코드를 봐요.
2. `hdr`이면 열쇠를 다시 붙여 넣어요. 그러면 끝이에요.
3. `dns`·`tls`·`conn`·`timeout`이면 함수 기록에서 지역을 봐요.
   - 서울이 아니면 **A안**을 써요.
   - 서울인데도 막히면 **B안**을 써요. 요금은 대표님이 결정해요.

# 알림톡 재검수 5종 — 서버에서 쓰는 곳 · 고친 문안 초안 (2026-10-15)

> 총괄 방 요청. 2026-10-12 에 솔라피(카카오 알림톡)로 등록한 템플릿 중 **재검수 5개**:
> 차곳간_잔액안내 · 차곳간_자료보관기한 · 차곳간_로그인제한예정 · 차곳간_이용제한시작 · 차곳간_기간종료예정
> 반려 사유는 대표님께 받는 대로 맞춰 고쳐요. 아래는 그 전에 만든 초안이에요.

## 결론 먼저
1. **지금 서버(워시 sb1~sb4)는 이 5개 템플릿을 하나도 쓰지 않아요.** 같은 내용을 모두 **문자(SMS/LMS)** 로 보내고 있어요(`noticeSms`, 보내는 번호 `SMS_FROM`).
   → 그래서 **템플릿이 통과될 때까지 따로 할 일 없이 지금처럼 문자로 나가요.** 끊기는 안내는 없어요.
2. 템플릿이 통과되면 서버 새 판에서 「알림톡 먼저, 안 되면 문자로 대신(대체 발송)」으로 바꿀게요(아래 「통과 뒤 서버 할 일」).
3. 지금 문자 문구에는 카카오 기준으로 걸릴 말(「충전하기 ▶」, 「결제하시면 바로 다시 열립니다」)이 있어요. 알림톡 문안은 아래처럼 **정보만** 남기고 바꿨어요.

|---|---|---|---|
| 차곳간_잔액안내 | `smsWarnOwner` (무료 문자를 다 썼을 때 · 문자가 멈췄을 때, 각 1번) · `cronExpire` ④ 캐시 만료 30일·7일 전 | 문자를 보내려다 남은 양이 없을 때 / 매일 정해진 시각 | 업체 이름, (캐시) 남은 금액, 만료일, 남은 일수 |
| 차곳간_자료보관기한 | `cronExpire` ③-2 `del` | 자료 정리일 7일 전 | 업체 이름, 정리 예정일 |
| 차곳간_로그인제한예정 | `cronExpire` ③-2 `block` | 로그인 차단 전날 | 업체 이름, 차단 시작일 |

- 받는 사람: 모두 **업체 대표(사장님) 휴대폰** (`wash_shops.owner_phone`) — 차곳간을 쓰는 업체에게 계약상 알리는 정보예요.
- 관제센터 「만료 안내」에서 문구 3개를 직접 고칠 수 있어요(`exp_cfg.tpls`). 알림톡으로 바꾸면 **등록한 문안과 글자가 같아야** 해서, 그때는 관제센터 문구 고치기를 「문자로 보낼 때만」으로 바꿔야 해요.

## 고친 문안 초안 (카카오 알림톡 기준에 맞춤)
지킨 것: ① 정보성만(광고·할인·결제 권유 문구 없음) ② 변수는 꼭 필요한 것만, 고정 문장이 더 많게 ③ 맨 아래 **수신 사유** 문구 ④ 버튼은 「웹링크 — 이용 현황 보기」 하나(정보 확인용). 변수 이름은 `#{…}`.

**① 차곳간_잔액안내**
```
[차곳간] 문자 잔여량 안내

#{업체명} 대표님, 차곳간 문자 이용 현황을 알려 드립니다.

■ 현재 상태: #{상태}
■ 기준일: #{기준일}

잔여량이 없으면 출고 안내 문자가 발송되지 않습니다.
이용 현황은 아래 버튼에서 확인하실 수 있습니다.

※ 이 메시지는 차곳간 서비스를 이용 중인 사업장 대표님께 이용 현황을 알려 드리기 위해 발송됩니다.
```
- `#{상태}` 예: 「무료 문자 모두 사용」, 「문자 발송 멈춤」, 「캐시 12,000원 · 2026-11-30 만료 예정」

## 통과 뒤 서버 할 일 (워시 다음 새 판)
- `noticeAta(휴대폰, 템플릿코드, 변수, 대신보낼문자)` 를 만들어 위 5곳에서 부르기. 솔라피 `kakaoOptions { pfId: PF_ID, templateId, variables, disableSms: false }` → **알림톡이 안 되면 솔라피가 자동으로 문자로 대신 보냄**(지금 문자 문구를 그대로 대체 문구로).
- 템플릿 코드는 비밀값이 아니라 관제센터 설정 칸(`wash_hq`)에 이름별로 넣기(비밀값 이름 `PF_ID` 는 이미 있음).
- 템플릿 코드가 비어 있으면 지금처럼 문자로만 → 통과 전후 언제 올려도 안전.
- 관제센터 「만료 안내」 문구 고치기는 「문자로 보낼 때만」 적용으로 바꾸기.

## 체크 서버는?
- 체크 서버의 차량 도착 알림은 검사소별 템플릿 설정(`check_deliv_conf.ata_tpl`)으로 이미 알림톡을 쓰고, 이 5종과는 상관없어요.

## 한 것
1. **영어·코드·데이터베이스 원문은 사용자 화면에 안 보여요** — 네 서버 모두 오류를 돌려주기 직전에 `userMsg()` 로 한 번 거릅니다.
   - 우리말 앞부분(「보기 주소를 만들지 못했습니다」 등)은 남기고, 뒤에 붙던 원문(`relation … does not exist`, 토스·팝빌 코드 등)은 빼고 「잠시 뒤 다시 해 주세요. 계속되면 차곳간(010-9559-3663)으로 알려 주세요.」를 붙여요.
   - 빼낸 원문은 **서버 기록(로그)에만** 남아요(`userMsg hidden:`).
   - 허용하는 영어: TEST · SMS · LMS · MMS · PDF · JPG · QR · 주소(cgg.co.kr 등).
   - **본사(관리) 응답은 거르지 않아요** — 대표님이 고칠 수 있게 비밀값 이름(예: `TOSS_SECRET_KEY`)·SQL 번호 안내가 그대로 보여요.
2. **설정 안내를 우리말로** — 업체·검사소·딜러 화면에 비밀값 이름이나 SQL 파일 이름이 나오던 글을 「○○ 설정이 아직 끝나지 않았습니다. 차곳간(010-9559-3663)으로 알려 주세요.」로 바꿨어요(문자·세금계산서·카드 결제·자동 결제·번호판 읽기·체험판·딜러앱·통합 입구).
3. **번호판 읽기(AI) 오류** — 「AI 응답 오류 401 …」 같은 글 대신 「번호판을 읽지 못했습니다. 번호를 직접 적어 주세요.」
4. **모르는 기능 이름** — 「허용되지 않은 기능: xxx」(코드 이름) 대신 「지원하지 않는 기능입니다. 화면을 새로 고쳐 주세요.」
5. **표준형·띄어쓰기·용어** — 「넣어주세요」→「넣어 주세요」 같은 띄어쓰기, 「관제센터」→「관리」, 「돈」→「금액」, 「가입 코드을」→「가입 코드를」, 체크 기사 가입 신청 안내를 표준형으로.
6. **알림·안내(note)는 해요체** — 관리의 계정 바꾸기 결과, 자동 결제 준비 중, 지갑 미연결, 결제 대기 안내, 카드 결제 준비 중(「PG사 …」 → 「카드 결제는 준비 중이에요」, 사과 문구 뺌).

# 홈페이지 → 요금제 → 가입 → 결제 → 앱 열림 (설계 · 2026-10-15 · 보안 방 검토 전 · 아직 안 만듦)

> 대표님 말씀: 「첫 사용자는 대표 홈페이지에서 결제할 수밖에 없다」 · 총괄 요청: 가입용 결제 창구를 이 흐름에 맞게 정리 · 화면은 홈페이지·앱 방
> 판: **워시 sb12** (설계 14와 같은 판) + **SQL 08** 에 칸 더함

## 지금 있는 것과 문제
- 가입 `signup` 은 곧바로 **체험(30일)** 으로 업체를 만들고 앱을 열어요. 결제와 이어져 있지 않아요.
- 홈페이지 결제 `payStart`(로그인 없음)는 `wash_payments` 에 ready 줄만 만들고 「준비 중」을 돌려줘요(PG 미연결). 결제가 끝나도 가입·요금제와 이어지는 곳이 없어요.
- 가입은 「가입 코드」 번호만 돼요(`needInvite`) — 자유 가입은 `OPEN_SIGNUP=1` 비밀값으로만.

## 새 흐름 (서버 창구 · 모두 이미 있는 이름 + 작은 더하기)
1. `planList()` — 요금제 (그대로)
2. `joinCheck([휴대폰])` — 가입 가능? (`open`·`invite`·`joined`·`none`) (그대로 · 자유 가입 스위치는 아래)
3. `sendCode([휴대폰, "signup"])` → `verifyCode([휴대폰, 번호])` — 문자 인증 (아래 횟수 제한 더함)
4. `agree([휴대폰, 판, 광고])` — 약관 (그대로)
5. **`signup([휴대폰, 상호, 업종, 비밀번호, 대표이름, 요금제])`** — 6번째 칸 **요금제** 를 더함
   - 요금제가 `trial`(또는 비움) → 지금처럼 체험으로 바로 열림
   - 유료 요금제 → 업체를 **「결제 기다림」(`pay_wait`)** 으로 만들고 로그인 열쇠를 줌. 앱은 안 열리고 결제 창구만 됨
6. 로그인한 열쇠로 **`payDue()` → `payStart(["plan",0,0])` → 토스 결제창(v2) → `payConfirm(...)`** — sb11 에서 고친 로그인 결제 창구 그대로
7. 결제가 반영되면(`payDone`): `pay_wait` 해제 · 이용기간 +30일 · **고른 제품의 출입 명단(`cgg_access`)에 `wash` 넣기** → 앱이 열림
8. 결과는 관리로 — 관리 결제 목록(설계 14)에 꼬리표 `홈페이지 가입` 으로 보임 (주문 who = `join:<번호>`)

## 「결제 기다림」 계정
- 로그인은 되지만 `lockState` 가 **`pay`** 상태를 돌려줘요 → 화면은 「결제 이어 하기」만 보여 주면 돼요(잠금 화면과 같은 자리)
- 쓸 수 있는 창구: 결제 6개 + 내 정보·로그아웃 (지금 잠금 때 쓸 수 있는 목록 `LOCK_OK` 그대로)
- 7일 동안 결제가 없으면 관리 「할 일」에 보이고, 30일이 지나면 자료가 없는 업체라 관리에서 지울 수 있어요(자동 삭제 안 함)

## 가입 코드 없이 가입할 때 — 문자 인증 횟수 (구상 문서 2026-10-14)
자유 가입 스위치: 관리 설정 `wash_hq.open_signup` (기본 꺼짐 · 비밀값 `OPEN_SIGNUP` 도 그대로 받음)
| 묶음 | 한도 (기본값 · 관리에서 바꿈) |
|---|---|
| 같은 번호 | 하루 5번 (지금 그대로) |
| 같은 IP | 가입 인증 하루 5번 (지금은 모든 인증 20번 — 가입만 따로 더 낮게) |
| 전체 | 가입 인증 하루 200번 · 넘으면 「잠시 뒤」 + 본사 휴대폰에 문자 한 번 |
| 끝까지 안 한 가입 | 같은 IP 에서 「결제 기다림」 업체를 하루 3개까지만 |

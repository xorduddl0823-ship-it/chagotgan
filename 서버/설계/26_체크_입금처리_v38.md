# 설계 26 — 체크 입금 처리 서버 (체크 v47 약속 · 체크/기획/2026-10-18_입금처리_창구_약속_초안.md · check-api v38 + SQL 14)

## 먼저 할 일 (대표님)
1. SQL 13을 실행해요(아직 안 했으면).
2. `서버/sql/14_체크_입금처리.sql`을 실행해요.
   - 입금 표에 `hold`(사람이 되돌린 입금)와 `notice_at`(알림 보낸 때) 칸이 생겨요.
   - state 값을 거르는 규칙이 있으면 «입금 처리», «지움»이 들어가게 풀어요.
   - 지우는 자료는 없어요.
3. check-api v38을 올려요. v37의 모든 것이 들어 있어요.
   - SQL 14 없이도 돌아가요. 빠지는 건 두 가지예요: 되돌린 입금을 자동 맞추기가 다시 잡지 않게 하기, 알림을 «입금마다 한 번»만 보내기.

## 창구 (모양은 체크 방 약속 그대로)
| 창구 | 누가 | 하는 일 |
|---|---|---|
| `depositApply({ids ≤50, invoiceId})` → `{n, invoice:{id, paid, total, state}}` | 대표·직원 | 고른 입금을 그 청구서에 맞춰요. 자세한 규칙은 아래에 있어요. |
| `depositUnapply({ids ≤50})` → `{n}` | 대표·직원 | 청구서 금액을 빼고 입금을 «확인 대기»로 돌려요. `hold`를 켜서 자동 맞추기가 다시 잡지 않아요. 0원이 되면 청구서는 «보냄»(보낸 적 없으면 «만듦»)으로 돌아가요. |
| `depositKind({ids ≤200, kind})` → `{n}` | 대표·직원 | 갈래(검사비·정비비·보험료·기타·미분류)만 바꿔요. 다른 값은 거절해요. |
| `depositDel({ids ≤200})` → `{n, kept}` | 대표만 | 실제로 지우지 않고 «지움»(휴지통)으로 바꿔요. 청구서에 맞춘 입금은 `kept`로 돌려줘요(«먼저 되돌려 주세요»). |
| `depositRestore({ids})` → `{n}` | 대표만 | «지움» → «확인 대기» |
| `depositTrash()` → 줄 목록 | 대표만 | 휴지통 목록 |
| `depositImport({rows ≤1000})` → `{got, dup, bad, matched}` | 대표만 | 은행 엑셀 줄을 넣어요. 자세한 규칙은 아래에 있어요. |
| `depositList` | 지금처럼 | «지움»을 빼고 줘요. 줄마다 `id`, `invoice_id`가 있어요. |

**맞추기(`depositApply`)**
- «확인 대기»이면서 아직 안 맞춘 입금만 조건부로 먼저 잡아요. 그래서 두 번 눌러도 한 번만 더해요.
- 금액은 SQL 13 함수로 한 번에 더해요.
- 입금은 «입금 처리»가 되고, 갈래가 «미분류»면 «검사비»로 바꿔요.
- 입금확인 알림톡을 보내요.

**은행 엑셀 넣기(`depositImport`)**
- 받는 값
  - 날짜: 최근 400일 안이어야 해요.
  - 금액: 0보다 큰 정수여야 해요.
  - 보낸 분: 40자까지이고, `< >`와 제어 글자는 지워요.
- 잘못된 줄은 `bad`로 돌려줘요(줄 번호와 까닭).
- 겹침 막기
  - 같은 줄을 두 번 넣으면 막아요. 열쇠는 `x|한국 시각(분까지)|금액|보낸 분`이에요.
  - **팝빌 줄과 겹치면 `dup`**: 같은 검사소에서 한국 날짜·금액·보낸 분(공백과 (주)를 뗀 것)이 같으면 겹침으로 봐요. 그래도 넣어야 하는 줄은 `force:true`로 보내요.
- 다 넣으면 자동 맞추기를 한 번 돌려요.

- 모두 이 검사소 입금·청구서만 다뤄요. 다른 검사소 것이 섞이면 전체를 거절해요.
- 맞추기·되돌리기·갈래는 검사소당 하루 300건까지예요(`CHECK_DEP_OP_DAY`).
- 모두 `check_log`에 기록을 남겨요.

## 함께 바뀐 것
- **입금확인 알림은 입금마다 한 번이에요.** 보내기 전에 `notice_at`을 조건부로 먼저 잡아요. 그래서 되돌렸다가 다시 맞춰도 다시 안 가요(SQL 14 뒤).
- 팝빌 계좌조회 때 엑셀로 이미 넣은 같은 입금(같은 날·금액·이름)은 새로 넣지 않아요. 그래서 엑셀과 팝빌 어느 쪽이 먼저 들어와도 겹치지 않아요.
- 자동 맞추기(`depositMatch`)는 `hold`가 켜진 입금을 건너뛰어요.

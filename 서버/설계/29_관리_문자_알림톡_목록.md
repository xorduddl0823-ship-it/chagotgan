# 관리(admin.cgg.co.kr)에서 나가는 문자 — 알림톡 전환 목록 (서버 방 · 2026-10-18 · wash-api sb22)

> 관리 화면은 **워시 서버(wash-api) 하나만** 불러요. 그래서 관리에서 나가는 문자는 모두 wash-api 안에 있어요.
> 통합 입구 로그인(cgg-api v1.6)은 이미 알림톡 «차곳간_인증번호» 먼저예요(코드 칸 같은 곳: `wash_hq.ata_cfg.tpl.auth`).
> 템플릿 코드 넣는 곳: **관리 → 알림 → 알림톡 템플릿 → «차곳간_인증번호» 줄** (채널 ID도 같은 화면). 코드가 비면 지금처럼 문자로 나가요.

## 1. 이번 판(sb22)에서 알림톡으로 바꾼 것 — 통과 템플릿 13번 «차곳간_인증번호»
| 무엇 | 누구에게 | 예전 | sb22 |
|---|---|---|---|
| 관리 로그인 인증번호 (hqLogin) | 본사 알림 번호 | 문자 | **알림톡 먼저** → 안 되면 확정본 대체 문구 문자 · 코드가 비면 예전 문자 그대로 |
| 본사 알림 번호 바꾸기 인증번호 (hqPhoneStart) | 새 번호 | 문자 | **알림톡 먼저** → 위와 같음 |

변수는 `#{인증번호}`(6자리) · `#{유효시간}`(5) 둘만. 원문은 손대지 않았어요.

## 2. 이미 알림톡 먼저인 것 (그대로)
| 무엇 | 누구에게 | 템플릿 |
|---|---|---|
| 기한 안내 손으로 보내기 (hqExpSendNow, 남은 날 0 이상) | 업체 대표 | 기간종료예정 |
| 캐시 넣기 (hqCashAdd) | 업체 대표 | 충전완료 |
| 입금 확인 · 결제 처리 (hqPayMark 등) | 업체 대표 | 결제완료 · 충전완료 |
| 가입 인증번호 (sendCode → otpSend) | 가입하는 사람 | 인증번호 |

## 3. 맞는 템플릿이 없어 **문자 그대로** 둔 것 → «새 템플릿 필요» (원문 초안 1줄씩)
업체·회원에게 가는 것
| 무엇 (서버 창구) | 누구에게 | 초안 |
|---|---|---|
| 임시 비밀번호 — 워시 계정 (hqUserPw) | 그 계정 휴대폰 | `[차곳간] 임시 비밀번호 안내` / 임시 비밀번호: #{임시비밀번호} · 로그인한 뒤 바로 바꿔 주세요. 요청하지 않았다면 010-9559-3663 으로 알려 주세요. |
| 임시 비밀번호 — 체크 기사 (hqPersonAct 비밀번호 초기화) | 기사 휴대폰 | 위와 같은 템플릿을 같이 써요(제품 이름 변수 #{제품} 하나 추가). |
| 관리자가 계정 처리함 (hqPersonAct: 멈춤·다시 열기·잠금 풀기 등) | 그 회원 | `[차곳간] 계정 처리 안내` / 관리자가 회원님 계정의 «#{처리}»을 처리했습니다. 본인이 요청하지 않았다면 010-9559-3663 으로 알려 주세요. |
| 기한 안내 손으로 보내기 — 기한이 이미 지난 업체 (hqExpSendNow) | 업체 대표 | 통과된 «이용제한시작»으로 돌릴 수 있는지 알림톡 방 확인 (지금은 관리에서 고친 문구 문자) |

본사(대표님 번호)에게 가는 것 — 받는 사람이 대표님 한 분이라 **새 템플릿 1개(본사 알림)**로 묶기를 추천
| 무엇 (서버 창구) | 초안 |
|---|---|
| 관리에 로그인함 (hqLogin2) | `[차곳간] 관리 로그인 알림` / 관리에 로그인했습니다 (#{일시}). 본인이 아니면 비밀번호를 바로 바꿔 주세요. |
| 본사 알림 번호 바꾸기 시도 · 바뀜 (hqPhoneStart · hqPhoneVerify, 옛 번호·새 번호) | `[차곳간] 본사 알림 번호 변경` / 본사 알림 번호가 #{번호}(으)로 #{상태}. 본인이 아니면 바로 비밀번호를 바꿔 주세요. |
| 카드 환불 (hqPgCancel) · 캐시 넣기/빼기 (hqCashAdd · hqCashTake) | `[차곳간] 본사 처리 기록` / #{업체} #{내용} #{금액} (#{처리자}) |
| 그 밖의 본사 알림 (업체 쪽에서 생겨서 대표님께 가는 것: 사업자번호 처음 넣음 · 입금했어요 · 캐시 신청 · 상담 신청 · 하루 캐시 한도 · 결제 캐시 오류 · 가입 인증 한도 · 관리 계정 바꾸기 너무 많음) | `[차곳간] 본사 알림` / #{내용} — 관리에서 확인해 주세요. |
| 기한 안내 시험 보내기 (hqExpSendNow «나에게») | 시험용이라 문자 그대로 두기를 추천 (문구를 시험하는 기능) |

> 위 «새 템플릿» 초안은 알림톡 방이 다듬고 심사해요. 통과해서 코드가 생기면 서버 방이 그 키를 연결해요(다음 판).

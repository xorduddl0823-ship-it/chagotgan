# 결제 표 모양 내보내기 — 대표님용 (2026-10-15 · 결제 방 요청 (바))

> 왜: 운영 중인 결제 표(`wash_pay_order` · `wash_payments` · 캐시 표)를 만든 SQL 이 저장소에 없어요. 짐작해서 다시 쓰면 실제와 다를 수 있어서, **표의 모양(칸 이름·종류)만** 한 번 받아 `서버/sql/` 에 보관하려는 거예요.
> **표 안의 자료(업체·금액·카드 정보)는 나오지 않아요.** 칸 이름과 종류만 나와요. 비밀 열쇠도 나오지 않아요.

## 대표님이 할 일 (PC에서 3분)
1. 수파베이스 → 왼쪽 **SQL Editor** → **New query**
2. 아래 글을 통째로 붙여 넣고 **Run**
3. 아래쪽에 결과가 **한 칸짜리 긴 글**로 나와요 → 그 칸을 눌러 **복사** → 총괄 방(또는 서버 방) 대화에 그대로 붙여 넣기

```sql
-- 결제·캐시 표 모양만 보기 (자료는 안 나옴 · 바꾸는 것 없음)
select string_agg(line, E'\n' order by tbl, ord) as "표 모양"
from (
  select c.table_name as tbl, 0 as ord, '' as line0,
         '## ' || c.table_name as line
    from information_schema.columns c
   where c.table_schema = 'public'
     and (c.table_name like 'wash_pay%' or c.table_name like 'wash_cash%')
   group by c.table_name
  union all
  select c.table_name, c.ordinal_position, '',
         '- ' || c.column_name || ' ' || c.data_type
         || case when c.is_nullable = 'NO' then ' not null' else '' end
         || coalesce(' default ' || c.column_default, '')
    from information_schema.columns c
   where c.table_schema = 'public'
     and (c.table_name like 'wash_pay%' or c.table_name like 'wash_cash%')
  union all
  select i.tablename, 9999, '', '  · ' || i.indexdef
    from pg_indexes i
   where i.schemaname = 'public'
     and (i.tablename like 'wash_pay%' or i.tablename like 'wash_cash%')
) t;
```

- 결과가 비어 있으면 표 이름이 다른 거예요 → 그대로 「비어 있어요」라고만 알려 주세요.
- 함수(`wash_cash_add` · `wash_cash_take`)는 서버 방이 이미 확인한 모양으로 정리해요. 따로 안 하셔도 돼요.

## 서버 방이 할 일 (받은 뒤)

# 통합 로그인 시험 전 할 일 — 대표님 PC 에서 한 번 (2026-10-15)

> 운영 서버는 그대로(워시 sb1 · 체크 v21 · 경비실 v1.1)예요. 이 장은 **출입 명단(`cgg_access`)에 시험 번호 세 개를 넣는 것**만 해요.
> 번호는 이 문서에 적지 않아요. 아래 `<…>` 칸에 대표님이 직접 넣고 Run 해 주세요.

## 0. 먼저 확인 (번호마다)
| 번호 | 열릴 제품 | 미리 되어 있어야 하는 것 |
|---|---|---|
| 대표님 번호 | 워시 + 체크 | 워시에 가입돼 있음 · 체크 검사소 직원으로 등록돼 있음 |
| 서브 번호 | 워시만 | 워시 **가입 코드로 직접 가입** (가입하면 자기 사업장의 **대표** 직급이 돼요 — 서버 코드에서 확인함) |
| 회사 대표번호 | 체크만 | 체크 검사소 직원으로 등록 + **체크에 한 번 로그인해서 비밀번호가 정해져 있음** |

- 통합 입구 비밀번호는 **원래 쓰던 비밀번호 그대로**예요. 워시 권한이 있으면 워시 비밀번호로 먼저 확인해요. 대표님 번호는 워시·체크 비밀번호를 같게 맞춰 두시면 편해요.

## 1. 명단에 넣기 (수파베이스 → SQL Editor → 붙여 넣고 `<…>` 만 바꿔서 Run)
```sql
insert into cgg_access (phone, name, products) values
  ('<대표님 번호 숫자만>',   '대표님',   '{wash,check}'),
  ('<서브 번호 숫자만>',     '서브',     '{wash}'),
  ('<회사 대표번호 숫자만>', '회사대표', '{check}')
on conflict (phone) do update
  set products = excluded.products, name = excluded.name, active = true,
      fail_count = 0, locked_until = null, updated_at = now();
```
- 번호는 `01012345678` 처럼 **숫자만** 넣어요 (`-` 없이).
- 여러 번 Run 해도 안전해요 (같은 번호면 고쳐 쓰기).

## 2. 잘 들어갔는지 보기
```sql
select name, products, active from cgg_access order by created_at;
```
- 세 줄이 보이고, 제품이 위 표와 같으면 끝이에요.

## 시험할 때 알아 둘 것 (운영 워시가 sb1 이라서)
- 통합 입구로 들어오면 워시에는 휴대폰이어도 **「PC」로 기록**돼요. 그래서 **같은 번호로 켜 둔 워시 PC 로그인이 끊길 수 있어요.** (대표 직급이라 들어가는 데는 문제없어요)
- 「워시만 계정으로 체크 서버를 부르면 거절」은 체크 v21 이 명단을 보지 않아서 이번 시험에서는 확인하지 않아요 (체크 v24 올린 뒤).
- 시험이 끝나고 명단에서 빼려면: `update cgg_access set active = false where name in ('대표님','서브','회사대표');`

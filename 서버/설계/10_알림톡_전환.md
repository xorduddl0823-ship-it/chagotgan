# 알림톡 전환 (문자 비용 줄이기) — 워시 sb5 · 2026-10-15 · 배포 전

> 대표님 지시: 솔라피 문자가 알림톡보다 훨씬 비싸서 알림톡 전환을 먼저.
> 통과된 템플릿 8개부터 쓰고, 재검수 5개(설계 09)는 통과되면 같은 방식으로 붙여요.

## 한 줄 요약
워시 서버 **sb5** 에 「알림톡 먼저 → 안 되면 문자로 대신」(`noticeAta`)을 넣었어요. 템플릿 코드는 **관제센터 설정 칸**(`wash_hq.ata_cfg`)에서 읽고, **비어 있으면 지금처럼 문자**예요. 그래서 sb5 를 먼저 올려도 아무것도 바뀌지 않다가, 코드를 넣는 순간부터 알림톡으로 바뀌어요.

## 통과된 8개 — 어디서 무엇으로 나가나
| 템플릿 | 받는 사람 | 보내는 곳 | sb4 까지 | sb5 부터 (코드를 넣으면) |
|---|---|---|---|---|
| 인증번호 | 가입·비밀번호 찾기 하는 사람 | 워시 `sendCode` → `otpSend` | **문자** | **알림톡**, 안 되면 문자로 대신 |
| 충전완료 | 업체 대표 | 카드 충전 `payDone`(cash) · 본사가 캐시 넣기 `hqCashAdd`(유료) | 업체엔 안 보냄 (본사에만 문자) | **알림톡만** (새 안내라 문자로는 안 보냄) |

- **이번 판에서 아직 문자인 인증번호**: 관제센터 로그인 문자(본사만), 딜러앱 인증번호(dealer-api), 경비실 문자 확인(cgg-api), 체크 첫 비밀번호 확인 문자(check-api v28). → 같은 방식으로 다음 판에서.

## ⚠ 변수 이름 대조 — 확정본 원문 기다리는 중
알림톡은 템플릿의 `#{변수}` 와 서버가 보내는 이름이 **글자까지 같아야** 나가요. 2026-10-10 확정본 13개 원문이 저장소에 없어서 아직 대조하지 못했어요(총괄 방에 요청함). 지금 서버가 보내는 이름:

| 템플릿 | 서버가 보내는 변수 (sb5 `ATA_TPL` 표) |
|---|---|
| 인증번호 | `#{인증번호}` |
| 충전완료 | `#{업체명}` `#{충전금액}` `#{잔액}` `#{충전일}` |
| 결제완료 | `#{업체명}` `#{결제금액}` `#{요금제}` `#{이용기한}` |
| 입금확인 | `#{업체명}` `#{입금액}` `#{확인일}` |
| 출고안내 | 화면이 보냄 — 워시 화면 기본 문안: `#{업체}` `#{딜러}` `#{차량번호}` `#{목적지}` `#{작업}` `#{금액}` |
| 청구서 | 화면이 보냄 — `#{업체}` `#{청구월}` `#{받는분}` `#{대수}` `#{합계}` `#{계좌}` |
| 추가작업 | 화면이 보냄 |

- 원문이 오면 이 표(`ATA_TPL`)만 고치면 돼요. **이름이 틀려도 손님이 못 받는 일은 없어요**: 인증번호는 알림톡이 거절되면 서버가 바로 문자로 보내요. 새 안내(충전·결제·입금)는 그 건만 안 나가요.
- 그래서 **원문 대조가 끝난 뒤에 코드를 넣는 걸** 권해요.

## 대표님이 할 일 — 템플릿 코드 넣기 (3단계)
1. **솔라피** → 카카오 알림톡 → **템플릿 목록**에서 통과된 템플릿을 누르면 보이는 **템플릿 ID**(`KA01TP…` 모양)를 복사해요. (비밀값 아니에요)
2. **수파베이스 → SQL Editor** 에 아래를 붙여 넣고, 쓸 줄의 `<…>` 만 복사한 ID로 바꿔요. (안 쓸 줄은 지워도 돼요)
   ```sql
   update wash_hq set ata_cfg = jsonb_build_object('tpl', jsonb_strip_nulls(jsonb_build_object(
     'otp',     '<인증번호 템플릿 ID>',
     'charge',  '<충전완료 템플릿 ID>',
     'pay',     '<결제완료 템플릿 ID>',
     'deposit', '<입금확인 템플릿 ID>',
     'out',     '<출고안내 템플릿 ID>',
     'bill',    '<청구서 템플릿 ID>',
     'add',     '<추가작업 템플릿 ID>'
   ))) where id = 1;
   ```
3. **Run** → 1분 안에 서버가 새 코드로 보내요. 되돌리기: `update wash_hq set ata_cfg = '{}'::jsonb where id = 1;` (다시 모두 문자)
- 채널 ID 는 이미 있는 비밀값 `PF_ID` 를 써요. 다른 채널을 쓰려면 위 `jsonb_build_object('tpl', …)` 앞에 `'pfId', '<채널 ID>',` 를 더해요.
- 관리(관제센터) 방이 화면을 만들면 SQL 대신 화면에서 넣을 수 있어요(서버 창구 `hqAtaGet`·`hqAtaSave` 준비됨).

## 다른 방이 할 일
- **워시 방**: 출고안내·청구서·추가작업을 알림톡으로 보낼 때, 업체가 자기 템플릿을 정하지 않았으면 `sendMsg` 에 `kind:"ATA", ataKey:"out"|"bill"|"add", variables:{…}, text:(문자로 대신 보낼 글)` 을 주기. 변수 이름은 확정본과 같게.
- **관리 방**: 관제센터에 「알림톡 템플릿 코드」 칸(`hqAtaGet`/`hqAtaSave`) — 급하지 않음(SQL 로도 됨).

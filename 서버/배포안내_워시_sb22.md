# 워시 서버 sb22 올리기 안내 (대표님용 · 2026-10-18 · 보안 통과)

> **sb22 = sb21 + 관리 로그인 인증번호를 알림톡으로.**
> 관리(admin.cgg.co.kr) 로그인할 때 오는 인증번호가 카카오 알림톡 «차곳간_인증번호»로 와요.
> 알림톡이 안 되면 지금처럼 문자로 대신 와요. 본사 알림 번호를 바꿀 때 오는 인증번호도 같아요.
> SQL 없음 · 화면 바꿀 것 없음.

## 대표님이 하실 일
1. **템플릿 코드 확인** — 관리 → 알림 → 알림톡 템플릿 → «차곳간_인증번호» 줄에 코드(KA01TP…)가 있는지 봐요.
   - 비어 있으면 솔라피 → 알림톡 템플릿 → «차곳간_인증번호»의 템플릿 코드를 복사해 넣고 저장해요. (채널 ID 칸도 비어 있지 않아야 해요.)
   - 비어 있어도 고장 나지 않아요. 지금처럼 문자로 와요.
2. **워시 서버 sb22 올리기** — `서버/1_차곳간워시_서버_wash-api_sb22.ts`(6,630줄)를 wash-api에 올려요. 지금까지와 같은 방법(Verify JWT 끔).

## 올린 뒤 확인
- 관리에서 로그아웃 → 다시 로그인 → 인증번호가 **카카오톡**(차곳간 채널)으로 오면 끝이에요.
- 관리 → 알림 → 발송 기록에 «auth · 알림톡»으로 남아요.
- 문자로 왔다면: 1번 코드가 비어 있거나, 알림톡이 실패해서 대신 온 거예요(로그인은 그대로 돼요).

## 되돌리고 싶을 때
- `서버/1_차곳간워시_서버_wash-api_sb21.ts`를 다시 올리면 돼요. SQL이 없어서 따로 되돌릴 것은 없어요.

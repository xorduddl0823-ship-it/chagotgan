# 체크 서버 v49 올리기 안내 (대표님용 · 2026-10-18)

> **체크 서버는 v49 한 판만 올리시면 돼요.** v44(가온 검사비 바로잡기) · v45(v50 단추 창구) · v46·v47(세금계산서 입금 뒤 · 전산외) · v48(신청인 청구서) 내용이 모두 들어 있어요.
> v44~v48은 따로 올리지 않아요.
> **v49 = v48 + 카모두 상사명부·딜러명부 한꺼번에 넣기**(워시 v134와 같은 기능).
> **v48 = v47 + 거래처에 없는 «신청인»도 청구서**(대표님 TEST · 나스처럼) · 다 지운 달은 저절로 다시 안 만듦.

## 결론 — 올리는 순서
| 차례 | 무엇 | 파일 | 줄 수 |
|---|---|---|---|
| — | SQL 18 · 19 · 20 | **이미 실행하셨어요**(v47과 함께) — 다시 안 해도 돼요 | — |
| 1 | SQL 22 (신청인 청구서 허락 · 안전장치) | `서버/sql/22_체크_신청인_청구서.sql` | 18 |
| 2 | 체크 서버 v49 | `서버/2_차곳간체크_서버_check-api_v49.ts` → check-api (Verify JWT 끔) | 4,631 |
| 3 | 체크 화면 | 체크 방이 알려 드리는 최신 판 | — |

- v48·v49에 필요한 **새 칸·표는 없어요.** SQL 22는 «청구처 id» 칸이 빈 칸을 막도록 되어 있을 때만 풀어 주는 안전장치예요(이미 받으면 아무것도 안 바꿔요). 끝에 «빈칸_받음 = YES»면 돼요.
- 저장소에는 그 표를 처음 만든 글이 없어서, 막혀 있는지 미리 알 수 없었어요. 그래서 SQL 22로 확인하고 필요하면 풀어요.

## v44~v47에 새로 들어간 것 중 세금계산서·전산외 (대표님 «세금계산서 매우매우 중요»)
1. **세금계산서는 입금한 곳만** — 청구 금액이 다 들어온 청구서만 발급해요. 화면뿐 아니라 **서버에서도 막아요.**
   - **예외는 없어요**(대표님 결정). 입금 전이면 대표님 계정으로도 발급되지 않아요.
   - 발급 목록에 «입금 금액 · 남은 금액»이 보여요.
2. **전산외(나스 엑셀)** — 엑셀 금액(부가세 포함) 그대로 청구해요. «계산서발행(Y/N)» · «사유»를 저장하고, **N인 차 금액은 세금계산서에서 빼요**(청구서에는 그대로 들어가요).
   - 매출 화면에서 전산외는 검사비와 따로 보여요.
3. **정비비** — 지금 창구 그대로 돼요(바뀐 것 없음).
4. **보험료 부가세 설정** — 설정에서 «미포함»(기본) / «포함»을 골라요. 매출 화면 보험료 합계(부가세 포함)에 써요.
5. **정산 기록** — 달마다 «청구서 몇 장 · 세금계산서 몇 장»이 보여요.

## v49에 새로 들어간 것
- **상사명부 · 딜러명부 한꺼번에 넣기** — 카모두에서 받은 명부를 한 번에 넣어요(대표님만).
  - 이미 있는 상사(이름 같음) · 딜러(이름 + 소속 상사 같음)는 **빈 칸만 채우고 덮어쓰지 않아요.** 같은 명부를 두 번 넣어도 늘어나지 않아요.
  - 딜러 명부에만 나오는 상사 이름은 상사로도 만들어요.
  - **회사코드 같은 다른 칸은 받지도 저장하지도 않아요.**
  - 사업자번호(10자리)·휴대폰(010…) 모양이 틀린 줄은 그 번호만 빼고 넣고, 몇 번째 줄인지 알려 줘요. 먼저 «미리 세기»로 몇 곳이 들어갈지 볼 수 있어요.

## v48에 새로 들어간 것
1. **거래처에 없는 신청인도 청구서** — 엑셀 «신청인»이 거래처에 아직 없어도 신청인마다 청구서가 생겨요(나스처럼). 10월 정답 **35곳 · 3,927,000원**(0원 15곳은 숨김).
   - 이런 청구서는 «번호 없음»으로 보이고, **세금계산서 · 보내기는 거래처에 넣은 뒤**에 돼요(받는 곳 정보가 없어서).
2. **청구서를 모두 지운 달** — 다시 열어도 저절로 다시 만들지 않아요. «청구서 만들기»를 누를 때만 다시 생겨요.
3. **매출 보험료** — 엑셀 «성능보험료» 합계 그대로예요(서버는 부가세를 더하지 않아요). 표에 보이는 값은 설정 «보험료 부가세»(미포함/포함)에 따라 화면이 보여 줘요.

## 올린 뒤 확인 (가온)
- 10월 청구서를 다시 만들기 → **35곳**, 검사비 합계 **3,927,000원**이면 맞아요.
- 단가표 «가온 규칙으로 맞추기» → 10월 청구서 다시 만들기 → 검사비 **3,927,000원**(v44 안내와 같음).
- 아직 입금 안 된 청구서로 세금계산서 발급을 눌러 봐요 → «아직 입금 전입니다 (남은 금액 ○원)»가 나오면 맞아요.
- 다 입금된 청구서는 지금처럼 발급돼요.

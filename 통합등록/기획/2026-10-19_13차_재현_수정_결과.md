> 실제 전산에는 접속하지 않았습니다. 재현은 **진짜 프로그램(기존 업무용 전송 코드 그대로)**을 띄워 단추를 누르고, 상대는 **흉내 경기조합 사이트**입니다.

> 시험 차량은 가짜(99가9999) — 이전에 시험·문서에 썼던 실제 차량번호는 가짜 값으로 바꿨습니다(지난 커밋 기록에는 남아 있음).

## 2. 원인별 수정 내역
| 원인 | 수정 | 파일 |
|---|---|---|
| 경기조합은 **저장 전 사진 자리를 누르면 접수를 등록**(모델) — 프로그램이 사진 자리를 눌렀고, 다시 보낼 때마다 반복 | 경기조합 사진 자리를 **누르지 않음**(`CARMODOO_PHOTO_AUTO = false`) · 사진 순서 설정 «확인 전»(null) | `main.js` · `src/sites/site-config.js` |
| [경기조합만]은 누를 때마다 **새 접수 화면**을 열고 같은 차 확인이 없었음 | 새 접수를 열기 전에 접수차량 리스트(머리글 «성능번호·접수일·차량번호»)에서 **같은 차 오늘 접수**를 찾음 → 있으면 멈춤 · **리스트를 못 읽으면 멈춤** · 차량번호 없이(딜러 고르기 등) 새 접수 안 엶 · 이미 열린 접수가 **다른 차**면 값을 넣지 않음 | `main.js`(`ensureCarmodooForm` · `sendToSite`) |
| 카인포 [신규등록]도 같은 차 확인이 없었음 | 목록(#carcheckTable)에서 같은 차 오늘 줄 → 있으면 멈춤 · 목록 못 찾으면 멈춤 | `src/carinfo-prepare.js` |
| **먹통**: 프로그램 안쪽 오류(연결 실패 등)가 화면으로 «거절»되어 «전송 중…»이 영영 안 닫힘 | 화면과 프로그램 사이 모든 호출에서 거절을 «실패 결과»로 바꿔 결과 창을 띄움(쉬운 말 · «저장하지 않고 멈췄어요») | `preload.js` |
| **지연**: 사이트 알림창이 페이지를 멈추면 15·90초를 다 기다림 | 개발자 연결로 알림창이 **뜨는 순간** 알고 그 화면 명령을 바로 멈춤 · [확인]/[취소]는 사람이 | `src/sites/dialog-watch.js` · `main.js`(`runScript`·`runFrame`) |
| 재시도·자동 재등록 | 사진 자동 올리기 꺼짐 · 알림창 뒤 다시 하지 않음 · 저장은 원래 사람(기존 기능) — 삭제·취소·재등록 기능 없음 | — |

## 4. Windows 실행 가능 여부 · 검증 범위
- **윈도우 시험판 EXE 를 만들었습니다**: `성능점검 이중등록 시험판.exe`(무설치 폴더판, electron-builder `--win dir`, 같은 코드 · `test-install.json` 포함 → 기록 폴더 `%APPDATA%\carcheck-dual-시험판`).
- **이 환경(리눅스)에서는 EXE 를 실행하지 못했습니다**(윈도우·wine 없음). 같은 코드를 리눅스 포장판으로 실행해 확인한 것이 한계입니다.
- 서명·아이콘 넣기는 하지 않았습니다(윈도우가 «알 수 없는 게시자» 경고를 띄울 수 있음 → [추가 정보] → [실행]).
- 윈도우에서만 생기는 문제(입력 칸 초점·알림창 모양·파일 경로)는 확인 전입니다.

# 대표님 화면 확인 안내서 (10차)

**목적**: 세 전산 화면의 «칸 이름»을 기록 파일로 만들어 방에 보내기.
**원칙**
1. **지금 쓰는 업무용 프로그램은 건드리지 않아요.** 시험판을 **다른 폴더**에 따로 풀어요. 시험판은 기록 폴더도 업무용과 따로 써요(업무용 설정·로그인 정보·작업 기록을 읽지도 고치지도 않음).
2. 진단 중에는 **[저장] · [신규등록] · [사진등록] · [전송] 단추를 누르지 않아요.** 프로그램이 이런 요청을 막도록 되어 있지만, 실제 전산에서는 아직 검증 전이에요.
3. 기록 파일은 보내기 전에 **따로 한 번 더 검사**해요.

---

## A. 준비 (처음 한 번 · 20분쯤)
| 순서 | 할 일 |
|---|---|
| 1 | **업무용 프로그램을 꺼요**(업무용 프로그램 폴더는 그대로 둬요) |
| 2 | 받은 묶음을 **새 폴더**(예: `C:\차곳간_시험판`)에 풀어요. 안에 `carcheck-dual-시험판` 폴더가 생겨요. **업무용 프로그램 폴더에 덮어쓰지 않아요.** |
| 3 | `carcheck-dual-시험판` 폴더의 `0_업무용기록_백업.bat` 더블클릭 → 업무용 기록이 `문서\차곳간_백업\` 에 복사돼요(복사만, 업무용은 그대로 · 로그인 정보는 복사 안 함) |
| 4 | `1_준비.bat` 더블클릭(인터넷 필요 · 몇 분) |
| 5 | `7_전산진단_켜기.bat` 더블클릭 — 시험판 폴더에서만 켜져요 |
| 6 | `2_실행.bat` → 창 제목 끝에 **«시험판(업무용과 기록 따로)»**이 보이고, 아래쪽에 **[전산 진단 (저장 안 함)]** 단추가 보이면 준비 끝 |

시험판은 업무용과 로그인 상태도 따로예요 → 시험판에서 세 전산에 **처음 한 번 다시 로그인**해야 해요.

## B. 어떤 단계에서 실제 서버에 요청이 가나요?
| 단계 | 실제 서버로 가는 요청 | 데이터가 바뀌나 |
|---|---|---|
| 시험판에서 전산 창 열기 | 화면 불러오기(보기) | 안 바뀜 |
| 로그인 · 문자 인증(진단 **전**) | 로그인·인증 요청 — 평소 로그인과 같음 | 기록은 안 바뀜(로그인 기록·문자 발송은 생김) |
| 진단 시작 | 프로그램 쪽에 막는 장치만 켬 — 서버 요청 없음 | 안 바뀜 |
| 진단 중 화면 보기 | «읽기 전용으로 확인된 주소»만 내보내도록 되어 있음. 지금은 확인된 주소가 없어 **보기 요청도 대부분 막혀** 화면이 덜 그려질 수 있음 | 안 바뀌도록 막음(실제 전산에서는 검증 전 → 쓰기 단추는 누르지 않음) |
| [지금 화면 칸 기록] | 서버 요청 없음 — 이미 열린 화면을 읽기만 | 안 바뀜 |
| [진단 끝] | 서버 요청 없음 — 막는 장치를 풂 | 안 바뀜 |
| 진단 끝난 뒤 | 평소와 같음 — **이때부터 누르는 [저장]은 실제로 저장돼요** | 누르면 바뀜 |

## C. 엔트리 (먼저)
1. [전산 진단 (저장 안 함)] → «엔트리 주소» 칸에 엔트리 주소(`https://...`).
2. **[엔트리 창 열기 (로그인용)]** → 열린 창에서 로그인 + 문자 인증.
3. 진단 창 **[엔트리 진단 시작]**.
4. 아래 화면마다 **[지금 화면 칸 기록]**:

| # | 화면 | 메모 |
|---|---|---|
| ① | 성능점검 현황(목록) | 처음 화면 그대로 |
| ② | [간편 접수]를 누른 창 | 번호는 **고치지 않아요**. 창이 안 뜨면(막힘) 그대로 다음 |
| ③ | [불러오기]를 누른 뒤 | 안 바뀌면(막힘) 그대로 다음 |
| ④ | 목록의 [성능점검](상세) | 안 열리면 그대로 |

5. **[진단 끝]** → 결과 화면의 «개인정보 검사»와 **기록 파일 위치** 확인.

## D. 카인포
1. 진단 창 [닫기] → 맨 위 **[카인포 창]** → 로그인.
2. **[카인포 진단 시작]** → 화면마다 [지금 화면 칸 기록]: ① 성능점검 목록 ② 저장된 차 줄을 눌렀을 때 ③ 그 차의 [성능점검] 화면 ④ [차량사진] 창
3. **[진단 끝]**. ※ [신규등록] 창은 **열지 않아요**(목록에 줄이 생길 수 있음).

## E. 경기조합(카모두)
1. 진단 창 [닫기] → 맨 위 **[경기조합 창]** → 로그인.
2. **[경기조합 진단 시작]** → 화면마다 [지금 화면 칸 기록]: ① 접수차량 리스트 ② 저장된 차를 눌러 연 접수 화면 «① 신청인 및 접수정보» 탭 ③ «④ 자동차사진» 탭
3. **[진단 끝]**. ※ [접수등록]으로 새 접수 화면은 **열지 않아요**.

## F. 보내기 전 따로 검사 → 보내기 → 끄기
1. `9_진단파일_검사.bat` 더블클릭 → 파일마다 **[통과]** 또는 **[보내지 마세요]**가 나와요(고객정보·차대번호·인증·세션 정보로 보이는 것을 «개수만» 셈 — 값은 안 나옴).
2. **[통과]한 파일만** 클로드 대화에 올려요. [보내지 마세요]가 나오면 그 화면을 사진으로 보내 주세요.
3. 다 끝나면 `8_전산진단_끄기.bat`.

## 이럴 땐
| 상황 | 이렇게 |
|---|---|
| 진단이 «멈췄어요» 하고 끝남 | 안전을 위해 멈춘 거예요. 결과 화면 사진을 보내 주세요 |
| 화면이 덜 그려짐 | 확인 안 된 보기 요청까지 막아서 그래요. 그대로 [지금 화면 칸 기록] |
| 실수로 [저장]·[신규등록]·[전송]을 누름 | 바로 [진단 끝] → 그 전산 목록에서 **바뀐 것이 없는지** 확인 → 방에 알려 주세요 |
| 업무용과 헷갈림 | 창 제목에 «시험판»이 있으면 시험판이에요. 업무는 업무용 프로그램으로만 |

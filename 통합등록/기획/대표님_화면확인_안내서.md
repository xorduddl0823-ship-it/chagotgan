# 시험판 — 차 1대 관찰 기록 안내 (12차 · 수요일 10/21)

**목적**: 직원이 평소처럼 실제 차 1대를 세 전산에 등록하는 동안, 프로그램이 «어느 단추가 어느 주소로 어떤 칸 이름을 보내는지»를 기록해요. 이 기록으로 세 전산 자동 저장을 연결해요.
**원칙**
1. **지금 쓰는 업무용 프로그램은 건드리지 않아요.** 시험판은 다른 폴더에 풀고, 기록 폴더도 업무용과 따로 써요.
2. 관찰 기록은 **아무것도 막지 않아요.** 평소 업무와 똑같이 등록돼요. 그러니 **어차피 등록할 실제 차 1대**로 해요.
3. 기록에는 값(차량번호·차대번호·이름·전화번호)을 남기지 않고 가려요. 보내기 전에 한 번 더 검사해요.

## A. 준비 (처음 한 번 · 20분쯤)
| 순서 | 할 일 |
|---|---|
| 1 | 업무용 프로그램을 꺼요(업무용 폴더는 그대로) |
| 2 | 받은 묶음을 **새 폴더**(예: `C:\차곳간_시험판`)에 풀어요. **업무용 프로그램 폴더에 덮어쓰지 않아요.** |
| 3 | `carcheck-dual-시험판` 폴더의 `0_업무용기록_백업.bat` → 업무용 기록이 `문서\차곳간_백업`에 복사돼요(복사만) |
| 4 | `1_준비.bat` (인터넷 필요 · 몇 분) |
| 5 | `7_전산진단_켜기.bat` |
| 6 | `2_실행.bat` → 창 제목 끝 **«시험판(업무용과 기록 따로)»**, 아래쪽 **[전산 진단 (저장 안 함)]** 단추가 보이면 준비 끝 |

시험판은 로그인 상태도 업무용과 따로예요 → 처음 한 번 세 전산에 다시 로그인해요. 자동 로그인을 쓰려면 [설정 (로그인 정보)]에 다시 넣어요.

## B. 차 1대 관찰 기록 — 카인포 → 경기조합 → 엔트리 (평소 순서 그대로)
한 번에 한 전산만 기록해요. 전산 하나가 끝나면 [기록 끝]을 누르고 다음 전산으로 가요.

**공통 시작 방법**: 아래쪽 [전산 진단 (저장 안 함)] → 맨 위 **«관찰 기록» 칸에 체크** → 그 전산의 **[○○ 관찰 기록 시작]** → [닫기] → 평소처럼 등록 → 다 끝나면 아래쪽 **[관찰 기록 중 …]** 단추 → **[기록 끝]**

| 순서 | 전산 | 평소처럼 할 일 (프로그램은 지켜보기만) |
|---|---|---|
| 1 | **카인포** | 맨 위 [카인포 창]으로 로그인 → 관찰 기록 시작 → 입력 화면에 차 정보 입력 → [신규등록] → 카인포 전송 → 사진 → 카인포 화면에서 **[저장]** 직접 → 목록에서 그 차가 «점검완료»인지 확인 → [기록 끝] |
| 2 | **경기조합** | 맨 위 [경기조합 창]으로 로그인 → 관찰 기록 시작 → 경기조합 전송 → **«수동입력» 체크 + 카인포 번호 입력** → 사진 → **[저장]** 직접([접수저장] 아님) → 접수차량 리스트에서 그 차 확인 → [기록 끝] |
| 3 | **엔트리** | 진단 창 «엔트리 주소» 칸에 주소 → [엔트리 창 열기] → 로그인·문자 인증 → **관찰 기록 시작** → [간편 접수] → 번호 확인(**고치지 않음**) → [불러오기] → **[저장]** 직접 → 목록에서 그 차의 [성능점검](상세) 한 번 열어 보기 → [기록 끝] ([성능점검기록부 전송]·[출력]은 누르지 않아요) |

화면 칸 기록은 저절로 돼요. [지금 화면 칸 기록]은 눌러도 되고 안 눌러도 돼요.

## C. 보내기
1. `9_진단파일_검사.bat` → 파일마다 **[통과]** 또는 **[보내지 마세요]**(값은 화면에 안 나와요)
2. **[통과]한 파일만** 클로드 대화에 올려요(`…\carcheck-dual-시험판\diag\diag-…-관찰-….json` 3개). [보내지 마세요]가 나오면 그 화면을 사진으로 보내 주세요.
3. 다 끝나면 `8_전산진단_끄기.bat`

## 이럴 땐
| 상황 | 이렇게 |
|---|---|
| 등록 중 오류가 남 | 평소처럼 처리하고 그대로 [기록 끝] — 오류 난 기록도 도움이 돼요 |
| [기록 끝] 결과에 «기록된 쓰기 요청: 없음» | [저장]까지 했는지 확인. 했는데도 없으면 결과 화면 사진을 보내 주세요 |

| (예전 방식) 막고 보기만 하는 진단 | «관찰 기록» 체크를 끄면 예전 진단(요청 막기 · [저장] 누르지 않음)으로 돌아가요 |

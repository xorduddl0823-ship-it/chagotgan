# 시험판 — 차 1대 «실제 등록 관찰» 안내 (12차 보완 · 수요일 10/21)

**목적**: 직원이 평소처럼 실제 차 1대를 세 전산에 등록하는 동안, 프로그램이 «어느 단추가 어느 주소로 어떤 칸 이름을 보내는지»를 기록해요. 이 기록으로 세 전산 자동 저장을 연결해요.

**꼭 알아 둘 것**
1. **실제 등록 관찰은 실제 등록이에요.** 프로그램은 아무것도 막지 않아서 [저장]·[신규등록]·사진 올리기가 실제 서버로 전달돼요. 등록 결과도 프로그램이 알려 주지 않아요 — 등록은 평소처럼 직원이 확인해요.
2. **오늘 예정된 정상 업무 등록 1건에만** 써요. 연습용 차·가짜 차로 하지 않아요.
3. 평소 업무에 없는 조작(삭제·취소·다시 등록·전송 다시 하기)은 하지 않아요.
4. 지금 쓰는 업무용 프로그램은 건드리지 않아요. 시험판은 다른 폴더에 풀고, 기록 폴더도 따로 써요.
5. 기록에는 값(차량번호·차대번호·전화번호 등)을 가리고, 가린 뒤에도 남아 있으면 기록 파일을 만들지 않아요. 보내기 전에 자동 검사 + 눈으로 한 번 더 봐요.

## A. 준비 (처음 한 번 · 20분쯤)
| 순서 | 할 일 |
|---|---|
| 1 | 업무용 프로그램을 꺼요(업무용 폴더는 그대로) |
| 2 | 받은 묶음을 **새 폴더**(예: `C:\차곳간_시험판`)에 풀어요. **업무용 프로그램 폴더에 덮어쓰지 않아요.** |
| 3 | `carcheck-dual-시험판` 폴더의 `0_업무용기록_백업.bat` → 업무용 기록이 `문서\차곳간_백업`에 복사돼요(복사만) |
| 4 | `1_준비.bat` (인터넷 필요 · 몇 분) |
| 5 | `7_전산진단_켜기.bat` |
| 6 | `2_실행.bat` → 창 제목 끝 **«시험판(업무용과 기록 따로)»**, 아래쪽 **[전산 진단 (저장 안 함)]** 단추가 보이면 준비 끝 |

시험판은 로그인 상태도 업무용과 따로예요 → 처음 한 번 세 전산에 다시 로그인해요.

## B. 차 1대 실제 등록 관찰 — 카인포 → 경기조합 → 엔트리 (평소 순서 그대로)
한 번에 한 전산만 관찰해요. 전산 하나가 끝나면 [관찰 끝]을 누르고 다음 전산으로 가요.

**시작 방법 (전산마다 같음)**
1. 입력 화면에 **이번에 등록할 차의 차량번호**가 들어 있는지 확인해요(관찰할 차 확인용).
2. 아래쪽 [전산 진단 (저장 안 함)] → 설명 글 아래에서 **«실제 등록 관찰»**을 골라요. (창을 열 때마다 기본은 «전산 진단 (저장 안 함)»이라, 전산마다 다시 골라요.)
3. 노란 안내 «실제 서버로 전달돼요»를 읽고 → 그 전산의 **[○○ 관찰 시작]**
4. 확인 칸에 나온 **전산 이름과 대상 차량**이 맞으면 **[맞아요, 관찰 시작]**, 다르면 [취소]
5. [닫기] → 평소처럼 등록 → 다 끝나면 아래쪽 **[실제 등록 관찰 중 …]** → **[관찰 끝]**
6. 결과 화면을 보고 → **그 전산 목록에서 이 차가 실제로 어떻게 등록됐는지** 확인해요.

| 순서 | 전산 | 평소처럼 할 일 (프로그램은 지켜보기만) |
|---|---|---|
| 1 | **카인포** | 맨 위 [카인포 창]으로 로그인 → 관찰 시작 → [신규등록 + 차량정보·차대번호 가져오기] → [카인포만] → [사진만 전송 (카인포)] → 카인포 화면에서 **[저장]** → [관찰 끝] → 목록에서 «점검완료»·번호 확인 |
| 2 | **경기조합** | 맨 위 [경기조합 창]으로 로그인 → 관찰 시작 → [경기조합만] → 경기조합 화면에서 **«수동입력» 체크 + 카인포 번호 입력** → [사진만 전송 (조합)] → **[저장]**([접수저장] 아님) → [관찰 끝] → 접수차량 리스트에서 확인 |
| 3 | **엔트리** | 진단 창 «엔트리 주소» 칸에 주소 → [엔트리 창 열기] → 로그인·문자 인증 → 관찰 시작 → [간편 접수] → 번호 확인(**고치지 않음**) → [불러오기] → **[저장]** → 목록에서 그 차의 [성능점검](상세) 한 번 열어 보기 → [관찰 끝] ([성능점검기록부 전송]·[출력]은 누르지 않아요) |

※ [두 곳 동시 전송]은 쓰지 않아요. 관찰 중에는 그 전산 창을 닫지 않아요.

## C. 보내기 전 검사 (자동 + 눈으로)
1. `9_진단파일_검사.bat` → 파일마다 **[통과]** 또는 **[보내지 마세요]**
2. [통과]한 파일 옆에 생긴 **«…검토용.txt»**를 메모장으로 열어 봐요. 단추 이름·칸 이름·주소 경로(`/ct/...` 같은 것)만 있어야 해요. **사람 이름·전화번호·차량번호·차대번호·주소·아이디처럼 보이는 것이 있으면 그 파일은 보내지 않아요.**
3. 문제없는 **기록 파일(.json)만** 클로드 대화에 올려요(`…\carcheck-dual-시험판\diag\diag-…-관찰-….json`). 검토용 글 파일은 올리지 않아도 돼요.
4. 다 끝나면 `8_전산진단_끄기.bat`

| 예상과 다른 화면·오류가 나옴 | **바로 [관찰 끝]** → 그 전산 목록에서 실제 등록 상태(등록됐는지·번호)를 확인 → 평소처럼 처리 → 방에 알려 주세요. 다시 등록·삭제는 하지 않아요 |

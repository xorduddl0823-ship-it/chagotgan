# 대표님 화면 확인 안내서 (9차)

**목적**: 세 전산 화면의 «칸 이름»을 프로그램이 알 수 있게 기록 파일을 만들어요.
**지키는 것**: 진단 중에는 **[저장] · [신규등록] · [사진등록] · [전송]을 누르지 않아요.** 화면을 «보기»만 해요.
진단 중에는 그 전산에서 나가는 요청이 막혀서, 혹시 눌러도 서버로 가지 않아요. 그래도 누르지 않는 게 원칙이에요.
**걸리는 시간**: 전산 하나에 10분쯤.

---

## 준비 (처음 한 번)
1. 받은 묶음을 풀고, `carcheck-dual` 폴더를 지금 쓰시는 프로그램 폴더에 덮어써요.
2. 폴더 안의 `7_전산진단_켜기.bat` 을 더블클릭해요.
3. `2_실행.bat` 으로 프로그램을 켜요. 아래쪽에 **[전산 진단 (저장 안 함)]** 단추가 보이면 준비 끝이에요.

## 엔트리 (가장 먼저)
1. [전산 진단 (저장 안 함)] → «엔트리 주소» 칸에 엔트리 주소(`https://...`)를 넣어요.
2. **[엔트리 창 열기 (로그인용)]** → 열린 창에서 로그인 + 문자 인증.
3. 진단 창에서 **[엔트리 진단 시작]**.
4. 아래 화면을 차례로 열고, 열 때마다 **[지금 화면 칸 기록]**을 눌러요.

| # | 열 화면 | 하는 일 |
|---|---|---|
| ① | 성능점검 현황(목록) | 처음 화면 그대로 [지금 화면 칸 기록] |
| ② | [간편 접수]를 누른 창 | 번호가 미리 들어간 창이 뜨면 [지금 화면 칸 기록] — **번호는 고치지 않아요** |
| ③ | 그 창의 [불러오기]를 누른 뒤 | 화면이 바뀌면 [지금 화면 칸 기록] (막혀서 안 바뀌면 그대로 두고 다음으로) |
| ④ | 목록의 [성능점검] (상세) | 화면이 열리면 [지금 화면 칸 기록] |

5. **[진단 끝]** → «개인정보 검사» 결과와 **기록 파일 위치**가 나와요.

## 카인포
1. 진단 창 [닫기] → 맨 위 **[카인포 창]**으로 열고 로그인.
2. 진단 창 **[카인포 진단 시작]**.
3. 화면마다 [지금 화면 칸 기록]:
   ① 성능점검 목록 ② 저장된 차 줄을 눌렀을 때(위쪽 차량정보가 채워진 화면) ③ 그 차의 [성능점검] 화면 ④ [차량사진] 창
4. **[진단 끝]**.
※ [신규등록] 창은 열지 않아요(열면 목록에 줄이 생길 수 있어요).

## 경기조합(카모두)
1. 진단 창 [닫기] → 맨 위 **[경기조합 창]**으로 열고 로그인.
2. 진단 창 **[경기조합 진단 시작]**.
3. 화면마다 [지금 화면 칸 기록]:
   ① 접수차량 리스트 ② 저장된 차를 눌러 열린 접수 화면의 «① 신청인 및 접수정보» 탭(점검번호·수동입력 칸이 보이게) ③ «④ 자동차사진» 탭
4. **[진단 끝]**.
※ [접수등록]으로 새 접수 화면은 열지 않아요.

## 끝
- 기록 파일 3개(엔트리·카인포·경기조합)를 클로드 대화에 올려요. 파일 위치는 [진단 끝] 결과 화면에 나와요.
- `8_전산진단_끄기.bat` 을 더블클릭해요.

## 이럴 땐
| 상황 | 이렇게 |
|---|---|
| 진단이 «멈췄어요» 하고 끝남 | 안전을 위해 멈춘 거예요. 결과 화면을 사진으로 보내 주세요 |
| 화면 일부가 비어 보임 | 진단 중 막힌 요청 때문이에요. 괜찮아요 — 그대로 [지금 화면 칸 기록] |
| «개인정보로 보이는 글자가 남아…» | 파일을 만들지 않은 거예요. 결과 화면 사진을 보내 주세요 |
| 실수로 [저장]을 누름 | 진단 중이면 서버로 안 가요. 진단 끝난 뒤 저절로 다시 보내지도 않아요 |

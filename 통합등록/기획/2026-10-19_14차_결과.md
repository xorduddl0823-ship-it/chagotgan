### 윈도우에서 실제 실행 — 아직 못 함
- 이 개발 환경은 리눅스라 윈도우 EXE 를 실행할 수 없습니다. 위 시험은 **같은 시험 도구를 윈도우 EXE 에 그대로 돌릴 수 있게** 만들어 두었습니다(`PACKAGED_EXE=…exe`).
- **방법(대표님 허락 필요)**: GitHub 의 윈도우 PC 에서 자동으로 «EXE 만들기 → 위 시험 + 기존 [경기조합만] 6가지»를 돌리는 설정 초안 `carcheck-dual/ci/windows-exe-check.yml`. 저장소에서 GitHub 자동 실행을 쓴 적이 없어 켜기 전에 허락을 받습니다. 켜면 결과와 만든 EXE 를 내려받을 수 있습니다.

## 4. 모의 확인 vs 실제 미확인
| 기능 | 모의(흉내 사이트·화면 흉내)에서 확인 | 실제 사이트에서 |
|---|---|---|
| [경기조합만] 중복 접수 막기(같은 차·여러 쪽·Total 못 읽음) | 확인 | **미확인** — 실제 리스트가 «Total N»을 보여 주는지·오늘 접수가 첫 화면에 다 나오는지 |
| 경기조합 사진 자리 = 접수 등록 | 모델로 재현(대표님 PC 결과와 같은 숫자) | 사고로 드러남 · 저장 **뒤**에 누르면 어떻게 되는지 **미확인** |
| 경기조합 사진 자동 올리기 | 꺼짐 확인 | 꺼짐 유지 |
| 알림창 뜨면 즉시 멈춤 | 확인(값 넣는 중 알림창) | **미확인**(실제 알림창 종류·시점) |
| 연결 실패 시 먹통 없음 | 확인 | 대표님 PC 의 «먹통» 원인으로 추정 — 윈도우 **미확인** |
| 카인포 [신규등록] 같은 차·여러 쪽 확인 | 화면 흉내로 확인 | **미확인** — 실제 목록 표(#carcheckTable)·건수 안내 모양 |
| 카인포 «[성능점검] 상세 화면이 안 열림» | — | 원인 모름(자료 필요) |
| 경기조합 특기사항(메모) | — | 칸 이름 미확인 |
| 입력 칸 초점(윈도우) | 리눅스 확인 | **윈도우 미확인 → 확정 원인 아님** |
| 세 전산 완전 자동 등록 | 흉내 사이트로 확인 | 실제 설정 44개 미확정 · 자동 저장 꺼짐 |

## 2. 바뀐 것
### 2-1. 진단 중 GET — 확인된 읽기 전용 경로만 (지시 1·2)
- 판단 순서를 바꿈: **허용의 근거 = «읽기 전용으로 확인된 경로» 목록**(설정 `diagReadPaths`, 전산별). 금지 단어 검사는 «덧붙인 막기»로만 씀.
- 내보내는 것: ① **그 전산 주소의** 그림·글꼴·모양·코드 파일 GET(주소에 저장 같은 말이 없을 때) ② 확인된 경로에 맞는 화면·조회 GET.
- **확인 안 된 GET 은 기본 차단.** 지금 실제 세 전산의 목록은 **비어 있음**(확인 전) → 진단 중 화면·조회 GET 은 모두 막히고, 막힌 경로는 기록에 남음 → 그 기록을 보고 읽기 전용임을 확인한 경로만 다음 판에서 목록에 더함.
- 다른 주소의 코드·그림 파일도 이제 막음.

### 2-2. 진단 끝 안내·자동 저장 없음 검증 (지시 3)
- 결과 창에 «**요청 막기를 풀었어요 — 이제부터 이 전산 창에서 누르는 [저장]은 실제로 저장돼요. 진단 중에 눌렀던 [저장]은 다시 보내지 않아요.**»
- 진단 중에 막힌 요청은 실패로 끝내고(줄 세워 두지 않음) 다시 보내지 않음. 시험: 진단 중 [저장]·[신규등록]·사진을 누른 뒤 진단을 끝내고 1.5초 기다려도 서버 도착 **0건**, 그 뒤 사람이 [저장]을 누르면 그때만 1건.

### 2-3. 개인정보 계속 검사 (지시 4)
- 요청 기록 한 줄·화면 기록 한 번을 **남기는 순간 바로 가림**(메모리에도 가린 것만). 주소의 %EA… 같은 글자도 풀어서 가림.
- 파일로 쓰기 전 한 번 더 검사 → 남으면 파일을 만들지 않음(8차 보완판 그대로).

### 2-4. 엔트리 연결 모듈 (다음 단계 우선 개발)
[간편 접수] → 번호 확인 → [불러오기] → 차량정보 검증 → [저장] → 결과 검증

| 단계 | 하는 일 |
|---|---|
| 로그인 확인 | 카인포 저장 **전에** 엔트리 로그인 확인 — 끊겼으면 «문자 인증 로그인» 안내 후 멈춤(우회 없음) |
| [간편 접수] | 글자가 정확히 «간편 접수»인 단추를 눌러 창을 엶(보기만) |
| 번호 확인 | 미리 들어간 번호를 **읽기만** → 이 차 카인포 번호와 **같을 때만** 다음. 다르면 멈춤(번호 칸 안 고침 — 시험으로 확인) |
| [불러오기] | 글자로 찾아 누름. «성능 불러오기가 실패하였습니다»면 [확인]을 누르고, «순수 조회 확인»(pureRead) 때만 최대 3번 · 다시 할 때마다 번호가 바뀌면 멈춤 |
| 차량정보 검증 | 불러온 번호·차량번호·**차대번호 17자리**가 이 차와 같아야 |
| [저장] | 글자가 정확히 «저장»인 단추 하나만. 꺼져 있으면 «저장 불가 · 원인 확인 필요». [성능점검기록부 전송]·[출력]은 누르지 않음(시험으로 확인) |
| 결과 검증 | 목록에서 이번에 새로 생긴 줄 + 번호 일치 → 목록은 차량번호를 가리므로 [성능점검] 상세 화면의 차량번호·차대번호 17자리까지 맞아야 성공 |

- 모의 화면(`/entry2`)은 대표님 화면 사진의 모양(간편 접수 창 · 미리 들어간 번호 · 불러오기 · 전송/출력/저장 · 실패 안내 · 가린 목록 · 상세)을 따름. 시험 3개: 정상 끝까지 / 번호 다름 → 불러오기 안 함 / 이미 있는 번호 → [저장] 꺼짐 → 멈춤.
- 실제 엔트리 설정: 단추 글자(간편 접수·불러오기·확인·저장·성능점검)는 화면 사진으로 넣음. **번호 칸·불러온 칸·목록 줄·로그인 표시의 내부 이름은 비어 있음** → 연결 모듈이 «미구현»으로 표시되고 자동 등록은 엔트리 앞에서 멈춤.

## 4. 실제 연동까지 남은 작업 (우선순위)
1. 대표님 PC에서 **진단 1단계**(새 PC 묶음 사용): 로그인 → 진단 시작 → «화면 칸 기록»만 · [저장] 안 누름 → 기록 파일 받기
2. 기록 파일로 ① 엔트리 칸 이름(간편 접수 번호 칸 · 불러온 칸 · 목록 · 상세 · 로그인 표시) ② 막힌 GET 경로 중 읽기 전용인 것 확인 → 설정 채움 → 모의 시험
3. 실제 전산에서 «저장 직전까지»만 확인(저장 안 함)
4. 실제 전산에서 막기가 되는지 데이터가 바뀌지 않는 방법으로 확인하는 절차 검수 → 저장 요청 모양 확인
5. 대표님이 지켜보는 가운데 한 대로 첫 실제 자동 저장 → 통과한 전산만 `confirmed: true`
6. 엔트리 창을 진단용이 아닌 평소 입력 화면에서도 열 수 있게(지금은 진단 창에서만 엶) · 처리 시간 측정 · 화면의 «카모두» 표기를 «경기조합(카모두)»로 정리

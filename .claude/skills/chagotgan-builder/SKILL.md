# 차곳간 만들기 규칙

차곳간 제품(워시 · 체크 · 관리(옛 관제센터) · 파킹 · 딜러 · 기사앱 · 스튜디오 · 메인 홈페이지 www.cgg.co.kr)을 만들거나 고칠 때 항상 이 규칙을 지킨다.

## 0. 기본 원칙
- 사장님께 하는 말은 한국어, 쉬운 말로. 영어·전문 용어는 쓰지 않거나 바로 풀어 쓴다. 답은 짧고 가볍게.
- UI는 «무조건 직관적이고 간결하게». 화면 안내 문구는 한두 줄, 줄바꿈 적게.
- 모든 제품의 화면 모양·쓰는 방식은 «차곳간 워시» 기준으로 똑같이 맞춘다.
- 화면 모양·레이아웃을 크게 바꿀 때는 먼저 시안을 보여 주고 확인받은 뒤 반영한다.
- «관리»는 차곳간 운영 페이지(결제·계정 권한·API 관리)라 사용자 페이지(워시·체크·파킹·딜러·스튜디오)와 완전히 따로 운영한다.
- 체크는 가온진단평가 검사장에서 지금 쓰고 있다. 체크를 고칠 때는 지금 되는 기능이 멈추지 않게 조심한다.

## 1. 색 · 글꼴 · 스타일 (E안)
- 파랑 #1668C4 · 남색 #0B2545 · 하늘 #8FC9F2, 글꼴 Noto Sans KR
- 회색 바탕 위 흰 카드, 큰 숫자. 표는 줄 낮고 촘촘하게. 맨 위 머리말 한 줄만 남색.
- 상태 색: 파랑=하는 중 · 초록=끝남 · 주황=확인 필요 · 빨강=막힘
- 알림 색: 입고 파랑 · 출고 초록 · 입금 남색

## 2. 머리말
- 왼쪽: CI + 차곳간 + «제품 설명 · 제품 v번호 · 날짜» — 이 칸은 어느 제품이든 같은 크기
- 그 바로 오른쪽: 업체 이름 + 사업자번호 · 대표 (가운데에 두지 않는다)
- 오른쪽 순서: 공지 → 도움말 → 주소 → 새로고침 → 30초마다 → 연결됨 → 사람 단추
- «배치»는 머리말에서 빼서 안쪽으로. 휴지통·로그아웃은 사람 단추 안으로, 공지는 밖에.
- 사람 단추는 안에 마이페이지·휴지통 등이 있다는 것이 눈에 보이게.
- 제품 전용 단추는 하나만 (워시 = 현장 화면).

## 3. 탭 순서 (돈 도는 순서)
홈 → 일감 → 기록 → 월별 청구서 → 입·출금 내역 → 세금계산서 → (제품 전용) → 설정 ▸
- 홈은 워시·체크가 쓰는 레이아웃(일정 달력 등) 그대로. 달력 카드와 «이번 달 수금» 카드는 줄·열을 맞춘다.

## 4. 화면 뼈대 (순서 고정)
제목+설명 한 줄 → 할 일 띠 + [해결하러 가기] → 도구줄 → 숫자 칸 4개 → 표 → 접힌 도움 카드
- 요금제·사용량은 화면 위 줄 대신 «마이페이지» 팝업에서 보여 준다.
- 도구줄 안 칸·단추 높이 43px (좁은 화면 42px).
- 숫자 칸은 4칸 고정 · 가운데 정렬 · 자릿수 맞춤.

## 5. 공통 부품
- 표: 오름/내림차순 정렬, 검색, 보기 개수(5/10/20/30/50) 선택을 기본으로 넣는다. 체크칸은 크게. 이름 칸(딜러·상사명 등)은 틀 고정해서 옆으로 밀어도 보이게.
- 확인·안내 창: 브라우저 기본 경고창(alert / confirm / prompt) 금지. 화면 한가운데 팝업으로.
- 되돌리기 어려운 일(발급·발송 등)은 누구에게 · 총 몇 건 · 총 얼마인지 한 번 더 보여 주고 확인받는다.
- 날짜·달 고르기: 긴 목록(선택 상자) 금지, 달력으로.
- 자료 올리기: 달을 나눠 올리지 않고 엑셀 전체를 한 번에 올리고, 화면에 실시간으로 반영.
- 세금계산서, 거래처 관리, 업체등록, 알림톡처럼 공통인 것은 모든 제품에서 같은 UI · 같은 워딩.
- 상사·딜러 추가는 거래처 시안 방식: 한 화면에서 추가, 사진으로도 추가(상사=사업자등록증, 딜러=명함), 세금계산서 정보는 딜러 줄을 눌러 그 창에서 입력.

## 6. 사장님께 파일을 따로 줄 때
- 화면 파일은 .js 말고 HTML.
- 파일 이름에 어느 제품 것인지 확실히: «번호_차곳간_제품_내용_기간» 꼴 (예: 1_차곳간_워시_청구서화면.html).
- 번호는 올리는 순서와 똑같이. 여러 개면 압축 파일(zip)도 같이.
- 가이드·작업노트는 워드(.docx)로.

## 7. 사장님이 직접 해야 할 일을 안내할 때
- 올리는 곳 주소는 안내 파일 안에만 두지 말고 채팅에도 꼭 같이 적는다.
- «1단계 / 2단계»로 나누고 각 단계마다:
  ① 어떤 파일을 메모장으로 열어 Ctrl+A → Ctrl+C
  ② 중간 화면 없이 그 페이지가 바로 뜨는 전체 주소
  ③ 그 화면에서 누를 것: Ctrl+A → Delete → Ctrl+V → Run/Deploy
- «메뉴 → 메뉴» 줄임말 금지. 어느 메뉴를 어떤 순서로 누르는지 한 단계씩 풀어 쓴다.

## 8. 다 만든 뒤 점검
화면을 고쳤으면 끝내기 전에 chagotgan-ui-checker 일꾼에게 검사를 맡기고, 걸린 것을 고친 뒤 사장님께 보고한다.

규칙이 바뀌면 이 파일도 같이 고친다. 이 규칙과 사장님의 새 말이 다르면 새 말이 우선이고, 이 파일을 고칠지 물어본다.

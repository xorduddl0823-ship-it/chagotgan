## 올리는 법 (Cloudflare, 약 5분)
1. 지난번 워시를 올린 폴더를 통째로 복사해 새 이름(예: `워시_v122_올리기`)을 붙여요. 원래 폴더는 그대로 둬요(되돌릴 때 필요).
2. 복사한 폴더의 `index.html` 을 `워시/1_차곳간_워시_index_v122.html` 로 바꿔 넣어요(이름은 `index.html`).
3. Cloudflare → Workers & Pages → app.cgg.co.kr 칸 → Create deployment → 폴더를 끌어다 놓기 → Deploy.

## 올린 뒤 확인 (5분)
1. 새로고침 → 머리말 판 번호가 **«v122 · UI 3.0»** 이에요.
2. 메뉴 **홈 · 매출 · 일감 · 청구서 · 입출금 · 세금계산서 · 자재 · 설정**, 오른쪽 위 **사람 버튼 ▾** 안에 휴지통 · 화면 설정 · 상단 버튼 위치.
3. 일감 › 입출고 내역: 표 위 상태 탭(전체 · 작업 중 · …) · 줄마다 [출고]/[입금 완료].
4. 사람 버튼 ▾ › 요금제 → «이용요금» 창 · [결제 내역].
5. 폰으로 열어 아래 탭바와 현장 화면(입고 · 출고 큰 버튼)이 보이는지.
6. 내 번호로 입고 · 출고를 한 번씩 → 카카오톡(② 코드가 있으면) 또는 문자.

## 되돌리는 법 (1분)
- Cloudflare → Deployments → 바로 아래 줄 ⋯ → **Rollback** → 머리말이 예전 판 번호면 끝.
- 버튼이 없으면 1번에서 둔 원래 폴더를 다시 올리거나, 저장소의 `워시/1_차곳간_워시_index.html`(v111)을 `index.html` 로 올려요.
- **v111 로 되돌렸고 ④(Public 끄기)를 했다면 Public 을 다시 켜 두세요** — v111 은 예전 사진 주소를 써요.
- 서버(sb13)는 그대로 둬도 v111 · v119 화면이 돼요(`서버/설계/16` 확인).
- 되돌린 뒤 총괄 방에 한 줄만 알려 주세요.

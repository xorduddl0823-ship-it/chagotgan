# 워시 새 판 v114 올리는 법 · 되돌리는 법

> 워시 방 · 2026-10-15 · 보안 방 **통과** (`보안/검사기록/2026-10-15_워시v114_공통부품1.1.md`)
> 올리는 때: **다음 주 시험이 끝난 뒤**. 올리기는 대표님만 해요.
> 올릴 파일: 이 폴더의 `index.html` (= `워시/1_차곳간_워시_index_v114.html` 과 똑같은 파일, 확인 번호 `6080de29c6bd`)

## 먼저 알아 둘 것 (1분)
- 바뀌는 것은 **화면 파일 하나**예요. 서버(수파베이스)는 건드리지 않아요. 손님 자료도 그대로예요.
- 올린 뒤 이상하면 **버튼 한 번으로 예전 판(v111)으로 돌아갈 수 있어요.** (아래 «되돌리는 법»)
- 손님이 골라 둔 메뉴 배치 · 밝기 · 글씨 크기는 그대로 이어져요.

## 올리는 법 (Cloudflare, 약 5분)
1. 대표님 PC에서 **지난번에 워시를 올릴 때 쓴 폴더**를 찾아요. (`index.html` 과 그림 파일들 — `favicon.svg` 같은 것 — 이 들어 있는 폴더)
2. 그 폴더를 **통째로 복사**해서 새 이름을 붙여요. 예: `워시_v114_올리기`
   - 원래 폴더는 그대로 두세요. 되돌릴 때 필요할 수 있어요.
3. 복사한 폴더 안의 `index.html` 을 **이 폴더의 `index.html`(v114)로 바꿔 넣어요.** 다른 파일은 그대로 둬요.
   - 파일 이름이 `index.html` 이 아니라면, 원래 있던 화면 파일과 **같은 이름**으로 바꿔서 넣어 주세요.
4. Cloudflare 접속 → 왼쪽 **Workers & Pages** → **app.cgg.co.kr 이 연결된 칸**을 눌러요.
5. **Create deployment(새로 올리기)** → 3번에서 만든 폴더를 끌어다 놓아요 → **Deploy(올리기)**.
6. 1~2분 뒤 초록색 «Success»가 뜨면 끝이에요.

## 올린 뒤 확인 (3분)
1. PC에서 app.cgg.co.kr 을 열고 **새로고침**을 한 번 눌러요.
2. 머리말 판 번호가 **«v114 · UI 3.0»** 이면 새 판이에요.
3. 메뉴가 **홈 · 매출 · 일감 · 청구서 · 입출금 · 세금계산서 · 자재 · 설정** 8개로 보이면 정상이에요.
4. 오른쪽 위 **«마이페이지 ▾»** 를 눌러 «휴지통»이 보이면 정상이에요.
5. 휴대폰으로도 열어서 맨 아래에 **홈 · 입고 · 출고 · 오늘 · 날짜 검색** 탭이 보이는지 봐요.
6. 입고 한 건을 넣어 보고, 목록에 뜨면 끝이에요.

## 되돌리는 법 (문제가 생기면, 1분)
**가장 쉬운 방법 — Cloudflare 되돌리기 버튼**
1. Cloudflare → **Workers & Pages** → app.cgg.co.kr 칸 → **Deployments(올린 기록)**.
2. 지금 것 바로 **아래 줄(그 전에 올린 것)** 오른쪽 **⋯** → **Rollback to this deployment(이 판으로 되돌리기)** → 확인.
3. 새로고침하고 머리말 판 번호가 **«v111 · UI 1.1»** 이면 돌아온 거예요.

**버튼이 안 보이면 — 파일로 되돌리기**
- 위 «올리는 법»에서 2번에 그대로 둔 **원래 폴더**를 다시 올리면 돼요.
- 원래 폴더도 없으면 저장소의 `워시/1_차곳간_워시_index.html`(v111)을 받아서, 위 3번처럼 `index.html` 자리에 넣고 올려요.

되돌린 뒤에는 총괄 방에 «워시 v111로 되돌렸어, 이런 일이 있었어» 한 줄만 알려 주세요. 워시 방이 고쳐서 새 판을 다시 드려요.

## 같이 알아 둘 것
- 서버 새 판(워시 sb2)과 순서는 상관없어요. v114 는 지금 서버(sb1)와도, 새 서버(sb2)와도 돌아가요.
- 이 폴더의 `index.html` 은 v114 를 그대로 복사한 거예요. 워시 방이 새 판을 만들면 이 파일과 이 안내도 같이 바꿔요.

## 2. 오류 글 — 영어 · 코드 글자가 안 보여요 (말 대조표 3 · 5장, 알림톡 목록 A)
- 오류 글 만드는 함수가 붙이던 `[permission_denied]` 같은 코드 꼬리를 뺐어요.
- 새 도우미 `kmsg`: 서버가 보낸 **우리말 쉬운 글만** 그대로 보여 주고, 영어 · 개발 용어(열쇠 · 스크립트 · 배포 · 시트 · 주소 · 파일 이름)가 섞이면 정한 말로 바꿔요.
- `e.message` 를 그대로 보여 주던 곳 **25곳 전부** → «○○하지 못했어요. 다시 시도해 주세요.» 꼴. 로그인 · 가입 · 결제 중 오류만 표준형(«~하지 못했습니다. 잠시 후 다시 시도해 주세요.»).
- 개발 용어 안내 빼기: ANTHROPIC_KEY · 앱스스크립트 · /exec · Code.gs · Verify JWT · shops.json · 솔라피 열쇠 · 스크립트 속성 · 구글 시트 → 화면에는 «프로그램 설정을 불러오지 못했습니다. 차곳간에 문의해 주세요.» / «서버에 연결하지 못했습니다. 인터넷 연결을 확인하고 다시 시도해 주세요.»
- «서버 파일(Code.gs)이 옛 버전이라 느립니다 — [배포 관리]…» 띠는 대표님이 할 수 없는 일이라 화면에서 뺐어요.
- 「실패」 한 단어로 끝나는 글 → 무엇이 안 됐는지 + 할 일 한 줄 (예: «입고를 저장하지 못했어요. 인터넷 연결을 확인하고 다시 시도해 주세요.»).
- 그 밖의 화면 알림 글도 해요체로(둘째 판 254줄). «주세요» 띄어쓰기 통일.

## 6. 직원 주소 안내 — 알림톡 먼저 (총괄: «늘 문자로만 가는 문제»)
- [링크 복사] 창의 «직원 폰으로 주소 안내 보내기» → 이제 **본사 알림톡 `staff_link`** 로 먼저 보내요. 변수: `직원명`(고른 직원 이름, 없으면 «직원») · `업체명`. **`접속주소`는 화면이 보내지 않고 서버(sb14)가 열쇠 없는 직원용 주소로만 채워요.**
- 알림톡 템플릿 코드가 아직 없으면(심사 뒤) **그 한 건만** 문자로 다시 보내요 — 다른 본사 알림톡(입고 · 출고 · 추가작업 · 청구서 · 입금확인)은 끄지 않아요.
- 문자로 갈 때 글도 «이름과 4자리 코드로» → «본인 휴대폰 번호와 비밀번호로 로그인하면 돼요»로 고침(직원용 주소만 들어 있음 · 열쇠 주소 없음).
- 보낸 뒤 말: 서버가 실제 방식(`via: ata|sms`)을 돌려줄 때만 «알림톡을 보냈어요 / 문자로 보냈어요», 없으면 «보냈어요» (지금 sb14 는 값이 없어서 «보냈어요»).

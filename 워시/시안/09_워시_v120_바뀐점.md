## 한 줄 요약
카드 결제창이 토스 새 창(v2)으로 바뀌고, 대표가 원하면 **자동 결제**를 켤 수 있어요(기본 꺼짐). 청구서에 **입금 기한 날짜**가 함께 가요.

## 바뀐 것
| | 어디 | 무엇 |
|---|---|---|
| (가) | 결제창 | 서버가 `sdk:"v2"` 를 주면 v2(`js.tosspayments.com/v2/standard`) — `customerKey` ANONYMOUS · 금액 · 주문번호 그대로. 돌아온 뒤 `payConfirm` 같음. **옛 서버면 예전 v1 창** |
| (나) | 이용요금 창 (대표만) | 서버 `billInfo().open` 이 false 면 칸 자체가 없음 |
| | 꺼짐 | 「자동 결제 켜기」 → 동의 화면(매달 금액 · 요금제 · 결제일 · 첫 결제일 · 다시 시도 · 끄는 법 · 동의 문구 2026-10-15판, 체크해야 다음) → `billStart` → v2 카드 등록창 → 돌아오면 `billIssue([authKey, "2026-10-15"])` |
| | 켜짐 | 카드사 · 끝 4자리 · 다음 결제일 · 결제 안 된 횟수 + [카드 바꾸기] + [자동 결제 끄기](`billOff` · 「이번 이용기간 끝까지 쓸 수 있어요」) |
| | 실패 중 | 창 맨 위 빨간 칸 「결제가 되지 않았어요. 다음 시도일 ○○」 + 까닭 + [카드 바꾸기] |
| (다) | 청구서 | `viewBill` 에 `dueDate`(YYYY-MM-DD). 설정 «입금 기한» 칸이 «매월 10일»·«10일» 이면 청구 월 다음 달 그날(말일 넘으면 말일), «2026-12-05» 면 그날. 알림톡 #{입금기한} 도 같은 날(«11월 10일»). 날짜가 없는 글이면 예전처럼 글 그대로 · dueDate 비움 |
| 그 밖 | 결제 창 «대표만» | 지금까지 화면 확인이 늘 통과하던 것을 로그인 때 적어 둔 역할로 바로잡음 → 매니저 · 직원에게는 «대표님만 보실 수 있습니다» (서버는 예전부터 거절) |

## 서버 방에 부탁할 것 (화면만으로는 못 함)
1. **sb10 `billSnap` 이 `dueDate` 를 버려요** → 딜러앱(d6 은 `b.dueDate` 를 읽음)에 기한이 안 보여요. `dueDate: /^\d{4}-\d{2}-\d{2}$/ 이면 그대로` 한 줄 더해 주세요.
2. `billInfo` 에 **다음 시도일 `nextTry`**(YYYY-MM-DD)를 더해 주세요. 없으면 화면은 «곧 다시 시도해요»로 보여요.

## 시험 (가짜 서버 · 가짜 토스 · PC 1440 / 휴대폰 390)
| 경우 | 결과 |
|---|---|
| 월 요금 카드 결제 | v2 창에 method CARD · 33,000원 · ANONYMOUS · 돌아올 주소 ?pay=ok/no |
| 스위치 꺼짐 | 자동 결제 칸 없음 |
| 켜기 | 동의 체크 없이 누르면 «동의에 체크해 주세요» → 체크 후 billStart → 등록창(customerKey 서버 값) |
| 등록창에서 돌아옴 | billIssue([authKey, 2026-10-15]) → «자동 결제를 켰어요 · 신한 끝 1234» · 주소의 authKey 지움 |
| 켜짐 → 끄기 | 묻는 창 → billOff → «껐어요» → 다시 열면 꺼짐 |
| 실패 중 | 맨 위 «결제가 되지 않았어요. 다음 시도일 2026년 11월 16일 · 까닭» |
| 등록 취소 | «카드를 등록하지 않았어요 · 자동 결제는 켜지지 않았어요» |
| 매니저 · 직원 | «대표님만» 창 · 자동 결제 서버 호출 0번 |
| 입금 기한 5가지 | 매월 10일→11-10 · 31일→11-30 · 2026-12-05 그대로 · 날짜 없는 글/빈칸 → dueDate 비움 |
- 입고 알림톡(v118~v119) 시험도 그대로 통과 · 화면 오류 0 · 가로 넘침 없음.
- **토스 테스트 모드 시험은 대표님이 테스트 열쇠를 넣은 뒤** (지금은 계약 전).

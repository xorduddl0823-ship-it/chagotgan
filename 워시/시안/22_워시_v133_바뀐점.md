# 워시 v133 바뀐 점 (v132 위에 덧붙임 · 2026-10-18)

대표님 요청: 브라더광택이 거래처 · 배달 장소를 **엑셀(CSV) 양식으로 한꺼번에** 직접 올리게.

## 화면
- **설정 › 거래처**: 표 아래 «엑셀로 한꺼번에 올리기» 칸 — [엑셀 양식 받기] [엑셀로 한꺼번에 올리기] (대표만 보임)
- **배달 › 목적지**: 같은 단추 두 개 + 목록에 «메모» 칸
- 올리기 순서: 파일 고르기(끌어다 놓기도 됨) → 미리보기(모두 · 새로 · 이미 있음 · 틀린 줄과 까닭) → [N줄 넣기] → 못 넣은 줄이 있으면 그 줄만 보여 줌

## 규칙
- 거래처: 같은 사람 = 상사 + 딜러 이름 + 휴대폰. 이미 있으면 건너뜀(고치지 않음). 처음 보는 상사는 같이 만듦(띄어쓰기 달라도 같은 상사로 봄)
- 사업자번호 · 대표자 · 이메일 = 상사 것(세금계산서가 «딜러 본인»이면 딜러 것)
- 세금계산서 칸: 상사 이름으로 / 딜러 본인 / 안 끊음 / 나중에(워시는 «나중에»를 따로 저장 못 해서 상사 있으면 «상사 이름으로», 없으면 «안 끊음»). 빈칸도 같음
- 배달 장소: 같은 이름이면 건너뜀. 장소 이름만 꼭 필요
- 양식 둘째 줄(예시)을 지우지 않고 올려도 건너뜀
- 엑셀 «CSV UTF-8» · «CSV(쉼표로 분리)» 둘 다 한글 안 깨짐. .xlsx 를 고르면 CSV로 저장하는 법을 알려 줌(옛 엑셀 읽기 도구 0.18.5 는 쓰지 않음)

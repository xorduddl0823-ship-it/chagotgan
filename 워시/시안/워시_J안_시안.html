워시 J안 시안

디자인 방의 합친 디자인 J안(4판) 틀을 그대로 쓰고, 그 안에 워시의 실제 메뉴를 채운 시안이에요. J안에서 자리만 있던 매출 내역 · 출고 기록 · 월별 청구서 · 자재를 새로 그렸어요. 숫자와 이름은 예시예요. 지금 쓰는 워시 화면은 하나도 바꾸지 않았어요 (다음 주 시험은 지금 화면으로 해요).

PC 화면(가로 1280)을 화면 폭에 맞춰 줄였어요. 글씨가 작으면 «PC 원래 크기»를 눌러 보세요.

이번 시안에서 한 것

  • 휴지통 자리 — 「나」안: 설정 메뉴에서 휴지통을 빼고, 오른쪽 위 사람 버튼 ▾ 안에만 두었어요. 눌러 보면 휴지통 창이 열려요.
  • 매출 내역: 지금 워시 화면(체크에서 옮겨 온 것)의 구성 그대로 — 올해 숫자, 최근 12달 막대, 월별/년별 표, 부가세 포함 · 별도 바꾸기(눌러 보세요).
  • 출고 기록: 차가 어디로 갔는지와 딜러 알림 상태(보냄 · 실패 · 예약). 실패한 건만 골라 다시 보내기. 출고 문자 설정은 접힌 카드 안.
  • 월별 청구서: 원본 순서 그대로 «1. 청구서 만들기 → 2. 청구서 보내기». 청구 기준(딜러별 · 매매상사별) 같은 고르기는 두 칸 버튼으로.
  • 자재: 자재 종류 · 부족 · 이번 달 구매 숫자, 재고 표, 부족한 자재 주문 문자.
  • 입·출금 · 받아야 할 금액 · 세금계산서: 대표님 결정대로 서버 이사 뒤 체크 화면을 옮겨 올 자리만 표시했어요.
  • 홈 · 입출고 내역 · 현장 화면은 J안 4판 그대로예요.

지킨 것 — 탭 순서 그대로 · 표 열 차례(☐ → 이름 → 번호 → 내용 → 날짜 → 금액 → 상태) · 해요체 쉬운 말 · J안 색과 크기만 사용 · 폰은 표 대신 목록. 공통 틀과 스타일은 디자인 방 것이라 고치지 않았어요. 새로 넣은 부품(매출 막대 · 두 칸 버튼 · 단계 번호)은 디자인 방에 공통 부품으로 넣을지 물어볼게요.

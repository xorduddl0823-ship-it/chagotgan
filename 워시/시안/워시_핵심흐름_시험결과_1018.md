# 워시 핵심 흐름 검토·시험 결과 (10/18 밤 · 브라더광택 내일 첫날용)

## 한 줄 판단 — 내일 무엇을 쓸까
**v136.1 을 추천해요.** 지금 정식 v135 보다 안전해요.
- v135 와 다른 점: ① 세금계산서 합계 = 공급가액 + 세액으로 맞춤(v135 는 합계가 틀리게 보임 — 대표님이 찾은 오류) ② 거래처 사진으로 전화·이메일 채우기 ③ 위쪽 «주소»(링크 복사) 단추가 지금 서버에서 안 열리던 것 고침.
- 위험: 세금계산서 셈 부분만 바뀌어 그쪽을 다시 시험했고(아래 ⑤), 입고·출고·청구서·입금 흐름은 v135 와 똑같이 동작했어요. 문제가 생기면 Cloudflare 에서 v135 로 바로 되돌릴 수 있어요.
- v137(알림톡 잠금)·미수 묶어 보내기는 내일 쓰는 데 영향 없게 갈래에만 있어요.

## 결과표
확인 방법: 코드 = 화면 코드와 서버(sb23) 코드 맞춰 봄 · PW = 가짜 서버로 화면을 실제로 눌러 봄(Playwright) · 대표 = 실제 서버에서 대표님이 눌러 봐야 함

| 흐름 | 결과 | 확인 방법 | 비고 |
|---|---|---|---|
| ① 현장 입고 (딜러 찾기 → 사진 → 번호 → 작업·단가 → 입고 등록) | 확인함 | PW(폰 390px) + 코드 | 저장 뒤 입고 알림톡(intake) 나감. 사진 올리기(driveUploadMany)는 서버와 주고받는 모양이 맞음 |
| ① 현장 출고 (차 고르기 → «이 차가 맞나요» → 출고 사진 → 목적지 → 출고 처리) | 확인함 | PW(폰) | 상태 «출고»·목적지·사진 저장, 출고 알림톡(release) + 보기 코드 붙음 |
| ② 출고 → 도착 알림 → 딜러가 «도착 사진 보기» 열기 | 화면·서버 확인함 / 실제 열기는 대표님 시험 | 코드 + PW + 대표 | v.html 이 부르는 viewCar 와 서버 보기 코드(24자리)가 맞음. 실제 카톡 단추 눌러 사진 뜨는지는 실제 서버에서만 확인 가능 |
| ③ 월별 청구서 만들기 → 보내기 → 링크 → «보냄» | 확인함 / 실제 받기는 대표님 시험 | PW + 코드 + 대표 | 청구서 5줄 만들어짐, 청구서 알림톡(bill)·보기 코드 붙음 |
| ④ 입금 확인 (받을 금액 → 입금 확인) | 확인함 | PW | 4줄 → 3줄, «○○ 님 200,000원 입금 완료» |
| ④ 입금 되돌리기 | 확인함 | PW | 되돌리기 → 다시 4줄, «되돌렸어요». 받은 줄은 처음에 숨겨져 있어 «받은 건은 숨기기»를 꺼야 보임 (다음 판에서 안내 손보기) |
| ④ 은행 엑셀로 입금 맞추기 | 워시엔 아직 없음 | 코드 | 체크엔 있음. 서버 sb25 와 함께 공통 부품으로 다음 판 |
| ⑤ 세금계산서 (입금 끝난 것만 · 홈택스 양식 · sb23) | 확인함 | PW + 코드 | v136 에서 합계 = 공급가액 + 세액 맞춤 |
| ⑥ 거래처 엑셀 올리기 · 명부 | 확인함 | PW | 칸 짝짓기·xlsx 그대로 |
| 위쪽 «주소»(링크 복사) 단추 | **고친 것 (v136.1)** | 코드 + PW | 지금 서버엔 옛 주소 기능(webAppUrl)이 없어 «불러오는 중»만 뜨고 안 열렸음 → 직원용 주소로 바로 열림 |
| 체크에서 찾은 «최근 30일/62일만 받아 옴» 버그 | 워시엔 없음 | 코드 | 워시는 입고·출고·청구·입금 자료를 처음에 통째로 받아 와요(apiLoad). 기간을 정해 받아 오는 곳은 통장 연결(bankList, 고른 기간 그대로)뿐 → v135.1 필요 없음 |
| 통장 연결(자동 입금 확인)·세금계산서 수정발행 | 서버에 아직 없음 — 내일 쓰지 않기 | 코드 | 누르면 «지원하지 않는 기능» 이 떠요. 화면은 건드리지 않음(서버 sb25 때 함께) |

## 대표님 실제 시험 — 10~15분 (내일 아침, 받는 번호는 대표님 폰)
준비: 브라더광택으로 로그인 · 딜러 한 명을 **대표님 폰 번호**로 만들어 두기(시험용 딜러)

1단계 (폰, 3분) — https://app.cgg.co.kr 를 폰 크롬으로 열기 → 아래 «입고» → 시험용 딜러 고르기 → 아무 차 사진 → 번호 «12가3456» → 작업 하나 → «입고 등록»
   ▶ 대표님 폰에 **입고 안내 카톡**이 오면 통과
2단계 (폰, 3분) — 아래 «출고» → 방금 차 → «맞아요 — 출고하기» → 출고 사진 → 목적지 → «출고 처리 + 알림 보내기»
   ▶ **출고 안내 카톡** 오고, 카톡의 «도착 사진 보기»를 누르면 사진이 뜨면 통과
3단계 (PC, 4분) — https://app.cgg.co.kr → «월별 청구서» → «청구서 만들기» → 시험용 딜러 줄 «보내기»
   ▶ **청구서 카톡** 오고, «청구 내역 보기»를 누르면 금액이 맞게 뜨면 통과
4단계 (PC, 2분) — «입·출금 내역» → «받을 금액» → 시험용 딜러 «입금 확인»
   ▶ 그 줄이 사라지면 통과. 되돌리려면 «받은 건은 숨기기»를 끄고 그 줄의 «되돌리기»
5단계 (PC, 2분) — «세금계산서» → 방금 입금 확인한 줄이 보이고 합계 = 공급가액 + 세액이면 통과 (실제 발급은 누르지 않기)

안 되는 단계가 있으면 그 화면 사진만 보내 주세요. 문제가 크면 Cloudflare → chagotgan-wash → Deployments → v135 줄 ⋯ → Rollback 으로 바로 되돌려요.

# 워시 v118 바뀐 점 (v117 → v118)

> 워시 방 · 2026-10-15 · 총괄 요청 «입고 알림톡(intake)» · 운영 v111 · v112~v117 은 그대로
> 만드는 법: `워시/도구/만들기_워시_v118.py` (v117 을 읽어 v118 을 만듦) · 미리보기: `워시/시안/워시_v118_미리보기.html`

## 한 줄 요약
차가 들어오면 딜러에게 «차량 입고 안내» 알림톡을 보낼 수 있어요. **처음엔 꺼져 있고**, 업체가 켜야 자동으로 나가요.

## 바뀐 것
| 어디 | 무엇 |
|---|---|
| 설정 → 알림 | 「입고하면 딜러에게 알림톡 보내기」 켜고 끄기 칸 (기본 꺼짐 · 업체 설정 `send.autoIn`) |
| 입고 등록 → 완료 창 | 「딜러에게 입고 알림톡 보내기」 단추 — 한 건씩 보내기. 자동으로 이미 보냈으면 «다시 보내기», 결과(알림톡/문자/발송함)를 바로 보여 줌 |
| 보내는 내용 | 서버 sb7 키 `intake` · 확정본 «차곳간_입고안내» 변수 7개 (딜러명 · 상사명 · 업체명 · 차량번호 · 작업내용 · 입고일시 · 업체전화). 업체명 · 업체전화는 서버가 덮어씀. 보기코드 · rec 필요 없음 |
| 알림톡이 안 될 때 | 확정본 대체 문구로 문자 «[차곳간] 12가3456 입고되었습니다. ○○ 문의 …» (v117 과 같은 길) |
| 딜러 번호가 없을 때 | 안 보냄 · 완료 창에 «딜러 번호가 없어 입고 알림톡은 보내지 않았어요» |

- 판금·도색에서 돌아온 차(재입고)는 보내지 않아요 (새 입고만).
- 기본값(켜짐/꺼짐)은 총괄 방이 대표님께 다음 결정 묶음으로 여쭤요. 바꾸려면 `autoInOn()` 한 줄만 고치면 돼요.

## 시험 (가짜 서버 미리보기 · PC 1440 · 휴대폰 390)
| 경우 | 결과 |
|---|---|
| 꺼짐 · 단추 누름 · 코드 있음 | 알림톡(intake) 1건 |
| 꺼짐 · 단추 누름 · 코드 없음 | 알림톡 시도 → 문자로 1건 |
| 켜짐 · 코드 있음 | 등록하자마자 알림톡 · 완료 창 «입고 알림톡을 보냈어요» |
| 켜짐 · 코드 없음 | 문자로 · 완료 창 «입고 문자를 보냈어요» |
| 켜짐 · 딜러 번호 없음 | 안 보냄 · 단추 없음 |
| 설정 칸 | 처음 꺼짐 → 켜고 저장 → 켜짐 유지 |
- 모든 경우 화면 오류 0 · 가로 넘침 없음.

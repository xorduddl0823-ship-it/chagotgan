# 워시 화면 — 문자 보내는 곳 목록과 「알림톡 먼저」로 바꿀 계획 (규칙 5-6)

## 지금 워시가 문자를 보내는 길 (중요)
- 화면에서 실제로 보내는 곳은 **딱 한 함수 `sendNow`** 예요. 모든 발송이 여기를 거쳐 서버 `sendMsg` 로 가요.
- 알림톡 길은 **이미 있어요** (`ataPlan` → `kind:"ATA"` + 템플릿 · `disableSms`). 다만 지금은 **업체가 설정에서 켜야만**(`ataOn`) 쓰이고, 사진이 있으면 사진 문자로 가요.
- 그래서 할 일은 «새로 만들기»가 아니라 **«기본을 알림톡으로 뒤집기 + 템플릿을 관리 설정에서 받기»** 예요.

## 서버 방 새 판이 오면 화면에서 할 일 (v116)
1. `ataCfg()` — 업체가 켜지 않아도 **기본 켜짐**. 템플릿 코드 · 카카오 채널(pfId)은 업체 설정이 아니라 **서버가 주는 관리 설정 값**을 씀 (서버 방이 정하는 창구 이름으로 받기).
2. `ataPlan()` — «사진이 있으면 사진 문자로» 줄을 빼고, 알림톡 + `disableSms:false`(실패 시 문자 대체)로.
3. 템플릿이 비어 있으면 지금처럼 문자 (규칙 5-6 «비어 있으면 문자로» — 언제 올려도 안전).
4. 알림톡 본문은 **심사받은 템플릿 글과 똑같이** — 업체가 문구를 고치는 칸은 알림톡에선 막고 «문자로 보낼 때만» 쓰이게 안내.
5. 결제 · 충전 · 연장을 권하는 문장 · 버튼을 알림톡 본문에 넣지 않음 (청구서 «입금 계좌»는 정보라 괜찮은지 서버 방 · 총괄 확인).
6. 위 표의 문구 바꾸기 + 미리보기(가짜 서버)로 «알림톡 보냄 / 실패 → 문자» 두 경우 확인 → 보안 방 검사.

# 가입 완료 화면은 어디서 나오나 · 실제 사이트와 저장소 판 차이 (워시 방, 2026-10-14)

요청서: `운영/요청서/2026-10-14_03_워시_가입완료_문구.md`, `…_04_대표님없이_진행.md` 워시 1번

## 결론
- 「가입이 끝났습니다」 화면은 **워시 파일이 아니라 홈페이지의 회원가입 페이지(`cgg.co.kr/join.html`)** 에서 나와요.
  - 워시 v111 로그인 화면의 «무료로 시작하기»를 누르면 `cgg.co.kr/join.html` 로 넘어가요 (워시 파일 `ccwHomeUrl()` + `"join.html"`, 주석 «약관 동의가 있는 회원가입 페이지»).
  - 서버 wash-api sb1 의 `joinMode` 창구 주석에도 «회원가입 페이지가 물어봅니다»라고 적혀 있어요.
  - 워시 파일 안의 예전 가입 방식은 가입이 끝나면 완료 화면 없이 바로 화면으로 들어가요. 그래서 이 문구가 저장소에서 안 보였어요.
- **`join.html` 은 저장소 어디에도 없어요.** 홈페이지 서랍(`홈페이지/`)에도 없어요. → 이 파일은 **홈페이지·앱 방 서랍** 몫이라, 실제 문구를 바꾸는 일은 홈페이지·앱 방이 해요. 워시 방은 문구 시안까지 만들었어요.

## 실제 사이트와 저장소 판(v111) 차이
- 이 작업방에서는 `app.cgg.co.kr`, `cgg.co.kr` 에 **접속이 막혀 있어** 실제 사이트를 직접 열어 보지 못했어요. 그래서 판 번호를 비교하지 못했어요.
- 대표님이 확인하는 방법 (1분): 실제 워시 화면 맨 위 머리말에 작게 적힌 판 번호(예: «v111 · UI 1.1»)를 봐 주세요.
  저장소 판은 **«워시 v111 · UI 1.1 · 2026-10-12»** 예요. 같으면 화면 쪽 차이는 없어요.
- `join.html` 은 저장소에 없으니, 홈페이지·앱 방이 대표님 PC나 실제 사이트에서 받아 `홈페이지/` 서랍에 올려야 고칠 수 있어요.

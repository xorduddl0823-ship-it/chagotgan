## 한 줄 결론
- **청구서 보내기**는 이미 카카오 승인된 «차곳간_청구서» 템플릿으로 바로 만들 수 있어요. 막히는 곳은 하나예요: 승인된 버튼 주소가 **워시 쪽 보기 페이지(app.cgg.co.kr/v.html)** 라서, 그 페이지가 체크 청구서도 열 수 있어야 해요.
- **재검사 알림**은 승인된 템플릿이 **없어요.** 알림톡 방이 새 템플릿을 만들어 카카오 심사를 받아야 하고(며칠 걸림), 그동안은 문자로만 보낼 수 있어요.

## A. 청구서 보내기 (`billSend`) — 1순위
### 화면 (체크 v43 — 시험 뒤)
- 월별 청구서 › «2. 청구서 보내기» 카드를 그대로 살려요. 버튼 셋만 켜요: **선택한 곳에 보내기 · 내 번호로 시험 · (고르기 칸) 안 보낸 곳만**.
- 보내기 전 **이름 확인 창**(1.5 규칙 ②): 「하늘모터스 외 4곳에 9월 청구서를 보낼까요? 알림톡으로 가고, 안 되면 문자로 가요.」 → 보낸 뒤 결과 표: 곳마다 «알림톡 보냄 / 문자로 보냄 / 못 보냄(이유)».
- 문구는 **승인된 본문 그대로**라 화면에서 고치지 않아요. 고칠 수 있는 건 «입금 기한»과 «계좌» 두 가지만(설정에 저장된 값이 기본).
- 지금 «준비 중»인 예약 발송 · 문구 저장 · 청구서 그림으로 받기 · 다른 청구처로 옮기기는 이번에 안 해요(그대로 «준비 중»).

### 서버 창구 (서버 방 · check-api v33)
```
billSend({ ym, ids: [invoiceId…], due: "10월 25일", test?: true })
  → { sent: n, results: [{ id, name, ok, how: "ata"|"lms"|"sms", why }] }
```
- **대표만**(`ownerOnly`) · 한 번에 최대 100곳 · 같은 청구서는 10분 안에 다시 안 보냄(두 번 누름 막기).
- `ids`는 **이 검사소의 그 달 청구서**만 받아요. 다른 곳 id가 섞이면 전체 거절.
- 받는 번호 = 청구처(대표 딜러) 번호. `dealerTelOk`와 같은 확인(등록된 딜러 번호만).
- `test: true`면 받는 번호 = **로그인한 사람 번호**로 바꿔 한 통만, `sent_at`은 안 바꿔요.
- 변수는 **서버가 채워요**(화면 값을 믿지 않음 — 가짜 링크 막기, 설계/10과 같은 규칙):
  | 변수 | 값 |
  |---|---|
  | `#{기간}` | 「2026년 9월」 |
  | `#{받는곳}` | 청구처 이름 |
  | `#{업체명}` · `#{업체전화}` | `check_office.name` · `tel` |
  | `#{건수}` | 청구서 줄 수 |
  | `#{금액}` | `total_amount` 쉼표 (본문에 「원」 있음) |
  | `#{입금기한}` | 화면 값(날짜 모양만 · 20자) — 없으면 「확인 후 입금」 |
  | `#{계좌}` | `check_office.bank_fee` (정비비 계좌는 본문 칸이 없어 이번엔 안 넣음) |
  | `#{보기코드}` | 그 청구서 `view_key` (서버가 읽음) |
- 템플릿 키: `hqAta().tpl.bill` (워시와 **같은 승인 템플릿 · 같은 본사 채널**). 없으면 확정본 «대체 문구»로 문자.
- 보낸 뒤: `sent_at` · `send_how` · `send_err`(쉬운 말) 저장, `cgg_sendlog`에 `tpl:"check_bill"` · `ref:invoiceId`.
- 비용: 지금 체크 차량 도착 알림과 같은 방식(캐시를 깎지 않음)으로 시작하고, 과금은 결제 방과 따로 정해요 — **총괄 결정 ②**.

### 막히는 곳 — 버튼 주소 (총괄 결정 ①)
승인된 청구서 템플릿 버튼은 `https://app.cgg.co.kr/v.html?c=#{보기코드}` 예요. 이 페이지는 지금 **워시 보기코드만** 알아요.
| 안 | 내용 | 좋은 점 | 걸리는 점 |
|---|---|---|---|
| **1안 (추천)** | v.html이 코드를 못 찾으면 체크 서버 `invoiceView`에 한 번 더 물어 체크 청구서를 그려요 | 카카오 재심사 없음 · 바로 됨 | v.html 주인 방(워시 · 서버)에 일이 생김. 체크 코드와 워시 코드가 겹치지 않게 체크 코드 앞에 `k` 붙이기 |
| 2안 | 체크 전용 청구서 템플릿(버튼 `check.cgg.co.kr/b/#{보기코드}`)을 새로 심사 | 체크 안에서 끝남 | 심사 며칠 · 템플릿 14개로 늘어남 |
| 3안 | 알림톡 없이 문자만(주소 `check.cgg.co.kr/b/…`) | 오늘이라도 됨 | 규칙 6 «알림톡 먼저»와 맞지 않음 |
- 어느 안이든 **체크 청구서 보기 페이지**(로그인 없이 한 장 보기)는 새로 필요해요. 체크 방이 화면을 만들고(체크 서랍), 1안이면 v.html에 붙일 조각으로 넘겨요.
- `invoiceView` 보안 보강(서버 방): 열쇠 18자 그대로 · 열 때마다 `rateOk`(IP별) · 사업자번호 등 꼭 필요한 칸만 돌려주기(지금은 청구서 칸 전부 `select("*")` — 검사소 id · 세금계산서 칸 같은 내부 값까지 나가요).

## B. 재검사 알림 (`remindSend`) — 1순위, 템플릿 심사 뒤
### 무엇을 보내나
- 검사일 + `ins_valid_days`(예: 120일) = 만료일. 만료 **30일 · 15일 · 7일 · 3일 전**(검사소가 고름) 중 오늘 해당하는 차를 **딜러 한 명에 한 통**으로 모아요.
- 같은 차 · 같은 단계는 **한 번만**(보낸 기록 `check_remind_log(office_id, car_id, step)` 고유).
- 이미 판매·재검사된 차를 뺄 «빼기»는 `check_car.remind_off`(true면 다시 안 감).

### 화면 (체크 v43)
- 지금 화면 그대로 쓰되 숫자 카드 · 표를 서버 값으로 바꿔요. 켜는 버튼: **알림 규칙 체크(저장) · 고른 딜러에게 보내기 · 빼기 · 엑셀 다운로드**. 예약 발송은 «매일 자동»으로 대신해요(규칙에서 켜고 끔).
- 보내기 전 이름 확인 창: 「김하늘 님 외 3명에게 차 7대 재검사 알림을 보낼까요?」

### 서버 창구 (서버 방 · check-api v33)
```
remindRule()                         → { days: 120, steps: [30,15,7], auto: false, past: true }
remindRuleSave({ steps, auto, past }) (대표만 · steps는 30/15/7/3 중에서만)
remindList({ range: "15d" })         → [{ carId, dealer, plate, car, date, exp, left, step, sent }]
remindSend({ dealerIds, test? })      → { sent, results: [{ dealer, cars, ok, how, why }] }   (대표만 · 최대 100명)
remindOff({ carIds, off })            (대표 · 매니저)
매일 09:10 (한국 시각) 자동: auto=true 인 검사소만 · 오늘 단계 차 → 딜러별 한 통 · 하루 상한 rateOk
```
- 변수(알림톡 방 새 템플릿 제안 — 화면 시안 문구 바탕): `#{업체명}` `#{딜러명}` `#{유효일수}` `#{대수}` `#{빠른만료일}` `#{대표차량}` `#{업체전화}` + 버튼 «차량 목록 보기» `#{보기코드}`(딜러별 · 30일 유효 · 그 딜러 차만).
- 템플릿이 승인되기 전에는 `smsIfNoCode=true`(문자) — 문자 비용이 늘어서 **자동 발송은 템플릿 승인 뒤에만** 켤 수 있게 해요.
- 새 표(SQL · 서버 방): `check_remind_rule` · `check_remind_log` · `check_car.remind_off` · `check_remind_view(view_key, dealer_id, expires_at)`.

## 보안 검사 받을 것 (보안 방)
1. 대표만 보내기(`ownerOnly`) · 다른 검사소 id 섞이면 거절 · 받는 번호는 등록된 딜러만 · 시험은 내 번호만.
2. 공식 채널로 가짜 링크 못 보내게 — 변수는 서버가 채움, `#{보기코드}`는 서버가 읽은 그 청구서 것만.
3. 로그인 없이 여는 보기 주소 2개(청구서 · 재검사 차량 목록) — 열쇠 길이 · 기한 · 횟수 제한 · 돌려주는 칸 최소.
4. 하루 상한 · 두 번 누름 막기 · 기록에 번호 가림(`sendMask`).
5. 문구에 개인정보는 딜러 이름 · 차량번호 · 금액까지(차대번호 · 전화번호 원문 없음).

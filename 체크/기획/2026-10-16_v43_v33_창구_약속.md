## 1. 청구서 보내기
### `billSend(ym, ids, opt)` — 대표만
- `ym` 「2026-09」 · `ids` 청구서 id 배열(최대 100, 이 검사소 그 달 것만 — 하나라도 아니면 전체 거절) · `opt = {due:"11월 10일"(20자 안, 빈 값이면 «확인 후 입금»), test:true|false}`
- `test:true`면 `ids[0]` 하나만, 받는 번호 = **로그인한 사람 번호**, `sent_at` 안 바꿈.
- 돌려줄 것:
```
{ sent: 2,
  results: [ { id, name:"김하늘", ok:true,  how:"ata"|"lms"|"sms", why:"" },
             { id, name:"박바름", ok:false, how:"",                why:"카카오톡을 쓰지 않는 번호" } ] }
```
  - `name`은 청구처 이름(시험이면 아무 이름이나 — 화면은 그대로 보여 줌). `why`는 쉬운 말(`sendErrEasy`). 영어면 화면이 «보내지 못했어요…»로 바꿔요.
- 화면은 보낸 뒤 `invoiceList`를 다시 불러 «보냄 / 열어봄»을 봐요(지금 `sent_at` · `view_at` 그대로).

### `invoiceList` — 바뀌는 것 없음 (`sent_at` · `view_at` · `view_key`)
### `officeGet` — 화면이 `bank_fee` · `tel` · `name`을 미리보기 문구에 써요(지금 그대로).

## 2. 재검사 알림
### `remindRule()` — 대표 · 직원
```
{ days:120, steps:[30,15,7], past:true, auto:false, ataReady:false }
```
- `days` = `check_office.ins_valid_days` (비면 120). `ataReady` = 본사 템플릿 `check_remind` 코드가 있으면 true.
### `remindRuleSave({steps, past, auto})` — 대표만
- `steps`는 30 · 15 · 7 · 3 중에서만(그 밖 숫자는 거절). `auto:true`는 `ataReady`일 때만 받아요(아니면 «재검사 알림톡이 승인된 뒤에 켤 수 있어요.»).
### `remindList(range)` — 대표 · 직원
- `range`: `"today"` · `"week"` · `"15d"` · `"month"` · `"all"` (만료일 기준, 오늘부터 그 기간 안 + `past`면 이미 지난 차도)
- `remind_off` 차는 빼고 돌려줘요.
```
{ days:120,
  rows:[ { carId, dealerId, dealer:"김하늘", plate:"12가3456", car:"그랜저 IG",
           date:"2026-06-15", exp:"2026-10-13", left:-3, step:3, sentAt:"2026-10-16T09:10:00" | "" } ] }
```
  - `left` = 만료일 − 오늘(날수, 지나면 음수). `sentAt` = 이 차 · 이 단계로 마지막 보낸 때. **차대번호 · 전화번호는 넣지 않아요.**
### `remindSend(carIds, opt)` — 대표만
- `carIds` 최대 300, 이 검사소 차만(아니면 전체 거절). 서버가 **딜러별로 묶어 한 통**씩. 같은 차 · 같은 단계를 이미 보냈으면 그 차는 빼요(`check_remind_log` 고유).
- `opt = {test:true}`면 고른 차 중 첫 딜러 것만, 받는 번호 = 로그인한 사람, 기록 안 남김.
- 승인 전(`ataReady:false`)이면 확정본 대체 문구로 문자.
```
{ sent: 3, results:[ { dealer:"김하늘", cars:2, ok:true, how:"ata"|"lms"|"sms", why:"" } ] }
```
### `remindOff(carIds, off)` — 대표 · 직원
- `off:true` 빼기 / `false` 다시 넣기. `{ n: 바뀐 차 수 }`
### `remindView(key)` — **열린 창구**(로그인 없음) · `/r/` 화면이 불러요
- 열쇠 영문 · 숫자 24자 안, 딜러별 30일. IP별 `rateOk`. 그 검사소 + 그 딜러 차만(`remind_off` 빼고).
```
{ office:{ name, tel }, dealer:"홍길동", days:120,
  cars:[ { plate, car, date, exp, left } ] }          // 기한 지나면 { expired:true, office:{name,tel} } 만
```
  - 화면: `체크/보기/재검사_r.html` (주소 `check.cgg.co.kr/r/<열쇠>` · `?c=` · `#` 모두 읽음)

```

  office:{ name, tel, bank_fee, bank_repair },
```

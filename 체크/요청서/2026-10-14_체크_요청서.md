체크 방은 `체크/` 서랍만 고칠 수 있어서, 다른 방 일은 여기 적어 두고 넘겨요.

```
[작업 요청서]
보내는 곳: 체크 방
받는 곳:   총괄 방
제목:      결정 기록에 「가온정산 가져오기는 가온 업체에만」 추가

1. 왜 필요한가요?
   대표님이 2026-10-14에 정하셨는데 아직 결정 기록에 없어요.

2. 무엇을 해 주면 되나요?
   운영/04_결정_기록.md 에 아래 두 줄을 남겨 주세요.
   - 체크 설정 › 자료 올리기의 「예전 자료 가져오기(가온정산)」는 없애지 않고 가온 업체에만 보이게 함 (대표님, 관련 방: 체크·서버)
   - 체크 J안 시안 만들기 허락. 다음 주 시험 동안 실제 체크 화면에는 반영하지 않음 (대표님, 관련 방: 체크·디자인)

3. 끝났다고 보는 기준
   결정 기록에 두 줄이 보임

4. 기다리는 다른 일
   없음

5. 보안 검토 필요?  아니요
```

```
[작업 요청서]
보내는 곳: 체크 방
받는 곳:   서버 방
제목:      check-api 에서 「가온」으로 박혀 있는 곳 정리 (다음 주 시험 뒤)

1. 왜 필요한가요?
   다른 검사소도 체크를 쓰게 하려면, 서버가 업체를 모를 때 가온으로 넘어가면 안 돼요.

2. 무엇을 해 주면 되나요? (서버/2_차곳간체크_서버_check-api_v22.ts 기준)
   ① 관리자 로그인 때 검사소를 못 찾으면 무조건 GAON 으로 여는 부분 → 「검사소를 골라 주세요」로 바꾸기
   ② 사진 읽기(aiJson · aiPlate · aiCard · aiBiz)에서 업체를 모르면 "GAON" 을 쓰는 부분 → 업체 없으면 거절
   ③ 기사 가입 · 로그인(deliv_signup 등)이 기사를 「이름만」으로 찾음 → 검사소까지 같이 보고 찾기
      (다른 검사소에 같은 이름 기사가 있으면 섞일 수 있어요. 업체가 둘 이상이 되기 전에 꼭 필요)
   ④ 「예전 자료 가져오기」(importLegacy)를 가온 검사소만 쓸 수 있게 서버에서도 막기
      (화면에서 숨기는 것만으로는 보안이 아니에요 — 규칙 2-1)

3. 끝났다고 보는 기준
   시험용 두 번째 검사소로 로그인했을 때 가온 자료 · 가온 이름이 한 번도 안 보이고, 가져오기 요청은 거절됨

4. 기다리는 다른 일
   체크 J안을 실제 화면에 넣는 일 (다음 주 시험 뒤)

5. 보안 검토 필요?  예 (③ 다른 업체 기사 계정이 섞일 수 있음)
```

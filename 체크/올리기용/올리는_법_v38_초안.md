## 올리는 순서 (꼭 이 차례 · `서버/설계/16` · 시험 날 한 장과 같음)
> **서버(① ~ ③)는 시험 날 이미 올렸으면 건너뛰어요.** 시험 주소도 운영 수파베이스를 같이 쓰기 때문이에요. 그때는 ④ 화면부터 하면 돼요.

| 차례 | 무엇 | 어디서 | 안내 |
|---|---|---|---|
| ① | SQL: `02` · `04` → `05` → `06` → `07` → `08` → `09` | 수파베이스 → SQL Editor | 모두 여러 번 돌려도 안전해요. 파일은 `서버/sql/` 에 있어요 |
| ② | 같은 이름의 사용 중 기사 확인 SQL (읽기만) | 수파베이스 → SQL Editor | `서버/설계/16` 「SQL ①」. 나온 이름이 있으면 그 기사에게 회사 코드를 알려 주거나 한쪽 이름을 바꿔요 |
| ③ | **체크 서버 v30** → **워시 서버 sb13** (이 차례로) | 수파베이스 → Edge Functions → `check-api` 다음 `wash-api` → Deploy | Verify JWT 는 꺼 둬요 |

- **새 직원 · 비밀번호를 초기화한 직원**은 처음 로그인할 때 휴대폰으로 확인 번호 6자리를 받아요(알림톡, 안 되면 문자).
- **본사가 기사 비밀번호를 임시 비밀번호로 바꾼 기사**는 로그인하자마자 「비밀번호를 새로 정해 주세요」 창이 떠요. 바꾸기 전에는 다른 기능을 쓸 수 없어요(서버 v30 + 기사 v25).
- 서버 비밀값 이름(값은 적지 않음): `SOLAPI_KEY` · `SOLAPI_SECRET` · `SMS_FROM` · `PF_ID` · `ANTHROPIC_KEY` · `POPBILL_LINKID` · `POPBILL_SECRET`.

## 올리는 법 (Cloudflare, 약 5분)
1. 지난번 체크를 올린 폴더를 통째로 복사해서 새 이름을 붙여요(예: `체크_v38_올리기`). 원래 폴더는 그대로 둬요(되돌릴 때 필요해요).
   - ⚠ Cloudflare 는 올릴 때 **폴더 전체를 바꿔요**. 청구서 보기 `v` 폴더나 차량 사진 보기 `d` 폴더 같은 다른 파일이 빠지면 안 돼서, 꼭 지난번 폴더를 복사해서 써요.
2. 복사한 폴더에서 두 파일만 바꿔 넣어요.
   - `index.html` ← `체크/2_차곳간_체크_index_v38.html`
   - `driver/index.html` ← `체크/driver/index_v25.html`
3. Cloudflare → Workers & Pages → `check.cgg.co.kr` 칸 → Create deployment → 폴더를 끌어다 놓기 → Deploy.

## 올린 뒤 확인 (5분)
1. `check.cgg.co.kr` → **Ctrl + F5** → 머리말 작은 글씨에 「**체크 v38**」와 「**서버 v30**」이 보이면 돼요.
2. 메뉴는 **홈 · 매출 · 정산 기록 · 청구서 · 입출금 · 세금계산서 · 알림 · 설정**이에요. 오른쪽 위 **이름 ▾** 를 누르면 마이페이지 · 요금제(대표만) · 휴지통 · 화면 설정 · 로그아웃이 나와요.
3. 청구서 › 월별 청구서 표를 확인해요.
   - 위에 상태 탭(전체 · 열어봄 · 안 보냄 · 보냄)과 개수가 있어요.
   - 아래에 「총 N건 · 10개씩 보기 · 이전 / 다음」이 있어요.
   - 폰에서는 표 대신 목록으로 보여요.
4. 설정 › 거래처 › 딜러에서 두 명을 고르고 「선택한 딜러를 한 곳으로 묶기」를 눌러요. 고른 이름이 적힌 확인 창이 뜨면 돼요(눌러도 「취소」로 닫으면 아무것도 안 바뀌어요).
5. 이름 ▾ › 요금제 → 「이용요금」 창과 [결제 내역]을 확인해요(대표만). 지갑을 잇기 전이면 「준비 중」 안내가 나와요.
6. 휴대폰으로 `check.cgg.co.kr/driver` 를 열어 기사 로그인 화면이 열리면 돼요.

## 되돌리는 법 (문제가 생겼을 때)
**세 개를 같이** 되돌려요. 화면만 되돌리면 새 직원 로그인 짝이 안 맞을 수 있어요.

| 무엇 | 되돌릴 것 |
|---|---|
| 화면 두 개 | Cloudflare → Deployments → 바로 아래 줄 ⋯ → **Rollback**. 이 버튼이 없으면 1번에서 둔 원래 폴더를 다시 올려요. 원래 폴더도 없으면 `체크/올리기용/되돌리기용/index.html`(v21)과 `되돌리기용/driver/index.html`(기사 원본)로 올려요 |
| 체크 서버 | `서버/2_차곳간체크_서버_check-api_v21_2.ts` (v21 + 로그인 잠금 · 보안 통과) |
| 워시 서버 | 그대로 둬요. 워시 화면 · 옛 체크 화면 모두 sb13과 맞아요 |

- 돌린 SQL(02 · 04 · 05 ~ 09)은 그대로 둬도 돼요. 옛 판은 그 칸을 쓰지 않아요.
- 되돌린 뒤 총괄 방에 한 줄만 알려 주세요.

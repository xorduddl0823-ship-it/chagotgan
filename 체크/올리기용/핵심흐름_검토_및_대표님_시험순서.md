## 3. 대표님 시험 순서 (TEST 검사소 · 10~15분 · 받는 번호는 대표님 폰)
> 단계마다 «이렇게 나오면 정상» / 아니면 그 화면 사진을 총괄 방에 보내 주세요.

**0) 올린 판 확인 (1분)**
1. check.cgg.co.kr 새로고침 → 왼쪽 위 «체크 v55.1». → 정상
2. 휴대폰으로 check.cgg.co.kr/r/abc → «성능점검 유효기간 안내»(차량 0대). → 정상 / «찾을 수 없음»이면 사진

**① 배달 (3분)**
1. 휴대폰 check.cgg.co.kr/driver → 기사 계정으로 로그인.
2. 예시 차(12가3456) 사진 찍기 → 목적지 누르기 → 받는 딜러 = **대표님 번호로 등록한 시험 딜러**.
3. 대표님 폰에 «차량 출고 안내» 알림톡(안 되면 문자) → 단추 눌러 사진 열림. → 정상
4. PC 체크 › 배달 › 배달 기록 → 방금 차가 «보냄»으로 보임. → 정상

**② 청구서 보내기 (3분)**
1. 월별 청구서 › 10월 › «청구서 만들기».
2. 시험 딜러 줄을 고르고 «내 번호로 시험» → 뜨는 확인 창에서 «시험 보내기» → 대표님 폰에 청구 안내 → «청구 내역 보기» 눌러 열림. → 정상
3. (실제 보내기는 시험 딜러 1곳만) «선택한 곳에 보내기» → 뜨는 확인 창에서 «보내기» → 표에 «보냄». → 정상

**③ 입금 확인 (3분)**
1. 입·출금 내역 › 입금 · 출금 › 맨 아래 «통장 문자 · 시트 줄 붙여넣기» 펼치기 → `[신한] 10/18 14:21 123-456-789012 입금 11,000 시험딜러` 붙여넣기 → 가져오기.
2. 표에 «확인 필요» 1줄 → 고르고 «선택한 줄 청구서에 맞추기» → 시험 딜러 청구서 → 맞추기 → «완료». → 정상
3. 같은 줄 «선택한 줄 되돌리기» → 다시 «확인 필요». → 정상
4. **같은 줄을 한 번 더 맞춰 두세요**(2번과 똑같이) → «완료». ④ 세금계산서 시험에 이 «입금 완료» 청구서를 써요. (그 줄 «선택한 줄 지우기»는 ④가 끝난 뒤에 해요)

**④ 세금계산서 (2분)**
1. 설정 › 입금 자동 확인 › 팝빌이 **시험 모드**인지 확인.
2. 세금계산서 › «홈택스 일괄발급 엑셀 받기» → 뜨는 확인 창에서 «내려받기» → 엑셀 파일이 받아짐. → 정상
3. 입금 완료된 시험 청구서 1줄 고르고 «팝빌로 발급» → 확인 창에서 «발급해요» → 표에 «발급». → 정상 (입금 전 줄은 고를 수 없음이 정상)
4. 시험이 끝나면 입·출금 내역에서 ③의 시험 줄을 «선택한 줄 되돌리기» → «선택한 줄 지우기».

**⑤ 재검사 알림 (1분)**
1. 재검사 알림 › 시험 딜러 «내 번호로 시험» → 뜨는 확인 창에서 «시험 보내기» → 대표님 폰 알림 → «차량 목록 보기» 열림(check.cgg.co.kr/r/…). → 정상

**⑥ 자료 올리기 (2분)**
1. 설정 › 자료 올리기 › «① 상사명부 올리기» → 카모두 상사리스트 → 미리보기 숫자 확인 → 넣기.
2. «② 딜러명부 올리기» → 딜러리스트 → 넣기.
3. 같은 화면 아래 «엑셀 여러 개를 한꺼번에 끌어다 놓기» 칸에 10월 접수리스트 → 월별 청구서 10월 «청구서 만들기» → 35곳 · 3,927,000원이면 정상.

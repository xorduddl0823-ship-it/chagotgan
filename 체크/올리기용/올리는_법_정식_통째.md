## 올릴 파일
`체크/올리기용/2_차곳간_체크_정식_v55_통째.zip` (지문 0fbb9bfe239c) — 압축은 풀지 않아요.

| zip 안 | 무엇 |
|---|---|
| `index.html` | 사무실 화면 체크 v55 (보안 통과 14d8c99) |
| `driver/index.html` | 기사 폰 화면 v28 (보안 통과 · 딜러 등록 대기) |
| `r/index.html` | 재검사 차량 목록 화면 |
| `_redirects` | 옛 주소 넘기기: `/d/열쇠`(도착 사진) · `/v/보기코드`(청구서 보기) → `app.cgg.co.kr/v.html` · `/r/열쇠` → 재검사 목록 |
| `_headers` | `/r/` · `/d/` · `/v/` 화면을 남기지 않고 · 검색에 안 나오게 |

## 1단계 — 올리기 (휴대폰 · 3분)
1. 아래 주소를 열어요:
   https://dash.cloudflare.com/
2. Workers & Pages → **check.cgg.co.kr** 쪽 이름을 눌러요 → Deployments → Upload(또는 Create deployment).
3. 위 zip 하나를 고르고 → Deploy.
4. 1분 뒤 https://check.cgg.co.kr 새로고침 → 왼쪽 위 작은 글자 **«체크 v55 · 10/18»** 이면 끝이에요.

## 2단계 — 확인 (3분)
1. 휴대폰으로 https://check.cgg.co.kr/driver → 기사 로그인 화면이 떠요.
2. 예전에 받은 도착 문자의 사진 주소(`check.cgg.co.kr/d/…`)를 눌러요 → 주소가 `app.cgg.co.kr/v.html?c=d…` 로 바뀌며 사진이 열려요.
3. 체크 사무실 화면에서 설정 › 자료 올리기 «첫날 쓰는 순서»대로 해요(상사명부 → 딜러명부 → 단가표 → 접수리스트 → 청구서).

## 깨질 수 있는 것 (한 줄씩)
- 예전 체크 사이트의 `v` 폴더(청구서 보기) 주소로 나간 링크: 서버 기록상 청구서 링크는 모두 `app.cgg.co.kr/v.html` 로 나갔어요. 혹시 `check.cgg.co.kr/v/…` 로 나간 링크가 있으면 넘기기로 새 보기 화면으로 가요 — 단, 아주 옛날(서버 v30 전) 보기코드 모양이면 «찾을 수 없어요»가 뜰 수 있어요.
- 예전 `d` 폴더 화면: 이제 폴더 대신 넘기기가 같은 주소를 새 보기 화면으로 열어요(사진 · 내용은 같아요).
- 그 밖에 예전 사이트에만 있던 파일(우리가 모르는 것)은 사라져요. 이상한 주소가 있으면 그 주소를 체크 방에 보내 주세요.

## 이상하면 — 되돌리는 법 (1분)
1. Cloudflare → Workers & Pages → check.cgg.co.kr → **Deployments**.
2. 바로 전에 올라가 있던 것(어제 날짜 쪽)의 «…» → **Rollback to this deployment**(이 판으로 되돌리기).
3. 1분 뒤 새로고침 → 예전 화면이면 돌아온 거예요. 자료(청구서 · 입금 · 거래처)는 서버에 있어서 그대로예요.

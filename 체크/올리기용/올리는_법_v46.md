# 체크 v46 «거래처 한 화면» 올리는 법 — 대표님용 (✅ 보안 통과 · 총괄 «올려요» 뒤에 씀)

> 보안 통과(보안/검사기록/2026-10-18_체크v46_거래처_한화면.md · 높음·중간·낮음 0). 총괄이 «v46 올려요»라고 할 때 써요.
> 먼저 **시험 주소(t.cgg.co.kr)** 에서만 시험해요. 운영 체크 주소(check.cgg.co.kr)는 시험이 끝난 뒤 따로 정해요.

## 1단계 — 서버 (이미 준비됨 · 약 5분)
- 체크 서버 **check-api v35** (b93d7d7 · 보안 통과 · SQL 없음). 서버 방 안내(`운영/06` «10/18 서버 판 배포 순서» 2번)대로 올려요.
- **워시 v.html(d 갈래)와 같은 날** 올려요(서버 방 안내).
- v35가 없으면(서버 v32 그대로면) 거래처 화면은 «서버를 새로 올려야 쓸 수 있어요»라고만 나와요. 다른 화면은 그대로예요.

## 2단계 — 시험 주소에 화면 올리기 (휴대폰 · 3분)
1. 총괄 방이 보내 주는 **시험 주소 zip**(체크 v46이 들어간 새 묶음)을 휴대폰에 저장해요. 압축은 풀지 않아요.
   - zip은 홈페이지·앱 방이 만들어요. 체크 방은 «체크 v46 파일: `체크/2_차곳간_체크_index_v46.html`»만 넘겨요.
2. 지난번처럼 dash.cloudflare.com → Workers & Pages → **bold-water-9ce8** → Deployments → Upload → zip → Deploy.
3. 1분 뒤 t.cgg.co.kr 새로고침 → 체크 화면 맨 위 작은 글자에 **«체크 v46»** 이 보이면 끝이에요.

## 올린 뒤 확인 — TEST 검사소에서 (10분 · 요청서 A 기준)
> 시작 전에 설정 › 거래처 위의 **«딜러 ○명» · «매매상사 ○곳»** 숫자를 적어 두세요(바꾸기 전 개수).
1. 숫자가 올리기 전과 같아요(자료가 사라지거나 늘지 않음).
2. **+ 딜러 추가** → 상사(처음 보는 이름) · 이름 · 휴대폰 세 칸만 → 저장 → 딜러가 생기고 상사 목록에 새 상사도 생겨요.
3. **명함 사진으로 추가** → 명함 사진 고르기 → 이름 · 상사 · 휴대폰이 채워져요 → 저장.
4. [상사] 보기 → **사업자등록증 사진으로 추가** → 사업자번호 · 대표자가 채워지고 «사업자번호 확인됨» → 저장.
5. 딜러 줄을 눌러 «세금계산서는 누구 이름으로?» 네 가지 중 하나 → 저장 → 표의 칩이 바뀌어요.
   («나중에 정할게요»는 서버 다음 판이 오면 보여요)
6. 위 **«○명 · 모아 보기»** 를 누르면 계산서 정보가 빠진 딜러만 보여요.
7. 시험으로 넣은 딜러 · 상사를 골라 **선택한 줄 지우기** → 이름 확인 창 → 지우기.
8. 지난달 청구서 금액을 한 번 봐 두고, 시험 뒤 같은 달 금액이 **그대로**인지 확인해요(청구 규칙은 안 바꿨어요).
9. 휴대폰으로도 같은 화면을 열어 깨진 곳이 없는지 봐요.

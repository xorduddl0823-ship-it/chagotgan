## 순서 (하나 끝나면 다음)
1. **서버 먼저** — 서버 방 안내대로 SQL 12 → 체크 서버 check-api v33 (서버/설계/19). 서버가 먼저 올라가야 새 버튼이 동작해요.
2. **체크 화면** — `체크/2_차곳간_체크_index_v43.html` 을 체크 화면 자리에 올려요(보안 통과 dfcb3b9 · 판 f390b94).
3. **재검사 차량 목록 화면 (새로)** — `체크/보기/재검사_r.html` 을 올리고, 주소 `check.cgg.co.kr/r/…` 로 들어오면 이 파일이 열리게 해요(지금 `/d/` 도착 사진 화면과 같은 방식).
   - **꼭 넣을 머리글** (`_headers` 파일, 보안 방 요청):
     ```
     /r/*
       Cache-Control: no-store
       Referrer-Policy: no-referrer
       X-Robots-Tag: noindex, nofollow
     ```
     (뜻: 남의 컴퓨터에 남기지 않기 · 다른 사이트로 주소가 새지 않기 · 검색에 안 나오기)
4. **워시 보기 페이지** — 워시 방이 이미 v.html 안에 체크 청구서 조각을 넣었어요(aa9b693). 워시 방 안내대로 올려요.

> 대표님이 확인한 시안 v50(10/18) 그대로예요. ① 둘째 탭 «정산 기록» 유지 ② 청구처 묶음은 합쳐진 이름(«홍길동 + 김철수») ③ «준비 중» 단추는 빼지 않고 실제로 되게 했어요(대표님 고침).
> **기능은 v48.1과 같아요.** 청구서 만들기 · 보내기 · 입금 맞추기 · 엑셀 · 거래처는 그대로이고, 머리말 · 메뉴 차례 · 화면 뼈대만 워시와 같은 모양으로 바뀌었어요.
> **서버는 안 바꿔요.** 화면 파일 하나만 바꿔요.
> ✅ 보안 통과 (10/18 · 파일 b0353dd62d24 · 보안 기록 578f667) · 서버는 check-api **v46**(세금계산서 입금 전 막기 · 전산외 금액 그대로 · 보험료 부가세)까지 올려요

## 바뀐 것 (가온진단평가 직원분께 한 줄로)
- 메뉴 차례: 홈 → 정산 기록 → 매출 → 월별 청구서 → 입·출금 내역 → 세금계산서 → 배달 → 재검사 알림 → 설정
- «알림» 메뉴가 «배달» · «재검사 알림» 둘로 나뉘었어요.
- 메뉴 줄 오른쪽 끝 «기능 찾기»에 하고 싶은 일을 쳐요(예: 청구서 보내기, 직원 추가).
- 청구서 인쇄 · 그림 · 엑셀 단추가 청구서 표 바로 위로 올라갔어요.
- 직원 계정은 설정 › «직원 계정 · 권한»에 있어요(예전: 설정 백업 안).
- 은행 엑셀 가져오기 · 통장 문자 붙여넣기는 입금 내역 맨 아래 «펼쳐 보기»를 눌러요.
- 예전에 «준비 중»이던 단추가 이제 눌려요: 엑셀 양식 받기, 청구서 «다른 청구처로» · «보냄 표시 지우기» · «선택한 줄 지우기», 입금 «알림 설정» · «이 기간 엑셀», 문자 붙여넣기, 배달 문구 값 끼우기, 알람 소리 시험, 휴지통 되살리기, 설명서 링크.
  (청구서 지우기 · 보냄 표시 지우기 · 알림톡 ID · 수수료 규칙은 서버 다음 판 전까지 «이 화면 · 이 PC»에서만 바뀌어요. **다른 PC · 휴대폰에는 안 보여요** — 서버 방에 요청해 뒀어요)

- 설정 › 거래처 아래 «엑셀로 한꺼번에 올리기»: 양식을 받아 상사 · 딜러를 적어 올리면 한 번에 들어가요(워시와 같은 양식).

## 0단계 — 서버 먼저 (서버 방 안내 `서버/배포안내_체크_v44.md` 그대로)
- 체크 서버 **check-api v46** + SQL 18 · 19 (서버 방 안내 `서버/배포안내_체크_v46.md` 순서대로)를 먼저 올려요.
- 서버를 안 올리고 화면만 올려도 다른 기능은 그대로 돼요. 검사비 알림 · 금액 넣기만 서버 v44 뒤에 나와요.

## 1단계 — 시험 주소에 먼저 올리기 (휴대폰 · 3분)
1. 체크 방이 넘기는 파일 `체크/2_차곳간_체크_index_v52.html` 이 든 **시험 주소 zip**을 총괄 방(홈페이지 · 앱 방)에서 받아 휴대폰에 저장해요. 압축은 풀지 않아요.
2. 아래 주소를 열어요:
   https://dash.cloudflare.com/
3. Workers & Pages 를 눌러요 → **bold-water-9ce8** 를 눌러요 → Deployments 를 눌러요 → Upload 를 눌러요 → 받은 zip 고르기 → Deploy 를 눌러요.
4. 1분 뒤 https://t.cgg.co.kr 새로고침 → 체크 화면 왼쪽 위 작은 글자에 **«성능점검 정산 · 체크 v52 · 10/18»** 이 보이면 끝이에요.

## 2단계 — 시험 주소에서 확인 (TEST 검사소 · 10분)
1. 맨 위 줄: 공지사항 · 도움말 · 주소 · 새로고침 · 30초마다 · **연결됨(초록 점)** · 이름 단추가 이 차례로 보여요.
2. 메뉴를 하나씩 눌러 봐요. 화면이 모두 열려요(빈 화면 · 오류 글 없음).
3. **월별 청구서**: 맨 위 주황 띠 «안 보낸 곳 ○곳 · 입금 대기 ○곳» → [해결하러 가기] → 표가 «안 보낸 곳만»으로 바뀌어요. 표 위 «미리보기 · 인쇄» · «엑셀 (요약)»이 예전처럼 나와요.
4. 지난달 청구서 금액이 올리기 전과 **똑같아요**(계산은 안 바꿨어요).
5. **입·출금 내역 › 입금 내역**: 띠 [해결하러 가기] → «확인 필요»만 보여요. 하나 골라 «선택한 줄 청구서에 맞추기» → 맞추기 → «되돌리기»로 원래대로.
6. 설정 › **직원 계정 · 권한**에 직원 목록이 보여요.
6-2. 매출 › 자료 올리기 › «접수리스트» 단추 → 엑셀 양식이 내려받아져요.
6-4. 설정 › 거래처 › «엑셀 양식 받기» → 받은 파일에 시험 딜러 한 줄 적기 → «엑셀로 한꺼번에 올리기» → 미리보기 «1줄 넣기» → 거래처에 생겨요. 시험 뒤 그 딜러는 지워요.
6-3. 월별 청구서에서 두 곳을 골라 «고른 청구서 → 다른 청구처로» → 옮길 곳 고르기 → 확인 창 → 옮기기. 시험 뒤에는 같은 방법으로 원래대로 옮겨 놓아요.
7. 메뉴 줄 오른쪽 «기능 찾기»에 «청구서 보내기» → 눌러서 그 화면으로 가요.
8. 휴대폰으로도 열어 봐요: 아래 탭 «홈 · 정산 기록 · 월별 청구서 · 입·출금 · 전체», «전체»를 누르면 모든 메뉴가 나와요.

## 2-2단계 — 검사비 금액 바로잡기 (대표님 «금액이 안 맞아요» · 가온에서 한 번)
1. 설정 › **단가표**를 눌러요. 맨 위 주황 띠를 봐요.
2. «코드를 이름으로 맞추기» 단추가 있으면 먼저 눌러요 → 확인 창 → 맞추기.
3. «가온 규칙으로 맞추기»를 눌러요 → 바뀌는 줄(2026-05-31까지 25,000 · 35,000 / 2026-06-01부터 30,000 · 40,000)을 보고 → 맞추기.
   - 6월 전 단가(25,000 · 35,000)도 함께 바뀌어요. 지난달 청구서를 «청구서 만들기»로 다시 만들면 그 달 금액도 새 단가로 바뀌어요(세금계산서 · 입금이 붙은 청구서는 그대로).
4. **매출** 화면 숫자는 바로 바뀌어요. 청구서는 월별 청구서에서 그 달을 고르고 «청구서 만들기»를 한 번 더 눌러요.
5. 10월 검사비가 나스 «가온 정산»과 같은지 봐요(정답 **3,927,000원**, 부가세 포함).
   - 서버 v44부터 재검 · 가성능은 0원, 단가표에 없는 상품명은 0원으로 셈하고 맨 위 띠로 알려 줘요(«단가표 보기»).
6. 띠에 «금액 넣을 수출 가성능 N대»가 나오면 월별 청구서 › «수출 가성능 금액 넣기» → 차마다 검사비(부가세 별도) → 저장 → «청구서 만들기» 한 번 더.

## 2-3단계 — 세금계산서 «입금한 곳만» 확인 (대표님 «매우매우 중요»)
1. **세금계산서** 화면: 입금이 덜 된 곳은 회색 «입금 전 — 발급 안 함»이고 네모를 누를 수 없어요. «발급할 수 있는 곳 전체 선택»도 입금 완료만 골라요.
2. 입금 전에 꼭 내야 하는 곳은 그 줄 «입금 전에 발급» → 확인 창(누구에게 · 얼마 · 아직 입금 안 됨)에서 한 번 더 눌러요.
   - 서버 다음 판(요청함)부터는 서버도 입금 전 발급을 막아요(이 단추로 확인한 곳만 예외).
3. **홈택스 일괄발급 양식 내려받기** 시험:
   ① 체크 세금계산서 화면 «홈택스 일괄발급 양식 내려받기» → 확인 창(몇 건 · 얼마) → 내려받기. 대표님이 주신 홈택스 공식 양식(일반) 그대로 7줄부터 채워져요(입금 완료만 · 영수 01 · 100건씩 파일 나눔).
   - 파일이 2개 이상이면 크롬이 «여러 파일 다운로드»를 물어요. 주소창 오른쪽에서 «허용»을 눌러요.
   ② 홈택스 일괄발급 화면 열기 (바로 뜨는 고정 주소가 없어서 한 단계씩):
      1) 아래 주소를 열고 로그인해요.
         https://www.hometax.go.kr
      2) 맨 위 메뉴에서 «계산서·영수증·카드»를 눌러요.
      3) «전자(세금)계산서 발급»을 눌러요.
      4) «일괄/공동매입분 발급» 안의 «전자(세금)계산서 일괄발급»을 눌러요.
      - 메뉴 이름이 조금 다르면 홈택스 맨 위 찾기 칸에 «일괄발급»을 쳐서 들어가요.
   ②-2 그 화면에서 내려받은 파일을 **불러오기**만 해요(발급 단추는 아직 누르지 않아요).
   ③ 오류 없이 줄이 읽히면 성공이에요. 오류가 나면 오류 글을 사진으로 찍어 체크 방에 보내 주세요.

## 2-4단계 — 나스 엑셀 · 보험료 부가세
1. 매출 › 자료 올리기 › «나스 엑셀 올리기» → «전산외청구 파일 고르기»(전산외청구 2026.xlsx) → 달마다 건수 · 금액 확인 → 넣기. «정비비 파일 고르기»도 같아요.
2. 월별 청구서 › «청구서 만들기» 한 번 더 → «청구 합계» 카드의 검사비 · 전산외 청구 · 정비비 · 총계를 나스와 견줘요(9월 총계 11,370,000원).
   - 전산외 «가성능» 같은 금액 그대로 넣기 · «계산서 발행 안 함» 나누기는 서버 다음 판(요청함)부터 정확해요.
3. 설정 › 거래처 › 우리 사업장 «보험료 부가세»는 가온 = **부가세 미포함**(기본)이에요. 매출의 보험료가 엑셀 금액 그대로 보여요.

# 체크 v51 «화면 통합» 올리는 법 + 되돌리는 법 — 대표님용

> **실제 주소 바꿔치기는 이 v51로 해요**(v50 대신). v51 = v50 + 머리말 차곳간 심볼 · 브라우저 탭 아이콘 + 거래처 엑셀 한꺼번에 올리기.
> 대표님이 확인한 시안 v50(10/18) 그대로예요. ① 둘째 탭 «정산 기록» 유지 ② 청구처 묶음은 합쳐진 이름(«홍길동 + 김철수») ③ «준비 중» 단추는 빼지 않고 실제로 되게 했어요(대표님 고침).
> **기능은 v48.1과 같아요.** 청구서 만들기 · 보내기 · 입금 맞추기 · 엑셀 · 거래처는 그대로이고, 머리말 · 메뉴 차례 · 화면 뼈대만 워시와 같은 모양으로 바뀌었어요.
> **서버는 안 바꿔요.** 화면 파일 하나만 바꿔요.
> 보안 검사: (보안 방 결과를 받은 뒤 적어요)

## 바뀐 것 (가온진단평가 직원분께 한 줄로)
- 메뉴 차례: 홈 → 정산 기록 → 매출 → 월별 청구서 → 입·출금 내역 → 세금계산서 → 배달 → 재검사 알림 → 설정
- «알림» 메뉴가 «배달» · «재검사 알림» 둘로 나뉘었어요.
- 메뉴 줄 오른쪽 끝 «기능 찾기»에 하고 싶은 일을 쳐요(예: 청구서 보내기, 직원 추가).
- 청구서 인쇄 · 그림 · 엑셀 단추가 청구서 표 바로 위로 올라갔어요.
- 직원 계정은 설정 › «직원 계정 · 권한»에 있어요(예전: 설정 백업 안).
- 은행 엑셀 가져오기 · 통장 문자 붙여넣기는 입금 내역 맨 아래 «펼쳐 보기»를 눌러요.
- 예전에 «준비 중»이던 단추가 이제 눌려요: 엑셀 양식 받기, 청구서 «다른 청구처로» · «보냄 표시 지우기» · «선택한 줄 지우기», 입금 «알림 설정» · «이 기간 엑셀», 문자 붙여넣기, 배달 문구 값 끼우기, 알람 소리 시험, 휴지통 되살리기, 설명서 링크.
  (청구서 지우기 · 보냄 표시 지우기 · 알림톡 ID · 수수료 규칙은 서버 다음 판 전까지 «이 화면 · 이 PC»에서만 바뀌어요. **다른 PC · 휴대폰에는 안 보여요** — 서버 방에 요청해 뒀어요)

- 설정 › 거래처 아래 «엑셀로 한꺼번에 올리기»: 양식을 받아 상사 · 딜러를 적어 올리면 한 번에 들어가요(워시와 같은 양식).

## 1단계 — 시험 주소에 먼저 올리기 (휴대폰 · 3분)
1. 체크 방이 넘기는 파일 `체크/2_차곳간_체크_index_v51.html` 이 든 **시험 주소 zip**을 총괄 방(홈페이지 · 앱 방)에서 받아 휴대폰에 저장해요. 압축은 풀지 않아요.
2. 아래 주소를 열어요:
   https://dash.cloudflare.com/
3. Workers & Pages 를 눌러요 → **bold-water-9ce8** 를 눌러요 → Deployments 를 눌러요 → Upload 를 눌러요 → 받은 zip 고르기 → Deploy 를 눌러요.
4. 1분 뒤 https://t.cgg.co.kr 새로고침 → 체크 화면 왼쪽 위 작은 글자에 **«성능점검 정산 · 체크 v51 · 10/18»** 이 보이면 끝이에요.

## 2단계 — 시험 주소에서 확인 (TEST 검사소 · 10분)
1. 맨 위 줄: 공지사항 · 도움말 · 주소 · 새로고침 · 30초마다 · **연결됨(초록 점)** · 이름 단추가 이 차례로 보여요.
2. 메뉴를 하나씩 눌러 봐요. 화면이 모두 열려요(빈 화면 · 오류 글 없음).
3. **월별 청구서**: 맨 위 주황 띠 «안 보낸 곳 ○곳 · 입금 대기 ○곳» → [해결하러 가기] → 표가 «안 보낸 곳만»으로 바뀌어요. 표 위 «미리보기 · 인쇄» · «엑셀 (요약)»이 예전처럼 나와요.
4. 지난달 청구서 금액이 올리기 전과 **똑같아요**(계산은 안 바꿨어요).
5. **입·출금 내역 › 입금 내역**: 띠 [해결하러 가기] → «확인 필요»만 보여요. 하나 골라 «선택한 줄 청구서에 맞추기» → 맞추기 → «되돌리기»로 원래대로.
6. 설정 › **직원 계정 · 권한**에 직원 목록이 보여요.
6-2. 매출 › 자료 올리기 › «접수리스트» 단추 → 엑셀 양식이 내려받아져요.
6-4. 설정 › 거래처 › «엑셀 양식 받기» → 받은 파일에 시험 딜러 한 줄 적기 → «엑셀로 한꺼번에 올리기» → 미리보기 «1줄 넣기» → 거래처에 생겨요. 시험 뒤 그 딜러는 지워요.
6-3. 월별 청구서에서 두 곳을 골라 «고른 청구서 → 다른 청구처로» → 옮길 곳 고르기 → 확인 창 → 옮기기. 시험 뒤에는 같은 방법으로 원래대로 옮겨 놓아요.
7. 메뉴 줄 오른쪽 «기능 찾기»에 «청구서 보내기» → 눌러서 그 화면으로 가요.
8. 휴대폰으로도 열어 봐요: 아래 탭 «홈 · 정산 기록 · 월별 청구서 · 입·출금 · 전체», «전체»를 누르면 모든 메뉴가 나와요.

## 3단계 — 운영 주소(검사장)로 바꿔치기
- 2단계가 모두 괜찮을 때만, 검사장이 한가한 시간(점심 · 퇴근 뒤)에 올려요.
- 올리는 곳과 방법은 지금 체크를 올리는 곳 그대로예요(총괄 방이 운영 zip을 만들어 드려요).

## 이상하면 — 되돌리는 법 (2분)
1. 체크 방 파일 `체크/2_차곳간_체크_index_v48.1.html`(지금 검사장에서 쓰는 판)이 든 **예전 zip**을 다시 올려요.
   - 시험 주소: 지난번에 올린 시험 주소 zip 그대로 · 운영 주소: 지금 운영에 올라가 있는 zip 그대로.
2. 올리는 순서는 1단계 2~3번과 똑같아요(Upload → 예전 zip → Deploy).
3. 1분 뒤 새로고침 → 왼쪽 위 작은 글자가 **«체크 v48.1»** 이면 돌아온 거예요.
- 자료(청구서 · 입금 · 거래처)는 서버에 있어서 되돌려도 그대로예요. v51에서 바꾼 것(거래처 등)도 그대로 남아요.
- 어느 번호에서 무엇이 이상했는지 한 줄로 체크 방(또는 총괄 방)에 알려 주세요.

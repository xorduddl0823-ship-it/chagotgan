# 체크 사이트에 더할 파일 3개 — 대표님용 한 장 (시험 뒤 · 운영/06 M)

> 아직 올리지 마세요. **체크 서버 v34 + 워시 v.html(d 갈래)를 올린 날** 같이 올려요(총괄이 «M 올려요» 할 때).

## 무엇
| 파일 | 하는 일 |
|---|---|
| `_redirects` | ① 이미 딜러에게 간 옛 도착 사진 주소 `check.cgg.co.kr/d/열쇠` → 새 보기 화면 `app.cgg.co.kr/v.html?c=d열쇠` 로 넘겨요(옛 문자도 살아요). ② 재검사 차량 목록 주소 `/r/열쇠` 를 `r/index.html` 이 열게 해요 |
| `_headers` | `/r/` · `/d/` 화면을 남의 휴대폰에 남기지 않고 · 다른 사이트로 주소가 새지 않고 · 검색에 안 나오게 |
| `r/index.html` | 재검사 차량 목록 화면(체크 v43 짝 — 보안 통과). 서버 v33 이상에서 동작 |

## 올리는 법 (Cloudflare, 약 5분)
1. **지난번 올린 체크 사이트 폴더를 통째로 복사**해요(⚠ Cloudflare 는 폴더 전체를 바꿔서, `v` · `d` 같은 다른 폴더가 빠지면 안 돼요).
2. 복사한 폴더 **맨 위**에 `_redirects` · `_headers` 두 파일을 넣고, `r` 폴더를 통째로 넣어요. (이미 `_redirects` 가 있으면 체크 방에 보내 주세요 — 합쳐 드려요)
3. Cloudflare → Workers & Pages → `check.cgg.co.kr` → Create deployment → 폴더 끌어다 놓기 → Deploy.

## 올린 뒤 확인 (2분)
- 예전에 받은 도착 문자의 사진 주소(`check.cgg.co.kr/d/…`)를 눌러요 → 주소가 `app.cgg.co.kr/v.html?c=d…` 로 바뀌며 사진이 열려야 해요.
  - ⚠ 예전 `d` 화면이 그대로 뜨면, 폴더 안의 옛 `d` 폴더가 먼저 잡힌 거예요 → 그 `d` 폴더를 빼고 다시 올려 주세요(넘기기가 대신해요).
- 재검사 알림 «차량 목록 보기»를 눌러 차 목록이 나오면 끝이에요(템플릿 승인 전이면 문자의 주소를 눌러요).
- 이상하면 지난번 폴더 그대로 다시 올리고(되돌리기) 체크 방에 알려 주세요.

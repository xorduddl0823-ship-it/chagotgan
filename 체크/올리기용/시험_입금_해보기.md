# TEST 검사소에서 입금 맞추기 해 보기 — 대표님용 (체크 v47 이상 · 서버 v38)

> 모두 **지어낸 자료**예요(이름 · 차량번호 · 계좌 모두 가짜). TEST 검사소에서만 써 주세요.
> 파일 두 개: `체크/올리기용/시험_접수리스트_202610.csv`(차 6대 · 딜러 3명) · `체크/올리기용/시험_입금_예시.csv`(입금 3건 + 출금 1건)

1. **청구서 만들기** — 설정 › 자료 올리기에 `시험_접수리스트_202610.csv`를 올려요 → 거래처에 없는 신청인을 «한꺼번에 넣기»(시험딜러가 · 나 · 다) → 청구서 › 월별 청구서에서 **2026년 10월**을 고르고 «청구서 만들기». (청구서 3장: 가 66,000원 · 나 77,000원 · 다 88,000원)
2. **입금 넣기** — 입출금 › 입금 내역 › «은행 거래내역 엑셀 가져오기»에 `시험_입금_예시.csv` → 미리보기에 입금 3건(출금은 빠짐) → «3건 넣기». 이름이 같은 «시험딜러가 66,000원»은 **자동으로 맞춰지고**, «시험딜러다 40,000원»은 다 청구서에 일부 입금으로 들어가요.
3. **손으로 맞추기 · 되돌리기** — «확인 대기»로 남은 **«나딜러 개인» 77,000원**을 골라 «선택한 줄 청구서에 맞추기» → 10월 → **시험딜러나** → 맞추기(상태 «입금 처리» · 나 청구서 남은 금액 0원). 그다음 같은 줄을 골라 «되돌리기» → 다시 «확인 대기». (같은 파일을 한 번 더 넣으면 «이미 있던 3건은 건너뜀»)

- 시험이 끝나면: 시험 입금은 «선택한 줄 지우기»(맞춘 것은 먼저 되돌리기), 시험 딜러는 거래처에서 지우면 돼요.

# 체크 새 판 올리는 법 (대표님용 · 2026-10-15)

보안 방 검사: **통과 — 배포해도 됨** (`보안/검사기록/2026-10-15_체크묶음_서버v25_기사화면v24.md` 맨 아래 「체크 묶음 v29」)

## 올릴 것 3가지 — **같은 날 한꺼번에**
| 무엇 | 파일 | 어디에 |
|---|---|---|
| ① 체크 서버 v29 | `서버/2_차곳간체크_서버_check-api_v29.ts` | 수파베이스 → Edge Functions → `check-api` |
| ② 사무실 화면 v29 | `체크/올리기용/새판/index.html` | Cloudflare `check.cgg.co.kr` 맨 위 `index.html` |
| ③ 기사 폰 화면 v24 | `체크/올리기용/새판/driver/index.html` | Cloudflare `check.cgg.co.kr` 의 `driver` 폴더 안 `index.html` |

하나만 먼저 올리면 짝이 안 맞아요. (예: 서버만 올리면 새 직원이 확인 번호를 넣을 칸이 없어요.)

## 순서
1. **수파베이스 → SQL Editor** 에서 차례로 붙여 넣고 **Run**
   - `서버/sql/02_체크_기사_로그인_보안.sql`
   - `서버/sql/04_체크_첫비밀번호_문자확인.sql` (예전에 돌렸어도 **한 번 더** — 칸이 하나 늘었어요. 여러 번 돌려도 안전해요)
2. **수파베이스 → Edge Functions → check-api** 에 ① 서버 v29 내용을 넣고 **Deploy**
3. **Cloudflare** 에 ②·③ 화면 두 개를 올리기
   - ⚠ Cloudflare Pages 는 올릴 때 **폴더 전체를 바꿔요**. 지금 올라가 있는 다른 파일(청구서 보기 `v` 폴더, 차량 사진 보기 `d` 폴더 등)이 함께 들어 있는 **지난번 올린 폴더**에서 `index.html` 과 `driver/index.html` 두 개만 바꿔 넣은 뒤 폴더째 올려 주세요. 두 파일만 따로 올리면 다른 화면이 사라질 수 있어요.
4. **확인 (5분)**
   - `check.cgg.co.kr` 를 열고 **Ctrl + F5**(새로 불러오기) → 머리말 작은 글씨에 「**체크 v29**」와 「**서버 v29**」가 보이면 성공
   - 대표 계정으로 로그인 → 설정 › 설정 백업 → 「직원 권한」 목록이 보이면 성공
   - 휴대폰으로 `check.cgg.co.kr/driver` → 제목 「차곳간 배달알림」, 로그인에 「회사 코드 (선택)」 칸이 보이면 성공

## 미리 알아 둘 것
- **새 직원 · 비밀번호를 초기화한 직원**은 처음 로그인할 때 휴대폰으로 확인 번호 6자리를 받아요(알림톡, 안 되면 문자). 기존 직원은 그대로 로그인돼요.
- **새 배달 기사**는 폰에서 가입 신청 → 사무실이 「알림 › 차량 배달 알림 › 기사 계정」에서 **전화로 본인 확인 후** 「다시 쓰게 하기 (가입 승인)」를 눌러야 들어와요.
- 비밀번호를 5번 틀리면 10분 잠겨요(사무실 · 기사 모두).
- 차량 도착 알림은 **알림톡 먼저, 안 되면 문자**로 나가요. 알림톡 템플릿 코드를 아직 안 넣었으면 지금처럼 문자로 나가요(`서버/설계/10_알림톡_전환.md` 「대표님이 할 일」).
- 서버 비밀값 이름(값은 적지 않음): `SOLAPI_KEY` · `SOLAPI_SECRET` · `SMS_FROM` · `PF_ID` 가 수파베이스에 있어야 해요. 없으면 서버 방에 알려 주세요.

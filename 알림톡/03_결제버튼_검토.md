# 「결제하기」 버튼 — 지금 심사받을 수 있나? (알림톡 방 · 2026-10-15)

## 결론: 지금은 신청하지 않아요
1. **토스페이먼츠(PG) 승인이 아직이에요.** 워시 서버 sb5 기본 안내가 「PG사 승인 대기 중입니다. 지금은 계좌이체로만 충전하실 수 있습니다.」이고, 카드 결제는 관리 설정 `pg_on` 이 켜져야 열려요. 카카오는 결제 버튼 심사 때 **실제로 결제되는 화면 캡처**를 보는데, 지금은 찍을 화면이 없어요.
2. 반려 5개가 떨어진 이유가 바로 **연장·충전·결제를 권하는 버튼**이었어요. 기간종료·잔액 안내에는 PG가 열려도 결제 버튼을 넣지 않아요(규칙 5-6).
3. 손님(딜러·상사)이 업체에 내는 청구서 대금은 **업체의 계좌**로 받아요. 차곳간 PG는 업체가 차곳간에 내는 돈용이라 청구서에 결제 버튼을 달 수 없어요.

## 나중에 할 수 있는 경우 (조건이 모두 맞을 때)
| 조건 | 지금 |
|---|---|
| 토스페이먼츠 승인 · 관리 설정 `pg_on` 켜짐 | ❌ 승인 대기 |
| 버튼이 「특정 청구 건」의 결제 화면으로 바로 감 (금액이 이미 정해진 것) | ❌ 화면 없음 |
| 안내 자체가 이미 확정된 청구를 알리는 정보성 글 (연장·충전 권유 아님) | 템플릿 없음 |
| 심사 자료: 결제 화면 캡처 · PG 계약 확인 | ❌ |

→ 그때 쓸 후보: **「차곳간_이용요금청구」**(업체 대표에게 「이번 달 이용요금 ○원이 청구되었습니다」 + 버튼 「청구 내역 보기」). 처음엔 **「청구 내역 보기」(정보 화면)** 로 통과받고, PG가 열리면 그 화면 안에 결제 단추를 두는 방식을 권해요. 알림톡 버튼 이름에 「결제」를 넣지 않아도 손님은 한 번 눌러 바로 낼 수 있어요.

## 서버 방에 확인할 것 (요청서 `04_…` 에 넣음)
- 토스페이먼츠 승인 예정일, `pg_on` 을 켜는 시점
- 「청구 건 하나」를 열어 결제까지 가는 화면 주소를 만들 수 있는지 (로그인 없이 코드로, `v.html?c=` 처럼)

※ 카카오 심사 기준은 바뀔 수 있어요. 버튼 신청 전 솔라피 고객센터에 「결제 버튼 심사 자료」를 한 번 더 확인해요(총괄 방).

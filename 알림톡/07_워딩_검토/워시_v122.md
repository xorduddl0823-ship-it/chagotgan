# 워시 v122 — 고칠 말 목록

- 검사한 파일: `워시/1_차곳간_워시_index_v122.html` (약관 글은 뺐어요). 고칠 곳을 **꼭 고칠 것 100줄 + 맞추면 좋은 것 28줄, 모두 128줄**로 묶었어요. 같은 말이 여러 곳에 있으면 한 줄로 묶었어요.
- 가장 급한 건 **오류 글에 영어와 코드 글자가 그대로 보이는 것**이에요. 오류 글을 만드는 함수(`errMsg`)가 `[permission_denied]` 같은 영어 코드를 붙이고, 서버 답이나 `e.message`를 그대로 보여 줘요. 이 함수는 108곳에서 쓰여요. 그다음은 **도움말·안내에 나오는 메뉴 이름이 실제 화면과 달라서 길을 잘못 알려 주는 것**(없어진 「문자 연동」, 「차량 출고 설정」 등)이에요.
- 그다음은 **알림톡을 먼저 보내는데도 「문자」라고만 적은 곳**과 **「무료 체험」이라는 말**이에요(체험 기간으로 바꿔야 해요). 그리고 문장으로 된 알림 글(토스트) 약 185개 가운데 175개가 「~습니다」여서 해요체로 맞춰야 해요.

> 표 안의 「줄」은 파일의 실제 줄 번호예요. 「…」는 긴 글을 줄인 자리예요. 코드 쪽 고칠 방법은 이유 칸에 짧게만 적었어요.

## 그대로 두는 것 (애매해서 판단한 것, 짧게)

- **차 상태 칩**: 「입고 · 출고 · 수금 완료 · 작업 중 · 수금 대기 · 판금·도색 중 · 재입고」는 워시 차 상태라서 그대로 둬요. 공통 상태 4가지(2582·2631 줄 「진행 중 · 확인 필요 · 보류 · 완료」)는 이미 맞아요.
- **6220·10018 줄의 "관계없는 돈"**: 화면 글자가 아니라 **저장되는 값**이에요. 바꾸면 예전에 표시한 입금이 다시 풀려 보여요. 화면 버튼·안내 글만 「관계없는 입금」으로 바꾸세요.
- **12777~12808 줄 도움말 검색어**(「돈」, 「막힘」, 「남은돈」, 「에러」 등): 사용자가 칠 수 있는 말을 받아 주는 목록이라서 그대로 둬요.
- **4130, 9800, 10513, 11127 줄 「알림톡을 보냈어요 / 문자를 보냈어요」**: 실제로 어느 쪽으로 갔는지 정확히 알려 주니까 그대로 둬요. 원하면 문자 쪽을 「알림톡이 안 돼서 문자로 보냈어요」로 바꿔도 돼요. 9764 줄 「알림톡으로 보내요. … 준비 전이면 문자로 가요」는 규칙 6의 좋은 예예요.
- **딜러·거래처가 받는 글**(2711, 6532~6538, 7875, 7933, 10996~10997, 12093 줄): 승인받은 알림톡 문구와 문자 본문이에요. 바꾸면 다시 승인받아야 해서 이번 검토에서는 뺐어요.
- **폰 문자 앱을 여는 버튼**(4743 「문자만 보내기」, 10501 「문자 앱으로 직접」, 10565 「문자 앱으로」), **직원 주소 안내 문자**(5037), **도매상 주문 문자**(12038, 12090, 12161, 12166, 12389), **인증번호 문자**(7737): 실제로 문자로 가는 것이라서 그대로 둬요.
- **알림톡·팝빌 신청 화면의 칸 이름**(10598 「링크아이디(LinkID)」, 11286 「템플릿 ID」, 11309 「채널 ID (pfId)」, 11305~11306 솔라피 신청 순서): 바깥 사이트의 칸 이름과 똑같아야 따라 할 수 있어서 그대로 둬요.
- **로그인·가입·비밀번호 화면**(14143~14362 줄)과 **저장 오류 표**(2864~2868 줄)의 「~습니다」: 규칙 1의 예외라서 맞아요. 다만 A표의 원문(e.message) 문제는 고쳐야 해요.
- **「캐시」**: 충전한 금액이라는 제품 이름이라 괜찮아요. 다만 12601 줄의 「캐시」는 브라우저 저장소라는 뜻이라 E표에서 빼라고 적었어요.
- **9764 줄 「본사 알림톡」**: 규칙에서 금지한 말은 「본사 관제」라서, 「본사」만 쓴 것은 그대로 둬요.
- **AI에게 보내는 지시 글**(3953~3957, 4371, 4860, 8088, 9579 줄): 화면에 보이지 않아서 뺐어요. **약관 링크**(14104~14106)도 뺐어요.
- **12643 줄에 인용된 «직원 계정은 휴대폰에서만 들어올 수 있습니다»**: 이 파일에는 그 글이 없어요(서버가 보내는 것 같아요). 서버 방에서 실제 글과 맞는지 확인해 주세요.
- **9281·9328·15858 줄**: 문의 전화번호가 화면에 직접 적혀 있어요. 말을 고칠 곳은 아니라서 번호는 여기에 옮겨 적지 않았어요. 번호를 설정에서 불러오게 바꿀지는 총괄 방이 정할 일이에요.

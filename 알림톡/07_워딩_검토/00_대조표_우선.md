# 워딩 목록 ↔ 말 대조표 맞춤 (알림톡 방 · 2026-10-15)

> **기준은 디자인 방 `디자인/말_대조표.md` 예요.** 알림톡 방 목록(이 폴더의 6개 파일)과 겹치면 대조표 말로 고쳐요. 대조표에 없는 것만 알림톡 방 목록대로 해요.
> 총괄 방 결정(2026-10-15)도 함께 반영했어요.

## 1. 알림톡 방 목록보다 대조표 · 총괄 결정이 우선인 것
| 알림톡 방 목록에 적은 것 | 이렇게 바꿔서 적용 | 근거 |
|---|---|---|
| 화면의 「무료」(무료로 시작하기 · 무료 체험 · 앱은 무료 등) → 「체험」 쪽 말 | **화면은 그대로 둬요.** 「무료」 금지는 알림톡 심사 기준이라 화면에는 해당 없음 | 총괄 결정 ① |
| 「무료 캐시」 | **「기본 제공 캐시」로 바꿔요** (화면) | 총괄 결정 ② |
| 「기본 제공 알림을 다 썼어요」(체크 「무료 문자를 다 사용하였습니다…」) | 「무료」는 화면이라 둬도 되지만, 이 글은 **문장 섞임·충전 권유**가 문제 → 「무료 알림을 다 썼어요.」로 해요체만 맞춰요 | 대조표 0장 · 총괄 ① |
| 화면 오류 글을 「~습니다」로 | **화면 오류는 해요체** 「○○하지 못했어요. 다시 시도해 주세요.」 · **로그인·가입·결제 중 오류만** 「○○하지 못했습니다. 잠시 후 다시 시도해 주세요.」 | 대조표 3장 |
| 인터넷 끊김 「인터넷 연결이 끊겼습니다. 연결을 확인하고 다시 시도해 주세요.」 | **「연결이 잠시 끊겼어요. 다시 시도해 주세요.」** | 대조표 3장 |
| 「저장 실패:」「보내기 실패」 등 → 각 목록의 고칠 말 | **「저장하지 못했어요. 다시 시도해 주세요.」** 꼴로 통일 (「실패」 한 단어로 끝내지 않기) | 대조표 3장 |
| 「수금」「미수」 (목록에서 그대로 둔 곳) | 칩 밖의 「수금」→ **「입금」**, 목록·상태의 「미수」→ **「입금 대기」**, 합계 숫자 → **「받을 금액」** (워시 차 상태 칩 「수금 완료」만 그대로) | 대조표 2장 |
| 「삭제」 | **「지우기」 / 「지웠어요」 / 「○○을 지울까요?」** | 대조표 1장 |
| 「찾기」 | **「검색」** (머리말 「메뉴 찾기」만 그대로) | 대조표 1장 |
| 「계산서」 | **「세금계산서」** (폰 탭바 한 칸만 「계산서」) | 대조표 2장 |
| 「엑셀로 받기」「내려받기」 | **「엑셀 다운로드」** | 대조표 1장 |
| 딜러 「마이페이지」 | 딜러만 **「내 정보」** | 대조표 4장 |
| 「다시 로그인해야 합니다」 등 | **「다시 로그인해 주세요.」** | 대조표 1장 |
| ★ ✓ ⚠ 📝 ↻ ✕ 같은 기호 | **선 아이콘이나 글로** | 대조표 5장 |

## 2. 대조표에 없어서 알림톡 방 목록대로 하는 것 (주요)
- 알림톡/문자 안내: 「문자를 보냈습니다」→ **「알림톡을 보냈어요 (안 받으면 문자로 가요)」** — 단, 서버가 실제 방식(ata/sms)을 돌려줄 때만. 값이 없으면 **「보냈어요」**.
- 인증번호 안내: **「인증번호를 발송했습니다.」** (「문자로」 빼기)
- 「ATA」 같은 코드 표시 → **「알림톡」**
- 눌러도 아무 일 없는 버튼(체크 「내 번호로 시험」「예약 발송」 등) → 숨기거나 「준비 중」
- 없는 메뉴를 가리키는 도움말(워시 「설정 → 문자 연동」 등) → 실제 메뉴 이름
- 관리 알림톡 템플릿 이름 → 솔라피 등록 이름 그대로(「차곳간_」 붙이기)
- 맞춤법·띄어쓰기(코드을 · 목록를 · 아니오 → 아니요 · 다음달 → 다음 달 · ~해주세요 → ~해 주세요)

## 3. 다음 판 할 일 (시험 뒤 · 총괄 결정 ③)
- 화면에 직접 적힌 연락처 번호를 **설정에서 읽어 오기** (워시 · 체크 · 소개 시안 등) — 기능 변경이라 시험 뒤.
- 공통 부품(cgg-j4 1.5, 동결) 안의 글은 시험 뒤 다시 보기.

## 4. 알림톡 본문 ↔ 대조표 (다음 재심사 묶음 후보 · 지금은 바꾸지 않음)
통과된 템플릿은 한 글자만 바꿔도 재심사가 필요해요. 대조표와 견줘 봤어요.

|---|---|---|---|
| 청구서 | 「청구 금액」「입금 기한」「입금 계좌」 | 금액 · 입금 | ✅ 같음 |
| 입금확인 | 「입금이 확인되었습니다」 | 입금 | ✅ 같음 |

| 추가작업 · 출고 · 입고 | 「작업」「금액」「출고」 | 같음 | ✅ |

# 차곳간 배달기사 (기사 폰 화면 v25) — 고칠 말 목록

대상 파일: `체크/driver/index_v25.html` (줄 번호는 이 파일 기준, 2026-10-15 확인)

- **꼭 고칠 것 16가지**: 서버 원문·영어(「Verify JWT」, 「ATA」, 인터넷이 끊기면 나오는 「Failed to fetch」)가 보이고, 사진·딜러 칸이 아직 「문자(MMS)」만 말해요.
- **맞추면 좋은 것 12가지**: 로그인 밖 화면이 거의 다 「~습니다」라서 해요체로 바꾸고, 사무실 화면과 같은 말(취소 표시·취소 풀기 등)로 맞추는 일이에요.
- 로그인·가입·비밀번호 안내의 「~습니다」와 보낸 결과 표시(성공·실패·시험·취소)는 그대로 둬요.

## 그대로 두는 것 (짧게)

- **로그인·가입·비밀번호 바꾸기 안내** 113–128, 246, 300, 378–398, 412, 421, 426, 435, 439–444 (「~습니다」): 규칙 1 예외라서 그대로 둬요. 「로그인」「로그아웃」 말도 사무실 화면과 같아요.
- **보낸 결과 표시** 1143·1152 「성공 · 실패 · 시험 · 취소」: 일의 진행 상태가 아니라 알림을 보낸 결과라 규칙 3 상태 이름과 따로 둬요.
- **「그만두기」 버튼** 407, 1020, 1106: 사무실 화면은 「취소」지만, 기사 화면에는 배달 「취소 표시」가 따로 있어서 헷갈리지 않게 「그만두기」로 둬요.
- **「무료」「관제센터」「알람」「단추」「하는 중·끝남·막힘」**: 화면 글에 없어요(「막힘」은 245줄 코드 설명글에만 있음).
- **「시험 문자를 보냈습니다」 「문자로 보내기」**: 이 화면에는 없어요.

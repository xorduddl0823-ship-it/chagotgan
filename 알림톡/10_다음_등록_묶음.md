3. **버튼**: 「없음」이면 넣지 않아요. 재검사안내만 웹링크 1개를 넣어요.
4. 카테고리는 이미 통과된 비슷한 템플릿과 같은 것을 골라요. 저장한 뒤 **검수요청**을 눌러요.

## 1. 차곳간체크_재검사안내  (`check_remind`)
- 보내는 때: 성능점검 유효기간 만료 30·15·7·3일 전 (검사소가 고른 날, 딜러별 한 통)
- 받는 사람: 딜러
- 버튼: 웹링크 「차량 목록 보기」 → `https://check.cgg.co.kr/r/#{보기코드}` (모바일·PC 칸 둘 다 같은 주소)

본문
```
[차곳간] 성능점검 유효기간 안내
#{딜러명}님, #{업체명}에서 성능점검을 받은 차량 중 유효기간이 끝났거나 곧 끝나는 차량을 안내드립니다.

대상 차량: #{대수}대 (#{대표차량})
가장 빠른 만료일: #{빠른만료일}
유효기간: 검사일로부터 #{유효일수}일

차량별 만료일은 아래 버튼에서 확인하실 수 있습니다.
문의: #{업체전화}

※ 이 메시지는 #{업체명}에서 성능점검을 받은 차량의 딜러님께, 유효기간 만료 전에 발송됩니다.
```

대체 문구 (알림톡이 안 되면 문자로)
```
[차곳간] #{업체명} 성능점검 유효기간 안내 · #{대수}대 · 가장 빠른 만료 #{빠른만료일} · 문의 #{업체전화}
```

## 2. 차곳간_접속주소안내  (`staff_link`)
- 보내는 때: 대표가 워시 직원 계정 「주소 안내」를 누를 때
- 받는 사람: 직원
- 버튼: 없음

본문
```
[차곳간] 접속 주소 안내
#{직원명}님, #{업체명}에서 차곳간 직원 계정을 만들었습니다.

접속 주소: #{접속주소}
로그인: 이 휴대폰 번호로 인증

주소를 열고 본인 휴대폰 번호로 로그인하시면 됩니다.

※ 이 메시지는 #{업체명}의 요청으로, 직원 계정이 만들어졌을 때 차곳간이 보내드립니다.
```

대체 문구 (알림톡이 안 되면 문자로)
```
[차곳간] #{업체명} 직원 접속 주소 #{접속주소} (본인 번호로 로그인)
```

## 체크 도착 = 출고안내 (같이 쓸 때 채우는 값 · 알림톡 방 검토)
| 출고안내 변수 | 체크 도착에 넣을 값 | 판단 |
|---|---|---|
| `#{딜러명}` `#{상사명}` | 딜러 이름 · 상사 이름 (상사가 없으면 「개인」) | ✅ |
| `#{업체명}` `#{업체전화}` | 검사소 이름 · 검사소 전화 | ✅ |
| `#{차량번호}` | 차량번호 | ✅ |
| `#{작업내용}` | **「성능점검 · 배달」** | ✅ 실제 한 일과 맞아요 |
| `#{목적지}` | 도착한 곳 | ✅ (본문 칸 이름이 「도착한 곳」) |
| `#{출고일시}` | **출발(기사가 차를 가지고 나간) 시각**이 맞아요. 출발 시각이 없으면 도착 시각도 괜찮아요 | △ 본문 칸 이름이 「출고시각」이라 출발 시각이 더 정확해요 |
| `#{보기코드}` → 버튼 `https://app.cgg.co.kr/v.html?c=…` | ⚠ **버튼 주소가 워시 보기 화면으로 고정**돼 있어요. 체크 도착 사진(`check.cgg.co.kr/d/…`) 코드를 넣으면 **열리지 않아요** | ❌ v.html 이 체크 코드도 열게 고치거나(청구서 1안과 같은 방식), 그 전엔 체크는 문자로 |
- 카카오 심사 기준(정보성 · 실제 내용과 맞음)으로는 본문 글(작업이 끝나 출고 · 도착한 곳 · 사진 확인)이 체크 배달에도 사실과 맞아서 **문제 없어요.** 걸리는 건 **버튼 주소 하나**예요.

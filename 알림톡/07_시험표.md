## 시험 전 확인 3가지

### ① 템플릿 코드가 관리에 들어 있는지
- 보는 곳: **관리 › 알림 › 알림톡 템플릿**
- 맨 위 「카카오 채널 ID」 칸이 **「넣어 둠」** 이어야 해요. 「채널 ID가 아직 없어요」가 보이면 → 모든 안내가 문자로만 나가요.
- 「템플릿 코드」 표 오른쪽 위 숫자가 **8 / 15 넣음** 이면 맞아요. 통과된 8개 줄(입고안내·출고안내·추가작업·청구서·입금확인·결제완료·충전완료·인증번호)에 `KA01TP…` 로 시작하는 코드가 있고, 맨 오른쪽 「보내는 방법」이 **「알림톡 먼저」** 여야 해요.
- 재검수 5개(기간종료예정·이용제한시작·로그인제한예정·자료보관기한·잔액안내)와 새 2개(차량도착 · 접속주소안내)는 **비어 있는 게 맞아요.** (통과 전에 넣으면 알림톡이 실패하고 문자로 대신 가요)
- 코드를 넣고 「코드 저장」을 누른 뒤 **1분** 기다리고 시험을 시작하세요(서버가 1분마다 다시 읽어요).

### ② 받을 휴대폰은 대표님 본인 번호
- **시험 업체의 대표 휴대폰** = 대표님 번호 (충전완료·결제완료·기한 안내가 여기로 가요)
- 워시에서 차를 입고할 때 **딜러 연락처** 칸 = 대표님 번호 (입고·출고·추가작업·청구서·입금확인이 여기로 가요)
- 체크 기사 앱에서 도착을 찍을 때 **딜러 연락처** = 대표님 번호
- 관리 › 설정 › 내 계정의 **본사 알림 번호** = 대표님 번호 (기한 안내 「내 번호로 시험 보내기」가 여기로 가요)
- 같이 볼 것: 워시 설정에 **보내는 번호(발신번호)**가 들어 있어야 자동 발송이 돼요(없으면 휴대폰 문자 앱이 열려요). 시험 업체에 **캐시나 문자 건수가 남아 있어야** 워시 화면 발송이 나가요(없으면 「문자 발송이 멈췄습니다」). 출고·청구서는 워시 설정에서 업체 자기 알림톡을 고르지 않은 상태(기본)여야 **차곳간 알림톡**으로 나가요.
- ⚠ 워시 **가입** 인증번호는 「아직 아무 데도 가입 안 된 번호」에만 가요. 대표님 번호가 이미 가입돼 있으면 「이미 쓰고 있는 휴대폰 번호입니다」가 떠요 → 대표님 번호로는 **비밀번호 찾기**로 시험하세요.

### ③ 결과 보는 곳
1. **대표님 휴대폰**: 카카오톡의 「차곳간」 채널 대화방에 오면 = 알림톡 / 문자 앱에 오면 = 문자로 대신 간 것
2. **솔라피 사이트 › 메시지 › 발송 내역** (메뉴 이름이 「메시지 로그」로 보일 수도 있어요): 알림톡으로 도착했는지, 문자로 대신 갔는지, 실패인지 가장 정확해요. **지금은 여기가 유일한 「최종 결과」예요.**
3. 제품 화면 안의 기록 (아래 「발송 기록 확인하는 법」 참고)
- **어디서 확인하나요?**
  - **서버 sb15 · 관리 v4.6 이 올라간 뒤**: 관리 › 알림 › **「발송 기록」** 화면에서 확인해요(모든 제품 · 템플릿 · 알림톡/문자 대체/실패가 한곳에 남아요).
  - **그 전에는**: **휴대폰 + 솔라피 발송 내역**으로 확인해요. 관리 v4.5 에는 발송 기록 화면이 없고, 서버도 워시 화면에서 보낸 것만 기록해요.

## 템플릿마다 짧은 칸

> ② = 대표님 휴대폰에 보이는 모양(가짜 값) · ③ = 알림톡이 안 될 때 · ④ = 어디에 기록이 남는지

### 1~6. 차곳간_인증번호 (`auth`) — 통과
**② 보이는 글 (알림톡)**
```
[차곳간] 인증번호 안내
요청하신 인증번호를 보내드립니다.

인증번호: 123456
유효시간: 5분

인증번호는 다른 사람에게 알려주지 마세요.
```
**③ 알림톡이 안 될 때** — 6곳 모두 알림톡 먼저 → 안 되면 문자로 대신(`disableSms:false`).
- 코드가 없거나 채널 ID가 없으면 처음부터 문자로 보내요. 문자 글은 곳마다 조금 달라요:
  - 워시(가입·비밀번호 찾기·직원): `[차곳간] 인증번호 123456 (5분 안에 입력해 주세요)`
  - 딜러앱: `[차곳간 딜러] 인증번호 123456 (5분 안에 입력해 주세요)`
  - 체크 첫 비밀번호: `[차곳간체크] 확인 번호 123456 (5분) — 본인이 로그인한 게 아니면 넣지 마세요`
  - 통합 입구: `[차곳간] 확인 번호 123456 (5분 안에 넣어 주세요)`
- 알림톡을 보냈는데 카카오가 못 전하면 솔라피가 `[차곳간] 인증번호 123456 (5분 안에 입력)` 으로 대신 보내요.
- 연결 상태 (지금 코드):
  - 워시 가입·비밀번호 찾기·직원 인증 → **연결됨** (sb13 `otpSend` → `noticeAta("auth", …, 문자로도 보냄)`) · 홈페이지 가입(join_v4)도 같은 워시 서버 `sendCode`

### 19. 차곳간_기간종료예정 — 재심사 중 — 지금은 문자로 감
**② 지금 보이는 글** — 알림톡 템플릿이 아니라 관리 「기한 안내 문자」에 적어 둔 문구예요. 「내 번호로 시험 보내기」는 이런 값으로 채워요:
```
[차곳간] 시험업체 사장님, 이용기한이 10월 17일에 끝납니다.
…(관리에 적어 둔 문구 그대로)
```
- 시험법: 관리 › 알림 › 기한 안내 문자 › 「지금 바로 보내기」 › 누구에게 「내 번호로 시험 보내기」 › 「이 문자 보내기」 → **본사 알림 번호**로 문자 한 통.
- 시험 업체를 고르면 그 업체 대표 번호로 진짜 값이 채워져 가요.
- 자동 발송(끝나기 3일 전·당일, 정한 시각부터 30분 안)은 날짜를 맞춰야 해서 시험 날 만들기 어려워요.

**③** 지금은 늘 문자(본사 문자 비용). **④** 업체로 보내면 「보낸 기록」에 「손으로 보냄」 줄이 생겨요. 「내 번호로 시험」은 기록이 안 남아요.

### 20~22. 이용제한시작 · 로그인제한예정 · 자료보관기한 — 재심사 중 — 지금은 문자로 감
- 서버 자동 시계(`cronExpire` ③-2)가 날짜에 맞춰 코드에 적힌 문자 글을 보내요. 손으로 보내는 버튼이 없어요.
- 시험 날 일부러 만들기 어려움 → **건너뛰기**.
- 기록: 관리 › 업체 › 잠금 · 차단 쪽 기록(`wash_lock_log` 「문자 보냄」)과 `wash_expire_log`.

### 23. 잔액안내 — 재심사 중 — 지금은 문자로 감

## 발송 기록 확인하는 법

### 관리 (지금 있는 것 · v4.5)
- **관리 › 알림 › 알림톡 템플릿**: 맨 위 숫자 4칸(알림톡 · 문자 단문 · 문자 장문 · 사진 문자)의 **건수와 대략 금액**. ⚠ 이 숫자는 **늘 「지난달」**(10월 시험이면 9월)이고, **워시 화면에서 나간 것만** 세요. 이번 주말 시험은 여기 숫자에 **안 보여요.**
- **관리 › 알림 › 기한 안내 문자 › 보낸 기록**: 보낸 때 · 업체 · 무엇 · 끝나는 날 · 단계 · 받은 번호 · 내용 — 기한·캐시 안내 문자와 「손으로 보냄」만.
- **관리 › 알림 › 「발송 기록」 화면은 관리 v4.6 · 서버 sb15 부터 생겨요.** 그 전 판에서는 없어요.

### 관리 v4.6 › 알림 › 발송 기록 — 보는 칸 (서버 sb15 가 올라간 뒤)
| 화면 칸 (이름) | 뜻 | 시험 때 볼 것 |
|---|---|---|
| 시각 (`at`) | 보낸 때 | 내가 누른 시각과 맞는지 |
| 제품 (`product`) | 워시 · 체크 · 딜러 · 경비실 · 관리 | 누른 제품과 맞는지 |
| 업체 (`shop` · `shopName`) | 어느 업체 일인지 | 시험 업체 이름 |
| 템플릿 (`tpl`) | 서버 키 (`auth` `intake` `release` `extra_work` `bill` `deposit_ok` `cash_done` `pay_done` `bill_on` `bill_fail` `staff_link` …) | 위 표의 「서버 키」와 같은지 |
| 받는 번호 (`to`) | 가운데를 가린 번호 (예: 010-****-0000) | 끝 네 자리가 대표님 번호인지 |
| 방식 (`via`) | `ata` 알림톡 · `sms` 단문 · `lms` 장문 | 알림톡이어야 할 것이 문자로 가지 않았는지 |
| 결과 (`result`) | **알림톡 도착 · 문자 대체 · 실패 · 대기** | 「대기」는 솔라피 결과가 아직 안 온 것 — 몇 분 뒤 새로고침 |
| 메시지 번호 (`msgId`) | 솔라피 메시지 번호 | 솔라피 발송 내역에서 같은 번호로 찾기 |
| 오류 (`err`) | 실패한 까닭 | 실패면 이 칸 글을 그대로 총괄에 |
- 위 「한눈에 보기」 표의 **관리 발송 기록 확인 칸**은 sb15 · v4.6 뒤에는 모두 이 화면의 **템플릿 · 방식 · 결과** 세 칸으로 확인해요. 그 전 판이면 휴대폰 + 솔라피.

### 서버 기록 (`wash_sendlog`) — 워시 서버만 남김
- 남는 칸: 업체 · 종류 이름(예: 「입고 알림」「출고 알림」「월 청구」「추가 작업」「입금 확인」「주소 안내」) · 받는 번호 · 방식(ATA = 알림톡으로 보냄 / AUTO·SMS·LMS·MMS = 문자) · 성공 여부 · 솔라피 메시지 번호 · 오류 · 내용(대체 문구 500자) · 참조 · 시각
- 없는 칸: **템플릿 키**, **최종 결과**(알림톡 도착인지, 문자로 대신 갔는지). 「ATA」로 적혀도 실제로는 문자로 대신 갔을 수 있어요.
- 남는 것: 워시 화면에서 보낸 것(9~13, 15)만. **인증번호 · 충전완료 · 결제완료 · 자동 결제 안내 · 본사 문자는 워시에서도 안 남아요.**
- **체크 · 딜러 · 경비실은 아직 기록이 안 남음 — 서버 방 고치는 중.**
- 관리 화면이 나오기 전 보는 법(읽기만): 수파베이스 › Table Editor › `wash_sendlog` 표.

### 제품 화면 안 기록
- **워시 › 설정 › 문자 연동 · 발송함** (PC 「발송함」): 만든 시각 · 종류 · 받는 번호 · 방식 · 상태(보냄/실패/예약) · 내용. ⚠ 코드가 없어 서버가 문자로 바꿔 보낸 경우에도 화면은 「알림톡」「알림톡을 보냈어요」로 보여요(아래 빈 곳).
- **체크 › 차량 배달 알림** 목록 「알림」 칸 + 상세 「알림 보낸 방법」.

### 가장 정확한 곳 — 솔라피
- **솔라피 사이트 › 메시지 › 발송 내역**(「메시지 로그」로 보일 수도 있어요)에서 대표님 번호로 찾아요.
- 줄마다 보는 것: **종류**(알림톡 / 문자) · **상태**(성공 / 실패) · 알림톡이 실패해 **문자로 대신 보냈는지**(대체 발송 표시 — 화면에 나오는 이름은 확인 필요) · 시각.
- 요금 참고: 알림톡 13원 · 단문 18원 · 장문 45원 · 사진 문자 약 110원 (부가세 별도).

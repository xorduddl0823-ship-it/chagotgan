# 알림톡 방 → 총괄 방 보고 (2026-10-15, 총괄 안내 2건 반영)

1. 통과 8개는 글자 그대로 쓰고 다시 심사받지 않아요. 서버 sb6 변수·대체 문구가 확정본과 **모두 맞는 것을 확인**했어요(템플릿 코드는 sb6 를 올린 뒤에). 남은 7가지(「무료」→「체험 기간」, 접속 주소에 열쇠 막기, 인증번호 같이 쓰기 등)는 서버 방 요청서로 넘겼어요(`알림톡/04_…`).
2. 반려 5개는 서버 최종본(09)으로 내되 **두 줄만 고쳐** 내길 권해요: 이용제한시작 꼬리말의 「무료 체험」→「체험 기간」(카카오 금지어), 기간종료예정 꼬리말(「0일 전」 방지). 빠졌던 대체 문자 5개도 만들었어요(`01_…`).
3. 워시·체크·딜러·홈페이지·서버 목록을 모아 빠진 알림 초안 5개(차량도착·작업완료·접속주소안내·가입완료·작업시작)와 서버 초안 캐시소멸예정 검토를 넣었고, 인증번호는 모든 제품이 한 템플릿을 같이 써요(`02_…`). 「결제하기」 버튼은 토스 승인 전이라 지금은 신청하지 않아요(`03_…`).

### 대표님께 모아 드릴 결정거리 (총괄 방 판단)
- 새 템플릿 등록 순서: 추천 = 차량도착(체크) → 작업완료 → 캐시소멸예정 → 추가작업_2 → 접속주소안내 → 가입완료 → 작업시작
- 반려 5개 두 줄 고쳐 내기: 추천 = 고쳐 내기 (이미 냈으면 그대로 기다리고, 반려되면 고친 판으로)
- 도매상 주문 문자: 추천 = 알림톡으로 바꾸지 않고 지금처럼 휴대폰 문자 앱

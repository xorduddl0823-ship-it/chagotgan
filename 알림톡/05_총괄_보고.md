# 알림톡 방 → 총괄 방 보고 (2026-10-15)

1. 통과 8개는 글자 그대로 쓰고 다시 심사받지 않아요. 서버 sb6 변수·대체 문구를 확정본과 글자까지 대조해 **모두 맞는 것을 확인**했어요(sb5 는 다 틀렸으니 템플릿 코드는 sb6 를 올린 뒤에). 남은 작은 것 4개는 서버 방 요청서로 넘겼어요(`알림톡/04_…`).
2. 반려 5개는 서버 최종본(09)으로 내되 기간종료예정 꼬리말 한 줄만 고치길 권하고, 빠졌던 대체 문자 5개를 만들었어요(`01_…`). 워시 화면 변수가 옛 이름이라 입고·출고·청구 알림톡은 워시 방이 화면을 바꿔야 나가요.
3. 손님 여정 지도로 빠진 알림 새 초안(차량도착·작업완료·가입완료·작업시작 + 서버 초안 캐시소멸예정 검토)을 만들었고(`02_…`), 「결제하기」 버튼은 토스 승인 전이라 지금은 신청하지 않아요(`03_…`).

### 대표님께 모아 드릴 결정거리 (총괄 방 판단)
- 새 템플릿 등록 순서: 추천 = 차량도착(체크) → 작업완료 → 캐시소멸예정 → 추가작업_2 → 가입완료 → 작업시작
- 기간종료예정 꼬리말 고쳐 내기: 추천 = 고쳐 내기 (이미 냈으면 그대로 기다림)

### 다른 방에 넘길 것
- 워시 방: 화면 알림톡 변수를 확정본 이름으로 (`04_…` 아래 표) · 「작업 시작/완료」 상태와 `v.html` 진행 상태 표시 여부 알려 주기

## 등록하는 법 (템플릿마다 같아요)
1. 솔라피 › 카카오 알림톡 › 템플릿 등록 → **템플릿 이름** 칸에 아래 이름을 그대로 넣어요.
2. **카테고리**: 1·2번은 「회원 정보」 쪽, 3·4번은 「업무 알림」 쪽(목록에 없으면 이미 통과된 인증번호와 같은 분류).
3. **본문** 칸에 회색 상자 글을 **통째로** 붙여 넣어요. `#{…}` 부분은 고치지 말아요.
4. **버튼**: 「없음」이면 넣지 않아요. 3·4번만 웹링크 1개.
5. 저장 → **검수요청**.

## 1. 차곳간_임시비밀번호  (`temp_pw`)
- **언제**: 관리에서 회원 비밀번호를 초기화했을 때 (워시 계정 hqUserPw · 체크 기사 hqPersonAct «비밀번호 초기화»)
- **누구에게**: 그 계정에 등록된 휴대폰
- **버튼**: 없음
- **변수**: `#{이름}` 회원 이름(없으면 「회원」) · `#{제품}` 「차곳간 워시」/「차곳간 체크」 · `#{임시비밀번호}` · `#{처리일시}` 「10월 18일 14:30」

본문
```
[차곳간] 임시 비밀번호 안내
#{이름}님, #{제품} 계정의 비밀번호가 초기화되어 임시 비밀번호를 보내드립니다.

임시 비밀번호: #{임시비밀번호}
초기화 일시: #{처리일시}

로그인하신 뒤 바로 새 비밀번호로 바꿔 주세요.
임시 비밀번호는 다른 사람에게 알려주지 마세요.

※ 이 메시지는 차곳간 관리자가 회원님 계정의 비밀번호를 초기화했을 때, 계정에 등록된 휴대폰 번호로 발송됩니다.
본인이 요청하지 않았다면 바로 알려 주세요.
문의: 010-9559-3663
```

대체 문구 (알림톡이 안 되면 문자로)
```
[차곳간] #{제품} 임시 비밀번호 #{임시비밀번호} (로그인 후 바로 변경). 요청하지 않았다면 010-9559-3663
```

| 구분 | `#{내용}` 예 |
|---|---|
| 관리 로그인 | `휴대폰에서 로그인` (접속 기기 · 없으면 「관리 화면에서 로그인」) |

| 알림 번호 변경 완료 | `알림 번호가 010-****-1234(으)로 바뀜` |

## 4. 차곳간_본사업무알림  (`hq_task`)
- **언제**: 관리에서 확인할 일이 생겼을 때 — 본사가 한 처리 기록(카드 환불 hqPgCancel · 캐시 넣기 hqCashAdd · 빼기 hqCashTake)과 업체 쪽에서 생긴 일(사업자번호 처음 넣음 · 입금했어요 · 캐시 신청 · 상담 신청 · 하루 캐시 한도 · 결제 캐시 오류 · 가입 인증 한도 · 관리 계정 바꾸기 너무 많음)
- **누구에게**: 본사 알림 번호(대표님)
- **버튼**: 웹링크 「관리 열기」 → `https://admin.cgg.co.kr/`
- **변수**: `#{구분}` · `#{업체명}`(업체가 없으면 「-」) · `#{내용}` · `#{일시}`

| 구분 | `#{내용}` 예 |
|---|---|
| 카드 환불 | `55,000원 환불 (처리: 본사)` |
| 캐시 넣기 / 빼기 | `10,000원 넣음 (처리: 본사)` |

| 캐시 신청 · 상담 신청 | `캐시 50,000원 신청` / `상담 신청` |
| 사업자번호 등록 | `사업자번호 처음 입력` |
| 한도 · 오류 | `하루 캐시 한도 도달` / `결제 캐시 오류` / `가입 인증 한도 도달` / `관리 계정 변경 시도 많음` |

## 새로 안 만든 이유 — 기한 지난 업체 안내 (hqExpSendNow, 남은 날 0보다 작음)
이미 통과된 템플릿으로 대신해요. **업체 상태를 보고 서버가 고르면 돼요.**

| 업체 상태 | 쓸 템플릿 (통과본) | 서버 키 |
|---|---|---|
| 기간이 끝났고 로그인 제한일(`차단일`) 전 | `차곳간_이용제한시작` | `use_limit` |
| 로그인 제한일 하루 전 | `차곳간_로그인제한예정` | `login_block` |
| 로그인이 이미 막힘 (자료 정리 전) | `차곳간_자료보관기한` | `data_keep` |

- 변수는 `08_통과5개_서버연결표.md` 그대로(`업체명` `무엇` `종료일` `차단일` `보관일`). 대체 문구도 08 그대로.
- ⚠ 이용제한시작 본문에 「오늘부터 일부 기능이 제한」, 꼬리말에 「종료일 다음 날 한 번 발송」이 있어요. 그래서 **손으로 다시 보내는 건 업체당 한 번만**, 자동 발송(`cronExpire` lock)이 이미 나간 업체에는 로그인제한예정·자료보관기한 쪽을 쓰길 권해요. 걱정되면 이 경우만 지금처럼 문자로 둬도 돼요.

## 서버 방에 넘길 것 (통과 뒤 · 다음 판)
- 관리 › 알림 › 알림톡 템플릿에 **새 줄 4개**: `temp_pw` `acct_act` `hq_secure` `hq_task` (이름은 위 템플릿 이름 그대로).
- 변수 이름은 위 «변수» 줄과 **글자까지 같게**. 날짜·일시는 「10월 18일 14:30」 모양, 금액은 쉼표 넣고 뒤에 「원」.
- 코드가 비어 있으면 지금처럼 문자로(`smsIfNoCode = true`) — 통과 전후 언제 올려도 안전.
- ⚠ `#{내용}`·`#{처리}` 에는 «광고·할인·무료» 같은 말이 들어가지 않게, 위 표의 정해진 말만 넣어 주세요.
- 전화번호는 본문·문자에 가운데를 가린 모양(`010-****-1234`)으로.

## 대표님이 할 일
**1단계 — 솔라피에 4개 등록하기 (약 10분)**
1. 컴퓨터로 **https://console.solapi.com** 에 로그인해요.
2. 왼쪽 메뉴 «카카오 알림톡» → «템플릿 관리» → «템플릿 등록»을 눌러요.
3. 위 1~4번을 차례로: 템플릿 이름 칸에 이름 → 본문 칸에 회색 상자 글 통째로 → 3·4번만 버튼 «웹링크» 하나(이름 «관리 열기», 주소 `https://admin.cgg.co.kr/` 를 모바일·PC 칸 둘 다) → 저장.

**2단계 — 심사 요청하기**
1. 저장한 4개 옆의 «검수요청»을 눌러요. 보통 1~2일 걸려요.
2. 통과되면 템플릿 ID(`KA01TP…`)를 복사해 **관리 › 알림 › 알림톡 템플릿**의 같은 이름 칸에 넣고 «코드 저장». (새 줄 4개는 서버 방이 다음 판에서 만들어요 — 그 전까지는 문자로 그대로 나가요.)
3. 반려되면 반려 글을 그대로 총괄 방에 보내 주세요. 알림톡 방이 고쳐 드려요.

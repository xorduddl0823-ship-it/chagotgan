## 일을 주고받는 흐름 (예: 워시에 새 기능)

```
총괄   "워시에 ○○ 기능 추가" 결정 → 결정 기록
  ↓
서버   자료 저장 창구 만들기 (서버/)
  ↓
워시   화면에 기능 붙이기 (워시/, 디자인 기준틀 따라)
  ↓
보안   검사 → 문제 있으면 해당 방으로 되돌림 (보안/검사기록/)
  ↓
대표님  Cloudflare에 배포
```

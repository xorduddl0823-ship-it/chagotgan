## 낮음
- **L1 검사소가 쓴 글이 공식 채널 변수로 남에게 가요.** 업체명·받는곳·계좌·딜러명·대표차량이 그 글이에요. 그 안에 `http://…` 같은 링크를 넣으면 차곳간 채널로 딜러에게 나가요. 받는 사람은 등록 딜러뿐이고 하루 상한도 있어요. v32 의 도착 알림(목적지 등)과 같은 모양이라 낮음으로 봐요. → 변수 공통 청소를 권해요: `://`·`www.`·도메인 모양 지우기, 칸마다 길이 자르기.
- **L2 10분 안 다시 보내기 막기가 «읽고 나서 쓰기» 순서예요.** 두 번을 동시에 누르면 두 통이 갈 수 있어요(하루 상한 안에서만). → 보내기 전에 `update … set sent_at=now() where id=… and (sent_at is null or sent_at < now()-10분)` 로 먼저 잡고, 잡힌 것만 보내기.
- **L3 청구서 보기 주소가 `?c=` 쿼리에 열쇠를 넣어요.** 화면 방 v.html·/r/ 은 `Referrer-Policy: no-referrer`·`noindex`·`no-store` 를 꼭 넣어야 해요(서버 방 메모와 같음). 가능하면 `#` 뒤로 옮기기.
- **L4 `remindOff` 는 매니저도 허용하는데 오류 글은 «대표님만»이에요.** 위험은 없고(내 검사소 차만) 말만 맞추면 돼요.
- **낮음 4건 고침 확인 (6524aca) — 모두 해결.**
  - L1: `cleanVars` 는 `://`·`www.`·도메인 모양을 지우고, 줄바꿈을 없애고, 40자(계좌 60자)로 잘라요. billSend·재검사·도착 알림(본사 채널·검사소 템플릿 둘 다)의 알림톡 변수에 걸려 있어요. 보기코드·링크는 서버 값이라 빼요. 대체 문자도 청소한 변수로 만들어요. 도착 알림의 검사소 문자 글(`sms_text`)은 검사소 자기 번호로 나가는 것이라 그대로 둬요(M2 때 정함).
  - L2: 조건부 `update … or(sent_at.is.null, sent_at.lt.10분전)` 로 먼저 잡고 잡힌 것만 보내요.
  - L3: 템플릿 재심사 때문에 `?c=` 는 그대로 두고, 화면 방 머리글로 막아요 — 화면 판 검사 때 머리글을 확인할게요.
  - L4: 오류 글 고침.
- **체크 v33 + SQL 12 최종 통과.** 배포는 시험 뒤에, SQL 12 → 서버 v33 → 화면 순서로 해요.

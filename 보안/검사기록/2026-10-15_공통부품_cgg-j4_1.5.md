# 공통 부품 cgg-j4 1.5 (동결판) 검토 (2026-10-15 · 보안 방 · 3da0f68)

## 결론
**부품 자체에 새 구멍은 없어요.** 다만 1.5에서 생긴 두 기능은 **제품이 쓰는 방법에 따라 위험**해질 수 있어서, 각 제품이 1.5로 바꿔 끼울 때 아래 두 가지를 꼭 지키게 하고, 보안 방이 그 줄을 확인해요. (부품이 동결이라 부품을 고치는 대신 쓰는 규칙으로 막아요.)

## 1.4 → 1.5 바뀐 곳
| 바뀐 것 | 보안 |
|---|---|
| 일괄 버튼 `bulk`/`onBulk` | 이름·key 는 esc · 누르면 «고른 줄 번호»를 제품에 넘김 → 아래 ② |
| 할 일 칸 너비 150 | 영향 없음 |
| 다시 그려도 상태 유지 `state` | 찾기·쪽·정렬·**고른 줄**까지 남음 → 아래 ② |
| 칸 HTML `render(row,k)` | 부품은 돌려받은 글을 **그대로** 칸에 넣음(esc 안 함) → 아래 ① |

## ① [중간 · 쓰는 규칙] `render` 는 넣는 값마다 esc 를 제품이 직접
- 부품이 `render` 결과를 그대로 넣어요. 손님·업체가 적은 글(상호·이름·메모·차량번호·주소 등)을 `render` 안에서 esc 없이 붙이면 그 글이 화면에서 움직이는 글(스크립트)이 될 수 있어요.
- 규칙: `render` 안에서는 **줄 값은 모두 esc**, 링크 주소는 정해진 모양(`https://` 우리 주소)만, `onclick=` 같은 속성에 값을 넣지 않기(버튼은 `data-…` + 부품의 onAction).
- 폰 목록(둘째 줄·이름)은 부품이 esc 하므로 영향 없음 — `render` 는 넓은 화면 칸과 폰의 금액 칸에만 쓰여요.

## ② [중간 · 쓰는 규칙] `state` 를 쓰면 자료를 새로 불러올 때 «고른 줄»을 비우기
- 고른 줄은 «몇 번째 줄»로 기억해요. `state` 를 넘겨 다시 그릴 때 **자료가 새로 바뀌면**(새로고침·다른 사람이 지움·정렬이 바뀐 새 자료) 앞서 고른 번호가 **다른 줄**을 가리켜요. 그 상태로 «선택항목 삭제» 같은 일괄 버튼을 누르면 엉뚱한 줄이 지워질 수 있어요.
- 규칙: 자료를 새로 받으면 `state.sel = {}` 로 비우고 그림. 일괄 삭제·발송처럼 되돌리기 어려운 일은 확인 창에 **고른 줄의 이름 목록**을 보여 주고, 서버에는 번호가 아니라 **그 줄의 id** 를 보냄.
- (1.6 때 부품에서 줄 id 로 고르게 바꾸기 권함)

## 그 밖

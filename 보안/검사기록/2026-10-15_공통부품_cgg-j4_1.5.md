# 공통 부품 cgg-j4 1.5 (동결판) 검토 (2026-10-15 · 보안 방 · 3da0f68)

## 결론
**부품 자체에 새 구멍은 없어요.** 다만 1.5에서 생긴 두 기능은 **제품이 쓰는 방법에 따라 위험**해질 수 있어서, 각 제품이 1.5로 바꿔 끼울 때 아래 두 가지를 꼭 지키게 하고, 보안 방이 그 줄을 확인해요. (부품이 동결이라 부품을 고치는 대신 쓰는 규칙으로 막아요.)

## 1.4 → 1.5 바뀐 곳
| 바뀐 것 | 보안 |
|---|---|
| 일괄 버튼 `bulk`/`onBulk` | 이름·key 는 esc · 누르면 «고른 줄 번호»를 제품에 넘김 → 아래 ② |
| 할 일 칸 너비 150 | 영향 없음 |
| 다시 그려도 상태 유지 `state` | 찾기·쪽·정렬·**고른 줄**까지 남음 → 아래 ② |
| 칸 HTML `render(row,k)` | 부품은 돌려받은 글을 **그대로** 칸에 넣음(esc 안 함) → 아래 ① |

## ① [중간 · 쓰는 규칙] `render` 는 넣는 값마다 esc 를 제품이 직접
- 부품이 `render` 결과를 그대로 넣어요. 손님·업체가 적은 글(상호·이름·메모·차량번호·주소 등)을 `render` 안에서 esc 없이 붙이면 그 글이 화면에서 움직이는 글(스크립트)이 될 수 있어요.
- 규칙: `render` 안에서는 **줄 값은 모두 esc**, 링크 주소는 정해진 모양(`https://` 우리 주소)만, `onclick=` 같은 속성에 값을 넣지 않기(버튼은 `data-…` + 부품의 onAction).
- 폰 목록(둘째 줄·이름)은 부품이 esc 하므로 영향 없음 — `render` 는 넓은 화면 칸과 폰의 금액 칸에만 쓰여요.

## ② [중간 · 쓰는 규칙] `state` 를 쓰면 자료를 새로 불러올 때 «고른 줄»을 비우기
- 고른 줄은 «몇 번째 줄»로 기억해요. `state` 를 넘겨 다시 그릴 때 **자료가 새로 바뀌면**(새로고침·다른 사람이 지움·정렬이 바뀐 새 자료) 앞서 고른 번호가 **다른 줄**을 가리켜요. 그 상태로 «선택항목 삭제» 같은 일괄 버튼을 누르면 엉뚱한 줄이 지워질 수 있어요.
- 규칙: 자료를 새로 받으면 `state.sel = {}` 로 비우고 그림. 일괄 삭제·발송처럼 되돌리기 어려운 일은 확인 창에 **고른 줄의 이름 목록**을 보여 주고, 서버에는 번호가 아니라 **그 줄의 id** 를 보냄.
- (1.6 때 부품에서 줄 id 로 고르게 바꾸기 권함)

## 그 밖
- CSS 바뀐 곳은 너비·자리뿐(보안 영향 없음). 비밀 열쇠·바깥 주소 없음. 서버를 부르지 않음.

# cgg-j4 1.6 초안 (c21d240 · 디자인 방) — 1.5 와 비교
**통과.** 높음·중간·낮음 없음. 1.5 검사에서 남긴 두 가지 권고가 부품 안에서 해결됐어요.
- **render 기본 esc**: `cell()` 이 글자는 늘 `esc`, `{html:…}` 일 때만 그대로 넣어요. `null`/`undefined` 는 기본 모양이에요. → 1.5 «render 그대로» 문제 해결.
- **rowId 로 고르기**: 내부 열쇠 앞에 `r` 을 붙여 `__proto__`·`constructor` 같은 이름과 안 겹쳐요. `selList` 는 `Object.create(null)` 에 지금 자료의 열쇠만 담고, `T.sel[k]===true` 인 것만 돌려줘요(없어진 줄 빠짐). `data-i` 값은 esc 해요. → 1.5 «줄 번호로 고름» 문제 해결.
- 창·메뉴 `focus({preventScroll:true})`·`scrollTop=0` 은 위치만 바뀌어요. 아이콘 refresh·alert 은 고정 SVG 예요. CSS 33줄은 이름과 크기만 바꾸고, `url()`·`@import` 은 없어요.
- **제품에 넣을 때 주의(검사 때 볼 것):**
  - ① 1.5 에서 render 로 HTML 글을 돌려주던 곳은 1.6 에서 글자로 보여요. `{html:…}` 로 바꾸는 줄마다 안의 사용자 글이 `CGG.esc` 를 거치는지 볼게요.
  - ② `rowId` 는 글자나 숫자를 돌려줘야 해요. 객체를 돌려주면 모두 «[object Object]» 로 겹쳐요.
  - ③ `onSelect`·`onBulk` 가 줄 번호 대신 id 를 받으니, 그 id 로 서버에 보낼 때 서버가 내 업체 것인지 다시 확인하는지 볼게요(지금 서버들은 확인함).

# cgg-j4 1.7 초안 (f6ca564 · ⑦ 메뉴 찾기) — 1.6 과 비교
**통과.** 높음·중간·낮음 없음.
- `find`: 사용자가 친 글은 화면에 넣지 않고 비교에만 써요. 결과 이름·경로는 상수 목록이고 `esc` 해요. `spot(sel)` 은 상수 선택자만 받고 try 로 감쌌어요.
- `quick`: localStorage 값은 try 안에서 `JSON.parse` 해요. 배열이 아니면 버리고, `Object.create(null)` 목록에 있는 글자 id 만, 겹침 없이 8개까지 남겨요. `data-qi`·체크 상자 value 는 esc 해요. 서버에는 보내지 않아요.
- `nav`·`allMenu`: 라벨·열쇠를 esc 해요. 아이콘은 고정 표(`IC`)에서만 꺼내요. 판은 body 에 하나만 만들어요.
- `layout`: 저장값은 top/side/icon 만 받아요.
- 메뉴 목록 파일(`워시_메뉴.js`·`체크_메뉴.js`)은 상수뿐이에요(주소·script·innerHTML 없음). CSS 에 url()·@import 이 없어요.
- 제품에 넣을 때 볼 것: `onPick(열쇠)`·`onGo(기능)` 을 받는 제품 쪽은 열쇠를 **자기 화면 목록에서만** 찾아 움직여야 해요. 열쇠로 주소를 만들거나 eval 하지 않아요.

# 통신판매업 신고 서류 길 (결제 방, 2026-10-15)

> 법률 자문이 아니에요. 인터넷 공개 안내를 모은 것이고, **최종 판단은 관할 구청 지역경제과와 토스페이먼츠 고객센터(1544-7772)** 가 해요.
> ⚠ 이 작업방에서는 토스페이먼츠·정부24·서울시 누리집을 **직접 열 수 없어서**(접속 차단) 검색 결과에 나온 내용으로 정리했어요. 출처마다 작성 시점이 달라서, 「확실도」 칸을 같이 적었어요.

---

## 0. 한 줄 결론 (대표님이 먼저 보실 것)

1. **구매안전서비스 이용확인증은 토스페이먼츠 「계약 완료」 뒤에 나와요.** 계약 전에는 보통 못 받아요. → 그래서 순서는 **토스 가입 신청 → 계약 완료 → 확인증 출력 → 구청 신고**가 가장 흔한 길이에요. (토스 가입 신청 자체는 신고번호 없이도 돼요.)
2. 차곳간은 **카드 결제 + 인터넷으로 쓰는 서비스(배송 없음)** 라서, 확인증 대신 **「구매안전서비스 비적용 대상 확인서(소명자료)」** 로 신고할 수 있을 가능성이 높아요. 이게 되면 **토스 계약을 기다리지 않고 바로 신고**할 수 있어요. → **구청에 전화로 먼저 물어보는 게 가장 빨라요.** (아래 4번 질문 1번)
3. 「서버가 해외라 온라인 안 됨」은 **다시 확인할 가치가 있어요.** 차곳간 서버 프로그램은 수파베이스가 **아마존(AWS) 서울 지역(ap-northeast-2)** 에서 돌리도록 지정돼 있어요. 데이터 보관 위치도 서울이면, 다른 쇼핑몰 회사들처럼 **AWS 한국 사무소 주소**를 적고 정부24 온라인으로 낼 수도 있어요. 어차피 방문해도 되니, 방문 준비물은 아래 2번대로 챙기시면 돼요.

## 1. 우리 서버는 어디에 있나요?

| 부분 | 쓰는 곳 | 위치 | 확인 근거 |
|---|---|---|---|
| 서버 프로그램(wash-api·check-api 등) | 수파베이스(미국 회사) → 실제 기계는 아마존 AWS | **서울 지역(ap-northeast-2)** 으로 지정해서 부름 | 저장소 화면 파일의 주소 끝 `forceFunctionRegion=ap-northeast-2` |
| 데이터 보관(데이터베이스) | 수파베이스 → AWS | **아직 모름** (서울·도쿄·싱가포르 등 중 하나) | 수파베이스 관리 화면 → Project Settings(프로젝트 설정) → General(일반)에서 Region(지역) 확인 |
| 홈페이지·화면 파일(cgg.co.kr, app·check) | Cloudflare(미국 회사) | 전 세계에 나눠 둔 망(한 곳이 아님) | — |

- 수파베이스 공식 문서: 서울 지역 코드는 `ap-northeast-2` 이고, 프로젝트 지역은 한 번 정하면 바꿀 수 없어요(바꾸려면 새 프로젝트로 이사). https://supabase.com/docs/guides/platform/regions
- 아임웹·캠페이너스 같은 쇼핑몰 회사는 「AWS 클라우드라 실제 서버 주소가 따로 없으니 **AWS 한국 사무소 주소(서울 강남구 논현로 508 GS타워 12층)** 를 적으라」고 안내해요.
  - https://imweb.me/faq?mode=view&category=29&category2=39&idx=2739
  - https://help.campaignus.me/article/231-register-merchandiser
- **대표님/총괄 방 확인 필요**: 수파베이스 데이터 지역이 서울(Seoul)인지. → 서울이면 「호스트 서버: 국내(AWS 서울)」로 설명할 수 있어요.

## 2. 서버가 해외일 때(또는 온라인이 막힐 때) — 구청 방문 신고

**정부24 안내 문구(인용 글 기준)**: 「호스트 서버의 소재지가 해외인 경우에는 업체 소재지의 시·군·구청에 직접 방문하여 신고하시기 바랍니다.」
- 출처(정부24 화면 인용, 2021년 글): https://www.cosmosfarm.com/threads/document/49358
- 같은 취지, 2026년 8월 수정 가이드: https://zuzu.network/resource/guide/mail-order-sales-registration/
- 정부24에서 온라인 바로 신청은 **단독대표 개인사업자** 위주예요. 공동대표는 방문해야 한다는 안내가 있어요(토스페이먼츠 고객센터 안내 인용). 법인은 정부24에서 되긴 하지만 구청마다 다르게 안내하기도 해요.

**어디로**: 사업장 주소 관할 **시·군·구청 지역경제과**(구청마다 이름이 조금 다름)

**방문 준비물** (강남구청 등 구청 안내 + 쇼핑몰 회사 안내를 합친 것)

## 3. 구매안전서비스 이용확인증

### 3-1. 왜 필요한가요?
- 법(전자상거래법)상 **「돈을 먼저 받고 물건·서비스를 나중에 주는(선지급식)」** 통신판매업자는 손님이 원하면 결제 대금을 제3자에게 맡겨 두는 장치(에스크로) 또는 소비자피해보상보험을 쓸 수 있게 해야 해요. 신고할 때 그걸 쓰고 있다는 증명이 이용확인증이에요.
- 출처: 토스페이먼츠 블로그 「쇼핑몰 창업, 구매안전서비스 이용확인증 꼭 필요할까?」 https://www.tosspayments.com/blog/articles/semo-4

### 3-2. 차곳간은 「비적용 대상」일 가능성이 높아요
법이 정한 **예외**(인터넷 안내들의 공통 내용):
- ① **신용카드로 결제**하는 거래
- ② **인터넷으로 전송되거나 배송을 제3자가 확인할 수 없는** 상품(=배송이 없는 디지털 상품·서비스) 거래
- ③ 나눠서 계속 제공되는 상품(정기 이용 등)을 사는 거래

서울시 안내는 신고 구비서류를 **「구매안전서비스 이용 확인증 또는 소명자료(구매안전서비스 비적용 대상 확인서)」** 로 적고 있어요. → 예외에 해당하면 확인증 대신 확인서를 낼 수 있다는 뜻이에요.
- 서울시 경제분야 누리집: https://news.seoul.go.kr/economy/archives/95
- 예외 정리(2차 자료): https://thecheck.co.kr/?p=6357

**차곳간에 맞춰 보면**
| 항목 | 차곳간 | 예외 해당? |
|---|---|---|
| 결제 수단 | 카드(토스) 위주, 계좌이체도 받음 | 카드는 ①에 해당. **계좌이체(현금)는 해당 안 됨** → 현금도 받으면 구청이 확인증을 요구할 수 있어요 |
| 상품 | 인터넷으로 쓰는 업무용 프로그램(배송 없음) | ②에 해당할 가능성 높음 |
| 판매 방식 | 월 구독 | ③과 비슷 |
| 손님 | 업체(사업자) | 법은 「장사 목적으로 사는 거래」엔 원래 적용하지 않는다는 조항도 있지만, 신고 실무에서 그것만으로 빼 주는지는 구청 판단 |

> ⚠ 법 조문 원문(전자상거래법 제13조·제24조, 시행령)은 이번에 직접 열어 보지 못했어요. 국가법령정보센터(law.go.kr)에서 「전자상거래 등에서의 소비자보호에 관한 법률」로 확인할 수 있어요. 구청이 최종 판단해요.

**비적용 대상 확인서는 어디서?** 정해진 양식이 구청마다 있거나, 「우리는 예외에 해당한다」는 내용을 대표자 이름으로 적어 내는 방식이에요. **구청에 양식을 달라고 하면 돼요.** 결제 방이 내용 초안을 만들어 둘 수 있어요(요청 시).

### 3-3. 토스페이먼츠에서 이용확인증 받는 법
| 단계 | 내용 | 확실도 |
|---|---|---|
| 언제 | 토스페이먼츠 심사 상태가 **「계약 완료」** 가 된 뒤 | 높음(여러 안내 일치) |
| 어디서 | 토스페이먼츠 **상점관리자** 접속 → **[상점 들어가기]** → 화면 맨 아래 **「구매안전서비스 이용 확인증」** → **상점ID·사업자등록번호** 입력 → 출력 | 높음 |
| 다른 길 | 토스페이먼츠 **「가입 진행 현황 조회」** 화면에서도 발급 가능 | 보통(쇼핑몰 회사 안내) |
| 에스크로 계약 | 확인증 전에 **에스크로 계약이 들어가 있는지** 확인. 없으면 상점관리자 **「변경 신청」** 에서 에스크로 추가 계약 | 보통 |
| 계약 전 발급 | **보통 안 됨.** 「확인증은 PG 계약 완료 후 관리자 화면에서 발급되니, 계약 완료 후 신고하라」는 안내가 일반적 | 높음 |
| 「통신판매업 바로신청」 | 토스페이먼츠가 무료로 확인증 발급 + 정부24 신고를 한 번에 해 주는 서비스. **단독대표 개인사업자만** 가능, 온라인 신고 길이라 **서버 해외로 방문해야 하는 경우엔 못 쓸 수 있음** | 보통 |

## 4. 토스페이먼츠 가입·심사 순서

1. **온라인 신청** (토스페이먼츠 누리집 → 전자결제 신청). 통신판매업 **신고번호 없이도 신청 가능**.
2. **서류 내기 + 전자계약**: 보통 **1~3영업일**
3. **계약 완료** → 이때부터 **구매안전서비스 이용확인증 출력 가능**, 상점ID 생김
4. **카드사 심사**: 계약 완료 뒤 **약 2주(10~14영업일)**. 카드사별로 따로 열림
   - ⚠ **통신판매업 신고번호가 없으면 KB국민카드 심사가 빠져요.** (토스 블로그) → 신고 뒤 신고번호를 토스에 등록하면 국민카드 추가 심사
5. 실제 결제 켜기(차곳간 서버의 `pg_on` 스위치는 서버 방 담당, 배포는 대표님)

**필요 서류** (쇼핑몰 회사 안내 기준, 최신 목록은 토스 신청 화면에서 확인)
| 개인사업자 | 법인 |
|---|---|
| 사업자등록증 | 사업자등록증 |
| 대표자 명의 정산 계좌 | **법인 명의** 정산 계좌(개인 계좌 불가) |
| 대표자 휴대폰 본인인증 | 법인 등기사항증명서, (법인)인감증명서 |
| — | 주주명부(주식회사), **실제 소유자 확인 서류**(실제소유자 신분증 등) |

**심사 전에 홈페이지에 있어야 할 것** (카드사 심사 기준)
- 판매 상품(요금제)과 가격이 보이는 화면 1개 이상
- 화면 맨 아래 사업자 정보: 상호·대표자·사업자등록번호·사업장 주소·**유선 전화번호**·(있으면) 통신판매업 신고번호
- 이용약관, 환불 규정, 개인정보처리방침
- → 홈페이지 방이 준비 중인 하단 정보와 같아요. **요금제 화면이 cgg.co.kr에 보이는지** 확인 필요.

## 5. 추천 순서 (결제 방 추천)

**추천안 A — 비적용 확인서로 먼저 신고 (가장 빠름)**
1. 구청 지역경제과에 전화 → 아래 「구청 질문」 1~3번
2. 된다고 하면: 비적용 대상 확인서 + 준비물 들고 방문 신고 → 신고번호 받기
3. 그다음 토스 가입 신청 (신고번호가 있으니 **국민카드까지 한 번에** 심사)

**추천안 B — 구청이 확인증을 꼭 달라고 하면**
1. 토스페이먼츠 가입 신청 지금 바로 (신고번호 칸은 비워 둠, 에스크로 포함으로 신청)
2. 계약 완료(1~3영업일) → 상점관리자에서 이용확인증 출력
3. 구청 방문 신고 → 신고번호 받으면 토스에 등록 → 국민카드 추가 심사

> 어느 쪽이든 **토스 가입 신청을 지금 같이 넣어 두면** 기다리는 시간이 겹쳐서 빨라요. (신청만으로 돈이 나가거나 결제가 켜지지 않아요. 계약은 대표님이 하세요.)

## 6. 물어볼 질문 목록

### 구청 지역경제과에 (전화로 먼저)
1. 「업체(사업자)만 쓰는 인터넷 업무 프로그램 **월 이용료**를 **카드**로 받습니다(배송 없음). **구매안전서비스 비적용 대상 확인서**로 신고할 수 있나요? 양식이 있나요?」
2. 「**계좌이체로도 받을 수 있는데**, 그래도 비적용으로 되나요? 아니면 계좌이체를 빼면 되나요?」
3. 「호스트 서버가 **수파베이스/Cloudflare(미국 회사)** 이고 실제 기계는 **아마존 서울 지역**입니다. 정부24 온라인으로 되나요, 방문해야 하나요? 호스트 서버 소재지 칸에 무엇을 적나요? 증명 자료(관리 화면 캡처 등)가 필요한가요?」
4. 「(법인이면) 법인도 온라인 되나요? 대리인이 가면 필요한 서류는?」
5. 「등록면허세는 얼마고, 신고증은 언제 받나요?」

### 토스페이먼츠 고객센터(1544-7772)에
1. 「통신판매업 신고 전인데 가입 신청해도 되나요? 신고번호는 나중에 넣어도 되나요?」
2. 「구매안전서비스 이용확인증은 **계약 완료 전**(심사 중)에도 발급되나요? 가입 진행 현황 조회에서 바로 되나요?」

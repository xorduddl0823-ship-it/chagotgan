> **실제 돈은 나가지 않아요.** 토스 **테스트 열쇠**(이름 `TOSS_SECRET_KEY` 자리에 테스트 키, 관리에 테스트 client key)를 넣은 상태에서만 해요. 화면에 「테스트 모드」 표시가 보이는지 먼저 확인.
> 카드 번호는 토스 결제창이 안내하는 테스트 방법대로 넣어요(실제 카드 번호를 문서·대화에 적지 않아요).
> 새 판(J안) 한 번에 시험해요. 걸리는 시간: 약 40분. 결과는 「됨 / 안 됨 + 화면 캡처」로 총괄 방에 주시면 돼요.
>
> **토스 테스트 열쇠가 아직 없으면?** (토스 개발자센터에 가입하면 계약 전에도 테스트 열쇠가 나와요. 그것도 아직이면) 아래 표 「열쇠 없이」 칸이 **⏭** 인 줄은 건너뛰고, **✅** 인 줄만 해요(약 15분). 건너뛴 줄은 결과에 「⏭ 열쇠 없음」이라고 적어 주세요 — 실패가 아니에요.
> 열쇠가 있는지 보는 법: 관리 → 받는 금액 › 카드 결제 제목 옆에 **「테스트 모드」** 표시가 보이면 있음. 안 보이면 없음(또는 실제 열쇠 — 그때는 시험하지 말고 총괄 방에 알려 주세요).

### 결제 알림톡이 발송 기록에 남는지 (대표님 지시 「실수 없이」)
> 보는 곳: **관리(v4.6) → 알림 › 발송 기록** 화면. 줄마다 **제품 · 업체 · 템플릿 키 · 알림톡/문자 · 성공 여부**가 보여야 「됨」.
> 결제 알림톡(결제완료·충전완료·자동결제 등록·실패)은 **템플릿 코드가 없으면 문자로 대신 보내지 않고 아예 안 보내요**(서버 sb14 `noticeAta` 확인). 코드가 있는데 알림톡이 실패할 때만 문자로 대신 가요.
> 서버가 직접 보내는 결제 알림톡도 「모든 서버 같은 발송 기록」 판(**워시 sb15**)부터 남아요(`cgg_sendlog`: 제품 · 업체 · 템플릿 키 · 알림톡/문자 · 결과, 번호는 `010-****-1234`만). 코드가 없어 안 보낸 것도 결과 **「skip — 알림톡 코드가 없어 보내지 않음(설계대로)」** 으로 남아요 — 「안 보낸 것」은 실패가 아니에요. sb15가 올라가기 전이면 24·25·27·28·29는 「안 됨(서버 판 대기)」으로 적어요.

## 끝나면
- 자동 결제 스위치는 **다시 끄기**(토스 자동결제 실제 계약 전까지)
- 테스트 열쇠 → 실제 열쇠로 바꾸는 건 **토스 계약 완료 + 보안 방 배포 전 검사 뒤**, 대표님이 직접(값은 대화·문서에 적지 않음)
- 실제 결제 첫 확인은 **1건만**(가장 싼 요금제) 하고 바로 관리에서 환불해 보기 — 규칙 5-5와 같은 조심

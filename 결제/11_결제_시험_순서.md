> **실제 돈은 나가지 않아요.** 토스 **테스트 열쇠**(이름 `TOSS_SECRET_KEY` 자리에 테스트 키, 관리에 테스트 client key)를 넣은 상태에서만 해요. 화면에 「테스트 모드」 표시가 보이는지 먼저 확인.
> 카드 번호는 토스 결제창이 안내하는 테스트 방법대로 넣어요(실제 카드 번호를 문서·대화에 적지 않아요).
> 새 판(J안) 한 번에 시험해요. 걸리는 시간: 약 40분. 결과는 「됨 / 안 됨 + 화면 캡처」로 총괄 방에 주시면 돼요.

## 시험 전 준비 (서버 방·관리에서, 대표님은 확인만)
- 워시 서버 sb12 · pay-hook · 딜러 d6 · SQL 06·08 올라감
- 토스 개발자센터 웹훅 주소 등록(`…/functions/v1/pay-hook`, `PAYMENT_STATUS_CHANGED`)
- 관리 → 카드 결제 켜기(테스트), 자동 결제 스위치 **켜기(테스트 때만)**

## 끝나면
- 자동 결제 스위치는 **다시 끄기**(토스 자동결제 실제 계약 전까지)
- 테스트 열쇠 → 실제 열쇠로 바꾸는 건 **토스 계약 완료 + 보안 방 배포 전 검사 뒤**, 대표님이 직접(값은 대화·문서에 적지 않음)
- 실제 결제 첫 확인은 **1건만**(가장 싼 요금제) 하고 바로 관리에서 환불해 보기 — 규칙 5-5와 같은 조심

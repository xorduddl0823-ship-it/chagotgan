# 결제 기능 「끝난 기준」 — 제품별 새 판(J안) 확인표 (결제 방, 2026-10-15)

> 쓰는 법: 각 방이 J안 새 판을 만들면 이 표로 결제 기능이 **빠짐없이** 들어갔는지 확인해요. ☐ 를 ☑ 로 바꾸면서 확인(확인은 각 방 + 결제 방).
> 서버 창구 이름은 워시 서버 sb12 기준(`서버/설계/12`~`15`). 시험은 **토스 테스트 모드만**(실제 결제 시험 순서는 `11_결제_시험_순서.md`).
> 공통: 해요체 · 「금액」(규칙 4-2) · 화면 파일 하나로 PC·휴대폰(규칙 1-6) · 결제·연장 권유는 화면 안에서만, 알림톡엔 없음(규칙 5-6) · 비밀 열쇠는 화면에 없음(공개 client key만 서버가 줌).

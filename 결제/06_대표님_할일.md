# 대표님 할 일 — 통신판매업 신고 + 토스 가입 (한 장)

> 확정된 것: 개인사업자 · 카드 + 계좌이체 · 서버 서울(아마존 서울 지역). 자세한 근거는 `01_신고_서류_길.md`.

## 순서 (3단계)
1. **구청에 전화 5분** (아래 「읽을 말」 그대로) → 온라인으로 되는지, 확인증이 꼭 필요한지 확인
2. **토스페이먼츠에서 확인증 받기 + 가입 신청** (아래 「토스 순서」)
3. **신고** (정부24 온라인 또는 구청 방문) → 등록면허세 내기 → 신고번호를 결제 방·홈페이지 방에 알려 주기

---

## 1. 구청 전화할 때 읽을 말
**어디로**: 사업장 주소 관할 구청 **지역경제과**(「통신판매업 신고 담당」 바꿔 달라고 하세요)

> 「안녕하세요. 통신판매업 신고하려고 여쭤봅니다.
> 저희는 **개인사업자**이고, 자동차 관련 업체가 인터넷으로 쓰는 **업무용 프로그램**의 **월 이용료**를 받습니다. **배송하는 물건은 없습니다.** 결제는 **카드와 계좌이체** 두 가지입니다.
> 세 가지 여쭤볼게요.
> 첫째, 구매안전서비스 **이용확인증**을 꼭 내야 하나요, 아니면 **비적용 대상 확인서**로 내도 되나요?
> 둘째, 서버는 아마존 클라우드 **서울 지역**에 있습니다. **정부24 온라인**으로 신고해도 되나요? 호스트 서버 소재지 칸에는 뭐라고 적으면 되나요?
> 셋째, 등록면허세는 얼마이고, 신고증은 언제 받을 수 있나요?」

**답에 따라**
| 구청 답 | 하실 일 |
|---|---|
| 「확인증 내세요」 (가장 가능성 높음) | 아래 2번 토스 순서대로 확인증 받기 |
| 「비적용 확인서도 돼요」 | `07_비적용_대상_확인서_초안.md` 빈칸 채워서 내기(구청 양식 있으면 그것) |
| 「온라인 돼요」 | 정부24에서 「통신판매업 신고」 검색 → 신청 |
| 「방문하세요」 | 준비물: 신분증, 도장, 사업자등록증 사본, 확인증(또는 확인서) |

메모해 둘 것: 담당자 이름, 등록면허세 금액, 호스트 서버 칸에 적으라고 한 말.

## 2. 토스페이먼츠 순서
**A. 확인증 먼저 (무료)** — 토스페이먼츠 누리집 → **「통신판매업 바로신청」**
- 대표가 **한 명인 개인사업자**만 돼요. 확인증 발급과 정부24 신고를 한 번에 해 줘요(번호 받기까지 1~3일).
- 호스트 서버 칸이 나오면: **국내 — 아마존 웹 서비스(AWS) 서울 지역**. 주소를 물으면 AWS 한국 사무소 「서울 강남구 논현로 508 GS타워 12층」.
- 안 되면(공동대표 등) → B 계약 완료 뒤 확인증 받기.

**B. 카드 결제 가입 신청 (같은 날)** — 토스페이먼츠 누리집 → **전자결제 신청**
1. 사업자등록증, **대표자 이름의 정산 계좌**, 휴대폰 본인인증 준비
2. 신청서: 업종 「업무용 소프트웨어(클라우드) 월 이용 서비스」, 홈페이지 cgg.co.kr, 결제 수단 카드(+계좌이체), **에스크로 포함**
   - 메모 칸(또는 담당자 전화 때): 「**자동결제(정기 구독)** 와 **지급대행**도 쓰고 싶어요」
3. 통신판매업 신고번호는 **비워 두고 신청해도 돼요**(나중에 등록)
4. 토스 담당자 연락(1~3영업일) → 전자계약 → **계약 완료**
   - 계약 완료 뒤 확인증 받는 곳: 상점관리자 → [상점 들어가기] → 맨 아래 「구매안전서비스 이용 확인증」
5. 카드사 심사 약 2주 → 신고번호 등록하면 국민카드까지 열려요
- 심사 전 확인: 홈페이지 맨 아래에 상호·대표자·사업자번호·주소·**유선 전화**·이용약관·환불 규정·개인정보처리방침, **요금제 화면**이 보여야 해요(홈페이지 방 준비 중)
- 막히면 토스페이먼츠 고객센터 **1544-7772**

⚠ 계약·신고는 대표님만 하세요. 비밀 열쇠(토스 「시크릿 키」)를 받으면 **대화방·문서에 붙이지 말고** 수파베이스 서버 비밀값에 `TOSS_SECRET_KEY` 이름으로 직접 넣으세요(넣는 법은 서버 방이 안내).

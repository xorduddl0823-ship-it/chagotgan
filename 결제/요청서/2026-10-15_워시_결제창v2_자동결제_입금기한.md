⚠ **시안(미리보기) 먼저** 대표님께(규칙 3-7, 총괄 방 통해). 시험은 토스 **테스트 모드**만. 비밀 열쇠 값은 화면에 절대 안 넣음(공개 client key만 서버가 줌).

1. 왜 필요한가요?
   - 지금 결제창은 토스 옛 v1이에요. 서버 sb10이 v2 값(`customerKey: "ANONYMOUS"`, `sdk: "v2"`)을 주기 시작했어요.
   - 업체 대표가 매달 누르지 않아도 되게 **자동 결제**를 켤 수 있어야 해요(꺼진 게 기본).
   - 딜러앱 청구서 묶음에 **입금 기한**을 보여 주려면 워시가 청구서를 만들 때 기한을 같이 보내야 해요.

2. 무엇을 해 주면 되나요?
   (가) **결제창 v2**: `loadToss()` 를 v2 SDK(`https://js.tosspayments.com/v2/standard`)로, `payStart` 응답의 `clientKey`·`customerKey`·`orderId`·`amount`·`orderName` 그대로 사용. 돌아온 뒤 `payConfirm` 은 지금과 같음.
   (나) **자동 결제 화면**(대표만, 서버가 `billInfo().open` 이 false면 칸 자체를 숨김):
       - 꺼져 있을 때: 「자동 결제 켜기」 → **동의 화면**(매달 금액·결제일·해지 방법·첫 결제일, 동의 문구판 번호 함께) → `billStart()` 로 받은 customerKey·clientKey로 v2 **카드 등록창** → 돌아오면 `billIssue([authKey, 동의문구판])`
       - 켜져 있을 때: 카드사·끝 4자리·다음 결제일·실패 횟수(`billInfo`) + [카드 바꾸기](등록창 다시) + [자동 결제 끄기](`billOff`, 「이번 기간 끝까지 쓸 수 있어요」 안내)
       - 실패 중이면 맨 위에 「결제가 되지 않았어요. 다음 시도일 ○○」 + [카드 바꾸기]
   (다) **청구서 입금 기한**: 청구서 보기를 만들 때 `viewBill` 에 `dueDate`(YYYY-MM-DD)를 함께 보내기(알림톡 `bill` 의 #{입금기한}과 같은 값)
   - 문구 해요체, 「금액」(규칙 4-2). 결제·연장 권유 문구는 알림톡에 안 넣음(규칙 5-6) — 화면 안은 괜찮음.

3. 끝났다고 보는 기준 (테스트 모드)
   - v2 창으로 월 요금 결제 → 이용기간 +30일 / 창을 닫아도 1분 안에 반영
   - 자동 결제 켜기 → 카드사·끝 4자리 보임 → 끄기 → 다음 결제 없음
   - 매니저·직원 계정에는 자동 결제 칸이 안 보이고, 불러도 서버가 거절
   - 청구서 보내기 → 딜러앱 청구서에 입금 기한이 보임

4. 기다리는 다른 일
   - 서버 sb10·SQL 06 배포(대표님), 보안 검사 통과
   - 자동 결제 실제 켜기: 토스 자동결제 추가 계약 + 관리 스위치 `billing_on`
   - 체크 화면도 같은 결제창 코드가 있어 체크 방에 같은 (가) 요청을 따로 보냄

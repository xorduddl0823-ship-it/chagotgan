## 2. 모든 제품이 똑같이 쓰는 것 (제품 방에서 바꾸지 않음)

J안 파일 안에서 **제품 등록부 `PR` 바깥**에 있는 것은 전부 공통이에요. 글자 하나도 바꾸지 않고 복사해요.
바꿔야 할 것 같으면 디자인 방에 요청서(`운영/01_작업_요청서_양식.md`)를 보내 주세요.

### 2-1. 틀과 메뉴 배치
- 메뉴 배치 3가지를 사용자가 골라요: **가로 메뉴 · 세로 메뉴 · 아이콘 메뉴** (사람 단추 › 화면 설정). 이 기기에만 저장돼요.
- 세 가지 배치 모두 **남색(`#0B2545`)** 틀을 써요. 세로 · 아이콘 배치일 때 본문 윗줄은 흰색이에요 (남색이 두 겹이 되지 않게).
- **본문은 세 배치 모두 글자까지 같아요.** 배치에 따라 본문을 다르게 만들지 않아요.
- 맨 위 메뉴는 8개 이하, 안쪽 작은 탭, 「전체 메뉴」 + 메뉴 찾기를 둬요.
- **메뉴 차례는 지금 쓰는 차례 그대로예요** (규칙 3-4). 시안에서 순서를 바꾸지 않아요.

### 2-2. 머리말 (가로 메뉴 기준)
- 왼쪽부터: CI + 차곳간 + 「설명 · 제품 v번호 · UI 3.0」(300px 고정) → 업체 이름 + 사업자번호 · 대표 → 오른쪽 끝 버튼들
- 버튼 차례: (워시만) 현장 화면 → 공지사항 → 도움말 → 링크 복사 → ↻ 새로고침 → 30초마다 자동 새로고침 → 사람 단추
- 그림 문자(📢 ❓ 🔗)는 쓰지 않아요. 얇은 선 아이콘만 써요.
- **사람 단추 ▾ 안**: 마이페이지 · 요금제 · 휴지통(건수) · 화면 설정 · 상단 버튼 위치 · 로그아웃. 빨간 개수 표시는 사람 단추 위에 붙여요.
- 여러 제품을 쓰는 계정은 「워시 ▾」처럼 제품 이름 옆에서 제품을 바꿔요.

### 2-3. 화면 일곱 칸 (규칙 3-6)
① 머리말 → ② 묶음 이름 › 제목 + 설명 한 줄 → ③ 할 일 카드 3장 → ④ 도구줄 → ⑤ 숫자 카드 4개 → ⑥ 표 → ⑦ 접힌 도움 카드(「이 화면 사용법」)

- ② 제목은 **말하는 제목**이에요. 예: «작업 중인 차 **5대**, 출고 대기 **3대**가 있어요». 숫자는 강조해요.
- ③ 할 일 카드는 상태 색(파랑 · 주황 · 빨강) 아이콘 + 굵은 한 줄 + 작은 설명 한 줄이에요.
- ⑤ 숫자 카드: 이름 · 큰 숫자 + 단위 · 「지난주보다」 늘고 준 값 · 작은 꺾은선 그래프.

### 2-4. 표
- 열 차례: **선택 → 이름 → 번호 → 내용 → 날짜 → 금액 → 상태**
- 열 너비: 선택 56 · 이름 180 · 번호 130 · 날짜 96 · 금액 130 · 상태 104 (시간 칸이 있으면 84)
- 머리줄 40px, 줄 50px, 가로선만 얇게, 선택 네모 20px(직접 그린 네모 — 기기의 어두운 설정을 따라가지 않음)
- 표 위: 상태별 탭 + 개수 · 필터 알약 · 오른쪽 위 버튼
- 금액은 오른쪽, 상태는 가운데 정렬. 이름을 누르면 「자세히」 창이 열려요.
- **파란 버튼은 한 화면에 하나만** 써요 (보통 「선택한 ○○ ○○」).

### 2-5. 창 3종
- 확인 400 · 입력 560 · 자세히 520(오른쪽에서 열림)
- 제목 → 내용 → 오른쪽 아래 [취소][동작]. 바깥을 누르거나 Esc · ✕로 닫혀요. 창이 열리면 뒤 페이지가 멈춰요.
- `alert` · `confirm`(브라우저 기본 알림창)은 쓰지 않아요.
- 확인 창에는 **누구 · 몇 개 · 합계 금액**을 꼭 보여 줘요. 예: «출고할까요? · 상사 · 대수 · 합계 금액»

### 2-6. 색 · 글자 · 모양
| 이름 | 값 |
|---|---|
| 파랑 (주 버튼 · 선택된 탭) | `#1668C4` |
| 남색 (틀) | `#0B2545` |
| 하늘 (남색 위 강조) | `#8FC9F2` |
| 바탕 / 카드 | `#F3F5F8` / `#FFFFFF` |
| 글자 / 보조 글자 | `#101828` / `#667085` |
| 상태 — 진행 중 | 파랑 `#1668C4` (바탕 `#E6F0FB`) |
| 상태 — 완료 | 초록 `#1E9E5A` (바탕 `#E4F5EC`) |
| 상태 — 확인 필요 | 주황 `#B26B00` (바탕 `#FFF2DD`) |
| 상태 — 보류 | 빨강 `#D64545` (바탕 `#FDE8E8`) |
| 카드 모서리 / 버튼 모서리 / 버튼 높이 | 18px / 12px / 43px |
| 글꼴 | Noto Sans KR 하나만 (굵기 400 · 500 · 700 · 900) |

화면 곳곳에 색 값을 직접 쓰지 않고, J안 맨 위 `:root` 변수 이름만 써요.

### 2-7. 폰 (가로 600px 이하) — 같은 파일, 따로 만들지 않음 (철칙 4)
- 배치와 상관없이 하나: **남색 윗줄 48px + 아래 탭바 56px** (5칸: 홈 · 제품 주요 메뉴 3개 · 전체)
- 글자: 제목 19 · 본문 13.5 · 작은 글 11.5 / 여백: 옆 12 · 칸 사이 10 / 버튼 38 / 카드 모서리 14
- 할 일: 카드 하나 안에 세 줄 (옆으로 넘기지 않음)
- 숫자 카드: 2×2
- 표 → **목록**으로 바뀌어요 (열 차례는 그대로). 전체 선택 + 정렬 고르기를 둬요.
- 창: 아래에서 올라와요. 안쪽 16 · 제목 17 · 칸 40 · 버튼 42
- 가로로 넘치는 곳이 하나도 없어야 해요.

## 3. 제품마다 다른 것 — 제품 등록부 한 덩어리

J안 파일의 `var PR = { wash:{…}, admin:{…} }`에 **제품 한 덩어리를 더하는 것만** 해요. 나머지는 손대지 않아요.

| 칸 이름 | 무엇 | 예 (워시) |
|---|---|---|
| `label` · `desc` · `sub` | 제품 이름 · 한 줄 설명 · 머리말 작은 글 | 워시 · 광택 · 세차 · «광택·세차 관리 · 워시 v111 · UI 3.0» |
| `biz` · `me` · `hello` | 업체 이름 · 사업자번호 · 대표 / 사람 단추 글자 / 인사 | 시안에는 **지어낸 값**을 써요 (6장) |
| `field` | 머리말 「현장 화면」 버튼 | 워시만 `true`, 나머지 `false` |
| `find` | 찾기 칸 안내 글 | «상사 · 차량번호 · 메뉴 찾기» |
| `menu` | 메뉴 묶음과 안쪽 작은 탭, 아이콘 | 4장 표의 차례 그대로 |
| `cols` · `kinds` · `rows` | 대표 목록의 열 이름 · 열 종류 · 예시 자료 | 열 종류: name · id · text · date · money · state (+ time) |
| `nums` | 숫자 카드 4개 | 오늘 입고 · 작업 중 · 출고 대기 · 이번 달 청구 금액 |
| `acts` | 할 일 카드 3장 | 출고 확인 3대 · 입금 대기 2곳 · 10월 청구서 보내기 |
| `home` · `homeH` | 홈 달력 일정 · 홈 첫 줄 · 입금 카드 · 이번 달 카드 | |
| `work` | 대표 목록 화면의 제목 · 설명 · 버튼 · 필터 · 정렬 · 도움말 · 확인 창 글 | |
| `tabbar` | 폰 아래 탭바 5칸 | 홈 · 일감 · 입출금 · 계산서 · 전체 |

## 6. 시안 만들 때 지킬 것

1. **새로 그리지 말고 J안 파일을 복사해요.** 제품 방은 `PR`에 자기 제품 한 덩어리만 더해요.
2. 시안 파일은 **자기 서랍에 새 이름으로** 저장해요. 예: `체크/시안_체크_J4.html`. 디자인 서랍의 J안 원본은 고치지 않아요.
3. 예시 자료(업체 이름 · 사업자번호 · 대표 이름 · 차량번호)는 **지어낸 값**을 써요. 실제 손님 정보는 넣지 않아요.
4. 문구는 쉬운 말 해요체로 써요. 「돈」이라고 쓰지 않고 **「금액」**이라고 써요. J안 시안 아래 **「말 바꾼 곳 (전 → 후)」 표 29줄**을 그대로 따라요 (검색 · 엑셀 다운로드 · 전체 선택 · 10개씩 보기 · 이 화면 사용법 · 버튼 등).
5. 원래 화면 문구를 바꿨으면 **원본 → 새 문구 대조표**를 시안 아래에 붙여요. 대표님이 그 표를 보고 확인해요.
6. 약관 글(이용약관 · 개인정보처리방침 · 환불정책)은 손대지 않아요.
7. 원래 메뉴 · 버튼을 없애지 않아요. 자리를 옮겼으면 어디로 옮겼는지 적어요.

### 시안을 넘기기 전 확인 목록
- [ ] PC 1600px · 폰 390px 두 크기에서 열어 봤어요
- [ ] 세 배치(가로 · 세로 · 아이콘) 모두 남색 틀이고, 본문이 똑같아요
- [ ] 폰에서 가로로 넘치는 곳이 0개예요
- [ ] 표 열 차례 · 너비, 줄 50px, 선택 네모 20px, 도구줄 버튼 43px(폰 38px)이 맞아요
- [ ] 파란 버튼은 한 화면에 하나만 있어요
- [ ] 확인 창에 누구 · 몇 개 · 합계 금액이 보여요
- [ ] 화면 오류(콘솔 오류)가 0개예요
- [ ] 원래 메뉴 중 빠진 것이 0개예요
- [ ] 바꾼 문구는 대조표에 적었어요

## 7. 아직 대표님 답을 기다리는 것

1. **설정 안 세 가지를 옮길지**: 자료 올리기(체크) → 매출 안 / 설정 안 휴지통을 없애고 사람 단추 한 곳만 둘지 / 도움말(체크) → 머리말
2. **파킹 · 스튜디오 메뉴 이름**이 실제 쓰는 말과 맞는지 (지금 순서로는 워시 · 체크 · 딜러가 먼저예요)
3. **딜러 메뉴**: 딜러 방이 4장의 네 가지를 보내 주면 시안을 만들 수 있어요

※ 「J를 기준틀 2판으로 정할지」, 「체크를 J 시안에 넣을지」는 이번 결정(전 제품 J안 4판)으로 답이 정해졌어요.
※ 상태 이름은 **진행 중 · 확인 필요 · 보류 · 완료로 확정**됐어요 (대표님, 2026-10-14). 모든 제품이 이 네 이름과 2-6장의 네 가지 색을 똑같이 써요.

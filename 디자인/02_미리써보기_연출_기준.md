# 미리 써 보기 · 체험판 — 연출 기준

> 작성: 디자인 방 (2026-10-15) · 읽는 곳: 홈페이지·앱 방(미리 써 보기 시안), 워시 · 체크 · 딜러 방
> 근거: 결정 기록 2026-10-15 «대표 홈페이지에서도 결제 + 앱 미리 써 보기», 2026-10-15 «체험판 기능 나누기»
> 대표님 방향: **«궁금하게 만들고, 계속 들어오게»** — 단, 과하게 막거나 속이는 느낌은 없게.

## 1. 두 가지는 같은 화면, 다른 단계예요

| | 미리 써 보기 | 체험판 |
|---|---|---|
| 누가 | **가입 전** 손님 (홈페이지에서) | **가입 뒤 · 결제 전** 사장님 |
| 화면 | 실제 제품 화면의 체험 모드 (따로 만든 가짜 화면 아님) | 같음 |
| 자료 | 예시 자료 (내 업종 고르면 그 업종 예시) | 같음 |
| 저장 · 문자 · 결제 | 안 됨 | 안 됨 (서버가 막음) |
| 잠금 14 · 3번 18 · 보기 13 | 같은 분류표 | 같은 분류표 |
| 맨 위 띠 꼬리표 | «미리 써 보기» | «체험판» |
| 띠 · 창의 파란 버튼 | **«무료로 시작하기»** (가입으로) | **«요금제 보기»** (결제로) |
| 3번 세기 | 이 기기 브라우저에만 (모양 맛보기) | 서버가 계정별로 셈 |

**모양은 공통 부품 `디자인/공통/cgg-j4` 1.2의 `CGG.trial` 하나로 그려요.** `CGG.trial.init("preview")`면 미리 써 보기, `init("trial")`이면 체험판이에요. 글과 버튼만 바뀌고 모양은 같아요.

## 2. «궁금하게» — 첫 방문

1. **첫 화면 = 제품 고르기 3장** (워시 · 체크 · 딜러). 카드마다 한 줄 설명과 «눌러 보기». 가입 칸은 보이지 않아요.
2. 고르면 **그 제품 홈으로 바로** 들어가요 (로그인 화면 없음). 업종을 고르면 그 업종 예시 자료로 채워져요 (세차 · 휠 · 판금 / 성능점검 / 딜러).
3. **모든 메뉴와 화면이 열려 있어요.** 잠그는 것은 화면 안의 버튼뿐이에요. 자물쇠 버튼을 누르면 한 줄 소개가 나와요. «이 버튼을 누르면 이런 일이 돼요»를 보여 줘서 궁금하게 만들어요.
4. 화면마다 **«이 화면에서 할 수 있는 것» 카드**로 잠금 · 3번 · 보기를 알려 줘요 (`CGG.trial.card`).

## 3. «계속 들어오게» — 다시 오기

1. **둘러본 화면 표시**: 맨 위 띠에 얇은 막대로 «둘러본 화면 5 / 20»을 보여 줘요 (`band({seen, total})`). 다 채우고 싶게 만들어요.
2. **이어서 둘러보기**: 다시 오면 «지난번에 본 ○○ 화면부터 이어서 볼까요?»를 한 줄로 보여 줘요 (이 기기에만 기억).
3. **3번 남은 기능**은 버튼 옆에 «3번 남음 → 2번 → 1번 → 다 씀». 다 쓰면 창 한 번만 보여 주고, 같은 창을 계속 띄우지 않아요.
4. 결제 안내 창은 **누를 때만** 떠요. 들어오자마자 뜨거나, 시간마다 저절로 뜨는 창은 쓰지 않아요.

## 4. 하지 않는 것 (속이는 느낌 막기)
- 화면 전체를 흐리게 가리거나, 숫자를 일부러 감추지 않아요.
- 남은 시간 초읽기 · «지금 아니면 끝» 같은 재촉하는 말은 쓰지 않아요.
- 잠금 창에는 늘 **«지금 할 수 있는 것»**을 함께 적어요 (`lockText`).
- 그림 문자(🔒)는 쓰지 않고 선 아이콘 자물쇠만 써요 (기준서 2-2).
- 예시 자료임을 늘 보여 줘요 (띠 · 꼬리표). 진짜 손님 정보는 넣지 않아요.

## 5. 요금제 · 결제 화면 모양
- 요금제 카드 3장을 나란히 놓아요 (폰은 세로로). **추천 하나에만** «추천» 꼬리표를 달아요.
- 카드 안의 차례: 이름 → 한 달 금액(큰 숫자) → «이런 게 열려요» 목록(잠금 14개 중 무엇이 열리는지) → 버튼.
- 파란 버튼은 화면에 하나뿐이에요 (추천 카드). 나머지는 흰 버튼이에요.
- 결제 창은 입력 창(560) 규격이에요. 버튼은 «○○원 결제하기»처럼 금액을 적어요. 확인 창에는 «요금제 · 기간 · 합계 금액»을 보여 줘요.
- 안내 말투는 결제 · 가입 · 오류만 표준형(«~습니다»)이고, 나머지는 해요체예요 (규칙 4-1).

## 1. 이번에 바뀐 순서
예전: 시험 먼저 → J안은 시험 뒤. **지금: J안 완성 모양을 제품 새 판에 넣고 → 그 판으로 대표님 확인과 시험을 한 번에.**
그래서 이번 새 판은 **모양까지 완성본**이에요. 뼈대 · 배치 · 창 · 표 모두 J안 4판 값이에요.

## 2. 모든 화면은 일곱 칸 (cgg-j4 1.3 함수와 짝)

| 칸 | 무엇 | 공통 부품 |
|---|---|---|
| ① | 머리말 (남색 · 메뉴 배치 셋 · 사람 단추 ▾) | `.cgg-app/.cgg-hdr/.cgg-nav` + `CGG.layout` · `CGG.menu` · `CGG.badge` |
| ② | 묶음 › 화면 + 말하는 제목 + 설명 한 줄 + 오른쪽 버튼 | `CGG.head({crumb,title,desc,acts})` |
| ③ | 할 일 카드 3장 (홈만) | `CGG.todos` |
| ④ | 도구줄 (상태 탭 · 거르기 · 검색) | `CGG.table` 안에 들어 있음 |
| ⑤ | 숫자 카드 4개 | `CGG.kpis` |
| ⑥ | 표 (폰은 목록) | `CGG.table({cols,kinds,rows,…})` |
| ⑦ | 접힌 도움 카드 | `CGG.help(글)` |
| 창 | 확인 400 · 입력 560 · 자세히 520(오른쪽) · 폰은 아래에서 | `CGG.dialog({size,title,rows,body,ok,onOk})` |
| 알림 글 | 저장 · 복사 뒤 한 줄 | `CGG.toast(글)` |
| 체험 | 미리 써 보기 · 체험판 띠 · 자물쇠 · 3번 | `CGG.trial` |
| 폰 | 남색 윗줄 48 + 아래 탭바 56 | `CGG.tabbar` |

- 홈이 아닌 화면은 ③을 비우고, 표가 없는 화면(설정 등)은 ⑤⑥ 대신 카드 목록을 써요.
- 서버 부르는 코드와 계산은 **그대로 두고**, 그리는 부분만 공통 부품으로 바꿔요 (규칙: 기능 없애지 않기).

## 3. 모든 제품 공통 자리 (어느 제품이든 같은 자리에)

| 기능 | 자리 |
|---|---|
| 휴지통 | **사람 단추 ▾ 안 한 곳만** + 사람 단추 위 빨간 개수. 머리말 휴지통 버튼 · 설정 › 휴지통은 뺌 |
| 화면 설정 (밝기 · 글씨 · 메뉴 배치) | 사람 단추 ▾ › 화면 설정 (입력 창 560, `CGG.layout.chooser`) |
| 요금제 · 결제 (결제창 v2) | 사람 단추 ▾ › 요금제 → «이용요금» 입력 창. [결제]는 토스 v2 결제창. 대표만 보임 |
| 자동 결제 | 같은 «이용요금» 창 아래 칸. 꺼짐이 처음 값. [자동 결제 켜기] → 동의 확인 창(금액 · 결제일 · 끄는 법) |
| 환불 | **관리에서만** 해요. 제품 화면에는 «결제 · 환불 규정» 글 연결만 |
| 내 계정 | 사람 단추 ▾ › 마이페이지 (보기 전용). 계정 바꾸기 · 잠그기는 **관리 › 계정 › 번호로 계정 찾기** 한 곳 |
| 알림톡 | 손님에게 가는 알림은 «설정 › 알림»(제품별 자리는 각 장)에서 켜고 끔. 문안 관리는 관리 › 알림 › 알림톡 템플릿 |
| 공지사항 · 도움말 · 링크 복사 · 새로고침 | 머리말 (폰에서는 새로고침만, 나머지는 «전체» 안) |
| 미리 써 보기 | 같은 제품 화면 + `CGG.trial.init("preview")`. 따로 만든 가짜 화면 없음 |

## 4. 지금 판에서 고칠 곳 (모든 제품)
- 그림 문자(🎬 🔒 📢 등) → 선 아이콘. 
- 숫자 z-index 직접 쓰기 → `var(--z-…)` (탭바가 확인 창을 가리던 문제).
- 공통 부품 1.1 → **1.3**로 바꿔 끼우기 (`CGG.version`을 판 기록에).

# J안 완성 기준 — 홈페이지 (소개 시안 · 통합 입구 v5 · 가입 join_v3)

홈페이지는 **제품 화면이 아니라 소개 페이지**라서 일곱 칸 대신 아래 차례를 써요. 색 · 글꼴 · 버튼 · 창은 공통 부품 1.3 값 그대로예요 (`.cgg-btn` · `CGG.dialog` · `CGG.toast`).

## 페이지 차례
| # | 칸 | 모양 |
|---|---|---|
| 1 | 오픈 베타 띠 (넣은 안 / 뺀 안 — 대표님 고르실 것) | 남색 얇은 띠 한 줄 |
| 2 | 머리말 | 차곳간 · 미리 써 보기 · 요금제 · 회원가입 · 로그인 (폰은 ☰) |
| 3 | 첫 화면 | 말하는 제목 «입고부터 정산까지 …» · [가입 없이 미리 써 보기](파랑 하나) [요금제 보기] · 제품 카드 3장 |
| 4 | **미리 써 보기 `#try`** | 탭 워시 · 체크 · 딜러 → **실제 제품 화면 + `CGG.trial.init("preview")`** (연출: `디자인/02_미리써보기_연출_기준.md`). 옆 카드: 결제하면 열리는 기능(자물쇠 = 선 아이콘, 🔒 그림 문자 안 씀) |
| 5 | **요금제 `#price`** | 카드 3장 · «추천» 하나만 · 이름 → 한 달 금액 → 열리는 기능 → 버튼. 부가세 표시 · 환불 규정 연결 · 3단계(가입·로그인 → 결제 → 바로 사용) |
| 6 | 바닥글 · 사업자 정보 | 이용약관 · 개인정보처리방침 · 환불 규정 · 통신판매업 |

## 기능 자리
| 기능 | 자리 |
|---|---|
| 결제 (결제창 v2) | 요금제 [결제하기] → 로그인/가입 → **통합 입구가 `?buy=` 받아** 결제 창구로 (지금 v5는 못 받음 — 홈페이지·앱 방 할 일) |
| 자동 결제 | 첫 결제 창에서 «자동 결제로 등록» 고르기 (동의 확인 창 같이) |
| 결제 그만둠 | 다음 로그인 때 체험판 화면 + «결제 이어 하기» 띠 (`CGG.trial.band` 글만 바꿔 씀) |
| 가입 완료 | «회원가입이 완료되었습니다» + [로그인하러 가기] (가입 · 오류 안내는 표준형 «~습니다») |
| 환불 | 글 연결만 (실제 환불은 관리) |

## 지금 판에서 고칠 곳
1. 미리 써 보기 iframe 안 제품에 `CGG.trial` 띠 켜기 (체크 사본 대신 체크 새 판 + preview).  2. 그림 문자 🔒 → 선 아이콘.  3. 통합 입구 `?buy=` 처리, 제품 탭에 딜러 더하기 (홈페이지·앱 방).

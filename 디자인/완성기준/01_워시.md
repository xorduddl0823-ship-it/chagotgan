## 화면 목록 (메뉴 차례 그대로 — 규칙 3-4)
| 맨 위 메뉴 | 안쪽 작은 탭 | 화면 모양 |
|---|---|---|
| 홈 | — | ② 인사 + 말하는 제목 · ③ 할 일 3장 · ⑤ 숫자 4개 · 일정 달력 + 이번 달 입금 + 이번 달 일감 · ⑦ |
| 매출 | 매출 내역 | ② · ⑤ 올해 숫자 · 12달 막대 · ⑥ 월별/년별 표 (체크에서 옮긴 화면, 모양만 J안) |
| 일감 | 입출고 내역 · 출고 기록 | **대표 목록**. ② «작업 중인 차 N대, 출고 대기 N대» · ⑤ · ⑥ 상사명 · 차량번호 · 차종 · 작업 · 입고일 · 금액 · 상태 · 파란 버튼 «일감 등록» |
| 청구서 | 월별 청구서 | ② · ⑥ 청구처별 표 + **입금 기한** 열 · 확인 창 «청구처 · 건수 · 합계 금액» |
| 입출금 | 입·출금 · 받아야 할 금액 | ② · ⑤ · ⑥ (지금 화면 그대로. 체크 화면으로 옮기는 일은 서버 새 판 뒤) |
| 세금계산서 | — | ② · ⑥ · 파란 버튼 «선택 발급» |
| 자재 | — | ② · ⑥ 재고 표 |
| 설정 | 우리 사업장 · QR 코드 · 백업 · 기기 · 출고 지연 기준 · 거래처 · 직원 계정 · 작업 항목 · 단가표 · 배달 도착지 · 입금 자동 확인 · 알림 · 발송함 | 카드 목록 (표 없음) |
- 매니저 · 직원은 홈 · 일감 · 자재 · 설정만 (지금 규칙 그대로).
- **현장 화면**: 머리말 맨 앞 버튼 → 폰 모양(홈 · 입고 · 출고 · 오늘 · 날짜 검색). J안 4판 «현장» 값 그대로.
- 폰 아래 탭바: 홈 · 일감 · 입출금 · 계산서 · 전체.

## 기능 자리
| 기능 | 자리 |
|---|---|
| 입고 알림톡 (처음부터 켜짐) | 설정 › 알림 › «입고하면 딜러에게 알림톡 보내기» 스위치. 입고 완료 창의 «딜러에게 입고 알림톡 보내기»는 그대로 |
| 결제창 v2 · 자동 결제 | 사람 단추 ▾ › 요금제 → «이용요금» 창 (공통 3장) |
| 청구서 입금 기한 | 청구서 표의 열 + 청구서 만들기 입력 창의 칸 |
| 딜러 연락처 «딜러앱에 공개돼요» | 입고 입력 창(현장 · PC 모두) 칸 이름 옆 파란 알약 (기준서 2-8) |
| 휴지통 | 사람 단추 ▾ 한 곳 — **머리말 휴지통 버튼 · 설정 › 휴지통은 빼기** |
| 미리 써 보기 · 체험판 | `CGG.trial` 띠 + 분류표(잠금 14 · 3번 18 · 보기 13). **지금의 «🎬 시연 모드» 주황 띠는 `CGG.trial` 띠로 바꾸기** |

## 지금 판에서 고칠 곳
1. 휴지통 네 곳 → 사람 단추 한 곳.  2. 시연 모드 띠 → 체험 띠(그림 문자 없음).  3. 공통 부품 1.3으로, 본문을 `CGG.head/kpis/table/help/dialog`로.  4. 머리말 «✥ 배치»는 사람 단추 › 화면 설정 › 상단 버튼 위치로.

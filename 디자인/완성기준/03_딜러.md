# J안 완성 기준 — 딜러 (지금 판 d3.2 · 공통 부품 1.1 → 1.3)

## 화면 목록 (딜러앱 차례 그대로 + 홈)
| 메뉴 | 화면 모양 |
|---|---|
| 홈 | ② 인사 · ③ 할 일 3장(도착한 차 상품화 완료 · 오늘 출고 받을 준비 · 3일 넘은 차) · ⑤ 숫자 4개(가안 확정) · 최근 내 차 |
| 내 차 | **대표 목록**. 상태 탭 = 전체 · 입고 · 작업 중 · 출고 · 도착. ⑥ 지금 위치 · 차량번호 · 차종 · 작업 · 마지막 기록 · 들어간 금액 · 단계(4칸 막대). 파란 버튼 «선택한 차 상품화 완료». 이름 누르면 **자세히 창 520**(사진 · 상품화 진행 기록 · 금액 · 카히스토리 조회) |
| 알림 | ② · 거르기 알약(전체 · 입고·출고 · 도착 · 청구서 · 재검사) · 목록 |
| 청구서 | ② «결제할 청구서» · 업체별 카드(입금 전 / 기한 지남 / 입금 확인됨) · [계좌 복사] [금액 복사] [내역 보기]. **[한 번에 결제]는 토스 지급대행 계약 뒤** — 그 전에는 버튼을 숨기고 «곧 열려요» 한 줄 |
| 카히스토리 | ② · «곧 열려요» 카드 (지금 그대로) |
| 내 정보 | 카드 목록: 알림 받기(스위치 4개) · 화면 설정 · 번호 · 약관 · 로그아웃 · 동의 철회 |
- 폰 아래 탭바: 홈 · 내 차 · 알림 · 청구서 · 전체.  남색 윗줄의 «알림» 버튼(빨간 숫자)은 그대로.
- 단계 색: 입고 · 작업 중 · 출고 = 진행 중(파랑), 도착 = 확인 필요(주황), 상품화 완료 = 완료(초록) → `CGG.table({stateMap:{…}})`.

## 기능 자리
| 기능 | 자리 |
|---|---|
| 알림톡 받기 | 내 정보 › 알림 받기 스위치 (보내는 쪽은 워시 · 서버) |
| 청구서 · 한 번에 결제 | 청구서 화면 (위). 결제창 v2는 계약 뒤 같은 공통 결제 창 |
| 사람 단추 | 딜러는 «내 정보» 메뉴가 그 자리 (사람 단추 ▾ 대신). 휴지통 · 요금제 없음 |
| 미리 써 보기 | 지금 `?demo` → **`CGG.trial.init("preview")` 띠**를 함께 보여 주기 |
| 개인정보 · 차량 매칭 | 보안 방 검토 전까지 넣지 않음 |

## 지금 판에서 고칠 곳
1. 공통 부품 1.3, 내 차 표를 `CGG.table`로 (상태 칩 · 폰 목록 · 쪽이 자동으로 같아짐).  2. 확인 창 z-index 70 → `cgg-dialog`(90).  3. 청구서 [한 번에 결제] 회색 버튼 → 숨기고 «곧 열려요».

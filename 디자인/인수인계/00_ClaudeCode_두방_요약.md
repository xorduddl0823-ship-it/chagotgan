## 3. 정해진 것
- 화면 구성은 H안(데이터 보기) + I안(현황판)을 합친 **J안**
- 남색 틀, 메뉴 배치(가로·세로·아이콘)는 사용자가 고름 (워시 「마이페이지 › 화면 › 메뉴 배치」 기능 살림)
- 폰 화면은 은행·토스 앱 정도로 촘촘하게, 할 일은 넘기지 않고 한 화면에
- 화면 일곱 칸: ① 머리말 → ② 묶음 제목·설명 한 줄 → ③ 할 일 띠 → ④ 도구줄(43px) → ⑤ 숫자 칸 4개 → ⑥ 표 → ⑦ 접힌 도움 카드
- 메뉴: 맨 위 탭 8개 이하, 「☰ 전체 메뉴」, 안쪽 작은 탭
- 표 열 순서: ☐ → 이름 → 번호 → 내용 → 날짜 → 금액 → 상태 (너비 56/180/130/96/130/104)
- 창 3종: 확인 400 · 입력 560 · 자세히 520
- 문구: 해요체, 「돈」 대신 「금액」, 고등학생 수준. J안 4판에 문구 「전 → 후」 표 29줄 있음
- 탭 순서 고정, 체크 「정산 기록」은 이름·자리(3번째) 그대로
- 워시 「현장 화면」은 머리말 맨 앞 버튼
- 「알람」 → 「알람 소리」, 「관제센터」 → 「관리」
- 원본은 덮어쓰지 않고 새 이름으로 저장
- 배포 때 기준틀의 `DEV = true` 를 `false` 로

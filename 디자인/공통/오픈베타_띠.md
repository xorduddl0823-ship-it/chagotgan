# 오픈 베타 띠 — 하나로 정한 모양 (디자인 방, 2026-10-15)

> 요청서 07 «오픈 베타 표시». 붙이는 곳: **워시 · 체크 · 딜러 · 홈페이지 · 통합 입구** (관리에는 넣지 않음).
> 공통 부품 cgg-j4는 **1.5 동결 그대로**예요. 이 띠는 부품이 아니라 «붙이는 조각»이라 각 방이 아래를 그대로 복사해요.
> 바탕: 홈페이지 소개 시안 «넣은 안». 영어 «OPEN BETA»는 쓰지 않고 우리말 꼬리표로 바꿨어요 (규칙 4장).

## 1. 문구 (모든 곳 똑같이)
- 꼬리표: **오픈 베타**
- 본문: **차곳간은 지금 오픈 베타예요. 쓰시면서 불편한 점을 알려 주시면 바로 고쳐요.**
- 닫기 버튼은 없어요 (시험 기간 내내 보여요).

## 2. 자리
- 화면 **맨 위, 남색 머리말보다 위**. 스크롤하면 같이 올라가요 (붙어 있지 않음).
- **한 화면에 띠는 하나만**: 통합 입구 안(iframe)에서 열린 제품은 띠를 그리지 않아요. 통합 입구 껍데기가 하나만 그려요. 아래 3번의 한 줄이 그걸 알아서 해요.
- 체험판 · 미리 써 보기 띠(`CGG.trial`)와 함께 있어도 돼요. 오픈 베타 띠가 맨 위, 체험 띠는 본문 안이에요.

## 3. 붙이는 조각 (그대로 복사)
**CSS** — 제품 `<style>` 맨 끝 (cgg-j4 CSS 다음):
```css
/* 오픈 베타 띠 (디자인 방 2026-10-15) */
:root{--beta-bg:#0d2440;--beta-ink:#e8f0fb}
@media (prefers-color-scheme:dark){:root:not([data-theme="light"]){--beta-bg:#1d3a5f}}
:root[data-theme="dark"]{--beta-bg:#1d3a5f}
.cgg-beta{background:var(--beta-bg);color:var(--beta-ink);font-size:13.5px;line-height:1.5;word-break:keep-all}
.cgg-beta .in{display:flex;gap:10px;align-items:center;justify-content:center;flex-wrap:wrap;text-align:center;
  padding-block:8px;padding-left:max(16px,env(safe-area-inset-left,0px));padding-right:max(16px,env(safe-area-inset-right,0px))}
.cgg-beta b{background:var(--beta-ink);color:var(--beta-bg);border-radius:6px;padding:1px 8px;font-size:12px;font-weight:800;flex:none}
.cgg-beta[hidden]{display:none}
@media (max-width:600px){.cgg-beta{font-size:12.5px}.cgg-beta .in{display:block;padding-block:6px}.cgg-beta b{margin-right:6px}}
```
**HTML** — `<body>` 바로 안, 맨 처음:
```html
<div class="cgg-beta" id="cggBeta" role="note"><div class="in"><b>오픈 베타</b><span>차곳간은 지금 오픈 베타예요. 쓰시면서 불편한 점을 알려 주시면 바로 고쳐요.</span></div></div>
```
**JS** — 스크립트 맨 앞 (통합 입구 안에서 열리면 숨김):
```js
try{ if(window.top!==window.self){ document.getElementById("cggBeta").hidden=true; } }catch(e){ document.getElementById("cggBeta").hidden=true; }
```
- 통합 입구 껍데기는 이 JS 없이 HTML · CSS만 붙여요 (늘 보임).
- 홈페이지 소개 시안의 «넣은 안 / 뺀 안» 고르기와 `.beta` 띠는 이 조각으로 바꿔요 (문구가 같아져요).
- 폰에서 머리말이 위에 붙는(sticky) 제품은 띠 높이만큼 내려가지 않아요 — 띠는 스크롤하면 사라지고 머리말만 남아요. 그대로 두면 돼요.

- 통합 입구에서 제품을 열었을 때 띠가 **하나만** 보이는지.

## 세로 · 아이콘 배치에서 (2026-10-18, cgg-j4 1.8 보강)
- 넓은 화면에서 세로 · 아이콘 배치를 고르면 머리말이 화면에 붙어 있어요. 그래서 띠도 맨 위에 붙이고(`html.cgg-lay-fixed .cgg-beta{position:fixed}`), 머리말 · 윗줄 · 본문을 띠 높이(`--beta-h`)만큼 내려요.
- 이 일은 **공통 부품 1.8이 해요**(`CGG.layout`이 띠 높이를 재요). 제품은 띠를 지금처럼 `.cgg-app` 바로 위에 두기만 하면 돼요. 띠 id는 `cggBeta`, class는 `cgg-beta` 그대로 써요.
- 가로 배치와 폰은 그대로예요. 띠가 글 흐름 맨 위에 있고 머리말이 그 아래에 붙어요.

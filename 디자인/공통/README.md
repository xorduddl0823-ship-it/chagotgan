# 디자인/공통 — J안 4판 공통 부품 (cgg-j4 1.0)

모든 제품(워시 · 체크 · 딜러 · 관리)이 **글자 하나 바꾸지 않고 똑같이** 쓰는 부품이에요. 체크 방 요청(2026-10-15)으로 만들었어요.

| 파일 | 무엇 |
|---|---|
| `cgg-j4.css` | ① 메뉴 배치 셋(가로 · 세로 · 아이콘) ② 폰 아래 탭바 ③ 홈 할 일 카드 3장 + 한국어 낱말 단위 줄바꿈 + 색(밝은 · 어두운 화면) |
| `cgg-j4.js` | `CGG.layout`(배치 저장 · 바꾸기 · 고르기 칸) · `CGG.tabbar`(아래 탭바) · `CGG.todos`(할 일 카드) · `CGG.ic`(선 아이콘) |
| `예시.html` | 체크 메뉴로 붙여 본 예시. 이 파일을 열어 보면 붙이는 모양을 바로 볼 수 있어요 |

바탕은 관리 v4.0의 `관리/v4재료/j4.css · j4.js`예요. 값(크기 · 색 · 여백)은 그대로 두고, 관리에만 있는 이름(`#app` `#nav` `TAB` `render`)에 묶이지 않게 바꿨어요.

## 제품에 붙이는 법 (각 제품 방이 자기 파일에서)
1. `cgg-j4.css` 내용을 `<style>` **맨 마지막**에, `cgg-j4.js` 내용을 `<script>` 맨 끝에 넣어요. 바깥 파일로 빼지 않아요.
2. 원래 id · class는 **그대로 두고**, 아래 class만 더해요. JS가 쓰는 이름은 바꾸지 않아요.
   - 바깥 상자 `cgg-app` · 머리말 `cgg-hdr` (안: `cgg-top` > `cgg-brand` · `cgg-biz` · `cgg-right`)
   - 큰 메뉴 `cgg-nav`: 버튼마다 `<svg class="ic">` + `<span class="lbl">`, 고른 버튼은 `aria-selected="true"`
   - 안쪽 작은 탭 `cgg-sub` (있을 때는 바깥 상자에 `hasSub`) · 본문 `cgg-main`
   - 폰에서 숨길 머리말 버튼은 `cgg-wide`
   - 맨 아래 `<nav class="cgg-tbar"></nav>`, 홈의 할 일 자리 `<div class="cgg-acts"></div>`
3. 스크립트에서 세 줄을 불러요.
   ```js
   CGG.layout.init(바깥상자, "cgg_check_layout");          // 저장 이름은 제품마다
   CGG.tabbar(탭바, [{key,icon,label} × 5], 지금key, function(key){ 화면 이동 });
   CGG.todos(할일자리, [{tone,icon,title,sub} × 3], function(i){ 그 화면으로 });
   ```
   화면 설정 창 안에서는 `CGG.layout.chooser(상자, 닫기함수)`로 「가로 · 세로 · 아이콘」 고르기 칸을 그려요.

## 규칙
- 폰(가로 600 이하)은 배치와 상관없이 **남색 윗줄 48 + 아래 탭바 56**이에요. 세로 · 아이콘 배치는 넓은 화면(1000 이상)에서만 바뀌어요.
- 아래 탭바는 5칸이에요. 홈 + 그 제품의 주요 메뉴 3개 + 전체.
- 할 일 카드는 3장이에요. 색은 run(파랑 · 진행 중) · chk(주황 · 확인 필요) · stop(빨강 · 보류)만 써요.
- 이 부품을 고치는 것은 **디자인 방만** 해요. 바꿀 것이 있으면 요청서를 보내 주세요.

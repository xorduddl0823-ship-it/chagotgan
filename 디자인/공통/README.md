바탕은 관리 v4.0의 `관리/v4재료/j4.css · j4.js`예요. 값(크기 · 색 · 여백)은 그대로 두고, 관리에만 있는 이름(`#app` `#nav` `TAB` `render`)에 묶이지 않게 바꿨어요.

## 제품에 붙이는 법 (각 제품 방이 자기 파일에서)
1. 넣는 위치 (공통 규칙, 1.1):
   - `cgg-j4.css` 내용은 제품 `<style>`의 **맨 마지막**에 넣어요. 앞의 값을 덮어야 해서예요.
   - `cgg-j4.js` 내용은 제품 스크립트보다 **먼저** 넣어요. 따로 `<script>` 하나를 두면 돼요. 제품이 처음 열릴 때 바로 `CGG`를 쓰기 때문이에요(워시 v113에서 확인).
   - 둘 다 바깥 파일로 빼지 않고 내용을 그대로 붙여요. 붙인 판 번호(`CGG.version`)를 제품 판 기록에 적어 주세요.
2. 원래 id · class는 **그대로 두고**, 아래 class만 더해요. JS가 쓰는 이름은 바꾸지 않아요.
   - 바깥 상자 `cgg-app` · 머리말 `cgg-hdr` (안: `cgg-top` > `cgg-brand` · `cgg-biz` · `cgg-right`)
   - 큰 메뉴 `cgg-nav`: 버튼마다 `<svg class="ic">` + `<span class="lbl">`, 고른 버튼은 `aria-selected="true"`
   - 안쪽 작은 탭 `cgg-sub` (있을 때는 바깥 상자에 `hasSub`) · 본문 `cgg-main`
   - 폰에서 숨길 머리말 버튼은 `cgg-wide`
   - 맨 아래 `<nav class="cgg-tbar"></nav>`, 홈의 할 일 자리 `<div class="cgg-acts"></div>`
3. 스크립트에서 세 줄을 불러요.
   ```js
   CGG.layout.init(바깥상자, "cgg_check_layout");          // 저장 이름은 제품마다
   CGG.tabbar(탭바, [{key,icon,label} × 5], 지금key, function(key){ 화면 이동 });
   CGG.todos(할일자리, [{tone,icon,title,sub} × 3], function(i){ 그 화면으로 });
   ```
   사람 단추 ▾ (1.1, 관리 방 요청): `CGG.menu(사람단추, {name,role}, [항목들 또는 "-"], function(key){…})`, 휴지통 건수는 `CGG.badge(사람단추, 건수)`.
   항목 차례는 마이페이지 · 요금제 · 휴지통 · ― · 화면 설정 · ― · 로그아웃이에요 (관리는 요금제 · 휴지통 없음).
   화면 설정 창 안에서는 `CGG.layout.chooser(상자, 닫기함수)`로 「가로 · 세로 · 아이콘」 고르기 칸을 그려요.

## 층 순서 (1.1 — 딜러 방 알림으로 정함)
화면 위에 겹치는 것들의 순서예요. 숫자는 `cgg-j4.css` 맨 위 `:root`에 이름으로 들어 있어요. **제품 파일에 숫자를 직접 쓰지 말고 이름만 써요.**

| 층 | 이름 | 값 |
|---|---|---|
| 안쪽 작은 탭 (세로 · 아이콘 배치) | `--z-sub` | 28 |
| 머리말 | `--z-hdr` | 30 |
| 폰 아래 탭바 | `--z-tbar` | 60 |
| 사람 단추 ▾ 펼침 | `--z-drop` | 70 |
| 창 (어두운 막 + 확인 · 입력 · 자세히 창) | `--z-dialog` | 90 |
| 알림 글 (토스트) | `--z-toast` | 100 |

- 제품의 창 상자와 어두운 막에는 `class="cgg-dialog"`를 더하거나, 제품 CSS에서 `z-index:var(--z-dialog)`로 맞춰요. 딜러 방이 따로 70으로 올린 값도 이걸로 바꿔 주세요.
- 알림 글(토스트)은 `cgg-toast`이고 맨 위에 와요.

## 규칙
- 폰(가로 600 이하)은 배치와 상관없이 **남색 윗줄 48 + 아래 탭바 56**이에요. 세로 · 아이콘 배치는 넓은 화면(1000 이상)에서만 바뀌어요.
- 아래 탭바는 5칸이에요. 홈 + 그 제품의 주요 메뉴 3개 + 전체.
- 할 일 카드는 3장이에요. 색은 run(파랑 · 진행 중) · chk(주황 · 확인 필요) · stop(빨강 · 보류)만 써요.
- 이 부품을 고치는 것은 **디자인 방만** 해요. 바꿀 것이 있으면 요청서를 보내 주세요.

## 1.5 쓰는 법 — 보안 규칙 두 가지 (보안 방 검토, `보안/검사기록/2026-10-15_공통부품_cgg-j4_1.5.md`)
1. **`render(row,k)`가 돌려주는 HTML은 그대로 화면에 들어가요.** 손님 · 업체가 적은 글(상호, 메모, 차종 등)을 넣을 때는 **반드시 `CGG.esc(값)`으로 감싸요.** 링크 주소도 우리가 만든 주소만 넣어요.
2. **`state`의 고른 줄은 «줄 번호»로 기억해요.** 자료를 새로 받아 줄 차례가 바뀌거나 줄이 늘고 줄면, 고른 줄이 다른 줄로 옮겨질 수 있어요. 그래서 **자료를 새로 받을 때는 `state.sel={}`로 고른 줄을 비워요.** 지우기 · 발급 · 환불처럼 되돌리기 어려운 일은 확인 창에 **고른 줄의 이름 · 번호를 다시 보여 주고** 그것으로 서버를 불러요.

## 1.6 초안 (2026-10-16 · **보안 통과** 9fd6c7a · 제품 적용은 시험 뒤)
> 보안 방이 제품에 넣을 때 볼 것: ① `render`로 HTML을 돌려주던 곳을 `{html}`로 바꿀 때, 안에 든 사용자 글이 `CGG.esc` 되는지 ② `rowId`는 글자나 숫자만 돌려주기 ③ id를 서버에 보낼 때는 서버가 다시 확인하기(권한 · 내 자료인지)
파일: `cgg-j4-1.6.css` · `cgg-j4-1.6.js` · 예시 `예시_1.6.html`. **1.5 파일은 그대로**예요(시험판이 쓰는 중).

### 제품이 1.5 → 1.6으로 바꿀 때 할 일 (세 가지)
1. 머리말 사업장 칸 class를 **`cgg-biz` → `cgg-hdr-biz`**로 바꿔요. 1.6 CSS는 `.cgg-hdr` 안의 `.cgg-hdr-biz`만 꾸며요. 그래서 법정 사업자 정보 칸에 옛 이름 `cgg-biz`가 있어도 폰에서 숨지 않아요.
2. **`render`가 HTML을 돌려주던 곳은 `{html:"…"}`로 감싸요.** 1.6에서는 그냥 글자를 돌려주면 **늘 esc**(화면에 글자 그대로)돼요. `{html}` 안에 손님 · 업체가 적은 글을 넣을 때는 1.5처럼 `CGG.esc`로 감싸요.
3. (권장) 표에 **`rowId:function(row){ return 줄 id; }`**를 넣어요. 그러면 다음처럼 바뀌어요.
   - 자료를 다시 불러와도 고른 줄이 그대로 남아요.
   - 없어진 줄은 고른 목록에서 저절로 빠져요. 1.5 규칙의 `state.sel={}`가 필요 없어요.
   - `onSelect` · `onBulk`에는 **줄 번호 대신 id 목록**이 와요.
   - `rowId`를 안 넣으면 1.5처럼 줄 번호로 동작해요.

### 저절로 좋아지는 것 (제품이 할 일 없음)
- 폰 목록 금액 칸 두 줄: `{html:'<span class="a">합계</span><span class="b">공급가 · 세액</span>'}` → 표와 폰 목록 모두 두 줄(체크-1)
- `.cgg-app` 밖 카드(홈페이지 기능 카드 · 체험 띠 · 창): 아이콘 크기가 정해지고, «결제 후 사용»이 한 줄로 보여요(홈-1)
- 폰 목록 이름 옆 둘째 값(번호 · 날짜)이 중간에서 끊기지 않아요(관리-2)
- 창을 열 때 화면이 아래로 밀리지 않고 제목과 X가 보여요(공통-1, 짧은 폰)
- 숫자 카드 오른쪽 빈자리는 작은 그래프가 있을 때만 생겨요(공통-2)
- 선 아이콘 `refresh`(새로고침) · `alert`(경고)가 생겼어요(체크 방 요청)
- 예시의 일괄 버튼 글을 말 대조표대로 «선택한 줄 지우기»로 고쳤어요

> 조사한 판: 워시 v122 · 체크 v38 · 딜러 d3.5 · 관리 v4.5 · 홈페이지 소개 시안 · 통합 입구 v7b · 가입 join_v3
> **«정한 말» 칸만 쓰면 돼요.** 오른쪽 «지금 쓰는 다른 말»을 찾아 바꿔 주세요. 줄 번호는 위 판 기준이에요(대략).
> 알림톡 방이 보내는 «고칠 말 목록»과 겹치면 **이 표가 기준**이에요(알림톡 방과 맞춰 둠).

## 0. 말투 규칙 (먼저)
| 어디 | 말투 | 예 |
|---|---|---|
| **가입 · 로그인 · 오류 · 결제 안내** | 표준형 «~습니다» | 회원가입이 완료되었습니다. / 다시 로그인해 주세요. |
| **그 밖의 모든 화면** (버튼 뒤 알림 글 · 빈 화면 · 설명 · 확인 창) | 해요체 «~요» | 저장했어요. / 아직 기록이 없어요. |
- 워시(«~습니다» 181 : «~요» 124)와 체크(18 : 12)가 섞여 있어요 → 위 규칙대로 해요체로 맞춰요.

## 3. 오류 글 (가장 중요)
| 경우 | **정한 말** |
|---|---|
| 하려던 일이 안 됐을 때 | **○○하지 못했어요. 다시 시도해 주세요.** (한 줄, 사과 없이) |
| 로그인 · 가입 · 결제 중 | **○○하지 못했습니다. 잠시 후 다시 시도해 주세요.** (표준형) |
| 인터넷 · 서버 연결 | **연결이 잠시 끊겼어요. 다시 시도해 주세요.** |
| 권한 없음 | **이 화면은 대표만 볼 수 있어요.** (누가 볼 수 있는지 말하기) |
- **«실패» 한 단어로 끝내지 않아요.** 워시 «저장 실패:»(L2993) «삭제 실패:»(L7600) «연결 실패:»(L10738 · L11265) «발송 실패»(L11160) «보내기 실패»(L6236) «추가 실패:»(L7871) · 체크 «보내기 실패»(L5274) · 관리 «읽기 실패 —»(L3459) «곳 실패»(L5256) → 위 표대로.
- **같은 뜻 두 말투**: 워시 «보내지 못했어요»(L10515) / «보내지 못했습니다»(L11273) → «보내지 못했어요».
- **«문제가 생겼습니다»**(워시 L2868) · **«오류가 발생했습니다»**(체크 L2150 · 통합 입구 · 가입) → 화면은 «○○하지 못했어요. 다시 시도해 주세요.», 로그인 · 가입은 표준형.

## 5. 화면에 보이면 안 되는 것
- **영어 · 코드 글자**: 서버 · 브라우저 오류를 그대로 보여 주는 곳 — `e.message`(«Failed to fetch» «TypeError» 등)
  워시 L7090 · 8843 · 9802 · 10515 · 11265 · 14306–14354 / 딜러 L1428 · 1479 · 1485 · 1494 · 1527 / 관리 L3397–3972(약 12곳) / 체크 L2150 / 통합 입구 L148 · 155
  → `e.message` 대신 3장 «정한 말». 서버가 보내는 쉬운 글(`__err`)이 있으면 그것만 보여 줘요(서버 방이 고치는 중).
- 홈페이지 «OPEN BETA»(L491) → 오픈 베타 띠 조각으로 바꾸기 (`디자인/공통/오픈베타_띠.md`).
- **그림 문자 · 기호**: ★ ☆(워시 L2420 · 4565 · 5373) · ✓(워시 L5438 «✓ 번호를 읽었습니다» → «번호를 읽었어요») · ⚠(체크 L3507 · 3899 · 4162) · 📝(관리 L3190) · ↻(체크 L1641) → **선 아이콘**(`CGG.ic`)이나 글로. 닫기 «✕»는 선 아이콘 x로.

## 6. 끝나면
각 방은 바꾼 말 개수를 총괄 방 3줄 보고의 «고친 말 개수»에 넣어요. 약관 글은 손대지 않아요(규칙 3-8).

# 차곳간 E안 UI 입히기 — 작업 지시서 (체크 · 워시 · 관리)

## 1. 할 일
차곳간 체크 · 워시 · 관리(예전 이름: 관제센터) 세 제품의 화면 **모양만** E안으로 바꾼다.
기능, 계산, 데이터, 문구(워딩)는 바꾸지 않는다.

같이 주는 파일
- `02_차곳간_공통_E안_스타일.css` : 색 · 크기 변수와 공통 부품 스타일. 정답 기준.
- `03_차곳간_공통_E안_기준시안.html` : E안을 입힌 «워시 · 일감» 화면 예시. 브라우저로 열어 모양을 확인할 것.

## 2. E안이란
- 화면 바탕은 회색(#F2F4F6), 그 위에 흰 카드. 카드는 선 없이 둥글게(18px).
- 숫자 칸 4개는 크고 굵게(30px), 가운데 정렬, 자릿수 맞춤.
- 표만 촘촘하게: 줄 높이 44px, 머리줄 연회색(#F6F8FA), 칸 사이 아주 옅은 세로선.
- 맨 위 머리말 한 줄만 남색(#0B2545). 탭부터 아래는 흰색 · 회색.
- 차곳간 색: 파랑 #1668C4 · 남색 #0B2545 · 하늘 #8FC9F2. 글꼴 Noto Sans KR.

## 3. 꼭 지킬 규격 (이미 정해진 것)
- 머리말 세 구역: 왼쪽 CI + 차곳간 + «제품 설명 · 제품 v번호 · 날짜» (세 제품 모두 같은 너비 300px) → 그 바로 오른쪽 업체 이름 + 사업자번호 · 대표 → 오른쪽 끝 공지 · 도움말 · 주소 · 새로고침 · 30초마다 · 연결됨 · 사람 단추.
  - 업체 이름을 가운데에 두지 않는다.
  - «배치»는 머리말에서 빼서 안쪽으로. 휴지통 · 로그아웃은 사람 단추 안으로.
  - 사람 단추에는 이름 아래 «마이페이지 · 휴지통 ▾»처럼 안에 뭐가 있는지 보이게.
- 탭 순서(돈 도는 순서): 홈 → 일감 → 기록 → 월별 청구서 → 입·출금 내역 → 세금계산서 → (제품 전용 하나) → 설정 ▸
- 모든 화면 일곱 칸, 순서 고정: 마이페이지(요금제는 팝업으로) → 제목 + 설명 한 줄 → 할 일 띠 + [해결하러 가기] → 도구줄 → 숫자 칸 4개 → 표 → 접힌 도움 카드
- 도구줄 칸 · 단추 높이 43px (폰 42px).
- 상태 색: 파랑 = 하는 중 · 초록 = 끝남 · 주황 = 확인 필요 · 빨강 = 막힘.
- 알림 색: 입고 파랑 · 출고 초록 · 입금 남색.
- 홈 화면은 지금 워시 · 체크가 쓰는 레이아웃(일정 달력 등)을 그대로 두고 색 · 모양만 E안으로. 달력 카드와 «이번 달 수금» 카드는 줄 · 열이 맞아야 한다.
- 모든 표: 오름 · 내림차순 정렬, 검색, 보기 개수(5/10/20/30/50), 큰 체크칸(24px), 이름 칸(상사명 · 딜러 등) 고정.
- 날짜 고르는 칸은 달력(input type=date 등). 긴 선택 목록 쓰지 않기.
- 확인 창은 브라우저 기본 alert/confirm 대신 화면 가운데 팝업(`.cg-modal`). 발급 · 발송처럼 되돌리기 어려운 일은 «누구에게 · 총 몇 건 · 총 얼마»를 보여 주고 확인받기.
- 안내 문구는 짧게 한두 줄.

## 4. 작업 방법
1. 세 제품 HTML 파일을 먼저 읽고, 지금 쓰는 색 · 클래스를 정리한다.
2. `02_...스타일.css` 내용을 각 HTML의 `<style>` 맨 위에 넣는다. (HTML 한 파일로 올리므로 별도 css 파일로 빼지 않는다.)
3. 원래 쓰던 색 값은 변수(`var(--cg-...)`)로 바꾼다. 같은 역할이면 `cg-` 클래스를 **추가**한다.
4. JavaScript가 쓰는 id · class 이름은 바꾸거나 지우지 않는다. 스크립트 로직은 손대지 않는다.
5. 순서: **워시 먼저** → 확인 → 체크 → 관리. (워시가 기준)
6. 끝나면 각 파일을 브라우저로 열어 가로 1280px · 390px 두 크기에서 확인하고, 콘솔 오류가 없는지 본다.

## 5. 결과물
- HTML 파일 세 개. 파일 이름에 제품을 넣는다: `차곳간_워시_E안.html`, `차곳간_체크_E안.html`, `차곳간_관리_E안.html`
- 원본 파일은 덮어쓰지 말고 새 이름으로 저장.
- 마지막에 바꾼 내용을 **쉬운 한국어로 짧게** 알려 줄 것(전문 용어 빼고, 제품별 3~5줄). 바꾸지 못한 곳이 있으면 어디인지 적을 것.

뼈대가 같다는 증거

세 제품 화면은 아래 함수 한 개가 그립니다. 제품마다 다른 건 APP.wash · APP.check · APP.admin 설정 덩어리뿐입니다.

function draw(){                      // 세 제품 공통 — 글자 하나까지 같음
  var A = APP[app], N = NAV[app];     // ← 여기서만 제품이 갈림
  mock.innerHTML =
      cgHead(A)                       // ① 머리말 (남색 한 줄)
    + cgTabs(N, cur)                  // ② 탭 (목록만 제품마다 다름)
    + '<div class="cg-body">'
    +   cgTitle(P)                    // ③ 제목 + 설명 한 줄
    +   cgSubTabs(subs, sub)          //    └ 안쪽 작은 탭
    +   cgTodo(P)                     // ④ 할 일 띠 + 해결하러 가기
    +   cgTool(P)                     // ⑤ 도구줄 (칸·단추 43px)
    +   cgNums(P)                     // ⑥ 숫자 칸 4개
    +   cgTable(P)                    // ⑦ 표 (정렬·찾기·쪽넘김)
    +   cgHelp(P)                     // ⑧ 접힌 도움 카드
    + '</div>';
}

표 규격도 한 벌입니다 — 줄 높이 44px · 머리줄 #F6F8FA · 체크칸 24px · 이름 칸 틀고정 · 오름/내림 정렬 · 찾기 · 보기 개수 5/10/20/30/50 · 처음 · 이전 · N/M · 다음 · 맨뒤.

탭 지도

세 제품은 하는 일이 달라서 탭 이름 · 개수는 제품마다 다릅니다. 대신 자리 차례(홈 → 일감 → 기록 → 월별 청구서 → 입·출금 내역 → 세금계산서 → 제품 전용 → 설정 ▸)와 모양 · 코드는 같습니다. ↘ 안으로 표시는 원래 맨 위 탭이었다가 안쪽 작은 탭으로 들어간 것입니다. 아래 «빠진 탭» 수는 원본 소스의 탭 목록과 자동으로 맞춰 본 결과입니다.

정해 주신 것 · 제가 정한 것

✔ 체크 2번 자리는 «정산 기록» 그대로 둡니다.
✔ 탭은 제품마다 다르게, 디자인 · 파일 뼈대는 같게 갑니다.

추천안에서 제가 자리를 정한 곳 — 마음에 안 드시면 말씀만 주세요. 설정 덩어리 한 줄만 고치면 됩니다.
· 체크 보험료 대조 → «입·출금 내역» 안 — 체크 소스에 이미 «보험료 미납 대조는 입금 내역 안쪽 작은 탭으로 들어갑니다»라는 주석이 있어 그대로 따랐습니다.
· 체크 재검사 알림 → «정산 기록» 안 — 재검사할 차는 검사 기록에서 나오므로 같이 두었습니다.
· 워시 출고 기록 → «일감» 안, 자재 → «현장 화면» 안 — 자재는 현장 폰에서 쓴 양을 적는 기능과 이어져 있어서입니다.
· 워시 3번 자리 = «매출 내역» — 체크와 같은 자리에 같은 이름이 오도록 맞췄습니다.
· 관리 — 운영 상태 → 홈 안, 잠금·차단 → 업체 안, 가입 코드 → 계정 안, 요금제·결제·충전·카드 결제 → 받는 돈, 정산·유지비 → 내는 돈, 공지사항·기한 안내 문자 → 알림, 보안·내 계정 → 설정 ▸.
· 휴지통 — E안대로 사람 단추 안에 넣고, 체크 · 워시 «설정 ▸» 안에 있던 휴지통도 그대로 둡니다.

이 시안에서 확인하실 것

① 머리말 세 구역 — CI+차곳간(300px 고정) · 업체 이름 · 오른쪽 단추들. 업체 이름이 가운데에 오지 않습니다.
② 사람 단추 안에 «마이페이지 · 휴지통 ▾» 가 보입니다. 배치 · 로그아웃 · 화면(밝기)도 그 안으로 들어갑니다.
③ 화면 일곱 칸 차례가 세 제품 모두 같습니다.
④ «선택 발급»을 눌러 보세요 — 되돌리기 어려운 일은 가운데 팝업으로 «누구에게 · 총 몇 건 · 총 얼마»를 먼저 보여 줍니다.
⑤ 홈 화면은 지금 쓰는 달력 배치를 그대로 두고 색 · 모양만 E안으로 입혔습니다. 달력 카드 아래 끝과 오른쪽 마지막 카드 아래 끝이 맞습니다.

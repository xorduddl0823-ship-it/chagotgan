## 체크 (v41 · v42 둘 다)

### 체크-1. 세금계산서 › 발급 대상 › 폰 목록 오른쪽 금액이 붙어 보여요 — 높음
- **화면**: 계산서 탭(세금계산서) › «발급 대상» 표가 폰에서 목록으로 바뀐 부분
- **위치**: 각 줄 오른쪽 금액. `418,000380,000 · 38,000` 처럼 **합계와 공급가액이 한 줄에 붙어** 41만 8천이 아니라 4억처럼 읽혀요.
- **까닭**: 표 칸에서는 `.cgg-table td>.a/.b{display:block}`로 두 줄이 되는데, 폰 목록(`.cgg-mrow`)에는 이 규칙이 없어요.
- **고칠 법** (체크 맨 끝 `<style>`에 한 줄):
  ```css
  .cgg-mrow .r b .a,.cgg-mrow .r b .b{display:block;text-align:right}
  .cgg-mrow .r b .b{font-size:11.5px;font-weight:600;color:var(--muted)}
  ```
  → 결과: 윗줄 `418,000` / 아랫줄 작은 회색 `380,000 · 38,000` (넣어 보고 확인함)

### 체크-2. 같은 목록, 이름 아래 줄에 상호와 사업자번호가 붙어요 — 높음
- **화면**: 위와 같은 곳
- **위치**: 이름 아래 작은 글 `하늘모터스000-00-00001`
- **까닭**: 폰 목록을 만들 때 `tbPlain()`(L2753)이 칸 안 글자만 뽑으면서 `.a`(상호)와 `.b`(번호) 사이에 띄어쓰기가 없어져요.
- **고칠 법** (`tbPlain` 안, `textContent` 읽기 바로 앞에 한 줄):
  ```js
  t.content.querySelectorAll(".b").forEach(function(b){ b.before(" · "); });
  ```
  → 결과: `하늘모터스 · 000-00-00001` (넣어 보고 확인함). 다른 표의 두 줄 칸도 함께 바르게 돼요.

> 참고(깨짐 아님): 같은 화면 숫자 카드가 5개라 폰에서 마지막 한 장이 혼자 한 줄을 차지해요. J안 기준은 4개예요. 시험 뒤에 정해도 돼요.

## 관리 (v4.6 · v4.7)

### 관리-1. 홈 › 달력 칸 안 금액이 세로로 쪼개져요 — 보통
- **화면**: 홈 › 이번 달 달력 (폭 360 · 390 둘 다)
- **위치**: 20일 칸 `35,00 / 0원` 이 세 줄로 쪼개지고 칸이 길게 늘어나요. 16일(오늘) 칸의 «오늘» 표시도 잘려요.
- **까닭**: 폰에서도 칸 글자 13.5px · 칸 최소 높이 78px 그대로예요. 체크는 이미 폰 달력 규칙이 있어요(체크 L7509–7512).
- **고칠 법** (관리 맨 끝 `<style>`, 체크와 같은 값):
  ```css
  @media (max-width:600px){
    .cal{grid-template-columns:repeat(7,minmax(0,1fr));gap:3px}
    .cal .d{min-width:0;min-height:58px;padding:4px 3px;overflow:hidden}
    .cal .amt{font-size:10.5px;overflow:hidden;text-overflow:ellipsis;white-space:nowrap}
    .cal .todaytag{font-size:9.5px;white-space:nowrap}
  }
  ```
  → 결과: 쪼개짐 없음, 칸 높이 고름. 다만 좁은 칸이라 `35,0…`로 줄여 보여요.
  **추천**: 폰에서만 금액을 «3.5만»처럼 만 단위로 쓰면 줄임표 없이 다 보여요(달력 아래 합계 줄에 정확한 금액이 이미 있어요).

### 관리-2. 결제 내역 › 폰 목록 이름 옆 날짜가 가운데서 끊겨요 — 낮음
- **화면**: 받는 금액 › 결제 내역 (폰 목록)
- **위치**: `새빛 성능장 ← 새빛 성능검사소 10-` / `13 15:02` — 날짜 «10-13»이 두 줄로 나뉘어요.
- **고칠 법** (관리 맨 끝 `<style>`):
  ```css
  .cgg-mrow .t b span{white-space:nowrap}
  ```
  → 날짜가 통째로 다음 줄로 내려가요.

## 딜러 방이 찾은 것 (d3.6 · d3.7에서 이미 고침) — 원인이 공통 부품이라 다른 제품도 확인
### 공통-1. 짧은 폰(높이 약 700px 이하, 예: 360×640)에서 «자세히» 창이 아래로 내려간 채 열려요
- 제목과 X가 가려져요. **까닭**: `CGG.dialog`가 열릴 때 아래 버튼에 `focus()`를 주면서 창 안이 아래로 스크롤돼요(cgg-j4.js L242).
- **제품 쪽 고칠 법**: 창을 연 바로 뒤에 `var d=document.querySelector(".cgg-dlg"); if(d) d.scrollTop=0;` (딜러가 이렇게 고침)
- 워시 · 체크 · 관리도 «자세히» 창 내용이 길면 똑같이 생길 수 있어요 → 폭 360 · 높이 640으로 한 번 열어 보기.
### 공통-2. 숫자 카드 이름이 작은 그래프가 없어도 두 줄로 꺾여요
- 360px에서 «상품화 기다리는 차»가 두 줄, 320px에서는 네 장 모두 꺾임. **까닭**: `.cgg-kpi small`의 오른쪽 빈자리(PC 80px · 폰 46px)가 그래프 자리인데, 그래프가 없어도 남아 있어요.
- **제품 쪽 고칠 법**: 그래프를 안 쓰는 카드에 `.cgg-kpi small{padding-right:0}` (그래프를 쓰면 그대로)

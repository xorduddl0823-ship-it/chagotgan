## 홈 차례 (두 제품 같음 — `CGG.home`)
1. 화면 머리: «홈 · 날짜» → **한 줄 요약 제목**(숫자는 파란 글자) → «오늘 … 기준»
2. (있으면) 알림 띠 — 예: 샘플 자료 지우기, 체험판 띠
3. **자주 쓰는 기능**(바로가기, 메뉴 찾기 D)
4. **오늘 할 일** 3장 + 위 오른쪽 «할 일 N건 모두 보기 ›»
5. **숫자 칸 4개** — 모두 작은 그래프 + 비교 줄
6. 왼쪽 **일정 달력** | 오른쪽 **이번 달 입금**(큰 금액 · 막대 · 받은 것/받을 것) · **이번 달 일감**(막대 목록 5줄)
7. 접힌 도움 카드

받는 곳:   딜러 방
제목:      확정된 통합 디자인을 실제 딜러앱에 넣기 — d3.9 → d4.0 (화면 모양만)

1. 왜 필요한가요?
   대표님이 통합 디자인을 확정했어요(챗지피티 검수 6 · 운영/04_결정_기록.md 10/19).
   워시 v141 · 체크 v56.x · 관리 v4.8.3 은 이미 공통 부품 1.13.2 모양이라, 딜러앱만 옛 모양이에요.
   딜러가 워시 · 체크와 같은 머리말 · 숫자 칸 · 표 · 확인 창을 보게 해서 «한 회사 제품»으로 보이게 해요.

2. 무엇을 해 주면 되나요?
   · 바탕: 실제 딜러앱 d3.9 (딜러/3_딜러앱_화면_d3.9/index.html) 그대로 복사해 새 판 d4.0 을 만들어요.
     d3.9 는 지우지 않아요(되돌리기용). 바꿔치기는 대표님 확인 뒤예요.
   · 모양 기준: 미리보기 11판 «딜러앱» 화면
       - 링크(나만 보기): https://claude.ai/artifact/W69ebqbenRtErB7jge4p1Y → 맨 위 «딜러앱»
       - 같은 내용 파일: 디자인/완성_미리보기.html#dealer · 디자인/완성_미리보기_더.js 의 «═══ 딜러앱» 칸(V.d_home · d_cars · d_noti · d_bill · d_hist · d_me · carDetail · DEALER 메뉴 지도)
       - 묶음: 디자인/시안/완성_미리보기_묶음.zip
   · 공통 부품: 디자인/공통/cgg-j4-1.13.2.css · cgg-j4-1.13.2.js (보안 통과 7257e11) 를 붙여요.
     쓰는 법은 디자인/공통/README.md «1.13.2» · «1.13.1» · «1.13» 칸이에요.

   [그대로 지킬 것 — 바꾸지 않아요]
   · dealer-api 와 주고받는 모양(요청 이름 · 넘기는 값 · 받는 값), 로그인(휴대폰 번호 + 인증번호, 이용 동의), 청구서 금액 셈.
   · 상태 말 «입고 · 작업 중 · 출고 · 도착 · 상품화 완료» 와 d3.9 의 색 짝(STMAP: 입고 · 작업 중 · 출고 run / 도착 chk / 상품화 완료 done).
   · 화면 하나가 PC 와 폰을 함께 처리해요(폰 전용 화면 따로 만들지 않아요). 폰 아래 탭(홈 · 내 차 · 알림 · 청구서 · 전체) 유지.
   · 날짜는 예시 기준일(10/18)이 아니라 실제 오늘 날짜.

   [화면마다 넣을 것 — 미리보기 11판과 같게]
   ① 머리말 (CGG.header): 차곳간 CI 로고(«차» 글자 로고 아님) · «차곳간 딜러» · 이름(상사 · 가린 번호).
      사람 단추 ▾ 안: 마이페이지 · 화면 설정 · 로그아웃(확인 창 «로그아웃할까요?»).
      딜러에는 휴지통 기능이 없으니 휴지통 줄 · 숫자 배지는 넣지 않아요(F18).
   ② 홈 (CGG.home): 첫 줄 → 오늘 할 일 3줄 → 숫자 칸 4개 → «최근 내 차».
      일정 · 이번 달 입금 · 일감 카드는 빼요(cal:false · money:false · rank:false).
      «최근 내 차» 표: select:false(고르기 칸 없음, F18) · 차량번호를 누르면 차 상세(F05).
   ③ 내 차 (CGG.table): 단계 칩 «전체 · 입고 · 작업 중 · 출고 · 도착» · 찾기 «차량번호 · 차종 · 업체 검색»
      · 정렬(최근 기록순 · 차량번호순 · 금액 높은순 · 단계순, 처음은 sort 로 «최근 기록순» — F03)
      · 폰은 mobileFields(차종 · 지금 위치 · 들어간 금액 · 단계)
      · 금액 0 은 «0원», 금액 없음만 «—»(1.13.2 F06 — 공통 부품이 해요)
      · «선택한 차 상품화 완료 (N)» 단추는 고른 차가 없으면 꺼짐 → 확인 창 «차 · 대수 · 들어간 금액 합계».
   ④ 차 상세 (CGG.dialog size:"detail"): 사진 · 상품화 진행 기록(최근이 위) · 지금 위치 · 들어간 금액 · [카히스토리 조회] [상품화 완료](완료된 차는 [상품화 완료 취소]).
   ⑤ 알림 (CGG.table): 첫 칸이 «내용»(폰에서도 본문이 보이게, F01) · 본문은 현장 말(예: «12가 3456 · ○○광택 → ○○상사 도착»).
      칩은 딜러가 보는 단계대로 «전체 · 출고 · 도착 · 상품화 완료 · 청구서 · 재검사»(F02 — 숫자도 같은 기준으로 세요).
      정렬 처음은 «언제 최근 순»(sort:[언제 열,-1], F03) · 일괄 단추가 없으니 select:false(F18).
   ⑥ 청구서: 제목 «낼 금액 ○원» + 보조 글 «기한 지난 것 ○원(○곳) + 기한 전 ○원(○곳) · 다음 기한 ○/○»(F07).
      카드 한 장: 업체 · «○월 · ○대 · 청구서명» · 금액 · 기한 글(기한 지난 카드는 «기한 ○/○ · N일 지남»처럼 실제 기한 · F07) · 상태(입금 전 / 기한 지남 / 입금 확인).
      단추 [계좌 복사] [금액 복사] [내역 보기](입금 확인된 건 [내역 보기]만). 아래 «한 번에 결제는 곧 열려요» 안내 그대로.
   ⑦ 카히스토리: 지금처럼 «곧 열려요» — 충전 · 조회 단추는 누를 수 없는 모양(꺼짐)으로.
   ⑧ 내 정보: 알림 받기 4줄(입고 · 출고 / 목적지 도착 / 청구서 / 재검사).
      재검사 줄 설명은 «검사소에서 정한 유효기간이 끝나기 전에 알려 드려요»(N03 — «#{유효일수}»나 «120일» 고정 글 쓰지 않음).
      [로그아웃] · [동의 철회] 는 확인 창. 맨 아래 «차곳간 딜러 d4.0».
   ⑨ 말: «성능점검» · «받을 금액 / 낼 금액» · «메시지» · «부가세 별도» 등 정한 말(디자인/말_대조표.md). «납부할 금액» · «잔액» 같은 말은 쓰지 않아요.

3. 끝났다고 보는 기준
   · 딜러/3_딜러앱_화면_d4.0/index.html 이 있고, d3.9 는 그대로 남아 있어요.
   · 검사 일꾼(chagotgan-ui-checker) 사진 대조: 11판 «딜러앱» ↔ d4.0 을 PC 1440 · 폰 400 으로 화면마다 찍어 견줘 «올려도 됨».
   · dealer-api 주고받는 모양이 d3.9 와 같아요(보낸 요청 이름 · 값 목록을 d3.9 와 나란히 적어 보고).
   · 브라우저 기본 경고창(alert · confirm · prompt) 0 · 화면 옆으로 넘침 0(PC · 폰) · 진짜 손님 이름 · 번호가 시안 / 미리보기에 없음.
   · 되돌리는 법(d4.0 → d3.9 로 바꿔치기 되돌리기)을 보고에 한 줄로 적어요.

4. 기다리는 다른 일
   없음 (공통 1.13.2 · 확정 미리보기 11판 준비 끝). 끝나면 홈페이지 «미리 써 보기»의 딜러 체험 묶음도 d4.0 으로 바꿀 수 있어요(홈페이지 방).

# 관리 v4.0 올리는 법 (대표님용)

> 올리기는 대표님만 해요. 보안 방 검사는 통과했어요 (`보안/검사기록/2026-10-15_관리_v4.0_배포전.md`). 시험이 끝난 뒤에 올려요.

1. 이 폴더(`관리/올리기용/`)에 `관리/3_차곳간_관리_index_v4.0.html` 을 복사하고, 이름을 `index.html` 로 바꿔요.
2. 이 폴더를 통째로 Cloudflare Pages 관리 프로젝트에 올려요. 같이 있는 `_headers` 파일이 검색에 안 잡히게 하고, 다른 사이트 안에 끼워 열리지 않게 막아 줘요.
3. **주소는 손님 주소와 다르고, 짐작하기 어려운 이름으로 정해 주세요** (예: admin 같은 흔한 이름은 피하기).

- 올리지 않는 것: `관리/시안/관리_v4.0_미리보기.html` (지어낸 자료로 보는 확인용)
- 문제가 생기면: 지금 판 `관리/3_차곳간_관리_index.html` (v3.6)을 같은 방법으로 다시 올리면 바로 되돌아가요.

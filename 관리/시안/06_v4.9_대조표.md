## 2. 돈 · 세금계산서 함수 — 셈은 그대로
- 함수 본문을 하나씩 견줬어요. 돈과 관련된 함수는 아래만 바뀌었고, **금액 셈 · 보내는 값은 같아요.**

| 함수 | 바뀐 것 | 까닭 |
|---|---|---|
| paySheet | 입금 확인 단추 앞에 확인 창(누구에게 · 몇 건 · 얼마 · 받은 방법). 보내는 값 `hqPayMark([id,"paid",방법])`은 같아요. «발급» → «발행» | 요청서 ④ · ⑤ |
| refundSheet | 환불 확인 창 글을 «누구에게 · 몇 건 · 얼마» 칸으로 | 요청서 ④ |
| cgSend | 캐시 넣기 앞에 확인 창을 새로 넣고, 빼기 · 큰 금액 창 글을 칸으로. 보내는 값 `hqCashAdd` · `hqCashTake`는 같아요 | 요청서 ④ |
| taxPayDraw · taxPayOpen | «발급» → «발행», 폰 3칸 | 요청서 ③ · ⑤ |
| expDraw · expSheet · eSync · opsDraw · slDetail | 화면 글 «잔액» → «남은 금액», «VAT» → «부가세» | 요청서 ⑤ |
| viewSettle | 손으로 그리던 «달마다 보기» 표 → 공통 표, 숫자 칸 → 공통 숫자 칸. `hqSettle`의 값은 그대로 보여 줘요 | 요청서 ③ |

- 그 밖에 바뀐 함수는 모두 화면 그리기예요.
  - 표: makeTable(table49.js)
  - 홈: viewSummary
  - 머리말 · 메뉴: render · hdrFill · tbarDraw · addCrumb · jgo · laySheet
  - 표 바꿈: viewCwal · cwDraw · pplDraw
  - 말 · 확인 창: cwSheet · viewPpl · viewMe · viewShops · viewUsers · viewInvites · viewPaysOld · prDraw · slDraw · ataDraw
- 없어진 함수
  - allSheet: 폰 «전체» 판을 공통 CGG.allMenu가 맡아요.
  - prompt0: copyLink 안으로 옮겼어요.
- 로그인(hqLogin · hqLogin2 · 문자 6자리)과 세금계산서 셈(taxSupply · taxSend)은 **한 글자도 안 바뀌었어요.**

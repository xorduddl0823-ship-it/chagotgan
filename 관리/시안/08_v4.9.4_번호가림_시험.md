# 관리 v4.9.4 — 사업자번호 승인 요청의 번호 칸 시험 (2026-10-25)

문제: 서버 sb31 부터 승인 요청 목록의 사업자번호(«876-**-***09») · 요청한 사람(«****1234»)이 이미 가려져 와요.
v4.9.3 은 숫자 10자리 이상만 가린 모양으로 만들고 나머지는 «***» 라서, sb31 과 붙이면 «***»만 보였어요.
고친 법: 서버 값에 * 가 있으면 숫자 · * · - 만 남겨 그대로 보여 줘요. 전체 번호(sb29 · sb30)는 예전처럼 화면에서 가려요. 승인 · 거절은 요청번호로 하니 그대로예요.

시험 방법 (미리보기 · 지어낸 자료): 업체 › 사업자번호 승인 요청 표의 글과 [승인] 확인 창을 읽어요.
sb31 모양은 미리보기 사본에서 서버 sb31 의 bizMask · phoneTail 과 같은 셈으로 미리 가려 보냈어요.

```
고치기 전 v4.9.3 + sb31(가린 번호)      PC 1440 | 보이는 번호: *** (모두)                         | 승인 창 사업자번호: ***
v4.9.4 + sb29·sb30(전체 번호)          PC 1440 | 000-**-***01 · 010-****-1111 …              | 승인 창: 000-**-***01 | 다 보이는 번호 0 · 오류 0
v4.9.4 + sb29·sb30(전체 번호)          폰 390  | 000-**-***01 …                               | 승인 창: 000-**-***01 | 다 보이는 번호 0 · 오류 0
v4.9.4 + sb31(가린 번호)               PC 1440 | 000-**-***01 · ****1111 …                    | 승인 창: 000-**-***01 | 다 보이는 번호 0 · 오류 0
v4.9.4 + sb31(가린 번호)               폰 390  | 000-**-***01 …                               | 승인 창: 000-**-***01 | 다 보이는 번호 0 · 오류 0
```
(폰은 «요청한 사람» 칸을 원래 줄 목록에 넣지 않아요 — v4.9.2 부터 같아요.)

함수 하나씩:
```
사업자 "1234567890" → 123-**-***90 · "123-45-67890" → 123-**-***90 · "123-**-***90" → 123-**-***90 · "***" → *** · "" → - · "<b>*</b>" → *
휴대폰 "01012345678" → 010-****-5678 · "****5678" → ****5678 · "-" → - · "" → -
* 가 섞인 전체 번호(검사 일꾼 지적 뒤 고침 — 숫자가 6개 넘으면 «가린 값»으로 믿지 않고 화면에서 가려요):
휴대폰 "010-1234-5678*" → 010-****-5678 · 사업자 "123-45-67890 *" → 123-**-***90
```
- 표 단추 시험(07 문서 방식)과 모든 단추 누르기: PC 303 · 폰 141 · 안 눌림 0 · 오류 0.

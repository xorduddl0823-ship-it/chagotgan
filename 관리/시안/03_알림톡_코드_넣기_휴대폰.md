# ③-6 알림톡 코드 넣기 — 휴대폰으로 (관리 v4.7 · 10분)

> 넣을 것: **채널 ID 1개 + 템플릿 코드 13개** (13개 모두 통과, 10/16). 코드 · 채널 ID는 비밀값이 아니에요.
> 새로 통과한 5개(기간종료예정 · 이용제한시작 · 로그인제한예정 · 자료보관기한 · 잔액안내)는 코드를 넣어도 **지금은 문자로 가는 게 정상**이에요 (서버가 시험 뒤 판에서 알림톡으로 바꿔요 — 알림톡/08).
> 체크 차량도착 · 접속주소안내 · 자동결제등록 · 자동결제실패 4칸은 **비워 둬요** (아직 심사 · 등록 전).

| 단계 | 할 일 | 확인 |
|---|---|---|
| ③-6-1 | 솔라피 → 카카오 알림톡 → **템플릿 목록**에서 13개의 템플릿 ID(`KA01TP…`)를 메모장에 차례로 복사해 둬요. **카카오 채널** 화면에서 채널 ID도 복사해요 | 14줄이 모임 |
| ③-6-2 | 관리 시험 주소 → 아래 탭바 **「전체」** → **알림** → **알림톡 템플릿** | «템플릿 코드 0 / 17 넣음» 카드가 보임 |
| ③-6-3 | **카카오 채널 ID (pfId)** 칸에 채널 ID 붙여 넣기 | |
| ③-6-4 | 아래로 내리면 템플릿마다 **카드**가 하나씩 있어요. 카드의 이름을 보고 그 아래 **코드 칸**(«비어 있음»)을 눌러 코드 붙여 넣기 | 넣은 칸 옆 «보내는 방법»이 «알림톡 먼저»로 바뀜 (새 5개는 «문자로 보냄 · 서버 준비 중») |
| | 넣을 13개: 입고안내 · 출고안내 · 추가작업 · 청구서 · 입금확인 · 결제완료 · 충전완료 · 인증번호 (통과 8) / 기간종료예정 · 이용제한시작 · 로그인제한예정 · 자료보관기한 · 잔액안내 (새 5) | |
| ③-6-5 | 맨 아래 **[코드 저장]** → 확인 창 «코드 넣음 13개» → **[저장]** | «코드를 저장했어요» · 위 카드가 «13 / 17 넣음» |
| ③-6-6 | **[새로고침]** 을 눌러 코드가 그대로 남았는지 확인 | 13칸이 채워져 있음 |

- PC에서는 같은 순서로 표 안의 «템플릿 코드» 칸에 넣으면 돼요.
- 코드를 잘못 넣으면 그 안내는 알림톡이 실패하고 **문자로 대신** 나가요 (안내가 끊기지는 않아요). «알림 › 발송 기록»에서 «문자 대체»로 보여요.

## 바뀐 것
1. **메뉴 순서와 이름** (추천안 `00_비교와_추천안.md`)
   - 순서: 홈 · 계정 · 업체 · 받는 금액 · 내는 금액 · 세금계산서 · 알림 · 설정
   - 화면 이름: 업체 → 업체 관리, 계정 → 계정 관리, 결제 → 결제 내역, 보안 → 보안 점검. 「내 계정」은 그대로
   - 17개 화면은 하나도 빠지지 않았어요
2. **J안 모양**: 남색 틀, 파란 버튼, 카드 모서리 18, 버튼 높이 43, 표 줄 50, 선택 네모 20, Noto Sans KR
3. **메뉴 배치 셋**: 가로 · 세로 · 아이콘 메뉴. 사람 단추 ▾ › 화면 설정에서 골라요 (이 기기에만 저장). 처음에는 지금처럼 가로 메뉴
4. **머리말 버튼**: 공지사항 · 도움말 · 링크 복사 · 새로고침 · 사람 단추 ▾ (마이페이지 · 화면 설정 · 로그아웃)
   - 로그아웃은 머리말에서 사람 단추 안으로 옮겼어요
5. **홈 윗부분**: 말하는 제목 (예: «결제일 지난 업체 1곳, 못 받은 금액 77,000원이 남아 있어요») → 할 일 카드 3장 → 숫자 카드 4개. 달력 · 이번 달 입금 · 운영 상태 · 유지비는 아래에 그대로
   - 「오늘 할 일」 칸은 할 일 카드 3장으로 바뀌었고, 나머지는 제목 옆 「모두 보기」로 봐요
6. **모든 화면 머리**: «묶음 › 화면 이름»을 제목 위에 붙임
7. **폰 (600px 이하)**: 남색 윗줄 48 + 아래 탭바 56 (홈 · 업체 · 받는 금액 · 계산서 · 전체). 「전체」를 누르면 17개 화면이 다 나와요
8. **말 바꾸기**: 「돈」 → 「금액」 (예: 이번 달 번 돈 → 이번 달 들어온 금액, 못 받은 돈 → 못 받은 금액), 수금 → 입금, 표에서 찾기 → 검색
9. **상태 이름** (규칙 4-5): 쓰는 중 → 진행 중, 멈춤 · 정지 → 보류

## 일부러 안 한 것 (이유)
- **30초마다 자동 새로고침**: 관리 화면에는 원래 없는 기능이에요. 업체 정보를 고치는 중에 화면이 다시 그려지면 적던 내용이 날아갈 수 있어서 넣지 않았어요
- **사람 단추 안 요금제 · 휴지통**: 본사 계정에는 요금제와 휴지통이 없어요
- **숫자 카드의 «지난주보다»와 작은 그래프**: 서버에 지난주 값이 없어서 지어내지 않았어요. 대신 지금 상태 한 줄을 넣었어요 (예: 진행 중 3곳 · 보류 1곳)
- **폰에서 표 → 목록 바꾸기**: 화면이 17개라 이번에는 표를 그대로 두고, 표 안에서만 옆으로 밀리게 했어요 (페이지 전체가 넘치는 곳은 0개)

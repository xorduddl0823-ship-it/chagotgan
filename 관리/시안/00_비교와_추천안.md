# 관리 J안 — 두 파일 비교와 관리 방 추천안

> 작성: 관리 방 (2026-10-14). 메뉴 묶음 순서 · 화면 이름은 **다음 주 시험 끝나고 대표님이 정해요.** 아래는 추천만이에요.
> 실제 관리 화면(`관리/3_차곳간_관리_index.html`)은 아직 아무것도 바꾸지 않았어요.

## 1. 두 파일 비교

| | `관리_J안_인수인계방.html` (인수인계 방) | `관리_J안_시안.html` (관리 방) |
|---|---|---|
| 만든 방법 | 디자인 J안 4판 원본에서 4줄만 바꿈 (제목 · 처음 열 때 관리부터) | 같은 J안 원본을 복사하고 `만들기_관리_J안_시안.py`로 관리만 남김 |
| 관리 화면 내용 (메뉴 · 표 · 숫자 카드 · 할 일 · 창 · 폰) | J안 원본과 **똑같음** | J안 원본과 **똑같음** |
| 워시 | 들어 있음 (위 「제품」 단추로 바꿔 볼 수 있음) | 뺌 |
| 업체 이름 · 사업자번호 · 대표 | J안 원본의 실제 값 그대로 | 지어낸 값으로 바꿈 (기준서 6-3) |
| 아래 설명 | J안 원본 설명 그대로 (워시 · 관리 같이) | 관리 메뉴 대조표 (지금 화면 → J안) |

**결론:** 관리 화면 부분은 두 파일이 같아요. 다른 점은 겉포장뿐이에요.
실제 반영할 때는 관리 방 판(`관리_J안_시안.html`)을 기준으로 쓰는 것을 추천해요.
- 기준서 6장의 규칙을 지켜요. 관리만 남겼고, 지어낸 값을 썼고, 대조표가 붙어 있어요.
- 디자인 J안이 바뀌면 만들기 도구로 바로 다시 만들 수 있어요.

인수인계 방 판은 워시와 나란히 비교해 볼 때 쓰도록 그대로 둬요.

## 2. 메뉴 묶음 순서 — 추천: J안 차례 그대로 (「계정」이 2번째)

홈 · **계정 · 업체** · 받는 금액 · 내는 금액 · 세금계산서 · 알림 · 설정

- 규칙 3-4: 메뉴 차례는 **지금 쓰는 차례 그대로**예요. 지금 쓰는 관제센터는 「가입 코드 · 계정」이 「업체」보다 앞에 있어요.
- 처음 만든 8묶음 시안(업체가 2번째)은 이 규칙을 놓쳤어요. 그래서 J안 차례를 추천해요.
- 다른 안: 본사가 가장 자주 여는 화면이 「업체 관리」라서 업체를 2번째로 올릴 수도 있어요. 다만 이렇게 하면 규칙 3-4의 예외가 되니 대표님 결정이 필요해요.

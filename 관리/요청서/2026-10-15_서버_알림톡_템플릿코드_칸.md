1. 왜 필요한가요?
   안내를 알림톡 먼저 보내려면 템플릿 코드를 관리 화면에서 넣고 바꿀 수 있어야 해요. 코드가 비면 지금처럼 문자로 보내요.

2. 무엇을 해 주면 되나요? (관리 v4.1 시안이 이 이름으로 부르고 있어요 — 다른 이름이 좋으면 알려 주세요, 화면을 맞출게요)
   - 저장 칸: `wash_hq.ata_tpls` (jsonb) = { 키: 템플릿 코드 } — 비밀값 아님 (설계 09 「통과 뒤 서버 할 일」과 같은 자리)
   - 키 13개: auth 인증번호 · cash_done 충전완료 · pay_done 결제완료 · deposit_ok 입금확인 · bill 청구서 · extra_work 추가작업 · release 출고안내 · etc8 (8번째 통과 템플릿 — 이름 알려 주세요) · balance 잔액안내 · data_keep 자료보관기한 · login_block 로그인제한예정 · use_limit 이용제한시작 · expire_soon 기간종료예정
   - 읽기 `hqAta([ym])` → { ok, pfSet: PF_ID 가 있는지(참/거짓, 값은 보내지 않음), tpls: {키:코드}, stats: { ym, ata:{cnt,won}, sms:{cnt,won}, lms:{cnt,won}, mms:{cnt,won} } }
     - stats 는 `wash_sendlog` 에서 그 달(ym, "2026-09" 꼴) 성공 건(ok=true)을 method 별로 센 값. won = 건수 × 솔라피 단가(13 · 18 · 45 · 110원, 부가세 별도)
   - 저장 `hqAtaSave([{키:코드}])` → { ok } — 13개 키만 받고, 빈 값은 지움. `hqOnly` 로 본사만
   - 보낼 때: 코드가 있으면 `kakaoOptions { pfId: PF_ID, templateId: 코드, variables, disableSms: false }`, 없으면 지금처럼 문자

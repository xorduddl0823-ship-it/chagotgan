# 인수인계 요청문

일반 채팅방에서 만든 작업을 이 서랍장으로 옮기기 위한 글입니다.

## 사용법
1. 각 일반 채팅방에 들어가 **「공통 요청문」** 을 붙여 넣습니다.
2. 바로 아래에 그 방의 **「추가 질문」** 도 함께 붙여 넣습니다.
3. 그 방이 만들어 준 인수인계서와 첨부 파일을 내려받습니다.
4. `이사/02_이사_체크리스트.md`를 보고 알맞은 서랍에 넣습니다.

> 순서는 디자인 → 워시 → 체크 → 관리 → 딜러 → 홈페이지 순서를 권합니다.

---

## 공통 요청문 (모든 방에 붙여 넣기)

```
이 방에서 만든 작업을 다른 작업방으로 넘기려고 해.
아래 형식으로 인수인계서를 만들어줘. 쉬운 말로 써줘.

1. 이 방에서 만든 제품/기능 이름
2. 최종 파일 목록 (파일 이름, 버전, 마지막으로 고친 날짜, 지금 실제로 배포된 것인지)
3. 내가 정한 규칙과 결정 사항 (내가 한 말 그대로 옮겨줘)
4. 끝내지 못한 일, 알려진 문제
5. 다른 제품(워시·체크·딜러·관리·서버·홈페이지)과 연결되는 부분
6. 서버(수파베이스) 코드나 표 만드는 글(SQL)을 이 방에서 만들었다면 그 목록
7. 비밀 열쇠(API 키 등)는 값을 절대 적지 말고 "이름만" 적어줘

마지막으로 최종 파일들을 내려받을 수 있게 다시 첨부해줘.
파일 안에 비밀 열쇠 값이 들어 있으면 그 줄은 지우고 첨부해줘.
```

## 방별 추가 질문

### 「[작업중] 차곳간 UI 통합 관리」 → 디자인 서랍
```
추가로 알려줘.
- 지금 기준틀은 몇 판(버전)이고, Claude Code 방의 「차곳간 UI 기준틀 v1.1」, 「합친 디자인 J 4판」과 어떤 점이 다른지
- 이 방에서만 정하고 Claude Code 방에는 아직 전달 안 된 결정이 있는지
```

### 「[작업중] 차곳간워시 정산 개발중_2」 → 워시 서랍
```
추가로 알려줘.
- 지금 최신 워시 파일의 APP_VER 값
- 아직 구글 시트/구글 스크립트를 쓰는 기능 목록
- wash-api(수파베이스 서버) 코드를 이 방에서 고쳤는지, 고쳤다면 최신본
- 정산 기능 중 끝나지 않은 것
```

### 「[작업중] 차곳간체크(가온정산도구)」 → 체크 서랍
```
추가로 알려줘.
- 지금 최신 체크 파일 버전과 check-api 서버 코드 최신 버전
- "가온"이라는 특정 업체에만 맞춘 기능이나 문구가 있는지 (다른 업체가 써도 되는지)
- 설정에 남은 「수집함 연결 — 구글 Apps Script」 카드를 지워도 되는지
```

### 「[작업중] 관제센터」 → 관리 서랍
```
추가로 알려줘.
- 관리 화면의 메뉴 전체 목록과 각 메뉴가 하는 일
- 서버(wash-api)에서 관리 전용으로 쓰는 창구(hq로 시작하는 것) 목록
- 결제·계정 권한·API 연결 관리 기능 중 끝난 것과 안 끝난 것
- 이름을 「관제센터」에서 「관리」로 바꿀 때 주의할 곳
```

### 「[작업중] 차곳간 딜러앱」 → 딜러 서랍
```
추가로 알려줘.
- 딜러 화면을 PC용과 앱(폰)용으로 따로 만들었는지, 아니면 한 파일인지
- dealer-api(수파베이스 서버) 코드 최신본
- 딜러가 다루는 개인정보 항목(이름, 전화번호, 주민번호 등) 목록
- 딜러 계정이 워시·체크 계정과 같은 로그인을 쓰는지
```

### 「[예약] 딜러앱 개인정보 및 차량 매칭」 → 딜러 서랍
```
추가로 알려줘.
- "예약"은 무엇을 예약해 둔 것인지 (언제, 무엇을 하기로 했는지)
- 계획한 개인정보 처리 방식과 차량 매칭 방식
- 아직 만들기 전이라면 지금까지 정한 설계만 정리해줘
```

### 「[작업중] 차곳간 홈페이지 시안」 + 「[작업중] 앱 및 홈페이지 작업」 → 홈페이지 서랍
```
추가로 알려줘.
- 이 방과 다른 홈페이지 방의 작업이 겹치는지, 다른지
- 앱은 어떤 방식으로 만들려고 했는지 (홈 화면 추가형 / 스토어 등록형)
- 홈페이지 주소와 배포 위치
```

차곳간을 여러 작업방(직원)이 나눠 만들고, 대표 한 명이 관리할 수 있게 만든 설명서와 양식 모음입니다.
이 폴더 하나가 앞으로 **공용 서랍장**이 됩니다.

> 이 저장소(`chagotgan`, 비공개)가 차곳간의 공용 서랍장입니다.

---

## 한 줄 요약

**입구는 하나, 방은 따로, 사장실(관리)은 별채, 열쇠는 금고, 화면은 하나로 PC·폰·앱 모두.**

## 서랍장 구조

```
chagotgan (저장소 맨 위)/
├─ CLAUDE.md        ← 모든 작업방이 자동으로 먼저 읽는 공통 규칙 요약
├─ 규칙/            ← 총괄 방만 고침 (규칙 장부, 방 구성표)
├─ 운영/            ← 총괄 방만 고침 (요청서·검사표·결정 기록)
├─ 이사/            ← 이사 기간에만 씀
├─ 방/              ← 작업방 시작 안내문 (총괄 방만 고침)
├─ 디자인/          ← 디자인 방
├─ 서버/            ← 서버 방
├─ 보안/            ← 보안 방 (검사 기록만 남김)
├─ 관리/            ← 관리 방
├─ 워시/            ← 워시 방
├─ 체크/            ← 체크 방
├─ 딜러/            ← 딜러 방
└─ 홈페이지/        ← 홈페이지·앱 방
```
